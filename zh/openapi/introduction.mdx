Open API 用于通过 HTTP 接口主动调用 Flashduty，查询和管理故障、协作空间、值班表等实体数据。使用 API 与您登录 [Flashduty 控制台](https://console.flashcat.cloud) 后进行页面操作本质上是相同的。

<Tip>
**不确定是否需要 Open API？** Flashduty 提供多种数据交互方式：

- **Open API**（本文档）— 您主动调用 Flashduty，查询或操作数据。查看 [API 总览](/zh/openapi/api-catalog) 了解全部接口。
- **标准告警事件** — 将自研监控系统的告警推送到 Flashduty，触发故障处理流程。详见[自定义告警事件](/zh/on-call/integration/alert-integration/alert-sources/standard-alert)。
- **自定义变更事件** — 推送变更事件关联故障，辅助根因分析。详见[自定义变更事件](/zh/on-call/integration/change-integration/custom-event)。
- **Webhook 推送** — Flashduty 主动向您的系统推送故障/告警事件通知。详见[故障 Webhook](/zh/on-call/integration/webhooks/incident-webhook) 和[告警 Webhook](/zh/on-call/integration/webhooks/alert-webhook)。
- **自定义操作** — 在故障详情页触发外部操作。详见[自定义操作](/zh/on-call/integration/webhooks/custom-actions)。
</Tip>

## 请求规范

### 请求地址

所有 API 只接受 **HTTPS** 访问，且只有一个 Endpoint：

```
https://api.flashcat.cloud
```

### 请求方法与 Headers

绝大多数接口使用 `POST` 方法、JSON 请求体，请设置：

```
Content-Type: application/json
```

少数读接口使用 `GET` 方法和 query 参数（例如状态页的查询接口、Prometheus 兼容的标签查询），以各接口页面标注的方法为准。不需要参数的 `POST` 接口请传 `{}`。

### 字符编码

请求与响应均使用 **UTF-8** 编码。

### 响应语言

错误信息会按语言返回。语言依次取自 query 参数 `locale`、query 参数 `lang`、请求头 `Accept-Language`，例如 `Accept-Language: zh-CN` 或 `en-US`。字段名、枚举值和错误码不会被翻译。

## 认证方式

所有 Open API 使用 **APP Key** 进行鉴权。

### 获取 APP Key

<Steps>
  <Step title="登录控制台">
    登录 [Flashduty 控制台](https://console.flashcat.cloud)
  </Step>
  <Step title="创建 APP Key">
    将鼠标悬停在左下角头像上，在 **个人中心** 一列选择 **APP Key**，输入名称并选择权限范围后，点击添加按钮完成创建。详见[个人设置](/zh/on-call/configuration/personal-settings#app-key)。

    - **全部权限**：不额外限制接口范围，但仍受创建者当前角色权限约束。
    - **自定义权限**：从可选 API 权限点中至少选择一项；该 APP Key 只能调用选中的接口范围。
  </Step>
</Steps>

<Warning>
APP Key 的实际可访问范围同时受其权限范围和创建者当前角色权限限制。创建成功后请立即妥善保存完整密钥；离开创建页面后无法再次查看。不要把 APP Key 硬编码在客户端代码里，请通过环境变量或密钥管理服务注入，并及时删除不再使用的密钥。
</Warning>

您可以在 APP Key 列表中编辑已有密钥的名称和权限范围。

### APP Key 泄露了怎么办

如果 APP Key 可能已泄露（例如被提交到公开代码仓库，或出现在日志、截图中），请按以下步骤处置：

<Steps>
  <Step title="创建替代密钥">
    在 **个人中心 → APP Key** 中创建一个新的 APP Key。
  </Step>
  <Step title="切换集成">
    把使用旧密钥的集成、脚本和配置切换到新密钥，并确认调用正常。
  </Step>
  <Step title="禁用或删除旧密钥">
    在 APP Key 列表中禁用或删除旧密钥。之后使用旧密钥的请求返回 `401 Unauthorized`。
  </Step>
</Steps>

### 传递 APP Key

通过 query 参数 `app_key` 传入：

```bash
curl -X POST 'https://api.flashcat.cloud/incident/list?app_key=YOUR_APP_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"start_time": 1712000000, "end_time": 1712086400, "limit": 20}'
```

也可以放在请求头 `Fd-App-Key` 中，避免密钥出现在 URL 和访问日志里：

```bash
curl -X POST 'https://api.flashcat.cloud/incident/list' \
  -H 'Fd-App-Key: YOUR_APP_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"start_time": 1712000000, "end_time": 1712086400, "limit": 20}'
```

两者同时存在时以 query 参数为准。缺少或无效的 APP Key 返回 `401 Unauthorized`。

<Note>
使用 Go？推荐用官方 [Go SDK](/zh/developer/go-sdk) 调用 Flashduty，直接获得类型化的请求参数、响应结构和错误码，无需手写 HTTP 请求。
</Note>

## 响应结构

所有响应均为 JSON，遵循统一结构：

| 字段 | 类型 | 必定返回 | 描述 |
| --- | --- | :---: | --- |
| `request_id` | string | ✅ | 请求 ID，同时通过响应头 `Flashcat-Request-Id` 返回。联系技术支持时请提供。 |
| `data` | any | | 接口返回的数据，格式见各接口页面。没有返回数据的接口会返回 `{}` 或完全不带 `data`，请不要依赖该字段一定存在。出错时不返回。 |
| `error` | object | | 仅在请求失败时返回。 |

成功时 HTTP 状态码为 `200`。失败时返回[错误码列表](/zh/openapi/rate-limits#错误码)中对应的 HTTP 状态码，但请以 `error.code` 而不是状态码做判断。

### 响应示例

<Tabs>
  <Tab title="成功响应">
```json
{
  "request_id": "01HK8XQE3Z7JM2NTFQ5YJ8P9R4",
  "data": {
    "team_id": 1467226103121,
    "team_name": "SRE"
  }
}
```
  </Tab>
  <Tab title="错误响应">
```json
{
  "request_id": "01HK8XQE3Z7JM2NTFQ5YJ8P9R4",
  "error": {
    "code": "InvalidParameter",
    "message": "The specified parameter team_name is not valid."
  }
}
```
  </Tab>
</Tabs>

### Error 对象结构

| 字段 | 类型 | 必定返回 | 描述 |
| --- | --- | :---: | --- |
| `code` | string | ✅ | 稳定的错误码，见[错误码列表](/zh/openapi/rate-limits#错误码) |
| `message` | string | ✅ | 按响应语言返回的错误描述，可能包含出错的字段名。请不要解析它。 |

## 数据约定

- **时间戳**均为 Unix 时间戳整数。大多数以**秒**为单位；部分（AI SRE 和 RUM 的大多数时间字段、故障动态、审计日志）以**毫秒**为单位。每个时间字段的描述都会写明单位。
- **枚举**区分大小写，可能是字符串或整数；每个字段都会列出可选值及含义。
- **ID** 按各字段标注的类型（整数或字符串）返回，回传时请保持相同类型。
- **列表**均分页返回，见[关于分页](/zh/openapi/pagination)。
- **更新接口**会逐字段说明：不传某字段时是保留原值还是清空。
