## 概述

---

AI SRE 开箱即用，但它**有多懂你的系统、排障有多准，取决于你为它装配了多少扩展资源**——尤其是[知识库](/zh/ai-sre/knowledge)。你在控制台里为 Agent 沉淀团队知识、封装可复用的排障流程、接入外部工具、指定运行位置，它在诊断故障时便会按需调用这些资源。**这些维护得越完整、越准确，AI SRE 就越精准、越好用。**

所有扩展资源集中在三大控制台入口（对应 AI SRE 左侧菜单）：

- **插件（Plugins）** —— 下设三个标签页：**Skill**、**Agents**（A2A 远端 Agent）、**MCP**（外部工具），为 Agent 扩展可执行的能力与可委派的对象。
- **知识库（Knowledges）** —— 以 Knowledge Pack 形式沉淀 DUTY.md、runbook 等运维知识，供 Agent 在会话中检索。**这是影响诊断质量的关键资源。**
- **环境（Environments）** —— 管理你自托管的运行环境（BYOC Runner）；Agent 的工具调用、MCP 连接与 Skill 执行都在所选环境中完成。

<Tip>
不知道从哪儿开始？在任意会话里输入 [`/init`](/zh/ai-sre/init)，Agent 会以访谈的方式带你从零把知识库搭起来；之后用 [`/insight`](/zh/ai-sre/insight) 复盘，持续发现还该补什么。
</Tip>

<Note>
菜单中是否显示某一入口，取决于你在该账户下是否拥有对应的访问权限。无权限的入口不会出现在导航中。
</Note>

## 作用域：账户与团队

---

每一类扩展资源（Skill、知识库、MCP、Agent、运行环境）都归属于一个**作用域**：

- **账户级** —— 在整个账户内可见、可用。
- **团队级** —— 仅对该团队的成员可见。

创建资源时在「账户或团队…」选择器里指定；列表的「范围」列会显示该行属于「账户」还是某个具体团队。

| 资源类型 | 控制台入口 | 账户级 | 团队级 |
|---|---|---|---|
| Skill | 插件 → Skill | 账户内所有会话可见、可加载 | 仅该团队成员可见，仅在该团队会话中加载 |
| MCP | 插件 → MCP | 账户内所有会话可调用 | 仅该团队成员可见、可编辑 |
| Agent | 插件 → Agents | 账户内可见，可被 AI SRE 委派 | 仅该团队成员可见、可编辑 |
| 知识库 Knowledge Pack | 知识库 | 对账户内所有会话可见 | 仅在该团队的会话中加载 |
| 运行环境 Environment | 环境 | 账户内所有会话可选用 | 仅该团队成员可见、可编辑 |

当某资源不属于你所在的团队时，列表会以「只读（其他团队）」标识——你可以查看，但无法编辑。

**编辑权限**：账户所有者或账户管理员可编辑账户内任意资源；团队成员可编辑本团队的团队级资源（无「创建者保留权限」例外）。各资源的具体说明见对应专页。

<Note>
绑定了团队的会话会自动加载该团队的知识、Skill 与 MCP，账户级资源则对所有会话始终可用。跨团队联合排障时，Agent 也能在需要时读取并加载其它团队的知识——账户是唯一的安全边界，跨账户的资源在任何情况下都不可见。
</Note>
