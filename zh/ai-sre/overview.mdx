## 什么是 AI SRE

AI SRE 是 Flashduty 推出的自治 SRE Agent 平台。您通过对话向 AI 下达指令，由它自主调查故障、排查根因、调用工具执行诊断，并把每次排障中沉淀的运维知识固化下来供后续复用。

它不是一个只会问答的聊天机器人，而是一个**能动手的排障工作者**：会自己规划步骤、读写文件、查询监控与日志、执行命令、调用外部工具（MCP），并在需要时把子任务委派出去，最终给出有调查过程支撑的结论。

AI SRE 与 Flashduty 的故障响应体系深度联动：当 Flashduty 产生故障（incident）或开启作战室协作时，可直接触发一个 AI SRE 会话，让 Agent 带着故障上下文进入排查现场——既可以在控制台里对话，也可以**直接在您的 IM 群（Slack / 飞书 / 钉钉 / 企业微信）里 @ 它**。

## 典型场景

AI SRE 不止是控制台里的一个对话框——它围绕「故障从触发到复盘」的完整生命周期，覆盖多个协作入口：

<CardGroup cols={2}>
<Card title="对话式排障" icon="comments">
  在控制台的对话工作区里主动提问：某个服务为何异常、一条告警的根因、一次变更的影响范围。Agent 流式输出规划、工具调用与中间发现，最终给出结论。
</Card>
<Card title="IM 内随手召唤" icon="comment-dots">
  无需切换工具——在 Slack、飞书、钉钉、企业微信的群聊或私聊里 **@ AI SRE** 即可发起或续接一次排查，它在**线程内**回答，团队成员全程可见。详见 [IM 集成](/zh/ai-sre/im)。
</Card>
<Card title="作战室自动诊断" icon="people-group">
  为故障开启 IM 作战室时，AI SRE **自动跑一轮初步诊断**并把结论回贴到作战室——人还没开始排查，第一手分析就已经在群里了。
</Card>
<Card title="运营复盘洞察" icon="gauge-high">

## 开通与计费

AI SRE 面向持有<strong>有效（已启用）</strong>On-call 专业版及以上订阅的账户开放，无需申请。

<AccordionGroup>
<Accordion title="计费规则" icon="gift">
  AI SRE 自 2026 年 9 月 16 日 8 点（北京时间）起按实际用量计费，以 credits 结算，1 credit = ¥1；此前的用量不收费。计量项为模型用量、沙箱在线时长和联网检索。开通免费，符合条件的账户每个计费周期赠送体验额度，也可以购买资源包（1,000 / 5,000 / 20,000 credits，对应 ¥950 / ¥4,500 / ¥17,000，自支付起 365 天有效）。按量付费默认关闭，由管理员开启，可设置每周期上限。完整规则见[《AI SRE credits 资源包购买协议》](/zh/compliance/ai-sre-credit-package-purchase-agreement)。

  体验额度、资源包与钱包余额都用尽时，AI SRE 会暂停新的对话，并在输入区上方提示原因和 **前往 AI SRE 计费** 入口。管理员可以在那里开启按量付费、购买资源包或充值，之后即可继续对话。
</Accordion>
<Accordion title="人工授权" icon="user-check">
  生产变更、重启、回滚和外部通知，最终都由您确认后才会执行。
</Accordion>

### 开通与关闭 AI SRE

在控制台进入 **费用中心 → 订阅**，选择 **AI SRE** 页签，即可自助开通或关闭。此功能仅 SaaS 版提供，需要**费用查看**和钱包交易权限。

| 操作 | 费用 | 结果 |
|------|------|------|
| **开通 AI SRE** | 免费 | 开通后即可使用 |
| **关闭 AI SRE** | 不扣款，也不退款 | 关闭后本账户不能再发起新的调查；已在进行中的运行不会中断，其用量照常计量 |

关闭后：

- 体验额度和已购资源包的余额、有效期都**保留**，重新开通后继续可用（体验额度仍只在发放的计费周期内有效）。
- 资源包退款按[《AI SRE credits 资源包购买协议》](/zh/compliance/ai-sre-credit-package-purchase-agreement)处理。
- 欠费或订阅已失效时也可以关闭。
- 如果关闭失败，直接重试即可。

### 订阅失效与恢复

AI SRE 需要**有效的** On-call 专业版及以上订阅。订阅不满足条件时，AI SRE 会立即暂停，控制台、IM、自动化和 A2A 调用都会收到提示：

| 情形 | 处理方式 |
|------|----------|
| 专业版及以上订阅已过期或被停用 | 续费 On-call 订阅 |
| 没有订阅，或订阅低于专业版 | 升级到专业版及以上 |

这时控制台提示旁的按钮是 **前往 On-Call 订阅**（其他原因则是 **前往 AI SRE 计费**）。续费或升级后，AI SRE 自动恢复，无需重新开通。

## 核心能力

AI SRE 围绕"对话排障 + 知识沉淀 + 自主执行"构建了一套完整能力，每一项都可在控制台中配置和管理。

<CardGroup cols={2}>
<Card title="对话式排障" icon="comments" href="/zh/ai-sre/sessions">
  以会话为单位与 Agent 协作。会话按顺序处理您的每条消息，支持流式输出、随时取消、长对话自动压缩上下文，以及从故障一键拉起。
</Card>
<Card title="IM 平台" icon="comment-dots" href="/zh/ai-sre/im">
  在 Slack / 飞书 / 钉钉 / 企业微信中 @ Agent 发起或续接排查，并在故障作战室里自动给出初步诊断。
</Card>
<Card title="Skill" icon="wrench" href="/zh/ai-sre/skills">
  可被 Agent 调用的 Skill 包，封装可复用的排障流程。范围可设为共享（即账户级）或团队，启用后在会话中按需加载。
</Card>
<Card title="管理知识" icon="book" href="/zh/ai-sre/knowledge">
  以 DUTY.md 为入口、按 @-引用索引的知识，承载服务清单、runbook、值班路径等长期上下文，按账户/团队分层加载。
</Card>
<Card title="MCP（外部工具）" icon="plug" href="/zh/ai-sre/mcp">
  通过 Model Context Protocol 接入外部工具与数据源。MCP 服务器不预连接，Agent 在调用时按需建连、执行、断连。
</Card>
<Card title="Agent" icon="satellite-dish" href="/zh/ai-sre/agents">
  通过标准 A2A 协议把任务委派给外部远端 Agent；AI SRE 自身也对外暴露 Agent Card，供外部客户端反向调用。
</Card>
<Card title="BYOC" icon="server" href="/zh/ai-sre/environments">
  Agent 的执行面：默认使用 Flashduty 托管的云端沙箱；也可在自己机器上部署常驻 Runner，让排障进入您的内网。
</Card>
<Card title="使用洞察" icon="gauge-high" href="/zh/ai-sre/insight">
  通过 /insight 复盘最近 30 天的 AI SRE 会话，输出量化概览、工作叙述与可复制的运维改进建议（只读，不自动落地）。
</Card>
<Card title="自动化" icon="robot" href="/zh/ai-sre/automations">
  让 AI SRE 按周期、API 调用或 On-call 故障事件触发执行隐藏会话，自动产出巡检、洞察或复盘结果。
</Card>
<Card title="Apps" icon="grid-2" href="/zh/ai-sre/apps">
  授权外部应用（目前为 GitHub），让 AI SRE 直接进入您的代码仓库工作：理解代码、调查 PR 与提交、按需开 PR 或提 Issue。
</Card>
</CardGroup>

## 控制台导航

进入 AI SRE 后，左侧导航有四个入口（菜单名与控制台一致）：

| 入口 | 作用 |
|------|------|
| 新对话 | 与 Agent 协作排障的主工作区。侧边栏列出会话（支持搜索、筛选、置顶、归档），右侧为对话与调查过程。详见[控制台对话](/zh/ai-sre/sessions)。 |
| 自动化 | 按周期、API 调用或 On-call 故障事件触发的后台任务。详见[自动化](/zh/ai-sre/automations)。 |
| 产物 | 查看和管理 Agent 通过 present_files 工具发布的文件与报告：支持搜索、按个人 / 团队筛选；每个产物可复制链接、下载、重命名或删除（重命名与删除需编辑权限）。详见[产物](/zh/ai-sre/artifacts)。 |
| 自定义 | 打开二级侧栏，管理 Agent 用到的资料、扩展和执行环境，分三组（见下表）。点击后默认进入 **插件 → 概览**。 |

**自定义** 下的三组：

| 分组 | 页面 | 作用 |
|------|------|------|
| 上下文 | 知识、记忆 | [知识](/zh/ai-sre/knowledge)：整个账户 1 份共享知识，每个团队最多 1 份团队知识。[记忆](/zh/ai-sre/memory)：AI 在对话里记下的偏好、做法、事实和教训，分个人和团队。 |
| 插件 | 概览、Apps、Skill、MCP、Agents | **概览** 是插件目录（MCP 模板、Skill 模板、内置 App）；[Apps](/zh/ai-sre/apps)（已授权的外部应用，如 GitHub）、[Skill](/zh/ai-sre/skills)、[MCP](/zh/ai-sre/mcp)（外部工具）、[Agents](/zh/ai-sre/agents)（A2A 远端 Agent）。 |
| 环境 | 自托管、云端 | [自托管](/zh/ai-sre/environments)：部署在您机器上的常驻 Runner；**云端**：Flashduty 托管的云端沙箱模板。无可用自托管环境时，会话回退到云端沙箱。 |

<Note>
各区域的可见性由您在该账户下的访问权限决定：没有对应权限的菜单或子标签不会在导航中展示。
</Note>
