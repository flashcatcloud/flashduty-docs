## 上下文是什么

上下文是 AI SRE 在一次排障里能反复用到的长期资料。它分成两种，在控制台 **AI SRE → 自定义** 侧栏的 **上下文** 分组下各有一页。

- [**知识**](/zh/ai-sre/knowledge)是人维护的。它写的是这个环境怎么运转：一份使用说明 `DUTY.md`，加上运行手册、服务清单等文件。会话开始时会读使用说明，其它文件在需要时再打开。入口：**AI SRE → 自定义 → 上下文 → 知识**。
- [**记忆**](/zh/ai-sre/memory)是系统整理的。会话结束后，系统从对话里留下以后还会用到的偏好、做法、事实和教训。您也可以在对话里直接说记住或忘掉一件事。入口：**AI SRE → 自定义 → 上下文 → 记忆**。

两页底部都有一个输入框：写下要改什么，控制台会打开新对话，由 AI 先说明改动、经您同意后保存。

## 三个范围

两类资料都按范围组织，但支持的范围不同。

| 范围 | 记忆 | 知识 |
| --- | --- | --- |
| 个人 | 您自己的 | 没有 |
| 团队 | 这个团队的 | 这个团队的那一份（每个团队最多 1 个） |
| 共享 | 没有 | 整个账户的那一份 |

个人范围没有知识。共享范围没有记忆。

## 作用域与权限

自定义下的所有资源（Skill、知识、MCP、Agent、运行环境）使用同一套两级作用域：**共享范围**（账户级）和**团队范围**。账户是安全边界，团队只用来标记归属和编辑权限。

| 动作 | 规则 |
| --- | --- |
| 使用 | 账户内任何成员都可以在会话里使用账户下的资源。 |
| 创建 | 创建到团队，需要是该团队的成员，账户 Owner 和管理员也一样。创建到共享范围，仅限账户 Owner 或管理员。 |
| 编辑、删除 | 团队资源仅该团队成员可操作，账户 Owner 和管理员需要先加入该团队。共享资源仅限账户 Owner 或管理员。创建者没有额外权限。 |
| 改归属 | 账户 Owner 或管理员可以把资源改到任意团队，普通成员只能改到自己所属的团队。设为共享，仅限账户 Owner 或管理员。 |
| 会话中加载 | 绑定了团队的会话只加载共享资源和该团队的资源，账户 Owner 和管理员也一样。个人会话加载共享资源和会话创建者所属团队的资源。 |
| 列表 | 管理页显示共享资源和您所在团队的资源。 |

需要跨团队联合排障时，请对方团队把相关资源设为共享。
