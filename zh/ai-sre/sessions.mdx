> AI SRE 需在控制台开通，面向 On-call 专业版及以上订阅，按实际用量计费，详见[开通与计费](/zh/ai-sre/overview#开通与计费)。

## 概述

会话（Session）是您与 AI SRE 的一次完整对话。它承载您发送的每一条消息、Agent 的流式回复、过程中的工具调用，以及 Agent 产出的产物（Artifacts，例如代码、报告、图表或 Skill 压缩包）。

每个会话相互隔离，拥有自己的上下文、绑定团队与运行环境。您在左侧边栏切换会话，在中间的对话区收发消息、查看回复与产物。切换会话不会中断正在运行的回合，返回时可以继续看到流式输出。

## 新建与管理会话

在左侧边栏点击 **新对话** 开启新会话。列表按最近活动排序，点击 **显示更多** 查看更早的会话。

新会话的输入框上方有四张场景建议卡片：**排查一个故障**、**用自然语言查数据**、**治理告警噪音**和**定时自动巡检**。点击卡片会把提示填入输入框，修改后再发送。

### 搜索与筛选

顶部搜索框按会话名称搜索。点击列表右上角的 **筛选** 图标可以按以下维度组合筛选（有筛选生效时图标上会显示小圆点）：

| 维度 | 可选值 |
|---|---|
| 范围 | 全部 / 个人 / 团队（团队可选 **我的团队** 或指定您所属的团队） |
| 发起人 | 全部 / 我发起的 / 指定成员（范围为个人时不显示） |
| 状态 | 活跃（默认）/ 归档 / 全部 |
| 最近活动 | 全部 / 24 小时 / 7 天 / 30 天 |

### 会话可见性与操作权限

会话不能跨账户访问。在同一账户内：

| 会话类型 | 可读取 / 继续对话 | 可重命名、归档、删除或关联故障 |
|---|---|---|
| 个人会话（未绑定团队） | 仅创建者本人 | 仅创建者本人 |
| 团队会话（绑定团队） | 同账户内拿到会话链接的成员 | 会话创建者、账户 Owner / 管理员、或该团队成员 |

置顶只影响您自己的列表。账户 Owner / 管理员可以管理团队会话，但不能读取其他成员的个人会话。

### 分享会话

对会话有管理权限时，可以点击聊天页头部的 **复制分享链接**。

- 只有登录了**同一账户**的成员能打开链接，不支持匿名访问。分享开启期间，链接保持不变。
- 打开链接的人以**只读**方式查看完整会话（包括子任务的执行详情），不能继续对话；可以点击 **Fork 为新会话** 在自己的新会话中继续排查。
- 点击 **取消分享** 后链接立即失效；再次分享会生成新链接。
- 个人会话默认只有创建者可见，分享链接是让同账户其他成员查看它的方式。

<Note>
隐身会话不能分享。分享只能在根会话上开启，不能单独分享子任务（Subagent / A2A）会话。
</Note>

### 单条会话操作

| 操作 | 入口 | 说明 |
|---|---|---|
| 置顶 / 取消置顶 | 鼠标悬停在会话行上 | 置顶的会话排在列表前列 |
| 归档 / 取消归档 | 鼠标悬停在会话行上 | 归档的会话在筛选中切到 **归档** 可以找回 |
| 重命名 | 点击对话标题 | 最长 60 字 |
| 删除 | 聊天页头部（需管理权限） | 删除后不可恢复，会话中仍在运行的后台任务也会被终止 |

新会话会在第一轮对话结束后自动生成标题，您可以随时重命名。

### 列表状态指示

| 标记 | 含义 |
|---|---|
| 旋转的圆圈 | Agent 正在运行 |
| 🔭 + 数字 | 正在运行的后台任务数，见[任务面板与后台任务](#任务面板与后台任务) |
| 蓝色小圆点 | 有您尚未查看的新内容，打开会话后消失 |
| 相对时间 | 最近活动时间（如 `5m`、`3h`） |

## 发送消息与流式响应

在底部输入框输入消息后按回车发送。输入框支持 Markdown，输入 `/` 可以调出 Skill 与命令菜单。控制台发布新版本时，输入框上方会提示刷新页面。

### 附件与上下文引用

<AccordionGroup>
  <Accordion title="上传附件" icon="paperclip">
    点击输入框左下角的加号选择文件，或直接粘贴截图。

    - **支持的类型**：图片、PDF、文本 / Markdown / CSV / HTML、Office 文档、压缩包（`.zip` / `.rar`），以及任何 UTF-8 编码的文本文件（如 `.go`、`.py`、`.yaml`）。空文件不能上传。
    - **大小与数量**：单个文件最大 **50MB**；每条消息最多 **9 个附件**，总大小不超过 **50MB**。
    - **文件夹**：可以从加号菜单选择 **上传文件夹**，或把文件夹拖进输入区。一个文件夹最多 **50 个文件**（`node_modules` 和以 `.` 开头的文件不计入），超过时整个文件夹会被拒绝；不符合要求的单个文件会被跳过并列出原因。一个文件夹算 1 个附件，目录结构会保留。
    - **Agent 如何读取**：附件以文本形式提供给 Agent；超过 64KB 的文本只直接提供开头部分，Agent 会在需要时从沙箱中读取完整文件。压缩包和文件夹不会直接展开，Agent 在沙箱中按需解包和读取。
  </Accordion>
  <Accordion title="上下文引用" icon="link">
    从故障、告警、监控规则、监控对象、数据源或 RUM 异常详情页（**AI 修复** 按钮）进入 AI SRE 时，相关对象会作为**引用标签**自动放进输入框，随消息一起发给 Agent。点击标签可以打开该对象，发送前也可以移除。

    这些入口通常还会预填一句提问（例如要求 Agent 区分已确认事实与推断），您可以修改后再发送。一次带入多个引用时不会预填提问。

    在任意会话中输入 `@` 可以搜索故障并插入引用。输入邮箱地址时不会触发搜索。
  </Accordion>
  <Accordion title="知识与 Skill" icon="book">
    会话启动时会按绑定团队自动加载对应的知识与 Skill；详见 <a href="/zh/ai-sre/knowledge">知识</a> 与 <a href="/zh/ai-sre/skills">Skill</a>。
  </Accordion>
</AccordionGroup>

### 实时流式输出

Agent 的回复会实时显示，包括文本、工具调用和思考过程。切换页面再回来，运行状态不会丢失。

<Note>
运行期间，发送按钮会变为停止按钮。点击停止会立即中断当前回合，该回合会标记为“已中断”。
</Note>

### 运行中继续输入（排队）

运行期间仍可以继续发送消息，消息会排队，在当前回合结束后依次执行。排队的消息显示在输入框上方，可以逐条编辑、移除或全部清空。Agent 开始处理某条消息后，就不能再撤回它；如需中断，请点击停止。

### 运行环境初始化

会话首次运行时，对话中会出现 **运行环境初始化** 卡片，显示沙箱的准备进度，完成后折叠为一行：

| 提示 | 含义 |
|---|---|
| 已初始化会话 | 为会话创建了新的云端沙箱 |
| 已恢复会话 | 复用此前的沙箱，文件保持不变 |
| 已重建会话 | 原沙箱已被回收，创建了新的沙箱 |

使用自托管 [BYOC Runner](/zh/ai-sre/environments#byoc-runner) 的会话只显示连接 Runner 这一步。

<Warning>
沙箱因闲置被回收后，其中的文件会被重置。需要保留的产出请**保存为 Artifact 或沉淀到知识**。初始化失败时，点击卡片可以查看错误详情，通常重新发起会话即可，或联系 Flashduty 支持。
</Warning>

## 工具调用与产物

Agent 调用的工具（读写文件、查询监控、执行命令、调用 MCP 工具等）默认折叠显示在对话中，点击可以查看输入与输出。

### 任务计划（Todo List）

执行三个及以上步骤的任务时，Agent 会在对话中显示进度徽标（如“第 X / N 步”），点击可以展开任务清单，查看每一步的状态与优先级。如果回合结束时某一步仍未完成，它会显示为“已暂停”，需要您发送新消息才会继续。

任务清单只在控制台和 IM 会话中提供，自动化、API 和子任务会话不生成清单。

### Agent 提问

Agent 需要您澄清信息时，会在对话中插入提问卡片，可能是单选、多选或文本输入。可以用键盘操作（↑↓ 选择、Enter 确认、Esc 跳过）；非必答题可以点击 **✕** 跳过。

如果您不回答卡片而是直接发送新消息，提问会被视为跳过，您的消息立即执行。已经跳过或在其他设备回答过的提问，再提交答案会作为一条普通消息发送。

### 需要授权时

工具或 MCP 调用缺少凭证或 OAuth 授权时，对话中会出现 **授权〈资源名〉以继续** 卡片：

- **密钥类**：点击按钮，粘贴 API Key / Token 并保存，任务会自动继续。
- **OAuth 类**：点击 **去授权** 完成第三方授权，然后点击 **继续任务**。授权链接过期后，需要重新发起任务。

<Note>
只有控制台显示授权卡片。在 IM 和 API 会话中，Agent 会直接给出 OAuth 链接，请在浏览器中完成授权后回复“已授权”；密钥类凭证需要在网页控制台打开同一会话填写，**不要**把密钥发到聊天中。自动化会话不会等待授权，会把缺失的授权列为阻塞项。详见 [IM 平台](/zh/ai-sre/im#连接与授权)。
</Note>

### 需要连接时

当您要求 Agent 使用某个插件市场中有、但账户还没连接的厂商（例如“帮我接一下 Datadog”）时，对话中会出现 **连接〈厂商名〉以继续** 卡片，不必先去插件市场查找。

1. 点击 **连接**，在弹出的对话框中填写凭证并完成连接测试。
2. 连接成功后，卡片变为 **〈厂商名〉 已连接**，点击 **继续任务**，Agent 会接着完成原来的任务。

以下情况不会出现卡片，Agent 会直接说明：该厂商已连接（可能需要启用或重新填写凭证）、只有 Owner 或管理员能连接、需要自托管 Runner 但当前会话没有可用的 Runner，或者插件市场中没有该厂商。

<Note>
只有控制台显示连接卡片。在 IM 和 API 会话中，Agent 会给出连接链接，连接后回复“继续”即可；自动化会话不会等待，会把缺失的连接列为阻塞项。详见 [IM 平台](/zh/ai-sre/im#连接与授权)。
</Note>

### 子任务（Subagent）

Agent 委派子任务时，对话中会出现一行子任务引用，显示类型（Agent / A2A）、名称、执行环境、状态与耗时，结束后显示工具调用数、Token 用量和失败原因。点击它会在右侧并排打开子会话，可以展开为全屏。

子任务还可能处于两种需要您处理的状态：

- **等待授权**：点击 **去授权** 完成授权，再点击 **继续任务**，子任务会在原任务上继续。
- **等待输入**：在任务面板中查看并回答子任务的问题。

停止子任务请在任务面板中操作。执行者丢失的子任务显示为 **失败**，被平台终止的显示为 **已终止**。

### 任务面板与后台任务

除了子任务，Agent 还可以在后台运行长时间命令（如构建、批量拉取数据），或启动监视器持续观察某个条件，直到满足条件或到达截止时间。

点击聊天页头部的 **任务** 按钮，可以按 **需要您 / 运行中 / 已结束** 查看本会话的全部任务。按钮上的数字是需要您处理和正在运行的任务数，有任务需要您处理时显示为红色。也可以点击对话中发起该任务的那一行打开详情。

- **子任务**的详情是子会话的执行记录。
- **后台命令和监视器**的详情包括状态、运行时长、截止时间、退出码、完整命令和事件时间线。
- 点击详情头部的 **停止任务** 或 **停止子代理**，只会停止该任务，不影响主会话。

监视器每次命中条件时，对话中会出现一行 🔭 记录，点击可以展开输出；任务结束时会显示结束状态与结果摘要。只剩监视器或后台命令在运行时，会话显示为空闲，列表中显示 🔭 和任务数。

### Artifacts 预览

点击 Agent 产出的文件，会在右侧打开预览：

| 类型 | 预览方式 |
|---|---|
| 代码 | 语法高亮与行号 |
| Markdown / HTML | 渲染视图，可切换 **源码** |
| 图片、PDF | 直接显示 |
| Skill 压缩包（`.skill`） | 文件树与内容，可以下载或 **保存 Skill** 到账户 |

预览支持 **复制** 和 **下载**。所有产物也可以在左侧导航的 **产物** 页统一管理，见 <a href="/zh/ai-sre/artifacts">产物</a>。

### 状态页更新草稿

Agent 可以为公开状态页**起草**公告：新建故障或维护事件，或为已有事件追加更新。草稿**不会自动发布**，必须由您审阅后在控制台手动发布，因为发布会立即通知订阅者且无法撤回。

草稿卡展示的就是将要发布的内容：标题、状态或计划时间、Markdown 正文、受影响组件及其状态、目标状态页与事件类型。如果正文中有状态页不支持的格式（如标题、代码块、引用、图片），卡片会列出提醒，这些内容在发布时会丢失。

点击 **审阅 →** 会在新标签页打开状态页发布表单，并自动填入草稿。发布后按钮变为 **已发布**，并链接到已发布的事件；草稿过期或不存在时，请让 Agent 重新起草。

<Note>
IM 和 API 会话不显示草稿卡，Agent 会在回复开头给出“审阅并发布”链接并概括草稿要点。草稿保存失败时，Agent 会改为文字总结，并请您在控制台手动核对。
</Note>

### 消息操作

将鼠标悬停在消息上，可以：

| 操作 | 适用 | 说明 |
|---|---|---|
| 复制 | 用户消息 / 产物 | 复制内容 |
| 重试 | 用户消息 | 用该消息重新运行一轮 |
| 编辑 | 用户消息 | 修改后重新发送，见下方说明 |
| Fork | 已完成回合的回复 | 从这里派生新会话，尝试另一条排查思路 |

<Note>
编辑历史消息会**回滚**会话：这条消息之后的内容会被替换，相关的后台任务和子任务也会停止。该回合仍在运行，或会话正忙（如正在压缩上下文）时无法编辑，请稍后重试。
</Note>

### Fork 会话

回合结束后，点击回复旁的 **Fork**，选择新会话的范围（个人或您能访问的团队）和运行环境，确认后即会派生并打开新会话。

- 新会话包含截至该回合的对话和工具调用记录，之后的内容互不影响。
- 源会话的团队或环境不可用时，会分别改为个人范围和 **自动**。
- 已完成或失败的子任务会连同结果复制到新会话；Fork 时仍在运行的子任务显示为“已中断”，需要时可以重新发起。
- 只能从已完成的主会话回合 Fork，不能从子任务会话 Fork。

### 会话反馈

点击聊天页头部的 **有帮助** 或 **没帮助** 为整个会话评分。选择 **没帮助** 时可以勾选原因（诊断 / 根因错误、没定位到问题、处置建议不可用、答非所问）并补充说明。

## 上下文压缩

对话变长后，AI SRE 会自动把较早的历史压缩为摘要，保留最近内容和关键结论，对话不会中断。Skill、MCP 工具定义等被折叠出上下文的内容，Agent 会在需要时重新加载。

| 触发方式 | 时机 |
|---|---|
| 自动 | 上下文占用超过阈值时（回合开始前或进行中），或会话事件累计约 **500 条**时 |
| 手动 | 输入 `/compact` |

压缩时对话中会显示进度，完成后聊天页头部的 **Context** 占用百分比会下降（悬停可查看 token 用量）。如果看到占用远低于阈值时也发生了压缩，是因为事件数达到了上限。

## 选择运行环境

新建会话时，可以在输入区选择 **运行环境**，决定 Agent 的工具、Skill 和 MCP 在哪里执行：

| 选项 | 说明 |
|---|---|
| 自动（默认） | 系统选择可用环境，没有可用环境时使用云端沙箱 |
| 云端环境 | Flashduty 托管的云端沙箱（默认模板或您创建的模板） |
| BYOC Runner | 选择一台在线的自托管 Runner，在您的内网中排障 |

离线的 Runner 不能选择；已选的 Runner 离线后无法发送消息。运行环境在会话创建后固定，如需更换，可以 Fork 一个新会话（IM 会话可以就地切换）。

## 绑定团队

新建会话时可以 **绑定团队**，会话启动时会加载该团队的知识、Skill 与 MCP。团队选择会被记住。未绑定团队的个人会话中，Agent 可以按需加载您所属团队的知识；绑定了团队的会话只使用账户共享内容和该团队的内容。

<Note>
故障和作战室场景下自动绑定团队的能力仍在完善中。
</Note>


## 会话来源

每个会话都记录它的来源，来源决定了一些行为差异：

| 来源 | 说明 |
|---|---|
| 控制台 | 运行环境与团队在创建时固定 |
| IM 平台（飞书 / 钉钉 / 企业微信 / Slack） | 可以在对话中用 `/env` 和 `/scope` 命令切换运行环境与团队 |
| API | 程序化集成。通过 `POST /safari/session/create` 创建时可以传入 `entry_kind`（`web` / `im` / `api` / `automation`，默认 `web`），创建后不可修改 |
| 自动化 | 由自动化规则触发 |

## 回复语言

会话创建时确定 **回复语言**，Agent 在整个会话中都使用该语言。

| 来源 | 回复语言 |
|---|---|
| 控制台 | 创建会话时的控制台界面语言，之后切换界面语言不影响已有会话 |
| IM / API / 自动化 | 账户的默认通知语言 |

## 通过 API 集成会话

本节面向通过 [Open API](/zh/api-reference/ai-sre/sessions/session-read-info) 集成 AI SRE 会话的开发者。

### 撤回排队消息

`POST /safari/session/get` 响应中的 `pending_messages` 字段是 Agent 尚未读取的排队消息（按执行顺序排列）。在 Agent 读取前，消息作者本人可以调用 `POST /safari/session/message/cancel` 撤回，请求体携带 `session_id` 与 `invocation_id`（发送消息时回执中的调用 ID）。响应的 `result` 字段：

| 结果 | 含义 |
|---|---|
| `removed` | 已从队列移除，不会执行；各客户端会收到 `user_message_cancelled` 帧 |
| `consumed` | Agent 已读取，撤回不生效；如需中断请使用停止 |
| `forbidden` | 调用者不是消息作者 |

只能撤回普通的人工消息，提问作答和系统内部产生的消息不能撤回。调用方需要具备该会话的对话权限。

### 流式事件中的错误标记

会话流中的事件帧可能带有 `is_error` 与 `error_code` 字段，表示平台向用户暴露的运行时错误。没有这两个字段不代表该帧不含诊断信息；它们也不同于下文导出流中表示流本身出错的 `error` 行。

### 会话数据导出

通过 `POST /safari/session/export` 可以将一个会话的全部事件以 **NDJSON**（`application/x-ndjson`）格式流式导出，每行一个 JSON 对象。这一能力适用于审计、归档、离线分析或将会话数据接入外部系统等场景。

#### 请求参数

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `session_id` | string | 是 | 要导出的会话 ID |
| `include_subagents` | bool | 否 | 为 `true` 时递归包含所有子 Agent 会话的事件流；默认 `false` |

#### 响应格式

响应的 `Content-Type` 为 `application/x-ndjson`，**第一行始终**是 `session_meta` 类型的会话元数据信封，后续各行为会话事件。启用 `include_subagents=true` 时，每遇到一条 `subagent_dispatch` 类型的行，其后紧跟该子会话的完整事件流，子会话同样以自己的 `session_meta` 行作为起始。

```
{"type":"session_meta","session_id":"s_...","app_name":"ai-sre","entry_kind":"web","started_at":"2026-09-08T08:00:00Z","ended_at":"2026-09-08T08:05:00Z"}   // 第一行：会话元数据（不携带 seq）
{"type":"user_message","seq":1,"session_id":"s_...","content":"帮我排查一下这个故障","ts":"2026-09-08T08:00:01Z"}   // 用户消息
{"type":"tool_call","seq":2,"session_id":"s_...","name":"bash","input":{"command":"..."},"status":"ok","call_id":"call_abc","ts":"2026-09-08T08:00:02Z"}   // 工具调用（模型请求侧）
{"type":"tool_call","seq":3,"session_id":"s_...","name":"bash","output":"...","output_bytes":123,"status":"ok","call_id":"call_abc","ts":"2026-09-08T08:00:03Z"}   // 工具调用（运行时回执侧）
{"type":"subagent_dispatch","seq":4,"session_id":"s_...","agent_name":"explore","call_id":"call_def","ts":"2026-09-08T08:00:04Z"}   // 子 Agent 派发
{"type":"session_meta","session_id":"sub-tsk_...","parent_session_id":"s_...","app_name":"ai-sre","entry_kind":"web"}   // 子会话元数据（include_subagents=true 时内联）
{"type":"user_message","seq":1,"session_id":"sub-tsk_...","content":"...","ts":"..."}   // 子会话事件
{"type":"final_answer","seq":5,"session_id":"s_...","content":"...","usage":{"input_tokens":0,"output_tokens":0,"cache_read":0,"cache_creation":0},"ts":"2026-09-08T08:05:00Z"}   // 回合结束的最终回答
```

<AccordionGroup>
<Accordion title="行类型">

导出流只包含以下行类型（`type` 字段），不会出现其它类型：

| 行类型 | 出现时机 | 关键字段 |
|---|---|---|
| `session_meta` | **每个会话的第一行**（主会话与内联子会话都有） | `session_id`、`account_id`、`app_name`、`parent_session_id`（子会话时）、`entry_kind`（`web` / `im` / `api` / `automation`，空值归一为 `web`）、`started_at` / `ended_at`（会话创建 / 更新时间） |
| `user_message` | 用户消息事件 | `content`（提取的文本：多个 text part 按 `\n` 连接，推理 / thought part 跳过；用户消息不携带 `usage`） |
| `system_reminder` | 以 `<system-reminder>` 开头的用户行 | `content`（locale / env / knowledge / memory / channel-guide / mount 等系统注入的上下文，不是用户输入） |
| `tool_call` | 模型请求工具（`function_call` part）或运行时回执（`function_response` part），**每个 part 一行** | 请求侧：`name`、`input`（参数对象）、`status`（乐观标记 `ok`）、`call_id`；回执侧：`name`、`output`（回执 JSON 序列化为字符串）、`output_bytes`、`status`（`ok` / `error`；行级错误时另带 `error` 信息）、`call_id` |
| `subagent_dispatch` | 模型发起 `agent_dispatch` 调用（每个调用一行） | `agent_name`、`call_id`；`include_subagents=true` 时该行之后内联子会话的完整事件流 |
| `final_answer` | 回合结束的 assistant 事件（优先于 `llm_call`） | `content`、`usage` |
| `llm_call` | 纯文本模型响应且携带 token 用量 | `content`、`usage`、`ended_at` |
| `agent_text` | 无用量、非回合结束的助手文本（后备类型） | `content` |
| `session_fork` | “Fork 新对话”分隔线行 | `content` |
| `error` | 流已开始后出错时追加在流末尾；或 `include_subagents` 下子会话不可用时内联 | `content`（错误文本；消费方需检测该行以判断流是否完整，见下方 Warning） |

</Accordion>
<Accordion title="字段与行为约定">

- **`seq`**：从 1 开始、按**输出行**计数的单调序号（按子会话重置；跨分页不重置）。一个 DB 事件产生多行时（见下），多行按 part 顺序连续编号。`session_meta` 行不携带 `seq`。
- **`call_id`（配对依据）**：`function_call` / `function_response` 的 ID（两侧共用同一个 `id`）。一个模型响应可以把多次工具调用**合并进一个 DB 事件**（例如同一事件里 2 个 `agent_dispatch` + 1 个 `bash`）；导出按 part 各输出一行（顺序与原事件一致），`call_id` 让消费方把回执行与对应的调用行重新配对，而不依赖输出顺序。
- **`usage`（token 用量）**：事件级计数（`input_tokens` / `output_tokens` / `cache_read` / `cache_creation`），无值时输出 `0` 而非省略。**只在事件的首行盖章**——一次批处理派发的多条行共享同一份用量，按行累计的消费方不会被多算 N 倍。
- **不含模型标识**：导出刻意**不携带服务模型标识**——`session_meta` 与 `llm_call` 行都没有 `model` 字段。导出是供客户下载的制品，服务模型标识与逐次 token 用量组合起来足以反推底层用量成本，因此导出与查询接口（包括 `/safari/session/get`）都不返回它。
- **时间与耗时**：`ts` 为事件写入时间（RFC 3339）。`llm_call` 与 `tool_call` 行以该时间近似**结束时间**（`ended_at`）；开始时间与耗时（`started_at` / `duration_ms`）当前不提供（为空 / 0）。
- **`include_subagents=true`**：每个 `subagent_dispatch` 行之后立即递归内联该子会话的完整导出流（批量派发的每个 dispatch 行都会内联一次）；子会话的 `seq` 从 1 重新计数，其 `session_meta` 携带 `parent_session_id`。子会话不存在或导出失败时不中断父流，输出一条内联的 `error` 行继续。
- 部分簿记行不产生导出行（例如 OAuth 授权成功标记），因此事件行数可能少于会话事件数。

</Accordion>
</AccordionGroup>

<Warning>
若流式传输已开始后发生错误，服务器**无法**切换回标准 JSON 错误包。此时会在流末尾追加一行 JSON 编码的错误对象，消费方需检测该行以判断流是否完整。
</Warning>

**权限**：导出端点使用与发送消息相同的权限门控，即要求调用方具备该会话的消息收发权限，单纯的只读访问权限不够。个人会话只能由创建者导出；团队会话可由同账户内具备会话访问能力的成员导出。
