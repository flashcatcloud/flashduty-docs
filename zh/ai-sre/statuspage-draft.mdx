## 概述

---

发布一条状态页事件会立即通知订阅者并展示在公开页面上，且不可撤回——所以**发布这个动作永远属于人**。AI SRE 内置的 `statuspage_draft` 工具遵循这一原则：Agent 只负责**起草**，把事件草稿校验并保存到服务端，然后由你在控制台真实的发布表单中逐项核对、按下发布按钮。Agent 在任何情况下都不会直接发布或更新状态页事件。

一份草稿可以是三种形态之一：

| 形态 | 说明 |
|---|---|
| 新故障 | 为一次意外中断起草新事件，含标题、初始状态（排查中/已定位/监控中/已恢复）、消息与受影响组件 |
| 新维护 | 为一次计划性维护起草新事件，含标题、计划时间窗口、消息与受影响组件 |
| 追加更新 | 向一个**已经开放**的故障或维护追加一条进展更新（新状态 + 消息 + 组件状态变化），不新建事件 |

起草前，Agent 会先检查目标状态页上是否已有覆盖同一问题的进行中的事件：有则起草「追加更新」而不是另开一个新事件——对客户而言，同一事故出现两个事件会被误读为两次独立的故障。

## 使用流程

---

<Steps>
  <Step title="向 Agent 提出发布需求">
    在 AI SRE 会话中描述要发布的状态页更新，例如「帮我在状态页上发布一条 Web 控制台性能下降的故障」或「给进行中的故障追加一条已定位的进展更新」。描述清楚影响的组件与当前状态，Agent 会据此起草。
  </Step>
  <Step title="Agent 起草并保存草稿">
    Agent 调用 `statuspage_draft` 工具，将草稿内容（标题、状态、消息、受影响组件等）提交给服务端校验并保存。校验规则与控制台发布表单一致，因此通过校验的草稿一定是可以被正常发布的。
  </Step>
  <Step title="在会话卡片中预览">
    会话中会出现一张审阅卡片，按与状态页控制台一致的样式展示草稿全文：标题、当前状态（或维护计划时间窗口）、消息正文（Markdown 渲染）、受影响组件及其影响状态，以及目标状态页。如果草稿存在需要留意的问题，卡片上会以警告条列出。
  </Step>
  <Step title="点击审阅，跳转发布表单">
    点击卡片上的 **审阅** 按钮，会在新标签页打开控制台对应状态页的发布表单（新事件表单或追加更新表单），草稿内容通过链接中的草稿 ID 自动预填，无需手工誊抄。
  </Step>
  <Step title="人工核对并发布">
    在表单中逐项检查每个字段——尤其是**受影响组件**（这是审阅人最经常需要修正的字段）与**是否通知订阅者**——确认无误后点击发布。发布动作由你完成，Agent 不参与。
  </Step>
</Steps>

<Note>
草稿保存在服务端，卡片链接只携带草稿 ID（形如 `?draft=<草稿ID>`），表单打开时再从服务端读取草稿内容。因此即使刷新页面或稍后重开链接，只要草稿未过期，内容依然完整。
</Note>

## 卡片状态说明

---

审阅卡片会实时向服务端查询草稿的最新状态，底部按钮随之变化：

| 状态 | 表现 | 含义与操作 |
|---|---|---|
| 待审阅 | **审阅** 按钮可点击 | 草稿有效，尚未发布。点击跳转控制台表单继续 |
| 已发布 | 按钮置灰显示「已发布」，目标状态页变为可点击链接 | 草稿已被发布（可能是你或其他成员完成的）。点击链接可查看已发布的事件 |
| 草稿已过期 | 按钮置灰显示「草稿已过期」 | 草稿已超过保留期被清理（或不存在）。请让 Agent 重新起草一份 |

## 草稿规则

---

草稿的存储与字段约束由服务端强制执行：

| 规则 | 说明 |
|---|---|
| 保留期 | 草稿创建后保留 **30 天**，无论是否已发布，到期后自动删除 |
| 发布次数 | 每份草稿**仅可发布一次**。发布后再次使用会被告知已发布，避免重复发布同一事件 |
| 标题 | 必填，1–255 个字符 |
| 消息 | 必填，Markdown 格式，支持的元素与控制台编辑器一致 |
| 草稿体积 | 整份草稿内容不超过 **64 KB** |
| 维护时间窗口 | 新维护的计划结束时间必须晚于计划开始时间 |
| 受影响组件 | 组件必须属于目标状态页；组件状态按事件类型校验（故障：运行正常/性能下降/部分中断/完全中断；维护：运行正常/维护中） |
| 事件状态 | 故障：排查中 → 已定位 → 监控中 → 已恢复；维护追加更新：已排期/进行中/已完成。新建维护不携带状态，是否按计划自动推进由审阅人在表单中决定 |
| 追加更新目标 | 追加更新的草稿必须指向同一状态页上、类型相同（故障对故障、维护对维护）的事件 |

<Warning>
草稿一旦发布即被标记为「已发布」，无法再次使用。如果发布后还需要继续通报进展，请让 Agent 起草一份新的「追加更新」草稿。
</Warning>
