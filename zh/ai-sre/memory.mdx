## 概述

AI SRE 每次新会话都从当前范围里已有的记忆文件读起。如果每次都要重新说明您的习惯、某类故障先看哪里、上次为什么放弃了某个做法，排障就得从头介绍背景。记忆把这些从对话里留下来，写成一份份 Markdown 文件，后面的会话继续用。

记忆与[知识](/zh/ai-sre/knowledge)是两类资料。知识由人维护，写的是环境怎么运转。记忆由系统整理，写的是从对话里留下来的偏好、做法、事实和教训。两者同属控制台的 [上下文](/zh/ai-sre/context) 分组，但各有一页：**AI SRE → 自定义 → 上下文 → 记忆**。

## 记忆类型

每份记忆文件开头写明名称、一句话说明和类型。类型只有四种：

| 类型 | 适合记下的内容 |
| --- | --- |
| preference（偏好） | 回答习惯，比如先给结论、用哪个时区 |
| procedure（做法） | 某类情况先做哪几步 |
| fact（事实） | 会反复用到的环境事实，比如某个系统归谁 |
| lesson（教训） | 一种做法为什么走不通，下次不要再走 |

记忆写入的范围由当时的会话决定。绑定了团队的会话写入这个团队；没有绑定团队的机器人私聊、Web 和控制台会话写入您个人；未绑定团队的共享群聊（含作战室）既不读取也不写入任何记忆。记忆留到您改掉或删掉为止。

## 记忆如何产生

记忆有三个来源：

- **在会话里提出**：要求记住、改掉或忘掉一件事，助手会在同一轮写好或改掉对应的记忆文件。您提出一条长期偏好、或纠正助手的做法时，也会直接存成一条偏好，不必说“记住”。
- **回合结束后的后台整理**：会话最后一个回合结束约 6 小时后，后台整理会沉淀做法、事实和教训。它不写偏好：您在对话里顺口提到的习惯不会因此变成记忆。
- **`/init` 导入**：`/init` 从本地 AI 编程工具导入资料时，会把个人偏好和可复用习惯写成记忆，见[初始化（/init）](/zh/ai-sre/init)。

前两种来源写入当前会话所属的范围；`/init` 写入它启动时选定的范围。

## Agent 如何使用记忆

会话开始时，当前范围里的记忆文件会准备好。助手先看到每份文件的名称和说明，需要细节时再打开正文。绑定了团队的会话用的是这个团队的记忆；没有绑定团队的机器人私聊、Web 和控制台会话用的是会话创建者的个人记忆；未绑定团队的共享群聊（含作战室）不加载记忆，也不写入记忆——群里需要记忆时，先用 `/scope` 把会话绑定到团队。

四类记忆的用法不同：procedure、fact、lesson 是过去的记录，用之前需要按当前情况核实；preference（偏好）是您明确提出的要求，在它说明的范围内照做，与 Skill 或工具的默认做法冲突时，以偏好为准。

## 作用域与隔离

记忆只有 **个人** 与 **团队** 两种范围，没有账户级记忆。

- **个人记忆**：只有记忆所属的本人可以读取。
- **团队记忆**：当前会话绑定了该团队，或读取者本人是该团队的成员。账户 owner、admin 也不例外，且没有跨团队读取的途径。

控制台里，团队记忆的查看、编辑和删除都要求您是团队成员：只读的 Viewer 角色即使属于该团队也打不开，账户 Owner 和管理员没有例外，未加入团队时同样打不开。个人记忆只有本人能查看和修改。

权限的整体规则见[作用域与权限](/zh/ai-sre/context#作用域与权限)。

## 在控制台查看和修改

进入 **AI SRE → 自定义 → 上下文 → 记忆**。

- **选范围**：顶部在 **个人** 和 **团队** 之间切换；选团队时再从下拉里挑一个您所属的团队。没有共享（账户级）记忆。
- **找记忆**：左侧列表按 偏好 / 做法 / 事实 / 教训 分组，组内按更新时间倒序；搜索框按名称、描述和文件名过滤。
- **编辑**：在右侧点 **编辑**，修改名称、一句话描述（什么时候用得上）和内容后保存。这个页面不提供新建入口——记忆只能在会话里产生或导入（见[记忆如何产生](#记忆如何产生)）；**类型** 也不能在这里改，它在记忆被写下时就已定下，页面只是按类型分组展示、保存时原样写回。
- **删除**：删除后，之后的对话不会再参考它。在对话里说忘掉一件事，效果相同。

如果这条记忆在您编辑期间被别人或 AI 改过，保存时会提示，再保存一次会用您的版本覆盖；取消可以查看最新内容。

### 让 AI 修改

有编辑权限时，正文下方有一个输入框（提示语为“想改什么？例如：把发布窗口改成工作日 10:00 到 16:00”）。发送后，控制台打开一个新对话，输入框里已带上这个范围的记忆引用和您的要求。个人记忆会开个人会话，团队记忆会开绑定该团队的会话，因为记忆只写入会话所属的范围。发出后，AI 先用文字说明要新增、合并或删除哪些记忆，您同意后才保存。
