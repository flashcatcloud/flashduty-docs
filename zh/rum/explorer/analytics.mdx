RUM 查看器提供**列表**与**分析**两种查看方式。**分析**视图把当前事件类型的事件按您选定的统计方式与分组汇总成图表，用于回答「哪个页面的加载最慢」「错误集中在哪些浏览器」这类问题；需要看单条事件时再切回列表。

## 列表与分析

查看器顶部有两个页签：**列表**逐条展示事件，**分析**把事件汇总成图表。两者共用同一套事件类型、查询条件和时间范围，切换页签不会丢失筛选条件。分析视图的状态保存在链接中，复制链接即可分享同一张图表（参数见[URL 参数](#url-参数)）。

## 选择统计方式与字段

分析视图顶部的**统计**一行决定算什么：先选**统计方式**，再按需选择**统计字段**，然后选择**分组字段**。

### 统计方式

| 统计方式 | 说明 |
|----------|------|
| **计数** | 事件条数，不需要字段 |
| **去重计数** | 字段去重后的取值个数 |
| **平均值** | 数值字段的平均值 |
| **求和** | 数值字段的合计 |
| **最小值** | 数值字段的最小值 |
| **最大值** | 数值字段的最大值 |
| **P50 / P75 / P90 / P95 / P99** | 数值字段的近似分位数，用于观察长尾 |

除**计数**外，所有统计方式都需要选择**统计字段**：

- 平均值、求和、最小值、最大值和分位数只能选数值字段（时间戳字段除外）。
- 去重计数可以选任一可分组的字段。
- 切换事件类型后，如果原字段在新类型上不存在，需要重新选择。

图例、表格和 CSV 中，计数和分布图的统计值显示为「事件数」，其他统计方式显示为「统计方式（字段名）」，如「平均值（view_loading_time）」。

### 分组字段

**分组字段**决定按什么拆开，每个取值单独展示。可以用**取前**选择保留前 `5`、`10`（默认）、`20` 或 `50` 组；不选分组字段时，结果汇总为单个数值。数组字段不能用于分组，**分布图**不使用分组。

<span id="cardinality-limits"></span>

### 分组字段的基数限制

分组还受字段基数约束，基数越高的字段分组代价越大：

- **事件的 ID 字段不能用于分组**：`session_id`、`view_id`、`resource_id`、`action_id`、`error_id`、`long_task_id`、`vital_id` 每条事件各有一个取值，按它分组等于一条事件一组，因此不出现在分组字段的可选项里。**去重计数**仍然可以选这些字段，用来数「有多少个会话 / 视图」。
- **高基数字段只能配计数或求和**：URL、用户、错误消息、堆栈、IP、`trace_id` 这类字段在字段列表中被标记为高基数。用它们分组时，**统计方式**只剩**计数**与**求和**两项（切到这类字段时非这两项的统计方式会自动改为计数），分组旁提示「高基数字段：仅支持计数/求和，时间范围最长 7 天」。
- 这类分组的时间范围最长 **7 天**：时间范围更长时图表不出图，提示「按高基数字段分组时，时间范围最长 7 天，请缩短时间范围」。

同一套规则也适用于[自定义看板](../analytics/custom-dashboards)的面板：保存时由服务端再次校验，错误为 `cannot group by an event ID` 与 `grouping by a high-cardinality field supports only count and sum`。

## 图表类型

分析视图提供五种图表类型：

| 图表类型 | 说明 |
|----------|------|
| **时序图** | 统计值随时间的走势（默认） |
| **排行** | 各分组按统计值从大到小排列 |
| **饼图** | 各分组的占比。需要选择分组字段，且统计方式为**计数**或**求和**（只有这两种可以相加为整体） |
| **表格** | 分组与统计值两列明细 |
| **分布图** | 一个数值字段按区间分桶后的事件数直方图，见[分布图](#分布图) |

**时序图**可以选择**柱状**（默认）或**折线**。有分组且统计方式为计数或求和时，柱状图按分组堆叠，柱高即合计值；其他统计方式的分组值不能相加，因此不堆叠。

## 点击下钻

点击图上的时间点、行、扇区或区间，可以从聚合结果下钻到明细事件：

| 菜单项 | 作用 |
|--------|------|
| **在列表中查看** | 切换到列表页签，只展示该元素背后的事件 |
| **拆分「值」** | 只保留该取值，并选择下一层分组字段继续拆分（分布图中为**筛选为「区间」**） |
| **排除「值」** | 从结果中排除点击的分组取值 |

下钻会添加普通的筛选条件（时间点下钻会缩小时间范围），可以在搜索框中查看和撤销。通过**在列表中查看**进入列表后，点击顶部的**返回分析**即可回到下钻前的分析视图。

<Note>
空值分组（显示为「(空值)」）暂不支持拆分和排除。
</Note>

## 缩放时序图

在**时序图**上拖选一段时间即可放大，只影响这张图，不改变查看器的时间范围。点击**已放大**标记上的关闭按钮恢复；切换事件类型、修改查询条件或时间范围也会重置缩放。

## 下载图片与导出 CSV

图表右上角可以：

- **下载图片**：导出为 2 倍清晰度的 PNG。表格和不分组的单个数值不支持。
- **CSV**：导出图表数据。时序图每行是「时间、分组、统计值」，其他图表每个分组一行。

## 保存到看板

同一排的 **保存到看板** 把当前这个分析问题固化成一个[自定义看板](../analytics/custom-dashboards)面板：

- 图表类型可选**时序 / 表格 / 单值**；**饼图**与**分布图**还不能保存，按钮会提示「饼图和分布图还不能保存到看板」。问题不完整（如没选统计字段）时提示「选择要统计的字段」。
- 可以**追加到现有看板**（打开该看板的编辑态并追加这个面板，保存前不写入任何数据），也可以**新建看板**（先创建只含这个面板的看板，再打开它的编辑态）。
- 面板沿用当前的应用、时间范围与过滤条件，并自动带上看板的 `env` / `service` / `version` 变量；标题按查询自动生成。

这里保存的查询条件和图表也可以先交给 AI 搭好：在查询框里用一句话描述，或让 AI SRE 对话直接设好统计方式、分组与图表类型，见[数据查询语法指南](/zh/rum/explorer/data-query#用-ai-sre-查询和分析)。

## 分布图

**分布图**按一个数值字段的取值区间分桶，展示每个区间的事件数，不使用统计方式和分组。

- 区间覆盖从最小值到 `P99`，边界取整齐的数值；高于 `P99` 的取值并入最后一个「≥ 边界值」区间，避免长尾把大多数数据挤进第一根柱子。
- 区间按字段单位显示，如 `1s–1.5s`。

## 采样估算

数据量较大时，结果按抽样数据估算，图表右上角会显示**采样估算**标记。

## URL 参数

分析视图的状态保存在 URL 中，复制链接即可复现同一次分析，也可以按下表拼出链接。非法取值会回退到默认值。

| 参数 | 含义 | 取值 | 默认值 |
|------|------|------|--------|
| `mode` | 查看方式 | `analytics` | 省略即列表 |
| `agg` | 统计方式 | `count`、`count_distinct`、`avg`、`sum`、`min`、`max`、`p50`、`p75`、`p90`、`p95`、`p99` | `count` |
| `aggField` | 统计字段 | 字段名 | 无 |
| `groupBy` | 分组字段 | 字段名 | 无（不分组） |
| `top` | 取前 N 组 | `5`、`10`、`20`、`50` | `10` |
| `viz` | 图表类型 | `timeseries`、`toplist`、`pie`、`table`、`distribution` | `timeseries` |
| `style` | 时序图画法 | `line`、`bar` | `bar` |
