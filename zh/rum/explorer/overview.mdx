RUM **查看器**（RUM Explorer）用来检索和分析应用上报的 RUM 事件：浏览用户的完整会话路径，调查影响页面、资源或操作的性能问题，排查错误和长任务，并把事件聚合成图表（见 [聚合分析](./analytics)）。

## 选择应用

使用顶部导航栏的应用选择器选择应用，查看器只显示该应用的 RUM 数据；切换应用即可切换数据视图。

## 搜索与过滤

在搜索栏输入查询条件并选择可视化类型，即可搜索和过滤 RUM 事件。查询语法见 [数据查询指南](./data-query)。

## 查看事件详情

点击数据项可查看事件详情，从多个角度展示 RUM 事件：

- 查看数据关系，进行数据下钻或者查看数据父节点详情
- 通过查看资源的 trace，和已有的监控系统进行 trace 关联

对于 Electron 会话，事件列表会为来自主进程的事件显示「主进程」徽标（无徽标的行即渲染进程事件），事件详情面板的 Other 属性组还会增加一个虚拟 `process` 属性（`main` / `renderer`），用于区分事件来自主进程还是渲染进程。

## 按平台显示的视图指标

打开任一 View 的详情面板时，「性能」标签页的指标卡片会根据该 View 所属平台自适应展示，确保看到的是该平台真正具备的核心指标。

| 平台 | 性能指标卡片 |
|------|--------------|
| **浏览器（Web）** | `LCP`、`FCP`、`INP`、`CLS` |
| **原生（Android / iOS）** | `refresh_rate`、`cpu_ticks`、`memory` |
| **微信小程序** | `first_render`、`lcp`、`fcp`、`onload_to_onshow`、`onshow_to_onready` |
| **Electron** | 渲染进程视图按 Web 指标展示；主进程视图无页面性能指标，面板展示说明文案 |

<Note>
平台由 View 事件自身的 `source` 字段决定，无需手动切换。微信小程序场景下，`onload_to_onshow` 和 `onshow_to_onready` 对应小程序页面生命周期的两段耗时，可用于排查页面冷启动慢的原因。
</Note>

事件表格的列选择器还可以添加以下小程序专属字段：`view_first_render`、`view_onload_to_onshow`、`view_onshow_to_onready`。

## 保存视图

把当前查询状态保存为视图，就能在不同分析场景之间快速切换。每个账户最多可创建 **20 个**保存视图，视图仅您自己可见。

### 视图保存的内容

| 保存项 | 说明 |
|--------|------|
| **时间范围** | 当前选择的时间筛选条件 |
| **查询类型** | 当前选择的事件类型（如 Sessions、Views、Actions、Errors 等） |
| **查询语句** | 搜索栏中的 DQL 筛选条件 |
| **自定义列** | 数据表格的列配置 |

### 视图操作

| 操作 | 方法 |
|------|------|
| **创建** | 点击查看器顶部的视图菜单，选择「保存为新视图」并输入名称（不可重复） |
| **切换** | 在视图菜单中点击目标视图，查看器会恢复其时间范围、查询类型、查询语句和列配置 |
| **编辑** | 在目标视图右侧的操作菜单选择「编辑视图」修改名称；修改了当前视图的查询条件后，可用「保存修改」更新视图 |
| **删除** | 在视图列表或操作菜单中选择「删除视图」；删除当前视图后会切换回默认视图 |
| **分享** | 在操作菜单选择「复制链接」，团队成员打开链接即可看到相同的查询视图 |
| **重置** | 在操作菜单选择「切换默认视图」，清空所有筛选条件 |

## 事件导出

查看器事件表格右上角提供 **CSV 导出** 按钮，可将当前筛选条件和列配置下的数据导出为 CSV 文件。

- **导出上限**：单次最多导出 5000 行。若符合筛选条件的数据超过上限，导出完成后会弹出提示告知已导出前 N 条、仍有更多数据未导出。
- **列匹配**：导出的列与当前事件类型的列设置一致——列名、顺序和单位跟随屏幕配置，字段元数据未就绪时导出的是原始字段名和裸数值。
- **取消导出**：导出过程中再次点击按钮可取消，已获取的数据不会落盘。
- **适用范围**：Sessions Explorer 事件表格中的所有视图类型均支持导出。
