## 快速上手

使用 Flashduty RUM 只需简单几步，即可开始监控您的应用性能。

### 接入步骤

<Steps>
<Step title="开通 RUM">
SaaS 账户尚未开通 RUM 套餐时，**应用管理** 页显示空状态，主按钮为 **免费开始使用**。点击后开通免费套餐，随即进入创建应用的引导。

已开通套餐的账户和私有化部署没有这一步，直接进入下一步。
</Step>

<Step title="创建应用">
RUM 应用是承载性能监控数据的容器。我们建议按照业务系统或应用来创建，例如：官网、商城、管理后台等。

1. 在 **应用管理** 页点击右上角的 **创建应用**（列表为空时，空状态主按钮为 **创建第一个应用**）
2. 在抽屉中依次填写 **应用类型**、**应用名称**、**管理团队** 和 **访问级别**
3. 同一抽屉的下半部分设置 **地理信息收集** 与 **告警配置**
4. 点击 **保存**

**应用类型** 决定可采集的数据，创建后不能修改；**访问级别** 默认为 **私有**，仅团队管理成员、应用创建者和账户管理员可见。从空状态主按钮进入的是引导式创建，只填应用类型、应用名称和管理团队，其余设置创建后在应用详情的 **基本信息**、**隐私设置** 与 **告警设置** 中调整。

<Tip>
前往 [应用管理](/zh/rum/quickstart/app-management) 了解更多配置选项。
</Tip>
</Step>

<Step title="接入 SDK">
创建好 RUM 应用后，您需要将 SDK 集成到您的应用中。

1. 在应用详情页获取 SDK 接入配置信息
2. 根据您的应用类型，选择对应的接入文档

<Step title="验证数据上报">
SDK 集成完成后，系统自动收集页面或界面性能、资源和网络请求、用户操作，以及错误与异常。各平台的具体采集范围见对应 SDK 的「数据收集」页，例如 [Web 数据收集](/zh/rum/sdk/web/data-collection)。

<Check>
数据通常在 2-5 分钟内显示在控制台中。
</Check>
</Step>
</Steps>
