性能数据分析页面通过分析真实用户流量数据来帮助识别浏览器性能问题的根本原因。使用核心网页指标（Core Web Vitals）和自定义加载时间指标等浏览器指标来排查页面加载缓慢的原因。这些指标从用户角度评估完整的页面加载时间。

## 访问性能分析

在 RUM 菜单进入 **性能分析**，用页面右上角的 **表格** 和 **树图** 两个按钮切换视图，分别从页面和指标的角度查看性能数据。

### 表格视图

点击 **表格**，列表按页面列出各指标的值，默认按访问次数从多到少排列：

- 指标数值前的颜色标识表示该指标所处的水位，可快速定位待提升的指标
- 悬停在指标上，可查看该指标在标准下的当前水位
- 点击整行记录，打开该页面的指标详情

### 树图视图

点击 **树图**，页面按所选指标分为 **良好**、**一般**、**较差** 三档，区块面积代表该页面的访问次数：

- 顶部的 **指标** 下拉只列出当前应用平台可选的指标（如微信小程序与浏览器 / Electron 的指标集不同），切换应用后选项随之变化
- 点击分区标题可放大该档，再点 **返回** 回到全部
- 点击区块代表的页面，可查看该页面下的指标详情，方便进一步做问题诊断

## 数据分析维度

通过全局筛选器，可以从不同维度对页面性能进行分析，从而洞察性能数据趋势变化：

| 维度 | 说明 |
|------|------|
| 浏览器名称 | 按浏览器类型筛选 |
| 连接状态 | 按设备连接状态筛选 |
| 设备类型 | 按设备类型筛选 |
| 国家 | 按用户所在国家筛选 |

<Tip>
页面右上角的 **详情展示** 提供 **侧边栏** 和 **页面** 两种方式。默认的 **侧边栏** 会在当前列表右侧打开指标详情；选 **页面** 后，详情在独立页面中打开，获得更完整的数据展示和诊断空间。
</Tip>
