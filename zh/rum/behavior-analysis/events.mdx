行为事件（简称事件）是一个命名的匹配规则集合，把自动采集的点击按页面和元素定义为业务名称，例如把商品详情页上的「立即购买」按钮定义为事件 `加入购物车`。漏斗步骤按事件名引用它，[漏斗分析](/zh/rum/behavior-analysis/funnel) 的流失分析也按事件统计点击。

事件在查询时匹配已采集的原始点击，不改写已存储的数据，因此保存后立即作用于最近的点击数据，无需发版。

## 页面结构

**事件管理** 有两个标签页：

- **事件（N）**：已定义的事件，含启用中与已隐藏两类。表格列为名称、命中、较上期、命中访客、被漏斗引用、最近修改和操作。
- **未归类点击（N）**：所选时间范围内还没有归属任何事件的点击。表格列为元素文本、页面、点击、挫败点击率和已归入，可一键用这些点击创建事件。

数据量大时，未归类点击的点击数按会话抽样估算，表头会标注抽样比例。

## 新建事件

<Steps>
  <Step title="打开新建表单">
    在 **事件管理** 点 **新建事件**，或在 **未归类点击** 里直接对某个点击点 **创建事件**。后者会按所选点击预填规则：页面等于该点击所在页面，元素文本等于该点击的元素名称。
  </Step>
  <Step title="填写名称与说明">
    **名称** 按用户意图命名，例如「加入购物车」，上限 128 个字符。**说明** 选填，上限 512 个字符，仅作备注。
  </Step>
  <Step title="添加匹配规则">
    一个事件至少需要一条规则。规则有两种类型，见下方「匹配规则」。
  </Step>
  <Step title="确认命中再保存">
    规则填完整后 **命中预览** 显示所选时间范围内命中的点击。若显示无命中，保存出的漏斗步骤也会是 0，建议先检查页面和元素条件。
  </Step>
</Steps>

## 匹配规则

| 规则类型 | 需要填什么 | 命中什么 |
| --- | --- | --- |
| **元素点击** | 页面条件 + 元素条件，两者都必须填 | SDK 自动采集的点击 |
| **自定义事件** | `addAction` 上报的事件名，完全相等才算命中 | 代码中通过 `addAction` 上报的同名动作 |

多条规则之间是 **或** 的关系：一个点击只要命中任意一条规则，就属于这个事件。

### 页面条件

页面条件按页面路径匹配，可选运算符：

| 运算符 | 含义 | 示例 |
| --- | --- | --- |
| **等于** | 路径完全相等 | `/product` 只匹配 `/product` |
| **包含** | 路径中出现该字符串 | `product` 匹配 `/product/123` |
| **前缀（含子路径）** | 路径以该字符串开头 | `/product` 匹配 `/product`、`/product/123` |
| **通配符（`*`）** | `*` 匹配任意一串字符 | `/product/*` 匹配 `/product/123`，不匹配 `/product` |
| **正则表达式** | 按正则匹配 | `^/product/\d+$` |

### 元素条件

元素可以按两种字段匹配，运算符有 **等于**、**包含**、**前缀**、**正则表达式** 四种（元素条件不支持通配符）：

| 匹配字段 | 说明 |
| --- | --- |
| **元素文本** | 被点击元素上的文本，例如「立即购买」。同一文本的多个元素合并命中。 |
| **选择器** | CSS 选择器。选择器里常含构建时自动生成的类名或 ID，发版后可能失效，因此优先按元素文本匹配。 |

## 上限

| 项目 | 上限 |
| --- | --- |
| 每个应用的事件数 | 200 |
| 每个事件的规则数 | 20 |
| 每个条件的值长度 | 512 字节；正则表达式 200 字节 |
| 保留的事件版本数 | 最近 50 个 |

## 隐藏、删除与版本

- 事件状态有 **启用中** 与 **已隐藏** 两种。隐藏后不再计入新的查询，但历史版本仍然保留。
- 被漏斗步骤引用的事件不能删除：点击删除会提示被哪些漏斗引用，请改为隐藏或先改掉漏斗步骤。
- 改名或改规则会生成一个新版本并记入历史；只改说明不产生新版本。

## AI 辅助

未归类点击里有两个 AI 入口，都只在当前选择的点击范围内工作：

- **AI 整理点击**：把未归类点击按用户意图分组并起业务名，同时标出不适合建成事件的点击（例如含人名等个人信息、整块容器文字、纯选择器），结果填进待确认表，由您勾选后批量创建。
- **AI 推荐事件**：结合上一步页面或未归类的点击，推荐可以建成事件的元素。

漏斗页面的 **用 AI 创建漏斗** 会在对话里直接建漏斗，见 [漏斗分析](/zh/rum/behavior-analysis/funnel)。
