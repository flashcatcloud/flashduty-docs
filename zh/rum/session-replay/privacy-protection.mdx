为满足不同场景的隐私需求，会话重放功能内置了灵活的隐私保护策略。通过配置 `defaultPrivacyLevel` 字段，开发者可控制数据采集的敏感度，支持从显示所有文本（除密码外）到完全隐藏页面文本的多种模式，确保用户数据的安全性和合规性。

<Warning>
input 类型为 password 的输入为敏感信息，**所有场景都不会收集**。
</Warning>

## 隐私策略

<Tabs>
  <Tab title="隐藏所有文本">
    配置 `defaultPrivacyLevel: "mask"` 将完全隐藏页面中的所有文本内容，仅保留操作行为和页面结构，适合对数据隐私要求较高的场景。

    ```javascript
    window.FC_RUM.init({
      applicationId: "YOUR_APPLICATION_ID",
      clientToken: "YOUR_CLIENT_TOKEN",
      // ...
      sessionReplaySampleRate: 10,
      defaultPrivacyLevel: "mask",
      // ...
    });
    ```

  <Tab title="隐藏输入框内容">

    ```javascript
    window.FC_RUM.init({
      applicationId: "YOUR_APPLICATION_ID",
      clientToken: "YOUR_CLIENT_TOKEN",
      // ...
      sessionReplaySampleRate: 10,
      defaultPrivacyLevel: "mask-user-input",
      // ...
    });
    ```

    配置 `defaultPrivacyLevel: "allow"` 允许采集页面中除密码字段外的所有文本内容，适合需要完整用户交互细节的场景。

## 配置对比

| 配置值 | 页面文本 | 输入框内容 | 密码字段 | 适用场景 |
|--------|----------|------------|----------|----------|
| `mask` | 隐藏 | 隐藏 | 隐藏 | 高隐私要求场景 |
| `mask-user-input` | 显示 | 隐藏 | 隐藏 | 保护用户输入 |
| `allow` | 显示 | 显示 | 隐藏 | 完整交互细节 |

## 针对单个元素设置隐私级别

`defaultPrivacyLevel` 作用于整个页面。如果只想隐藏或遮盖某一块区域（例如余额、身份证号、订单详情面板），可以直接在该元素上加 `data-dd-privacy` 属性，或者加 `dd-privacy-<级别>` 类名，两种写法效果相同。设置后，该元素及其所有子元素都按此级别处理。

| 属性写法 | 类名写法 | 回放效果 |
|----------|----------|----------|
| `data-dd-privacy="hidden"` | `dd-privacy-hidden` | 元素整体不采集，回放中显示为同尺寸的占位块 |
| `data-dd-privacy="mask"` | `dd-privacy-mask` | 保留元素结构，文本和输入内容替换为 `x` |
| `data-dd-privacy="mask-user-input"` | `dd-privacy-mask-user-input` | 只遮盖输入框内容，其余文本照常显示 |
| `data-dd-privacy="allow"` | `dd-privacy-allow` | 显示文本和输入内容（强制遮盖的字段除外） |

### 示例：隐藏某个元素

```html
<!-- 写法一：属性 -->
<div class="account-balance" data-dd-privacy="hidden">
  余额：¥12,345.67
</div>

<!-- 写法二：类名，适合无法自定义 HTML 属性的组件库 -->
<div class="account-balance dd-privacy-hidden">
  余额：¥12,345.67
</div>
```

在 React 等框架中写法相同：

```jsx
<section data-dd-privacy="hidden">
  <UserProfile />
</section>
```

### 示例：在全局隐藏的前提下放开某块区域

页面整体使用 `defaultPrivacyLevel: "mask"`，但希望导航栏等不含敏感信息的区域在回放中可读：

```html
<nav data-dd-privacy="allow">
  <a href="/orders">我的订单</a>
  <a href="/settings">设置</a>
</nav>
```

### 生效规则

- **子元素继承父元素的级别**，子元素可以用自己的 `data-dd-privacy` 覆盖父元素，例如在 `mask` 区域里对某个子元素设置 `allow`。
- **`hidden` 不能被覆盖**：父元素一旦设为 `hidden`，其内部任何元素设置 `allow` 都不会生效。
- **部分输入框始终遮盖**：`type` 为 `password`、`email`、`tel`、`hidden` 的输入框，以及 `autocomplete` 为 `cc-*`（银行卡信息）或 `*-password` 的输入框，即使设置 `allow` 也会被遮盖。
- 隐私处理在浏览器端完成，被隐藏或遮盖的内容不会上传到服务端，事后无法还原。
