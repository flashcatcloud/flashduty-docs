活跃告警页面汇总展示当前所有正在触发的告警，帮助您快速了解系统的整体告警状态。您可以按严重程度、标题、标签等维度进行筛选和查看。

<Note>
活跃告警功能依赖 monit-edge 版本 >= v0.64.0，请确保您已升级至该版本或以上。如尚未安装，请前往[告警引擎管理](https://console.flashcat.cloud/monit/engine/list)页面完成部署。
</Note>

## 查看活跃告警

**菜单入口**：选择一个文件夹后，切换到「活跃告警」标签页

活跃告警列表以表格形式展示当前正在触发的告警，默认列包括：

| 列名 | 说明 |
|------|------|
| **严重程度** | 告警的严重级别，包括 Critical（严重）、Warning（一般）、Info（轻微） |
| **告警标题** | 告警事件的标题 |
| **Job** | 告警携带的 job 标签值 |
| **Instance** | 告警携带的 instance 标签值 |
| **最后更新** | 该告警最后一次更新的时间 |
| **Hash** | 告警的唯一标识哈希值 |
| **Extra labels** | 告警携带的其他附加标签信息 |

## 筛选与搜索

页面顶部提供筛选条件栏，帮助您快速定位关注的告警：

- **告警规则**：按产生该告警的规则筛选（常驻条件，支持按规则名称搜索）
- **严重程度**：按 Critical、Warning、Info 筛选
- **告警标题**：按告警事件的标题筛选
- **Hash**：按告警的唯一标识哈希值筛选
- **Job**：按 job 标签值筛选
- **Instance**：按 instance 标签值筛选
- **Extra labels**：按其他附加标签筛选

各筛选条件之间为"与"的关系，同时满足所有条件的告警才会被展示。

在告警规则列表中点击规则所在行的「活跃告警」列（铃铛图标加计数，展示该规则当前的活跃告警数量，计数大于 0 时显示为红色），会自动切换到「活跃告警」标签页并按该规则过滤（URL 参数 `active_alert_rule_id`）。列表「状态」列展示的是规则运行状态，点击状态徽章打开的是运行详情抽屉，不再跳转活跃告警。

## 查看规则运行详情

告警规则列表的「状态」列展示每条规则的运行状态，点击状态徽章打开「运行详情」抽屉。运行状态取值及含义如下：

| 状态 | 含义 |
|------|------|
| **运行正常** | 规则最近一次执行成功 |
| **执行异常** | 规则最近一次执行失败，抽屉中会展示错误摘要 |
| **Edge 离线** | 负责该规则的 Edge 当前不在线 |
| **未匹配数据源** | 规则的数据源范围未匹配到可用数据源 |
| **配置待生效** | 中心配置已保存，Edge 尚未上报新版本；传播完成前可能仍在执行旧配置 |
| **状态已过期** | Edge 已超过预期执行周期没有上报新状态，展示的是最后一次已知结果 |
| **等待运行状态** | 尚未收到 Edge 的运行状态，规则可能仍在下发、等待首次执行，或当前 Edge 版本尚未支持状态上报 |
| **规则已停用** | 规则已停用，Edge 不再执行它，展示的是停用前最后一次已知结果 |

运行详情抽屉包含两个标签页：

- **当前状态**：每 15 秒自动刷新。展示最近执行信息（执行时间、执行耗时、执行结果、查询结果数、最近成功时间、连续失败次数等）、告警实例统计（活跃实例总数及 Threshold / AnyData / NoData 分类计数、最近产生的事件类型），以及 Edge 与配置信息（Edge 集群、Edge 实例、Edge 版本、在线状态、最近心跳）。当规则匹配到多个数据源时，可在抽屉右上角切换数据源分别查看。
- **执行历史**：记录关键执行摘要，包括执行失败、产生事件、告警恢复和定期采样，不保证每轮评估都生成一条记录。支持选择最近 15 分钟、1 小时、4 小时或 1 天的时间范围（最长 24 小时）；匹配记录超过 200 条时仅展示最近 200 条，请缩小时间范围查看。

<Note>
执行历史依赖服务端配置 VictoriaLogs 查询地址。未配置时执行历史标签页会提示"暂不可用"，当前状态不受影响。旧版本 Edge 不支持运行状态上报，此类规则的状态列会显示为「等待运行状态」。
</Note>

## 自定义列

点击列表右上角的列配置按钮，您可以：

- **显示/隐藏列**：勾选或取消勾选需要展示的列
- **调整列顺序**：拖拽调整各列的显示顺序

系统会记住您的列显示偏好，下次访问时自动应用。

<Tip>
当您添加标签类型的列时，对应的标签筛选条件也会自动出现在条件栏中，方便您快速过滤。
</Tip>

## 查看告警详情

点击列表中的任意一行，或点击告警标题，即可打开活跃告警详情抽屉，内容分为以下区块：

- **告警概览**：当前状态（活跃）、级别、活跃时长、通知次数
- **时间信息**：首次触发、最近评估、最近通知、最后更新
- **规则与来源**：告警规则、检测方式（阈值判定 / 数据存在 / 数据缺失）、数据源名称、数据源类型、实例类型、查询 Ref
- **当前值**：触发告警的查询结果值快照
- **告警维度**：告警的去重维度
- **事件标签**：告警事件携带的标签
- **告警注解**：告警事件携带的注解
- **备注描述**：规则的备注描述（如有）
- **诊断信息**（折叠）：告警 Hash、生命周期 ID、规则 ID、数据源 ID、Edge 集群、Edge 实例 ID、规则版本

标签与值均以 `key=value` 形式展示，点击即可复制，方便排障时引用。

## 关闭告警

如果某些活跃告警已不再需要关注（例如告警规则已调整但旧告警尚未自动恢复），您可以手动关闭：

<Steps>
<Step title="选择告警">
在列表中勾选需要关闭的告警，支持多选。
</Step>
<Step title="提交关闭">
点击**活跃告警关闭选中**按钮，确认提交后，所选告警将从活跃告警列表中移除。
</Step>
</Steps>

<Warning>
关闭操作仅将告警从活跃告警列表中移除。如果告警条件仍然满足，下次告警引擎执行检查时，该告警会重新出现。
</Warning>
