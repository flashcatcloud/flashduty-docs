当需要统一调整一批告警规则的配置时，可以在规则列表中选中多条规则进行批量编辑，避免逐条修改。批量操作支持修改附加标签（Labels）、自定义字段（Annotations）、数据源、检测频率、规则时区、生效时间、查询时间偏移、协作空间、重复发送配置、调试日志等字段。

## 操作入口

1. 进入告警规则列表页面；
2. 勾选需要修改的多条规则；
3. 点击批量编辑入口，在弹出的对话框中选择要修改的「字段」；
4. 按字段填写修改内容，确认后提交。

## 批量编辑附加标签 / 自定义字段

附加标签（Labels）和自定义字段（Annotations）支持两种更新方式：

| 更新方式 | 说明 |
|----------|------|
| **增量修改**（默认） | 在所选规则现有内容的基础上执行一组修改操作，每个操作可以是「设置键值对」或「删除指定 key」。设置时若 key 不存在则新增，若已存在则更新其值；删除操作仅移除指定的 key，其余内容不受影响 |
| **全量替换** | 用本次填写的内容整体替换所选规则的附加标签或自定义字段，规则上原有的其他 key 会被移除 |

### 候选值建议

在增量修改模式下，系统会汇总所选规则上已有的 key 和 value 作为候选值：

- 输入 key 或 value 时提供自动补全，并标注每个候选值在所选规则中的覆盖情况（如 `3/10` 表示 10 条所选规则中有 3 条包含该值）；
- 候选值仅作为参考，也可以直接输入新的 key 或 value；
- 候选值建议最多支持 **500 条规则**，所选规则超过 500 条时不加载候选值，仍可手动输入完成编辑。

### 影响预览

填写修改操作后，对话框会基于候选值统计实时展示本次修改的影响范围，例如：

- 设置 `key=value`：提示将新增多少条、更新多少条、多少条保持不变；
- 删除某个 key：提示会影响多少条规则，其余规则不变。

## 批量更新结果

提交后系统按规则逐项执行更新，并逐项返回结果：

- 全部成功时无逐项消息，修改即已生效；
- 部分失败时，对话框会列出失败规则的名称及对应的失败原因，便于定位问题后重试；成功的规则不受影响。

<Note>
批量更新以单条规则为粒度执行，不存在整体回滚。部分失败时请根据提示的失败原因修正后，仅对失败的规则重新操作。
</Note>
