仪表盘（Dashboard）把查询固化成图表：一个仪表盘由页签、分组和面板组成，每个面板绑定一个数据源与一组查询，打开时按当前时间范围和变量选择实时取数。它适合把日常巡检、故障复盘反复要看的几张图固定下来，不必每次去[查询工作台](/zh/monitors/explore/explore)重写查询。

## 入口

- **菜单**：左侧菜单 **可视化 → 仪表盘**。能查看数据源的成员即可看到该入口。
- **从查询工作台**：把跑出结果的查询直接**保存到仪表盘**，见[新建与保存](#新建与保存仪表盘)。

能否查看或编辑某个仪表盘，取决于它所在的**目录**，详见[权限](#权限)。

## 列表与目录

页面左侧是与告警规则共用的目录树，右侧是当前目录下的仪表盘。目录的创建、重命名、移动和删除都在树上完成，规则见[文件夹管理](/zh/monitors/folders/folders)。

- 搜索只在**当前目录**内进行。
- 目录、搜索词和页码会保留在页面地址中，链接可以分享，从仪表盘返回列表时也会还原。
- 每行的 **更多** 菜单提供：移动到其他分组、克隆到本分组、克隆到其他分组。克隆会生成一个标题带「副本」后缀的新仪表盘，**不带历史版本**；移动或克隆到其他目录时，您需要对目标目录可读。

## 新建与保存仪表盘

**新建**：在列表页右上角点击 **新建仪表盘**（需「仪表盘管理」权限）。新仪表盘默认时间范围为「过去 1 小时」，包含一个空的 `Overview` 页签。

**从查询工作台保存**：在工作台点击 **保存到仪表盘**，选择新建仪表盘或现有仪表盘，填写图表标题并选择图表类型（会按查询结果推荐，可以修改）。保存到现有仪表盘时，面板会追加到第一个页签的底部，在您点击保存前不会生效。

<Note>
仪表盘不支持 Prometheus 的 Both 查询方式。工作台里以 Both 运行的查询，保存为面板时会按 Range 保存。
</Note>

**编辑与保存**：

- 编辑时的所有修改都是草稿，可以撤销 / 重做（`⌘Z` / `⌘⇧Z`）。草稿只保存在当前浏览器页面，**刷新即丢失**，离开页面前会提醒您。
- 保存时可以填写**版本说明**（选填，最多 1024 字符）。每次保存都会产生一个新版本。
- 如果您预览时选择的相对时间范围与默认值不同，保存时可以勾选把它设为本仪表盘的默认时间范围。
- 如果别人在您编辑期间保存过，保存会失败，您可以选择另存为副本、放弃草稿并载入最新版本，或继续编辑。草稿不会自动合并。

## 页签、分组与面板布局

- **页签**是仪表盘的一级分区。双击标题可以重命名。
- **分组**位于页签内，可以折叠。**折叠的分组不加载数据**，适合放不常看的图。
- **面板**按 24 列网格摆放，可以拖动、缩放、复制和删除。
- 面板描述默认显示在标题右侧的 ⓘ 提示中，也可以设为显示在标题下方的副标题；描述不支持图片与 HTML。
- 只有当前页签和已展开分组中的面板会加载，视口内的面板优先。

数量上限见[配额与限制](#配额与限制)。

## 面板类型与查询

面板编辑器左侧是预览，右侧是配置。目前可用的图表类型：

| 图表类型 | 适合展示 |
|---------|------|
| **时序** | 随时间变化的趋势，支持多条曲线对比 |
| **表格** | 按行列展示明细，适合即时查询结果 |
| **单值** | 一个关键数字，支持阈值着色 |
| **文本** | Markdown 说明文字，不需要数据源与查询 |

柱状、仪表与日志类型将在后续版本支持。

**数据源**：支持 Prometheus、MySQL 和 Loki。可以选固定数据源，也可以选**数据源变量**，切换变量即可让整个仪表盘换数据源。

**查询方式**由数据源和图表类型自动决定：表格取即时值，时序图和单值图取区间数据，MySQL 按时间窗口查询。

| 配置项 | 说明 |
|--------|------|
| **查询表达式** | Prometheus / Loki 面板可以使用 `$变量名` 或 `${变量名}` 引用模板变量，以及[内置时间变量](#内置时间变量)。MySQL 面板不支持变量 |
| **多查询** | 只有时序图支持多条查询（`A`~`Z`）。切换到其他图表类型时需要选择保留哪一条 |
| **序列名称** | 时序图中每条曲线的显示名，如 `{{instance}}` 会替换为 `instance` 标签的值；留空显示全部标签 |
| **最小步长** | Prometheus 区间查询的步长下限，默认 15s |
| **取值字段** | 单值图显示的字段，区分大小写 |
| **单位 / 小数位 / 阈值** | 阈值可设「越高越差」或「越低越差」，分 warning / critical 两级，按文字或背景着色 |
| **表格列配置** | 为数值列设置单位、阈值和着色；背景着色可以应用到整行 |
| **值映射** | 把数值显示为文字和颜色（如 0 显示为「离线」并标红）。按顺序取第一条命中的映射，映射颜色优先于阈值色 |
| **下钻** | 面板链接与数据链接，见[点值筛选与下钻链接](#点值筛选与下钻链接) |

修改查询后按回车（或 `⌘/Ctrl + Enter`）运行预览；修改数据源、图表类型或时间会自动重跑，显示配置（单位、阈值等）即时生效。**保存不要求预览成功。**

### 面板级查询选项

以下选项作用于该面板的**全部查询**：

| 选项 | 说明 |
|------|------|
| **最大点数** | 每条序列最多返回的点数，决定查询步长。留空时按面板宽度自动计算 |
| **相对时间** | 让面板固定查询最近一段时间，不跟随仪表盘的时间范围，如 `5m` |
| **时间偏移** | 把查询时间整体前移，如 `1d` 可以和昨天同一时段对比 |
| **对比** | 同环比，见[同环比对比](#同环比对比) |

时长写作「数字 + 单位」（`s` / `m` / `h` / `d` / `w`），如 `5m`、`1h`、`1d`。设置了相对时间或时间偏移的面板会在标题旁标出实际查询的时间，提醒查看者它不跟随全局时间。

### 内置时间变量

在面板的查询表达式中可以直接使用以下变量，它们按该面板的时间窗口和步长自动计算：

| 变量 | 含义 |
|------|-----------|
| `$__interval` | 查询步长，如 `30s`，由时间范围与最大点数算出，不小于最小步长 |
| `$__rate_interval` | `步长 + 15s` 与 `60s` 中的较大值，适合直接用于 `rate()` |
| `$__range` | 时间窗口的长度，如 24 小时窗口为 `86400s` |
| `$__auto` | Loki 即时查询中为整个窗口的时长（如 `1h`、`5m`）；Loki 区间查询中等同于 `$__interval` |

可用范围：

| 数据源 · 查询方式 | 可用变量 |
|------------------|------------------|
| Prometheus · 区间 | `$__interval`、`$__rate_interval`、`$__range` |
| Loki · 区间 | `$__auto`、`$__interval`、`$__range` |
| Loki · 即时 | `$__auto`、`$__range` |

<Note>
内置时间变量只能用在**面板查询表达式**中，不能用于模板变量的候选查询，也不支持 `:raw` 之类的格式后缀。MySQL 面板不可用。用在不支持的位置时，仪表盘无法保存。
</Note>

## 模板变量

变量栏位于画布上方，每个变量是一个筛选项。编辑时点击变量栏末尾的 **管理变量** 可以新增、修改或删除变量。

| 类型 | 取值来源 | 配置项 |
|------|---------|--------|
| **Datasource** | 一个具体数据源 | 数据源类型（Prometheus / MySQL / Loki）、默认数据源 |
| **Custom** | 手写的候选列表 | 每行一个候选，`显示名=值` 或纯值 |
| **Query** | 查询数据源得到候选 | 数据源（固定或数据源变量）+ 查询 + 候选刷新时机 |

**Query 变量的候选查询**：

- **Prometheus**：填写 `label`（必填）和 `metric`（选填），可添加 `= / != / =~ / !~` 标签过滤。
- **SQL 数据源**：填写表达式和取值字段。
- **Loki**：填写表达式和字段。字段必须是流的标签名（不支持点分或 JSON 字段名），候选值取自仪表盘时间范围内选中流的该标签值；表达式留空表示所有流。

表达式中可以引用其他仪表盘变量，但不能使用内置时间变量。点击 **预览候选** 可以确认查询是否正确。

**命名与引用**：

- 变量名以字母或下划线开头，只能包含字母、数字和下划线，最长 64 个字符，不能以 `__` 开头，不能重名。
- 改名会自动更新所有引用该变量的地方。
- 仍被引用的变量不能删除，需要先清理引用。

**单选、多选与「全部」**：

- **单选**变量必须有一个值，默认取第一个候选。
- **多选**变量可以不选，**不选即「全部」**。「全部」表示不做筛选，而不是勾选当前所有候选。
- 允许「全部」的变量可以清空选择；不允许的变量必须保留一个值。
- 地址中没有指定值时，变量取默认值；没有默认值则取第一个候选（允许「全部」的变量取「全部」）。
- 通过链接带入的值即使不在候选中也会生效，控件会标出该值不在候选中。

变量的选择会写入页面地址，分享链接时会一起带上。

## 时间范围与自动刷新

- **时间范围**：默认使用仪表盘保存的默认时间范围。可设为默认的选项有 15m / 30m / 1h / 3h / 6h / 12h / 24h / 7d。
- **自动刷新**：仪表盘可保存的刷新频率为关闭 / 30s / 1m / 5m；查看时可以临时选择更多档位（10s 到 1h）。选择后立即刷新一次。
- **显示时区**：在时间选择器底部点击 **修改时区**，可以选择城市时区，或以下三个常用项。设置只作用于仪表盘，保存在当前浏览器中。相对时间范围（如「过去 1 小时」）表示时长，不受时区影响。

| 常用项 | 含义 |
|--------|------|
| **默认** | 跟随个人设置的生效时区 |
| **浏览器时间** | 跟随当前浏览器所在时区 |
| **协调世界时** | 固定使用 UTC |

## 同环比对比

在时序图或单值图的**查询选项 → 对比**中选择「前 1 天」或「前 1 周」，同一条查询会在前一个周期再运行一次，结果显示在同一张图中：

- **时序图**：对比曲线显示为同色虚线，图例标注周期，如「序列名（1 天前）」。
- **单值图**：显示相对对比周期的变化百分比，如「▲ 12.3% 较 1 天前」。对比值为 0 或缺失时不显示百分比。
- 对比查询失败只会少一条对比线，不影响本期结果。

## 多图光标联动

在任意一张时序图上移动鼠标，同一仪表盘中的其他时序图会同步显示该时刻的竖线，方便对齐多个指标。设置了相对时间或时间偏移的面板不参与联动。

## 点值筛选与下钻链接

**点值筛选**：点击图表中的数据（时序图的点、单值、表格单元格）时，如果数据的标签名或列名与某个仪表盘变量同名，可以选择「按 `k = v` 筛选」，把该变量设为这个值，整个仪表盘随之刷新。数据源变量不参与筛选。

**数据链接**：为面板配置数据链接后，点击数据点可以跳转到外部地址（`http(s)://`）或站内地址（`/` 开头），链接中可以带上被点数据的值、标签和时间：

- 时序图可以把一条链接设为**单击直达**（每个面板最多一条）。单值图和表格只有一条链接时直接打开，多条时弹出菜单。
- 插入的值会自动 URL 编码；需要原样拼接到路径中时写成 `${xxx:raw}`。
- 可用占位符：`${__value.raw}`（值）、`${__value.time}`（时间，毫秒）、`${__series.name}`（序列名）、`${__field.labels.<标签名>}`（标签值）、`${__from}` / `${__to}`（时间范围起止，毫秒）、`${__url_time_range}`（时间范围参数）、`${__all_variables}`（全部变量参数），以及任意仪表盘变量名。

**面板链接**：显示在面板标题旁，默认在新标签页打开，可使用上述除数据点外的占位符。

## 分享

仪表盘的时间范围、变量选择、全屏面板和自动刷新都保存在页面地址中，直接复制地址即可分享当前视图。在面板全屏时点击 **复制面板链接**，打开后会直接全屏显示该面板。

<Note>
仪表盘**不支持**公开或匿名分享。打开链接的人需要登录，并对仪表盘所在目录及面板使用的数据源有权限。
</Note>

## 全屏与查询详情

鼠标悬停在面板标题上时，可以 **编辑**（需管理权限）、**全屏** 或 **重试**。

- 全屏时可以单独修改该面板的时间范围，不影响其他面板。
- 全屏时可以 **复制面板链接** 或 **下载数据 CSV**。
- **查询详情**列出每条查询的表达式和状态，点击 **在查询工作台打开** 可以带着当前变量和时间去[查询工作台](/zh/monitors/explore/explore)调试。
- 快捷键：在面板上按 `v` 切换全屏，按 `e` 进入编辑。

## 版本历史与恢复

在查看页右上角点击 **⋮ → 版本历史**：

- **对比**：勾选两个版本后点击 **对比**，查看两版定义的 JSON 差异。
- **恢复**：在对比页点击 **恢复到 vN**。恢复会以旧版内容**产生一个新版本**，当前版本仍保留在历史中。
- 每个仪表盘只保留最近 **20** 个版本。

## 删除与回收站

删除的仪表盘进入回收站，**30 天**后连同历史版本永久删除。

控制台暂无回收站页面。如需恢复，请使用 Open API 查询回收站（`/monit/dashboard/trash/list`）并恢复（`/monit/dashboard/restore`）；原目录已不存在时，需要指定恢复到哪个目录。

## 权限

| 操作 | 需要的权限 |
|------|-----------|
| 查看仪表盘 | 「数据源查看」权限，且对所在目录可读 |
| 新建、编辑、移动、删除、克隆、恢复版本 | 「仪表盘管理」权限，且对所在目录（及目标目录）可读 |
| 面板显示数据 | 对面板使用的数据源有查询权限 |

- 目录的可读范围由目录上绑定的团队决定，主体账号和 Admin 可以读取所有目录，规则见[文件夹管理](/zh/monitors/folders/folders)。
- 对面板使用的数据源没有权限（或数据源已停用、不存在）时，该面板显示「无该数据源权限」。数据源授权见[数据源管理](/zh/monitors/data-sources/data-sources)。

## 导出 JSON

在查看页点击 **⋮ → 导出 JSON**，可以下载当前版本的完整定义，用于备份或提交到版本库对比。控制台暂不支持导入。

## 面板状态与常见问题

| 面板显示 | 原因与处理 |
|------------|------|
| 没有数据 | 查询成功，但该时间范围内没有数据 |
| **部分失败** | 部分查询失败，悬停查看原因；成功的部分照常显示 |
| 结果与图表配置不匹配 | 查询结果的形态不适合该图表类型（如表格拿到了时序数据），请更换图表类型或调整查询 |
| 变量未解析 | 面板依赖的变量还没有值，请先在变量栏完成选择 |
| 无该数据源权限 | 见[权限](#权限) |
| 查询超时 / 结果超出大小限制 | 缩小时间范围或精简查询 |
| 查询失败 | 查看错误信息，点击 **重试** 重新运行该面板 |

如果别人在您查看期间保存了仪表盘，页面会自动载入最新版本。
