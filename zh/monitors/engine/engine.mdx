告警引擎（`monitedge`）是部署在您私有网络中的核心组件，负责从 Flashduty SaaS 端同步告警规则，从本地数据源读取数据进行异常判定，并将告警事件推送到 SaaS 端进行后续处理。

**菜单入口**：告警引擎

告警引擎页面包含三个标签页：**告警引擎状态**、**引擎安装/升级**、**引擎失联告警**。

## 告警引擎状态

展示所有已注册的告警引擎实例信息，列表每 5 秒自动刷新。每页条数的选择记在浏览器本地，下次打开这个列表时沿用。

| 列信息 | 说明 |
|--------|------|
| **引擎集群名字** | 同名实例组成一个集群，共同分片处理告警规则 |
| **引擎实例 IP** | 实例运行的 IP 地址 |
| **引擎实例端口** | 实例监听的端口号 |
| **上次心跳时间** | 最近一次向 SaaS 上报心跳的时间，附带在线/离线状态指示 |
| **引擎实例版本** | 当前运行的 `monitedge` 版本号 |

<Note>
引擎实例超过 30 秒未上报心跳，状态会标记为离线（红色）。离线的引擎实例会显示**删除**按钮，您可以点击清除已不存在的实例记录。
</Note>

### 集群数据源 MD5 校验

同一集群内的多个引擎实例应该使用相同的数据源配置。如果集群内不同实例的数据源配置不一致，集群名称前会显示红色警示标记，请检查各实例的配置文件。

## 引擎安装/升级

提供一键生成安装和升级命令的功能，支持三种部署方式。

### 安装配置

<Steps>
<Step title="选择部署方式">
选择 **Linux**、**Docker** 或 **Kubernetes**。
</Step>
<Step title="设置引擎集群名字">
同机房部署多个实例时，使用相同的集群名字可组成高可用集群。不同机房使用不同的集群名字。

<Tip>
一般每个机房分别部署一套告警引擎集群，集群名字建议设置为机房名称。
</Tip>
</Step>
<Step title="选择 API Key">
从下拉列表中选择已有的 API Key，或点击**管理 API Key**创建新的 Key。
</Step>
<Step title="复制命令执行">
页面会根据您的选择自动生成安装命令和升级命令，复制后在目标机器上执行即可。
</Step>
</Steps>

<Note>
Linux 方式生成的安装/升级命令会从 `https://static.flashcat.cloud/monitedge/install.sh` 拉取安装脚本。命令里的脚本地址是固定的，不能改成其他脚本源。

离线或内网环境需要把 `install.sh` 和它引用的 `releases/download/<vX.Y.Z>/` 制品、`checksums.txt` 一起镜像到内网，并替换命令里的脚本地址；脚本内部的制品下载地址未参数化，镜像路径与默认公网路径不一致时需要一并调整脚本内容。
</Note>

### 部署方式对比

| 部署方式 | 适用场景 |
|----------|----------|
| **Linux** | 直接在物理机或虚拟机上安装，使用 systemd 管理进程 |
| **Docker** | 容器化部署，适合已有 Docker 环境的场景 |
| **Kubernetes** | 适合云原生环境，以 Deployment 方式部署 |

### 自动升级

Linux 部署的告警引擎支持由服务端推送的自动升级，部署方式选择 **Linux** 时页面上会提示：

> Linux 环境下的告警引擎支持服务端推送的自动升级，开启后无需手动执行升级命令；上方命令仍可作为手动升级的备用方式

推送与否由平台侧决定，控制台没有开关：完成上述安装配置后，Linux 实例会在收到推送时自行升级；尚未开通推送时，继续复制页面生成的**升级命令**在目标机器上执行即可。

| 项目 | 说明 |
|------|------|
| **适用部署方式** | 仅 Linux（systemd）部署生效；Docker 与 Kubernetes 部署不参与自动升级，升级方式仍是更换镜像版本 |
| **执行方式** | 引擎收到推送后自行下载并校验新版本、替换并重启，无需在目标机器上执行命令 |
| **升级成功** | 新进程有约 180 秒观察期，首次心跳成功即视为升级成功 |
| **失败回滚** | 观察期内没有成功心跳，或新版本连续 3 次启动仍未提交心跳时，自动回滚到上一版本；已回滚的版本在平台发布更新版本之前不会重复尝试，同一次升级失败后约 30 分钟内不再重试 |
| **退出自动升级** | 启动参数 `--alerter.disableAutoUpdate` 可让单个实例不再接受自动升级；容器环境、二进制所在目录不可写时也会自动跳过 |

自动升级需要引擎能够访问制品镜像，默认使用公网镜像；离线或内网环境需通过 `--alerter.updateMirror` 指向内部镜像，详见[引擎 CLI 参数参考](#引擎-cli-参数参考)的“自动升级参数”。

## API Key 管理

API Key 用于告警引擎与 SaaS 端的身份认证。您可以在引擎安装/升级页面点击**管理 API Key**打开管理面板。

### 功能说明

| 操作 | 说明 |
|------|------|
| **新增** | 创建新的 API Key，需要输入名称。每个账户最多创建 5 个 API Key |
| **重命名** | 点击 Key 名称即可编辑修改 |
| **删除** | 删除不再使用的 API Key，需要具备 API Key 删除权限 |

管理面板中还会展示每个 API Key 的当前状态：

| 状态 | 说明 |
|------|------|
| **启用中**（绿色图标） | API Key 正常工作，引擎实例可以使用该 Key 与 SaaS 端通信 |
| **禁用中**（黄色图标） | API Key 已被禁用，使用该 Key 的引擎实例将无法与 SaaS 端通信 |

<Warning>
删除 API Key 后，使用该 Key 的所有引擎实例将无法与 SaaS 端通信。请确保在删除前已将相关引擎切换到其他有效的 API Key。
</Warning>

### 权限要求

创建和删除 API Key 需要对应的操作权限。没有权限时，请联系管理员前往访问控制页面授权。

## 引擎 CLI 参数参考

`monitedge` 通过命令行参数配置。以下是与告警推送相关的参数。

### 告警推送参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `alerter.serverURL` | `https://api.flashcat.cloud` | Flashduty SaaS 服务地址 |
| `alerter.serverAPIKey` | —（必填） | 用于与 SaaS 端认证的 API Key |
| `alerter.serverTimeout` | `30s` | 单次推送请求的超时时间 |
| `alerter.alertRuleDeliveryWorkers` | `64` | 告警事件推送的并发数。同一条告警的事件按顺序推送 |
| `alerter.alertRuleEventQueueSize` | `2048` | 每个并发通道的待推送事件队列容量 |
| `alerter.alertRuleEventBatchSize` | `200` | 单次批量推送的事件条数上限，最大 200，且单批不超过 4 MB |
| `alerter.alertRuleDeliveryResponseBytes` | `8MB` | SaaS 端响应体大小上限，超出后本次推送按失败处理 |
| `alerter.serverSleep` | `3s` | 推送失败后的首次重试间隔，之后每次翻倍，最长 30 秒，直到推送成功 |

**调优建议**：

- **高吞吐场景**（规则数量多、告警频率高）：可适当提高 `alerter.alertRuleDeliveryWorkers`（例如 128），减少事件积压；必要时同步提高 `alerter.alertRuleEventQueueSize`。
- **网络或 CPU 受限场景**：可适当降低 `alerter.alertRuleDeliveryWorkers`（例如 16–32），避免并发出站连接过多影响其他业务流量。
- **网络质量差、丢包率高的场景**：可适当增大 `alerter.serverSleep`（例如 10s），减少拥塞期间的无效请求。

### 事件标题参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `alerter.titleRule` | 空 | 告警事件标题的生成规则，对该引擎上的所有规则生效。取值含 `{{` 时按 Go 模板渲染，可用变量与[备注模板](/zh/monitors/alert-rules/description-template)相同；否则按占位符替换标签，推荐 `[key]` 写法，如 `'[check] / [data_source_name]'`。命令行传参时请用单引号包住取值。留空时标题为 `check / data_source_name`（事件带 `resource` 标签时追加 ` - resource`）。规则自定义字段里配置了 `title` 时，以 `title` 的渲染结果为准 |

### 自动升级参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `alerter.disableAutoUpdate` | `false` | 关闭服务端推送的自动升级。设为 `true` 后该实例不再执行自动升级；容器环境会被自动识别并跳过，该参数优先级更高 |
| `alerter.updateMirror` | `https://static.flashcat.cloud/monitedge` | 自动升级制品的镜像根地址。引擎按 `<镜像根地址>/releases/download/<vX.Y.Z>/` 下载制品与校验文件；离线或内网环境需要改为内部镜像 |

自动升级仅在 Linux（systemd）部署下生效，并且要求引擎能够访问制品镜像。不满足条件时，请在控制台复制**升级命令**手动升级。
