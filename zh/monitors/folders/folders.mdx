Monitors 使用树形文件夹结构来组织和管理告警规则。每条告警规则都必须归属于某个文件夹，您可以通过层级结构进行分类管理，并为不同层级配置团队访问权限。

**菜单入口**：告警规则（左侧树形导航）

## 文件夹树

页面左侧展示文件夹树形结构。您可以：

- **新建文件夹**：在树中创建子文件夹
- **选择文件夹**：点击文件夹查看其详情和所属的告警规则
- **层级嵌套**：支持多级嵌套，满足复杂的组织结构需求

## 文件夹详情

选中文件夹后，右侧展示该文件夹的详细信息：

| 属性 | 说明 |
|------|------|
| **名称** | 文件夹名称，有权限的用户可点击编辑图标修改 |
| **备注** | 文件夹的补充说明，有权限的用户可点击编辑图标修改 |
| **更新者** | 最后修改该文件夹的用户 |
| **创建者** | 创建该文件夹的用户 |
| **更新时间** | 最后修改时间 |
| **创建时间** | 创建时间 |

## 移动规则到其他文件夹

您可以把告警规则移到别的文件夹。规则本身不变，只是换了归属。

- **单条规则**：点击行尾 `⋮` 菜单里的 **移动**。
- **多条规则**：勾选规则后，点击列表上方的 **移动**。
- **在规则编辑页**：打开规则后，区块 1 的 **所属分组** 是一个下拉框，选中目标分组并保存即完成移动。

两种入口都打开 **移动到其他分组** 对话框：

| 操作 | 说明 |
|------|------|
| **搜索分组** | 输入关键词按名称过滤文件夹树，命中结果保留完整层级路径 |
| 选择文件夹 | 在树里点击目标文件夹 |
| **确定** | 选中的就是规则当前所在的文件夹时，按钮保持禁用 |

文件夹树加载失败时会显示 `加载分组失败` 和 **重试**。移动成功后提示 `移动成功`，列表自动刷新；失败时提示 `移动失败`，规则仍留在原文件夹。

## 团队访问控制

文件夹支持基于团队的访问控制，通过为文件夹绑定团队来限制操作权限。

### 权限继承

文件夹详情下方的**权限继承**表格展示从当前文件夹到根节点的完整路径，以及每个层级绑定的团队。

| 列信息 | 说明 |
|--------|------|
| **节点路径** | 从根节点到当前节点的完整路径 |
| **关联团队** | 该层级绑定的团队，有权限的用户可点击编辑图标修改 |

### 权限判定规则

系统按以下规则判定用户是否有操作权限：

1. **主体账号**始终拥有所有文件夹的操作权限
2. 如果当前文件夹或其任何父级文件夹绑定了团队，用户必须属于对应团队才有权限
3. 如果文件夹链路上没有绑定任何团队，所有用户都可以操作

<Tip>
建议为顶层文件夹绑定团队，子文件夹会自然继承访问范围。这样可以实现按部门或按项目划分告警规则的管理权限。
</Tip>
