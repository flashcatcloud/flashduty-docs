查询工作台（Explore）是 Flashduty Monitors 中的即席查询界面，用于在不创建告警规则的前提下对数据源执行临时查询。支持 Prometheus、Loki、VictoriaLogs、阿里云 SLS、腾讯云 CLS 以及 MySQL、PostgreSQL、Oracle、ClickHouse、Elasticsearch 等数据源。

## 访问入口

- **从数据源列表**：进入 **监控 → 数据源**，点击目标数据源行的「查询工作台」入口。
- **直接 URL**：访问 `/monit/explore`，在页面内选择数据源。
- **从故障/告警标签**：在故障详情或告警详情的标签区域，查询类标签行右侧的「去查询」图标会带着告警触发时的查询和时间窗口直接打开工作台。

## 查询类型

不同数据源支持不同的查询类型，在编辑器上方切换：

| 数据源 | 查询类型 | 说明 |
|--------|---------|------|
| Prometheus | 图表 + 原始 | 同时展示折线图和原始样本 |
| Prometheus | 仅图表 | 只展示折线图（range 查询） |
| Prometheus | 仅原始 | 只展示原始样本（instant 查询） |
| Loki | Range | 区间查询，返回时间范围内的日志行 |
| Loki | Instant | 即时查询，返回当前时刻匹配的日志行 |
| VictoriaLogs | 原始日志 | 返回原始日志行 |
| VictoriaLogs | 即时统计 | 返回即时聚合统计 |
| VictoriaLogs | 趋势统计 | 返回区间趋势统计 |
| SLS / CLS | — | 无查询类型选择器，由供应商分类日志/表格 |
| MySQL / PostgreSQL / Oracle / ClickHouse / ES | — | SQL/查询表达式直接执行 |

Prometheus 数据源的编辑器工具栏提供「自动补全」开关，控制 PromQL 输入时的自动补全；该偏好按数据源分别记忆。

## 结果展示

结果区域根据数据源和查询类型自动布局：

- **Prometheus**：上下分屏，上方折线图（Graph）、下方原始样本（Raw），支持拖拽分隔。
- **其他数据源**：单结果区，根据查询类型展示日志视图、表格视图或样本视图。
- **Matrix 视图**：Prometheus instant 查询返回 range vector（如 `node_cpu_seconds_total[5m]`）时，Raw 区会切换为 Matrix 视图：按序列折叠分组（多序列默认收起），逐采样点显示时间戳、值及与上一点的间隔；偏离众数间隔的点会标黄，提示缺样本或抓取不稳。

### 图表功能

- **拖拽缩放**：在折线图上拖选时间段可缩放至该范围。
- **曲线图例筛选**：图例区支持按标签值搜索和按 metric 名称分组；曲线超过 10 条时出现搜索框，可输入关键词过滤图例。点击图例项可隐藏或单独显示对应曲线，按住 Ctrl（macOS 为 Cmd）或 Shift 点击可加选多条；图例区的筛选按钮支持按标签维度（facet）勾选取值过滤曲线：同一标签键内的多个取值之间是「或」，不同标签键之间是「与」，某个键一个值都未勾选时该维度不参与过滤，并支持一键清除全部筛选；超过展示上限的曲线会折叠，点击展开。
- **Tooltip**：悬停查看各曲线在该时间点的值，超出展示上限的曲线会在 Tooltip 中汇总提示。
- **样本视图**：即时查询返回的原始样本支持表格（Table）与原始文本（Raw）两种展示方式，切换只是换一种视图，不会重新查询。

### 日志时间分布

当查询类型包含日志时，结果区上方会展示日志时间分布图：

- 时间范围 ≤ 24 小时：自动加载。
- 24 小时 – 30 天：需手动点击加载。
- 超过 30 天：不支持加载，请将时间范围缩小到 30 天以内。

时间分布是主日志查询的补充视图：它与日志正文共用查询条件和时间窗口，但独立加载——时间分布加载较慢或失败不影响下方日志正文的展示。

### 日志视图

日志类数据源的查询结果以日志视图展示，支持以下交互：

- **排序切换**：最新 / 最早，仅翻转当前批次结果的显示顺序，与查询参数「检索方向」（决定拉取哪一批数据）互不影响。
- **换行开关**：控制日志正文是否自动换行，偏好保存在浏览器本地。
- **加为列**：展开单条日志详情后，可将字段「加为列」，日志区切换为表格视图，表头随列出现。
- **字段过滤（只看 / 排除）**：展开日志详情后，点击字段值旁的 +/- 按钮，会把过滤条件追加到查询表达式并立即重跑。是否提供按钮取决于数据源语法：Loki（追加 label filter，字段名须为合法标识符）和 VictoriaLogs（追加 `| filter` 管道，任意字段名均可）支持；SLS 仅检索语句（不含 `|` 的分析语句）支持；腾讯云 CLS 仅 Lucene 语法支持；SQL 类数据源不支持。字段名无法在该语法中安全表达（如含空格）时按钮不显示。
- **复制字段**：字段值支持一键复制。
- **条数提示**：结果区显示实际生效的返回条数；命中条数上限时会提示还有更多数据。

## 查询参数

除查询表达式外，部分数据源支持私有参数：

| 参数 | 适用数据源 | 说明 |
|------|-----------|------|
| 返回条数（limit） | Loki / VictoriaLogs / SLS / 腾讯云 CLS | 限制返回行数，默认 100 条 |
| 最小 step（秒） | Prometheus | range 子查询 step 的下限，最小值为 1；留空则不设下限，由后端按最大数据点数自动计算。该控件位于图表工具栏，仅影响分辨率，不改变查询内容 |
| 检索方向 | Loki / VictoriaLogs / SLS / 腾讯云 CLS | 最新优先或最早优先 |
| 项目 / 日志库 | SLS | 必填，拼入请求地址 |
| 地域 / 日志主题 / 语法 | 腾讯云 CLS | 必填；语法可选 Lucene / CQL，默认 CQL |
| PowerSQL | SLS | 开启 PowerSQL 模式 |
| 时间宏 | SQL 数据源 | `$__timeFilter(列名)`、`$__timeFrom()`、`$__timeTo()` 让时间范围生效 |

## 编辑器自动补全

查询编辑器默认开启自动补全（指标名、标签等）。对于指标基数极大的 Prometheus 数据源，可以按数据源单独关闭自动补全，避免每次输入都向后端请求指标名和标签列表。该偏好按数据源保存在本机浏览器（localStorage）中，不随 URL 分享。

## 时间范围

工作台提供专属的快速时间档位：最近 5 分钟、15 分钟、30 分钟、1 小时、3 小时、6 小时、12 小时、24 小时、2 天、7 天，默认为最近 1 小时。未手动选择绝对时间时保留相对表达（如 `now-1h`），刷新或再次打开时范围随当前时间前进。

## 查询历史

每次成功执行的查询会自动存入查询历史，仅保存查询表达式，不含时间范围和结果。历史按数据源隔离，存储在浏览器本地，最多保留 200 条。超出 200 条时最早的记录会被淘汰；查询表达式过大时不会存入历史但查询本身已成功执行。可以在历史面板中删除单条或清空当前数据源的全部历史。

## 分享与 URL 状态

工作台会将当前数据源、查询表达式、时间范围和查询类型编码到 URL 参数中（`schemaVersion` + `state`）。复制浏览器地址栏即可分享当前查询状态，打开链接后会自动恢复。

- **分享按钮**：工具栏的「分享」按钮一键复制链接，链接中的时间使用上次成功查询实际执行的绝对时间窗口而非相对时间——接收者打开后看到的与你是同一段数据。尚未成功运行查询时按钮不可用。
- **链接有效性**：URL 状态带版本号。链接损坏、字段不合法或版本号未知时，页面提示「链接无效」，不会执行查询。
- 若链接中的数据源不存在、已停用或无权限，页面会提示且不自动执行。

## Edge 版本要求

查询工作台依赖 monit-edge 执行实际查询。若数据源所在集群的 Edge 版本过低或版本不一致（混合版本），页面会显示升级提示并禁用查询。需要将集群内所有 Edge 升级至要求版本后才能使用。
