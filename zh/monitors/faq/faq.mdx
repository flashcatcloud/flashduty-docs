<Accordion id="debug-rule" title="告警规则的执行不符合预期，如何调试？">
在告警规则的列表页面，有一个**调试日志开关**，您可以打开这个开关，之后告警引擎进程 `monitedge` 会输出该规则的详细执行日志，方便您排查问题。

`monitedge` 会把日志输出到标准输出（`stdout`），查看方式取决于部署方式：

| 部署方式 | 查看日志命令 |
|---------|-------------|
| Docker | `docker logs <container_id>` |
| Kubernetes | `kubectl logs <pod_name>` |
| Linux (systemd) | `journalctl -u monitedge.service -f` 或查看 `/var/log/messages` |

<Note>
`monitedge` 不会把日志写到单独的日志文件，请通过上表方式查看，或由您的日志收集系统采集。
</Note>
</Accordion>

<Accordion id="overview-dashboard" title="概览仪表盘展示了哪些信息？">
**菜单入口**：概览

概览页面提供告警规则的全局视图，由以下卡片组成：

| 卡片 | 说明 |
|----------|------|
| **告警规则总量历史趋势图** | 告警规则总数随时间的变化趋势（面积图） |
| **各协作空间告警规则数量对比** | 各协作空间的告警规则数量分布（饼图）。默认显示 Top 10，其余汇总为“其他”，可点击展开 |
| **系统事件列表** | 告警引擎产生的系统事件（如引擎失联、配置异常），可分页浏览和删除 |

<Tip>
概览页面顶部会检查您是否已安装告警引擎。如果尚未安装，系统会显示引导提示，引导您前往告警引擎页面完成安装。
</Tip>
</Accordion>

<Accordion id="clone-rule" title="如何快速克隆一条告警规则？">
在告警规则的编辑页面或详情页面，您可以找到**克隆**操作按钮。点击后会基于当前规则的配置创建一条新规则，所有配置项会被复制过来（名称除外），方便您快速创建相似的告警规则。
</Accordion>

<Accordion id="preview-query" title="如何预览告警规则的查询结果？">
在创建或编辑告警规则时，配置好查询条件后，可以点击**查询预览**按钮。系统会立即执行一次查询并展示结果，帮助您验证查询表达式是否正确、返回的数据是否符合预期，无需等到下一个检测周期。

预览报错时，常见原因：

| 提示 | 原因与处理 |
| --- | --- |
| 无法识别查询结果格式 | 控制台与告警引擎的版本可能不一致，请联系管理员 |
| JSON 格式错误 / 不支持嵌套结构 | SLS / VictoriaLogs / Loki 的调试参数（debug JSON）非法或包含嵌套结构，修正后重试 |
| 无权访问该数据源 | 数据源拒绝了授权（HTTP 403）。参照[数据源权限（团队授权）](/zh/monitors/data-sources/data-sources#数据源权限团队授权)检查授权配置，或联系数据源的负责团队 |
</Accordion>

<Accordion id="notes-format" title="告警规则的备注描述支持什么格式？">
备注描述支持 Markdown 格式，您可以使用标题、列表、链接、代码块等 Markdown 语法来组织内容。同时支持引用变量，将告警事件的标签值、查询结果等动态信息嵌入到备注中，方便值班人员快速了解告警上下文。
</Accordion>

<Accordion id="recovery-values" title="恢复通知中如何显示恢复时的数值？">
恢复通知会重新渲染备注描述，在模板中用 `{{ if eq $status "recovered" }}` 区分恢复通知即可。

- **阈值判定**：恢复方式为“未触发任一阈值就算恢复”或“结果满足条件才算恢复”时，`$values` 就是恢复时的数值。
- **数据存在**：恢复方式为“查询检测查不到数据即恢复”时，恢复时已查不到数据，`$values` 是最近一次通知时的数值。需要恢复时的数值，请使用关联查询。

写法和示例见[在恢复通知中显示恢复时的数值](/zh/monitors/alert-rules/description-template#recovery-values)。
</Accordion>
