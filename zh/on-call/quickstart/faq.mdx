## 产品介绍

<AccordionGroup>
  <Accordion id="what-is-on-call" title="什么是 Flashduty On-call？">
    Flashduty On-call 是一站式告警响应平台，为 IT 团队提供值班、告警降噪、升级和自动化能力，加速故障响应，减少损失。
  </Accordion>

  <Accordion id="is-it-for-me" title="我是否适合使用 Flashduty On-call？">
    如果您的团队有以下需求，Flashduty On-call 会很合适：

    - 需要一个地方收集公司内所有来源的告警，统一处理、跟踪和分析
    - 需要按严重程度分级，用不同渠道通知关键人员，并自动升级，避免告警无人处理
    - 日常处理告警占用大部分精力，需要降噪来解决告警疲劳
  </Accordion>

  <Accordion id="advantages" title="Flashduty On-call 相比其他平台有什么优势？">
    功能更灵活易用、服务更专业、价格更合理。欢迎联系我们获取采购指南，或查看与 [PagerDuty](/zh/on-call/comparison/vs-pagerduty)、[Opsgenie](/zh/on-call/comparison/vs-opsgenie) 的对比。
  </Accordion>
</AccordionGroup>

## 收费与订阅

<AccordionGroup>
  <Accordion id="pricing" title="Flashduty On-call 如何收费？">
    按活跃用户收费，提供免费版、标准版和商业版三个版本，详细对比见[价格页面](https://flashcat.cloud/flashduty/price/)。

    - 当月使用了商业化功能的用户即为活跃用户，必须持有 License 才能使用。
    - 每个 License 对应一个账户成员。例如只购买了一个 License，就只有一个成员能使用全部功能；其他成员仍可被邀请加入，但只能接收故障通知。
    - 每个月度周期结束后，固定 License 保持有效，临时 License 被释放；成员被删除时，其 License 自动释放。

    **License 类型**：管理员分配 License 时可选择类型。

    | 类型 | 说明 |
    | --- | --- |
    | **固定** | 在购买有效期内长期有效，不会被抢占，适合需要处理故障、参与配置的成员 |
    | **临时** | 每个周期结束时自动释放；License 充足时，可通过分配或抢占占用 |

    **没有 License 的成员**：

    - 只能被动接收告警消息；分派策略中可以选择通知他们
    - 不能查看故障列表或详情，也不能认领、关闭故障；登录控制台时会提示没有权限
    - 与其他成员共享租户的邮件、短信、电话套餐额度
  </Accordion>

  <Accordion id="subscription-expired" title="On-call 订阅过期后会怎样？">
    订阅过期后，平台冻结**新建**类操作，已有的数据和配置不受影响：

    - **告警停止接入**：所有集成不再接收新的告警事件，也不会产生新故障
    - **历史数据仍可用**：历史告警和已有故障仍可查看与处理
    - **新建入口被冻结**：新建协作空间、值班表、手动创建故障、创建作战室等入口被禁用
    - **页面常驻提示**：告警列表、故障列表与侧边栏常驻显示订阅过期提示
    - **续费后自动恢复**：续费成功后自动恢复告警接入，无需重新配置
  </Accordion>
</AccordionGroup>

## 收不到通知

<AccordionGroup>
  <Accordion id="no-voice-call" title="为什么我收不到语音通知？">
    语音电话与终端信号和手机设置关系很大。如果持续收不到，请依次排查：

    1. 中国大陆以外注册的手机号，先确认所在地区在[支持范围](#voice-numbers)内
    2. 检查手机黑名单或通话记录中是否拦截了来电（通常是 010、021 等开头的固话号码），如有请解除拦截并加入白名单
    3. 手机上没有拦截记录时，可能是运营商开通了拦截服务：
       - **移动**：通过微信公众号「中国移动高频骚扰电话防护」检查
       - **电信**：通过公众号「天翼防骚扰」检查
       - **联通**：通过公众号「沃助理」检查，或咨询客服电话
    4. 手机号做过携号转网的，请同时查询多家运营商的拦截情况
    5. 尝试重启手机、重新插卡，或把手机卡插到其他手机上，排除终端或手机卡问题

    仍未找到原因，请联系我们。
  </Accordion>

  <Accordion id="no-email" title="为什么我收不到邮件通知？">
    1. 检查垃圾邮件文件夹，如有请移出
    2. 检查邮件客户端是否设置了自动删除规则，如有请修改
    3. 联系企业邮箱管理员，确认后台是否拦截（Gmail 等企业邮箱限制较严，发送过多会被拦截），如有请将发件来源加入白名单

    仍未找到原因，请联系我们。
  </Accordion>
</AccordionGroup>

## 安全与稳定

<AccordionGroup>
  <Accordion id="stability" title="Flashduty On-call 如何确保自身稳定？">
    **SLA 承诺**：

    - **功能可用**：核心功能 99.95% 的时间可用
    - **投递时效**：99.95% 的告警在触发后 5 分钟内完成投递

    **如何保证**：

    1. **同城多活**：基础设施构建在多个数据中心之上，有状态组件均为同城多活
    2. **异步处理**：告警上报后立即进入异步流程，出错有重试，减少告警丢失风险
    3. **冗余通知**：重要告警可选择多个渠道循环通知，确保送达
    4. **全球加速**：api.flashcat.cloud 已开启全球加速，确保各地上报链路稳定
    5. **持续监控**：全面采集系统指标，定期压测，及时甚至提前发现问题
  </Accordion>

  <Accordion id="data-security" title="Flashduty On-call 如何确保数据安全？">
    1. 全栈 HTTPS，确保数据传输安全
    2. 敏感信息加密存储，日志脱敏后落盘
    3. 重要数据修改需 MFA 校验，支持操作审计
    4. 定期参加国际国内认可的第三方安全认证审核（ISO27001、ISO9001）
    5. 有需要的客户可以签署保密协议
    6. 隐私协议：[查看隐私政策](/zh/compliance/data-security)
  </Accordion>

  <Accordion id="private-deployment" title="Flashduty On-call 是否支持私有化部署？">
    支持。Flashduty On-call 提供与 SaaS 服务几乎一致的私有化版本；由于维护成本较高，收费模式与 SaaS 不同。如无必要，推荐使用云服务。如需私有化版本，请联系我们。
  </Accordion>
</AccordionGroup>
