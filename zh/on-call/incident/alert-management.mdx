## 告警列表

告警管理页面提供了独立于故障的告警视角，您可以在此查看所有告警的详细信息，无论这些告警是否已被聚合到故障中。

在 **故障列表** 页右上角点击 **更多操作（⋯）** → **查看原始告警**，即可进入告警管理页面；从协作空间内进入时，列表已按该协作空间筛选。

告警列表展示以下信息：

| 列 | 说明 |
| :--- | :--- |
| **严重程度** | 以色条形式展示告警的严重程度（Critical、Warning、Info） |
| **标题** | 告警的标题描述 |
| **处理状态** | 告警当前的恢复状态（已恢复 / 未恢复），列表顶部支持按"未恢复告警"和"已恢复告警"快速筛选 |
| **故障处理进度** | 告警所关联故障的当前处理进度 |
| **关联事件数** | 告警关联的原始事件数量 |
| **关联故障** | 告警所属的故障，点击可跳转到故障详情 |
| **触发时间** | 告警首次触发的时间 |
| **集成来源** | 告警来源的集成名称和类型（共享或专属），点击可跳转：Monit 集成的告警跳转到产生它的告警规则，其他集成的告警跳转到对应集成详情页 |
| **协作空间** | 告警所属的协作空间 |

<Note>
被静默或抑制的告警会在标题前显示特殊标记，帮助您快速识别。
</Note>

### 字段说明

告警列表涉及三个容易混淆的字段维度，请注意区分：

| 字段 | 取值 | 说明 |
| :--- | :--- | :--- |
| **严重程度** | Critical / Warning / Info | 告警创建时确定；此后若有新事件合入该告警，严重程度会取历史级别与新事件级别中的最差值，即**只升不降**；列表顶部的严重程度筛选也作用于此项 |
| **告警状态** | Critical / Warning / Info / Ok | 反映告警当前的恢复状态，其中 **Ok 即表示已恢复**，其余取值均视为未恢复 |
| **故障处理进度** | Triggered / Processing / Closed | 该列展示的并非告警自身的状态，而是告警所关联故障的处理进度 |

### 筛选与搜索

告警列表顶部提供以下筛选项：

| 筛选项 | 说明 |
| :--- | :--- |
| **告警标题** | 按标题子串匹配，也支持通配与正则写法（见下方说明） |
| **严重程度** | 多选 Critical / Warning / Info |
| **告警状态** | 全部 / 未恢复 / 已恢复，常驻在筛选条上 |
| **协作空间** | 按所属协作空间筛选（仅全局告警列表） |
| **集成来源** | 按告警来源集成筛选（仅协作空间内的告警列表） |
| **告警标签** | 按标签键值筛选，支持动态加载候选值；值只做精确匹配；模糊、通配或正则查找标题时请用 **告警标题** |
| **告警 ID** | 支持输入多个 ID，按回车分隔；格式错误的 ID 不会被收下，并弹出 **ID 格式错误，请检查** 提示 |
| **告警标识** | 按告警标识（alert_key）完整匹配，支持多个值（任一匹配） |
| **是否被静默/抑制** | 筛选曾经被静默或抑制过的告警 |

单次查询的时间跨度最多 31 天；按告警标题检索时最多 7 天。

筛选条件会按视图保留，刷新或重新进入页面后自动恢复。

<Note>
**告警标题** 按**子串**匹配，且区分大小写。输入 `disk full` 会返回标题中包含该字符串的告警，不要求与标题完全一致。

- 值里含 `*` 或 `?` 时按**通配**匹配，需要匹配整个标题：`*` 匹配任意多个字符，`?` 匹配一个字符，其余字符按字面匹配
- 值用 `/…/` 包裹时按 **RE2 正则**匹配，命中标题中的一段即可；正则写错时退回子串匹配
- **标题筛选的时间范围最长 7 天**。时间范围选为 **最近 30 天** 之后再输入标题，查询会被拒绝，并返回 `the time range must not exceed 7 days when searching by title`。要看更长时间范围的告警时，请把区间拆成多段、每段不超过 7 天分别查询
</Note>

### 视图设置

点击列表顶部的视图设置按钮，可以在弹出的面板中调整以下选项：

| 选项 | 说明 |
| :--- | :--- |
| **详情展示** | 选择点击告警后以 **页面** 还是 **右侧面板** 打开详情；右侧面板无需跳转即可快速浏览 |
| **自动刷新** | 可选 关闭 / 5 秒 / 10 秒 / 20 秒 / 30 秒 / 1 分钟 / 2 分钟 / 3 分钟 / 5 分钟 / 10 分钟，默认 10 秒 |
| **展示属性** | 切换是否恢复、故障处理进度、关联事件、关联故障、触发时间、集成来源、协作空间等列的显隐 |

视图设置按视图分别保存在当前浏览器中。

### 批量操作

您可以在列表中勾选多条告警，点击顶部的 **并入** 按钮将所选告警一次性并入指定故障。

### 使用聚合视图

除了标准的列表视图，告警列表还支持 **聚合视图**。聚合视图将告警按指定维度分组显示，左侧展示分组卡片列表，右侧展示选中分组下的告警详情。

<Steps>
<Step title="创建聚合视图">
切换到聚合视图后，如果尚未创建聚合规则，系统将引导您创建第一个聚合视图。
</Step>
<Step title="选择分组维度">
选择用于分组的聚合规则，系统将按该维度对告警进行分组。
</Step>
<Step title="浏览分组">
左侧面板展示各分组卡片，包含分组标题、严重程度和告警数量。点击分组卡片，右侧列表展示该分组下的所有告警。
</Step>
</Steps>

<Note>
在聚合视图下，系统最多匹配 **100 条** 数据进行分组展示。如果需要查看全量数据，请切换为列表视图。
</Note>

## 告警详情

点击告警标题进入告警详情页。告警详情页顶部的信息栏展示告警标题、严重级别标签、告警 ID（悬停可复制全量 ID）、恢复状态（已恢复 / 未恢复）以及所属故障的处理进度标签。若告警曾被静默或抑制，标题前会显示对应图标。信息栏右侧提供 **并入** 操作按钮，可将当前告警并入某个故障。

详情页主体区分为两个 Tab：

| Tab | 说明 |
| :--- | :--- |
| **告警概览** | 左侧展示告警描述、标签、**告警事件**（最多 5 条，超过 5 条显示 **查看全部**，可跳转到 *告警事件* 页签）；右侧展示属性（协作空间、触发时间）、图片、告警来源、所属故障、Links。Monit 告警还会在 **属性** 之后多出一块 **排查入口**（详见下方 **排查入口**） |
| **告警事件** | 展示该告警关联的所有原始事件列表 |

在告警详情地址后附加 `?tab=events`（如 `/alert/detail/{id}?tab=events`）可直达 **告警事件** 页签；切换页签时地址栏会同步更新。故障详情中的 **查看完整事件历史** 链接就是这样打开的。

**告警来源**支持点击跳转，便于您快速溯源：

- **Monit 集成的告警**：显示产生该告警的规则名称，点击跳转到对应告警规则——实体树规则直接打开实体树的规则编辑视图，独立规则跳转到规则详情页
- **其他集成的告警**：显示集成名称和类型标记（共享或专属），点击跳转到对应集成详情页

### 排查入口

Monit 告警的右侧栏在 **属性** 之后多出一块 **排查入口**，与故障详情页右侧是同一块面板，显示告警触发那一刻的排查入口快照。其他集成（如 Zabbix、RUM）的告警不显示这一块。入口字段、异常徽标和无法显示时的提示，见[检索与查看故障 · 排查入口](/zh/on-call/incident/search-view-incident#排查入口)。

### 告警生命周期记录

告警从触发到关闭的整个过程会被系统完整记录，常见的记录类型如下：

| 时间线记录 | 含义 |
| :--- | :--- |
| 收到新的告警事件，系统自动触发告警 | 新告警产生 |
| 收到新的告警事件，系统自动更新了告警 | 新事件合入已有告警 |
| 手动合并告警至故障 | 告警被合并至故障 |
| 发表了评论 | 有人评论 |
| 静默了告警 | 命中[静默策略](/zh/on-call/channel/noise-reduction#静默策略)，直接跳过通知 |
| 抑制了告警，没有触发通知 | 命中[抑制策略](/zh/on-call/channel/noise-reduction#抑制策略)，没有触发通知 |

<Note>
**静默与抑制的区别：**
- **静默**：匹配静默规则的告警直接不发送通知，适用于计划内维护窗口。
- **抑制**：在某些"源告警"活跃期间，主动压制相关的目标告警通知，适用于由共性故障引发的次生告警。
</Note>
