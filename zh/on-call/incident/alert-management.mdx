## 告警列表

告警管理页面提供了独立于故障的告警视角，你可以在此查看所有告警的详细信息，无论这些告警是否已被聚合到故障中。

进入 **故障列表** → **告警列表**，即可访问告警管理页面。

告警列表展示以下信息：

| 列 | 说明 |
| :--- | :--- |
| **严重程度** | 以色条形式展示告警的严重程度（Critical、Warning、Info） |
| **标题** | 告警的标题描述 |
| **处理状态** | 告警当前的恢复状态（已恢复 / 未恢复），列表顶部支持按"未恢复告警"和"已恢复告警"快速筛选 |
| **故障处理进度** | 告警所关联故障的当前处理进度 |
| **关联事件数** | 告警关联的原始事件数量 |
| **关联故障** | 告警所属的故障，点击可跳转到故障详情 |
| **触发时间** | 告警首次触发的时间 |
| **集成来源** | 告警来源的集成名称和类型（共享或专属），点击可跳转：Monit 集成的告警跳转到产生它的告警规则，其他集成的告警跳转到对应集成详情页 |
| **协作空间** | 告警所属的协作空间 |

<Note>
被静默或抑制的告警会在标题前显示特殊标记，帮助你快速识别。
</Note>

### 字段说明

告警列表涉及三个容易混淆的字段维度，请注意区分：

| 字段 | 取值 | 说明 |
| :--- | :--- | :--- |
| **alert_severity**（严重程度） | Critical / Warning / Info | 告警创建时确定；此后若有新事件合入该告警，严重程度会取历史级别与新事件级别中的最差值，即**只升不降**；列表顶部的严重程度筛选也作用于此字段 |
| **alert_status**（告警状态） | Critical / Warning / Info / Ok | 反映告警当前的恢复状态，其中 **Ok 即表示已恢复**，其余取值均视为未恢复 |
| **故障处理进度** | Triggered / Processing / Closed | 该列展示的并非告警自身的状态，而是告警所关联故障的处理进度 |

### 筛选与搜索

告警列表顶部提供以下筛选项：

| 筛选项 | 说明 |
| :--- | :--- |
| **时间** | 可选 **最近 1 天** / **最近 7 天** / **最近 30 天** 三个预设，默认为 **最近 7 天**；也可以切换为自定义的绝对起止时间。预设是相对窗口，会随时间向前滑动，配合自动刷新时查询范围始终相对当前时刻 |
| **告警标题** | 按标题进行模糊匹配 |
| **严重程度** | 多选 Critical / Warning / Info |
| **协作空间** | 按所属协作空间筛选 |
| **集成** | 按告警来源集成筛选 |
| **标签** | 按标签键值筛选，支持动态加载候选值 |
| **告警 ID** | 支持一次输入多个 ID（回车分隔）；不是合法告警 ID 的输入会被直接拒收，并弹出标题为 **ID 格式错误，请检查**、内容为该输入值的警告提示，不会作为筛选项保留 |
| **告警标识** | 按告警的 [告警标识（`alert_key`）](/zh/on-call/integration/alert-integration/alert-sources/standard-alert) 筛选，支持一次输入多个值（回车分隔）；后端按完整值精确匹配，多个值之间为「或」关系 |
| **是否被静默/抑制** | 筛选曾经被静默或抑制过的告警 |

筛选条件会按视图保留，刷新或重新进入页面后自动恢复。

<Note>
告警列表的时间筛选与[故障列表](/zh/on-call/incident/search-view-incident)的时间筛选各自独立：本页默认查询 **最近 7 天**，故障列表默认 **最近 30 天**，互不影响。后端对单次查询的时间跨度有限制，**不能超过 31 天**（[告警列表 API](/zh/api-reference/on-call/alerts/alert-read-list) 同样如此），需要查询更早的数据时请调整起止时间分批查询。
</Note>

### 视图设置

点击列表顶部的视图设置按钮，可以在弹出的面板中调整以下选项：

| 选项 | 说明 |
| :--- | :--- |
| **详情展示** | 选择点击告警后以 **页面** 还是 **右侧面板** 打开详情 |
| **自动刷新** | 可选 关闭 / 5 秒 / 10 秒 / 20 秒 / 30 秒 / 1 分钟 / 2 分钟 / 3 分钟 / 5 分钟 / 10 分钟，默认 10 秒 |
| **展示属性** | 切换是否恢复、故障处理进度、关联事件、关联故障、触发时间、集成来源、协作空间等列的显隐 |

视图设置会按视图保留，在当前浏览器中长期保留。

### 批量操作

你可以在列表中勾选多条告警，点击顶部的 **并入** 按钮将所选告警一次性并入指定故障。

### 使用聚合视图

除了标准的列表视图，告警列表还支持 **聚合视图**。聚合视图将告警按指定维度分组显示，左侧展示分组卡片列表，右侧展示选中分组下的告警详情。

<Steps>
<Step title="创建聚合视图">
切换到聚合视图后，如果尚未创建聚合规则，系统将引导你创建第一个聚合视图。
</Step>
<Step title="选择分组维度">
选择用于分组的聚合规则，系统将按该维度对告警进行分组。
</Step>
<Step title="浏览分组">
左侧面板展示各分组卡片，包含分组标题、严重程度和告警数量。点击分组卡片，右侧列表展示该分组下的所有告警。
</Step>
</Steps>

<Note>
在聚合视图下，系统最多匹配 **100 条** 数据进行分组展示。如果需要查看全量数据，请切换为列表视图。
</Note>

## 告警详情

点击告警标题进入告警详情页。告警详情页顶部为 **HeaderInfo 信息栏**，展示告警标题、严重级别标签、告警 ID（悬停可复制全量 ID）、恢复状态（已恢复 / 未恢复）以及所属故障的处理进度标签。若告警曾被静默或抑制，标题前会显示对应图标。信息栏右侧提供 **并入** 操作按钮，可将当前告警并入某个故障。

详情页主体区分为两个 Tab：

| Tab | 说明 |
| :--- | :--- |
| **告警概览** | 左侧依次展示告警描述、**告警标识**（完整 `alert_key`，可一键复制）、标签、**关联事件预览**（最多 5 条，可跳转到 *关联事件* Tab 查看全部）；右侧依次展示属性（协作空间、触发时间）、**降噪记录**、图片、告警来源、所属故障、Links |
| **关联事件** | 展示该告警关联的所有原始事件列表 |

**告警标识** 展示该告警完整的 `alert_key`：不做截断，超长时自动折行，右侧的复制按钮可一键复制。`alert_key` 是系统判断哪些事件合入同一条告警的依据——[事件聚合](/zh/on-call/channel/noise-reduction) 只把 `alert_key` 相同的事件并进同一条告警，因此排查"某个事件为什么没有并进来"时，直接比对这里的值与上报方的 `alert_key` 即可。注意它与信息栏那枚短小的告警 ID 是两个不同的值，不要看混。若告警没有 `alert_key`，该区块不展示。

页签状态由 URL 参数 `tab` 控制：在告警详情地址后附加 `?tab=events`（如 `/alert/detail/{id}?tab=events`）可直达 **关联事件** 页签，页签切换也会同步到浏览器地址栏。故障详情中「仅展示最新 N 条告警事件」提示的 **查看完整事件历史** 入口即使用该方式打开。

**告警来源**支持点击跳转，便于你快速溯源：

- **Monit 集成的告警**：显示产生该告警的规则名称，点击跳转到对应告警规则——实体树规则直接打开实体树的规则编辑视图，独立规则跳转到规则详情页；老数据缺少规则标签时，回退显示集成名称并跳转集成详情
- **其他集成的告警**：显示集成名称和类型标记（共享或专属），点击跳转到对应集成详情页

<Tip>
你也可以在告警列表的视图设置中，选择以 **右侧面板** 模式查看详情，无需跳转新页面即可快速浏览告警信息。
</Tip>

### 降噪记录

告警详情右栏的 **降噪记录** 区块列出该告警命中过的降噪策略，用于回溯"这条告警当时为什么没有通知我"。只有曾被静默或抑制过的告警（信息栏标题前带对应图标）才会展示该区块，其余告警的右栏没有它；区块的数据来源正是告警生命周期记录中的 `a_m_silence` / `a_m_inhibit` 两条记录。

| 展示内容 | 说明 |
| :--- | :--- |
| **静默策略** | 该告警命中的静默策略名称，点击策略名会在协作空间的 **降噪处理** → **静默策略** 中打开对应的那条规则（新标签页） |
| **抑制策略** | 该告警命中的抑制策略名称，点击策略名会在协作空间的 **降噪处理** → **抑制策略** 中打开对应的那条规则（新标签页） |

- 同一条策略只占一行：一条告警可能多次命中同一条策略，区块按「策略类型 + 规则」去重，取最近一次命中记录中的策略名称，最近命中的策略排在最前面
- 记录里没有规则 ID 时，该行显示 **策略信息不可用** 且不可点击；有规则 ID 但取不到规则名时，回退显示规则 ID 本身，链接仍可跳转
- 区块内容每 10 秒自动刷新：加载中显示 **加载中...**，拉取失败显示 **策略记录加载失败** 并提供 **重试**，没有命中记录时显示 **暂无可用的策略记录**

### 告警生命周期记录

告警从触发到关闭的整个过程会被系统完整记录，常见的记录类型如下：

| 记录类型 | 含义 |
| :--- | :--- |
| `a_new` | 收到新的告警事件，系统自动触发告警 |
| `a_update` | 收到新的告警事件，系统自动更新了告警 |
| `a_merge` | 告警被合并至故障 |
| `a_comm` | 发起评论 |
| `a_m_silence` | 命中[静默策略](/zh/on-call/channel/noise-reduction)，直接跳过通知 |
| `a_m_inhibit` | 命中[抑制策略](/zh/on-call/channel/noise-reduction)，没有触发通知 |

<Note>
**静默与抑制的区别：**
- **静默**：匹配静默规则的告警直接不发送通知，适用于计划内维护窗口。
- **抑制**：在某些"源告警"活跃期间，主动压制相关的目标告警通知，适用于由共性故障引发的次生告警。
</Note>
