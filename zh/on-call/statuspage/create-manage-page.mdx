本文面向已经创建或迁移完成的状态页，介绍如何配置基础属性和显示设置。

如果你还没有状态页，先阅读[接入 Flashduty 状态页](/zh/on-call/statuspage/get-started)，完成创建或迁移。

---

## 基础信息

你可以随时编辑状态页名称、URL 标识和基础说明。状态页名称通常使用公司名、产品名或服务名，方便访客识别当前页面代表的服务范围。

### URL 标识

URL 标识是状态页访问地址中的唯一路径段。创建后可以修改，但同一账户内同类型状态页的 URL 标识不能重复。

系统会将名称自动转换为 URL 安全格式（小写化、非字母数字字符替换为连字符）。你也可以手动指定。

<Warning>
修改 URL 标识后，原访问地址将失效。正式对外发布的状态页建议提前规划 URL 标识，避免后续变更影响外部链接。
</Warning>

## 外观设置

你可以自定义状态页的品牌外观，使其与你的企业形象保持一致。

### Logo 与图标

| 设置项 | 说明 |
| --- | --- |
| **Logo** | 状态页顶部展示的品牌标识 |
| **暗色 Logo** | 在暗色模式下展示的品牌标识。未设置时默认使用主 Logo |
| **Logo 链接** | 用户点击 Logo 后跳转的目标地址 |
| **Favicon** | 浏览器标签页中显示的小图标 |

### 页面内容

| 设置项 | 说明 |
| --- | --- |
| **页头信息** | 状态页顶部展示的自定义文本 |
| **页脚信息** | 状态页底部展示的自定义文本 |
| **自定义链接** | 在状态页中展示额外的导航链接，方便用户快速跳转到相关资源 |
| **联系信息** | 获取帮助的联系方式，支持邮件地址或网站链接 |

## 自定义域名

默认情况下，状态页通过 Flashduty 提供的子域名访问。如果你希望使用自有域名（如 `status.yourcompany.com`），可以配置自定义域名。

<Steps>
  <Step title="添加 CNAME 记录">
    在你的 DNS 服务商中，为目标域名添加一条 CNAME 记录，指向 Flashduty 提供的状态页地址。
  </Step>
  <Step title="配置自定义域名">
    在状态页设置中填入自定义域名。系统会验证域名唯一性，同一域名不能被多个状态页使用。
  </Step>
</Steps>

<Warning>
自定义域名在全平台范围内必须唯一。如果该域名已被其他状态页使用，系统会拒绝设置。
</Warning>

## 显示设置

### 事件历史视图

状态页支持两种事件历史的展示方式：

| 视图模式 | 说明 |
| --- | --- |
| **日历视图** | 按日历形式展示历史事件，便于查看某一天的服务状态 |
| **列表视图** | 按时间线列出历史事件，适合快速浏览近期事件 |

<Note>
日历视图与列表视图均可向前回溯，**不受 90 天限制**——访客可一直翻看到该状态页**最早记录的事件**为止。最近 **90 天 / 50 条**的时间窗口**仅适用于 [RSS/Atom Feed](/zh/on-call/statuspage/subscriptions)**，不影响网页端的历史浏览。
</Note>

### 可用性统计展示

你可以控制组件可用性统计信息的展示方式：

| 展示模式 | 说明 |
| --- | --- |
| **图表与百分比** | 同时展示可用性趋势图和百分比数值 |
| **仅图表** | 仅展示可用性趋势图 |
| **不展示** | 隐藏可用性统计信息 |

## 编辑与删除

你可以随时编辑状态页的名称、URL 标识、外观设置和显示配置。

删除状态页将同时清除其下的关联数据，此操作不可恢复。
