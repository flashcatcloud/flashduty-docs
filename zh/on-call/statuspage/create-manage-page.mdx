本文面向已经创建或迁移完成的状态页，介绍如何配置基础属性和显示设置。

如果您还没有状态页，先阅读[接入 Flashduty 状态页](/zh/on-call/statuspage/get-started)，完成创建或迁移。

---

## 基础信息

您可以在 **设置 → 基础配置** 中随时编辑页面标题和状态页 URL。页面标题通常使用公司名、产品名或服务名，方便访客识别当前页面代表的服务范围。

### 状态页 URL

状态页 URL 是状态页访问地址中的唯一路径段。创建后可以修改，但同一账户内同类型状态页的 URL 不能重复。

系统会将页面标题自动转换为 URL 安全格式（小写化、非字母数字字符替换为连字符）。您也可以手动指定。

<Warning>
修改状态页 URL 后，原访问地址将失效。正式对外发布的状态页建议提前规划状态页 URL，避免后续变更影响外部链接。
</Warning>

## 外观设置

您可以自定义状态页的品牌外观，使其与您的企业形象保持一致。

### Logo 与图标

| 设置项 | 说明 |
| --- | --- |
| **Logo** | 状态页顶部展示的品牌标识 |
| **暗色 Logo** | 在暗色模式下展示的品牌标识。未设置时默认使用主 Logo |
| **Logo 链接** | 用户点击 Logo 后跳转的目标地址 |
| **Favicon** | 浏览器标签页中显示的小图标 |

### 页面内容

| 设置项 | 说明 |
| --- | --- |
| **页头信息** | 状态页顶部展示的自定义文本 |
| **页脚信息** | 状态页底部展示的自定义文本 |
| **自定义链接** | 在状态页中展示额外的导航链接，方便用户快速跳转到相关资源 |
| **联系信息** | 获取帮助的联系方式，支持邮件地址或网站链接 |

## 自定义域名

默认情况下，状态页通过 Flashduty 提供的子域名访问。如果您希望使用自有域名（如 `status.yourcompany.com`），可以配置自定义域名。自定义域名仅适用于**公开状态页**，内部状态页的基础配置页不提供该选项。

<Steps>
  <Step title="填写自定义域名">
    在状态页设置中填入自定义域名。
  </Step>
  <Step title="添加访问入口记录（CNAME）">
    在 DNS 服务商中为该域名添加 CNAME 记录，指向 Flashduty 托管访问入口：大陆访问入口为 `cn.statuspage.flashduty.com`，国际访问入口为 `statuspage.flashduty.com`。DNS 服务商支持 GeoDNS 时，可为同一域名同时配置国内与海外解析；不支持时选择其中一个入口即可。
  </Step>
  <Step title="添加证书托管记录（CNAME）">
    在 `_acme-challenge` 前缀下添加 CNAME 记录，把证书校验委派给 Flashcat 托管 DNS，用于证明您拥有该域名。记录名称与目标值以**检查配置**显示为准。
  </Step>
  <Step title="检查配置">
    在状态页设置中点击**检查配置**，查看每条记录的校验状态。两条记录均通过后，Flashduty 自动签发、续期并发布 HTTPS 证书，域名即可通过 HTTPS 访问，无需手动上传证书。
  </Step>
</Steps>

<Warning>
自定义域名在全平台范围内必须唯一。该域名既不能被其他状态页使用，也不能被任何账户用作[企业微信自建应用](/zh/on-call/integration/instant-messaging/wecom#self)的访问域名——即使占用方就是您自己的账户，系统同样会拒绝设置。
</Warning>

<Note>
**域名归首个占用者所有，释放后可被重新占用**

域名由首个占用者持有，直到该域名被释放。从状态页删除自定义域名、或把该域名从企业微信自建应用中移除后，系统会异步回收该域名的证书；回收完成前该域名仍算被占用，此时把它绑定到另一个状态页或另一个账户会失败。回收完成后域名释放，任何状态页或账户都可以重新占用。
</Note>

<Note>
**从旧入口切换，无 HTTPS 中断**

如果自定义域名当前仍指向旧兼容入口 `statuspage.flashcat.cloud`，只要证书托管记录校验通过，系统同样会提前签发并发布证书。此时再将 DNS 切换到托管访问入口，不会出现 HTTPS 中断。
</Note>

<Note>
**支持链式 CNAME**

您可以通过自己的中间记录链式指向托管入口，链上任一跳与托管入口匹配即视为已接入。
</Note>

## 显示设置

### 事件历史视图

状态页支持两种事件历史的展示方式：

| 视图模式 | 说明 |
| --- | --- |
| **日历视图** | 按日历形式展示历史事件，便于查看某一天的服务状态 |
| **列表视图** | 按时间线列出历史事件，适合快速浏览近期事件 |

<Note>
日历视图与列表视图均可向前回溯，**不受 90 天限制**——访客可一直翻看到该状态页**最早记录的事件**为止。最近 **90 天 / 50 条**的时间窗口**仅适用于 [RSS/Atom Feed](/zh/on-call/statuspage/subscriptions)**，不影响网页端的历史浏览。
</Note>

### 可用性统计展示

您可以控制组件可用性统计信息的展示方式：

| 展示模式 | 说明 |
| --- | --- |
| **图表与百分比** | 同时展示可用性趋势图和百分比数值 |
| **仅图表** | 仅展示可用性趋势图 |
| **不展示** | 隐藏可用性统计信息 |

---

## 编辑与删除

您可以随时编辑状态页的页面标题、状态页 URL、外观设置和显示配置。

删除状态页将同时清除其下的关联数据，此操作不可恢复。
