Flashduty 状态页允许用户主动订阅服务状态更新。当状态页中有新事件发布或事件状态变更时，您可以选择向订阅者推送通知。

---

## 订阅方式

不同类型的状态页支持不同的订阅方式：

| 状态页类型 | 订阅方式 | 说明 |
| --- | --- | --- |
| **公开状态页** | 邮件 | 访客通过邮件地址订阅，需完成邮件确认 |
| **公开状态页** | Slack | 访客通过授权 Flashduty Status Page 应用将状态更新推送到指定 Slack 频道，无需邮件确认 |
| **公开状态页** | Microsoft Teams | 访客通过 Microsoft Teams Workflows Webhook URL 订阅频道更新，无需邮件确认 |
| **公开状态页** | RSS/Atom | 通过 RSS 阅读器或自动化工具订阅事件更新，无需邮件确认 |
| **内部状态页** | IM 集成 | 组织内部用户通过已绑定的 IM 平台接收推送 |

订阅弹窗中的组件和分组名称随访客当前页面语言展示，系统同时记录订阅者的语言偏好。推送通知时，状态页标题和受影响组件名称按订阅者偏好语言渲染；若该语言已被状态页停用，则自动改用状态页唯一启用的语言。详见[多语言配置](/zh/on-call/statuspage/multilingual)。

## 用户自助订阅

### 邮件订阅（公开状态页）

访客在公开状态页上输入邮件地址后，系统会发送一封确认邮件。确认邮件的有效期为 **5 分钟**，过期后需重新发起订阅。

<Steps>
  <Step title="输入邮件地址">
    访客在状态页底部的订阅区域填写邮件地址。
  </Step>
  <Step title="选择订阅范围">
    选择订阅所有更新，或仅订阅特定组件或事件的更新。
  </Step>
  <Step title="确认订阅">
    访客在收到的确认邮件中点击确认链接，完成订阅。
  </Step>
</Steps>

<Note>
同一邮箱已有待确认的订阅时，访客再次提交表单既不会改写这次待确认的订阅范围，也不会重新发送确认邮件——最终生效的是首次提交时选择的范围。如需修改，请等确认邮件过期（5 分钟）后重新提交。已完成确认的订阅者修改订阅范围需要重新提交表单并点击新邮件中的确认链接，确认之前原有订阅保持不变，确认后新的范围会替换原有订阅；也可以直接使用通知邮件中的管理令牌自助修改。
</Note>

### Slack 订阅（公开状态页）

公开状态页开启 Slack 订阅后，访客可以直接将故障和维护更新推送到自己的 Slack 频道：

<Steps>
  <Step title="选择订阅范围">
    在状态页打开订阅弹窗，切换到 **Slack** 标签页，选择订阅全部更新或特定组件。
  </Step>
  <Step title="完成 Slack 授权">
    点击 **添加到 Slack**，在 Slack 授权页面选择目标工作区和频道并点击允许。
  </Step>
  <Step title="接收通知">
    授权完成后订阅立即生效。每条 Slack 通知卡片均附带自助管理或退订入口。
  </Step>
</Steps>

### Microsoft Teams 订阅（公开状态页）

公开状态页开启 Microsoft Teams 订阅后，访客可以通过 **Microsoft Teams Workflows** 在 Teams 频道接收 Adaptive Card 状态通知：

<Steps>
  <Step title="在 Teams 中获取 Workflows Webhook URL">
    在 Microsoft Teams 目标频道点击 **更多选项（`...`）→ 工作流 →「向频道发送 Webhook 警报」**（或「在收到 Webhook 请求时发布到频道」），复制生成的 Webhook URL（`*.logic.azure.com` 或 `*.environment.api.powerplatform.com`）。
  </Step>
  <Step title="在状态页提交订阅">
    打开状态页订阅弹窗，切换到 **Teams** 标签页，粘贴 Workflows Webhook URL，选择订阅全部更新或特定组件后提交即可生效。
  </Step>
</Steps>

<Note>
微软已下线旧版 Office 365 Connector 地址（`*.webhook.office.com`），系统会拒绝此类旧地址，请使用 Teams Workflows Webhook URL。
</Note>

### IM 订阅（内部状态页）

组织内部用户访问内部状态页后，可通过已绑定的 IM 集成（飞书、钉钉、企业微信、Slack）接收事件推送通知。IM 订阅无需邮件确认。

### RSS/Atom 订阅（公开状态页）

公开状态页会自动提供 RSS 和 Atom 两种格式的事件 Feed，方便访客通过 RSS 阅读器（如 Feedly、Inoreader）或自动化工具订阅状态更新。Feed 为匿名访问，无需注册或邮件确认。

每个公开状态页提供以下四个 URL，内容完全一致，`feed.*` 与 `history.*` 互为别名（后者用于兼容 Atlassian Statuspage 的链接习惯）：

| URL 格式 | 格式 |
| --- | --- |
| `{状态页地址}/feed.rss` | RSS 2.0 |
| `{状态页地址}/feed.atom` | Atom 1.0 |
| `{状态页地址}/history.rss` | RSS 2.0（别名） |
| `{状态页地址}/history.atom` | Atom 1.0（别名） |

其中 `{状态页地址}` 指公开状态页的访问地址，既可以是自定义域名（如 `https://status.example.com`），也可以是 Flashduty 分配的默认 URL。

Feed 的内容规则如下：

- 包含最近 **90 天** 内发布的事件（包括故障事件和维护事件），最多返回 **50 条**，按事件开始时间倒序
- 仅包含当前可见的组件影响记录：被设置为隐藏的分组或组件不会出现在 Feed 中
- 每条事件的 `<updated>` 使用最新一次时间线更新的时间；订阅者重新抓取时可据此发现新动态
- 响应支持 `ETag` / `If-None-Match`，未发生变化时返回 `304 Not Modified`
- 支持附加可选查询参数 `?lang=zh` 或 `?lang=en`（例如 `{状态页地址}/feed.rss?lang=zh`、`{状态页地址}/feed.atom?lang=en`），返回对应语言的状态页标题、受影响组件名称，以及**事件标题与更新正文**（某语言未填写时回退到另一语言；最新更新没有正文时回退展示事件描述）。仅启用单语的状态页会忽略未启用语言参数，始终返回已启用语言；同时启用中英双语且未传 `?lang=` 时默认返回英文。详见[多语言配置](/zh/on-call/statuspage/multilingual)

<Note>
Feed 仅对**公开状态页**开放。对内部状态页或不存在的状态页请求 Feed URL 会返回 `404 Not Found`。内部状态页请通过 IM 集成接收更新。
</Note>

<Tip>
如果您正在从 Atlassian Statuspage 迁移，可以直接把原有的 `history.rss` / `history.atom` 订阅地址替换为 Flashduty 状态页地址，无需修改订阅者配置。
</Tip>

## 订阅范围

订阅者可以灵活选择订阅范围：

| 范围 | 说明 |
| --- | --- |
| **全部更新** | 接收状态页上所有事件的通知 |
| **按组件订阅** | 仅接收指定组件相关事件的通知 |
| **按事件订阅** | 仅接收指定事件的后续更新通知 |

选择"全部更新"后，组件级和事件级的订阅设置将被忽略——订阅者会收到所有通知。

## 管理员管理订阅

### 订阅设置

在状态页设置的 **订阅** 页中，管理员可以按渠道控制订阅开关：

- **公开状态页**：分别提供 **邮件订阅**、**Slack 订阅** 和 **Microsoft Teams 订阅** 三个独立开关。关闭某个渠道后，对应标签页不会向访客展示，且发布事件时即使勾选了「通知订阅者」，也不会再向该渠道推送。
- **内部状态页**：提供页面级的 **IM 订阅** 开关。

订阅通知的用量规则：

- **邮件（公开状态页）**：事件通知邮件计入 Flashduty 账户的邮件用量。免费版账户的邮件用量超出限额后，事件通知邮件将暂停发送；付费版账户超出限额的邮件将单独计费，仅当账户欠费时暂停发送。
- **Slack 与 Microsoft Teams（公开状态页）**：通知直接推送至订阅的频道，不计入 Flashduty 账户的邮件用量。
- **IM（内部状态页）**：事件通知计入对应 IM 平台的 API 调用用量，超出 IM 平台的限额时通知将暂停发送。API 调用限额通常与您的组织使用的 IM 平台定价方案有关。

### 查看订阅者

在状态页设置的 **订阅** 页的「订阅者列表」区块中，管理员可以查看当前订阅者列表，并支持按**组件**和**订阅方式**（邮件、Slack、Microsoft Teams、IM）进行筛选。列表支持分页浏览，展示每位订阅者的订阅方式、接收人标识（如邮箱地址、Slack 的 `#频道 (工作区)`、Teams 的 `Teams Webhook (<标识>)`）、订阅的组件和语言偏好。

### 批量导入

<Tip>
**版本要求**：批量导入订阅者需要 Flashduty **专业版**。
</Tip>

管理员可以批量导入订阅者，适用于迁移场景或需要为特定用户群体预先设置订阅的情况。控制台没有导入入口，请调用 API 导入（见[批量导入订阅者 API](/zh/api-reference/on-call/status-pages/status-page-subscriber-import)）。导入时需提供：

| 字段 | 说明 |
| --- | --- |
| **接收人** | 邮件地址或用户标识 |
| **订阅范围** | 全部更新，或指定组件 ID / 事件 ID |
| **语言偏好** | 通知的语言设置 |

<Note>
通过管理员导入的订阅不需要邮件确认，会直接生效。导入相同接收人的订阅时，系统会替换该接收人之前的订阅设置。
</Note>

### 导出订阅者

<Tip>
**版本要求**：导出订阅者需要 Flashduty **标准版**及以上。
</Tip>

管理员可以在**订阅者列表**中点击 **导出 CSV**，导出包括每位订阅者的接收地址、订阅方式、订阅的组件等信息。

## 订阅者自助管理

每位订阅者都拥有一个唯一的**管理令牌**，可以通过该令牌自助管理自己的订阅：

- **查看当前订阅**：查看自己订阅了哪些组件和事件
- **修改订阅范围**：更改订阅的组件或事件
- **取消订阅**：完全退出订阅

管理令牌包含在每封通知邮件的底部，订阅者可以通过点击"管理订阅"链接进入自助管理页面。

### 邮件客户端一键退订

事件变更通知邮件支持一键退订。Gmail、Apple Mail、Outlook、Yahoo 等主流邮件客户端会在邮件顶部展示"退订"按钮，订阅者点击后立即解除该订阅。

<Warning>
一键退订是**立即且不可恢复**的操作：请求到达即生效，无需打开管理页面，也不会发送二次确认。如需重新订阅，需要订阅者重新在状态页提交邮箱并完成确认流程。
</Warning>

---

## 订阅与组件的关系

当您删除一个组件时，系统会自动清除该组件相关的所有订阅记录。订阅了该组件的用户将不再收到相关通知。

同样，当您删除一个事件时，系统会自动清除该事件相关的所有订阅记录。
