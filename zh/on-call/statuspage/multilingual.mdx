Flashduty 状态页支持 **简体中文**（`zh`）和 **English**（`en`）两种语言，且不设“默认语言”：两种语言地位平等、对称回退。您可以按受众只启用单语，也可以同时启用中英双语。

## 启用语言

进入状态页详情，打开 **设置 → 基础配置**，在 **语言** 多选下拉框中勾选需要的语言（**简体中文**、**English**），再点击 **保存**。

语言配置遵循以下规则：

- **至少保留 1 种语言**：仅剩 1 种语言处于选中状态时，该选项不可取消。
- **无“默认语言”概念**：同时启用两种语言时，无需指定主语言。系统按访客偏好自动匹配，留空字段自动对称回退。
- **新建状态页**：创建时无需选择语言，系统自动将您当前控制台语言设为该状态页唯一启用的语言。
- **存量状态页**：在多语言功能上线前已创建的状态页，默认视为同时启用 **简体中文** 和 **English**。
- **取消勾选不丢失译文**：取消勾选某种语言后，该语言下已填写的文案仍保留在后台。日后重新勾选，原有译文会无损恢复。

## 支持多语言的字段

状态页的**页面配置**共有 9 项支持按语言分别填写，分布在 3 个设置页中（事件与维护的内容另见[事件与更新的双语内容](#event-bilingual)）：

| 所在设置页 | 字段 | 说明 |
| --- | --- | --- |
| **设置 → 基础配置** | **页面标题** | 显示在状态页顶部和浏览器标签页中，至少在 1 种已启用语言中填写 |
| **设置 → 外观** | **页眉** | 显示在页面标题下方的说明文案 |
| **设置 → 外观** | **页脚** | 显示在状态页底部的说明文案 |
| **设置 → 外观** | **自定义链接 — 链接名称** | 每条自定义链接可按语言分别设置显示名称 |
| **设置 → 外观** | **自定义链接 — 链接地址** | 每条自定义链接可按语言分别设置跳转 URL，例如分别指向中英文文档或隐私政策 |
| **设置 → 组件和分组** | **组件名称** | 至少在 1 种已启用语言中填写，唯一性按语言分别校验 |
| **设置 → 组件和分组** | **组件描述** | 组件的简要说明 |
| **设置 → 组件和分组** | **分组名称** | 至少在 1 种已启用语言中填写，唯一性按语言分别校验 |
| **设置 → 组件和分组** | **分组描述** | 分组的简要说明 |

以下内容与语言无关，所有语言共用同一配置：

- **访问地址**：**状态页 URL**、**自定义域名**。
- **品牌素材与联系方式**：**Logo**、**深色模式 Logo**、**Logo 链接**、**Favicon** 和 **联系方式**。
- **展示与结构配置**：历史数据视图、可用性统计展示模式，以及组件和分组的排序、归属与可见性。
- **事件与维护动态内容**：发布事件与维护时填写的**标题**、**消息正文**，以及每条**时间线更新**的正文同样按语言分别填写，访客端按当前语言展示，未填写的一侧对称回退到另一语言；受影响组件名称和分组名称也一样。详见下方 [事件与更新的双语内容](#event-bilingual)。

## 控制台编辑体验

### 单语与双语输入形态

- **单语模式**（仅启用 1 种语言）：所有输入框保持单行形态，界面无额外语言切换控件。
- **双语模式**（同时启用 **简体中文** 和 **English**）：上述支持多语言的字段自动展开为合体双行输入框，行末分别标注 **简体中文** 和 **English**，便于在同一处对照编辑。自定义链接每行同时包含该语言的 **链接名称** 和 **链接地址**。
- **回退占位提示**：某语言的输入框留空且另一语言已填写时，空白行会以占位符显示另一语言的文案，提示访客端的回退展示内容。

### 校验与预览

- **必填校验**：页面标题、组件名称和分组名称只需在已启用语言中至少填写 1 种即可保存，无需同时填满两种语言。
- **重名校验**：组件名称和分组名称按语言分别校验唯一性。同一语言内不能重名，但同一组件或分组在中英文下可以使用相同名称（例如均命名为 `API`）。
- **双语预览**：在 **设置 → 组件和分组** 下方的 **预览** 区域，双语模式下提供 **简体中文** 和 **English** 切换标签，方便核对两种语言下的组件树与描述效果。

## 事件与更新的双语内容

事件与维护的**内容本身**也能按语言填写，不只是页面配置。双语状态下，所有编辑器共用同一个语言标签页：

| 编辑位置 | 按语言分别填写的内容 |
| :--- | :--- |
| **发布事件 / 发布维护** | **故障名称** 或 **维护名称**、**消息正文** |
| **追加更新**（事件或维护的详情页） | 每条更新的 **消息正文** |
| **编辑已有更新** | 该条更新的 **消息正文** |
| **回溯事件**（把已经处理完的事件补录到历史） | 事件名称、每条历史更新的正文 |
| **事件标题行内编辑** | 标题的中英文两侧，保存时同时写入 |

规则与页面级字段一致：

- **至少填写一种语言即可发布**，编辑器里有提示「至少填写一种语言即可发布；留空侧将自动展示另一语言。」
- 未填写的一侧在公开页自动展示另一语言的内容（对称回退），输入框里也会以另一语言的文案作为占位提示。
- **标签页顺序跟随控制台语言**：中文控制台是 **简体中文** 在前，英文控制台是 **English** 在前；打开编辑器时默认停在与控制台语言一致的那个标签（控制台语言未在该页面启用时取第一个启用的语言）。
- **页面只启用一种语言时没有标签页**，编辑器退化成普通输入框，也没有翻译按钮。
- 事件标题仍受 255 字符限制。

### 一键翻译（AI 翻译）

当**当前标签页为空、另一语言已有内容**时，编辑器会显示 **翻译** 按钮：点一下就把另一语言的内容机器翻译并填入当前标签，不必自己重打一遍。

- 翻译会带用该状态页的**术语表**——页面名称、分组名称、组件名称的中英对照都会作为译名约束，保证译出来的组件名与页面一致；Markdown 结构保留。
- 成功后右下角提示 **「已翻译为 English」** 或 **「已翻译为简体中文」**，并带 **撤销**：撤销即回到翻译前的内容；翻译之后再手动编辑，撤销入口失效。
- 失败时提示 **「翻译失败，请稍后重试」**，原有内容不受影响。
- **状态描述模板**支持整套翻译：当前语言所有状态都为空、另一语言已填好时，点一次 **翻译** 会把整套状态文案翻过来。
- 按钮只在**双语状态页**、且该状态页**已启用 AI 翻译**时出现；未启用（例如私有化部署未接翻译模型）时不显示，需要人工分别填写。

## 访客端语言行为

### 对称回退

任一支持多语言的字段在当前语言中留空时，状态页自动展示另一种语言已填写的文案，不会出现空白。例如，某个组件只填写了英文名称时，中文访客也会看到该英文名称；反之亦然。

### 语言识别与切换

<Tabs>
  <Tab title="仅启用单语">
    - 状态页的界面外壳和配置文案始终以该唯一启用的语言展示。
    - 页面右上角的语言切换器自动隐藏。
    - 即使访问链接带有未启用语言的 `?lang=` 参数，或浏览器语言与 Cookie 指向另一种语言，页面仍会钳制到已启用的语言。
  </Tab>
  <Tab title="同时启用中英双语">
    - 展示语言按以下优先级确定：URL 参数 `?lang=zh` 或 `?lang=en` > `NEXT_LOCALE` Cookie > 浏览器 `Accept-Language` 请求头（按浏览器偏好顺序取第一个支持的语言；都不匹配时展示 English）。
    - 访客可通过页面右上角的语言切换器随时切换语言。切换时，地址栏同步写入 `?lang=zh` 或 `?lang=en`，并更新 `NEXT_LOCALE` Cookie（有效期 1 年）记住偏好。
    - 您可以直接分享带 `?lang=zh` 或 `?lang=en` 的状态页链接（例如 `https://status.example.com?lang=en`），访客打开后会直接进入对应语言并写入 `NEXT_LOCALE` Cookie。
  </Tab>
</Tabs>

## 通知、Widget 与 RSS/Atom

状态页的多语言配置会自动联动订阅通知、嵌入组件和订阅源，无需额外设置：

- **订阅与通知**：访客打开订阅弹窗时，组件和分组名称按当前页面语言渲染，提交后记录订阅者的语言偏好。邮件、Slack、Microsoft Teams 和 IM 通知会按订阅者的语言偏好展示状态页标题、受影响组件与分组名称，**以及事件的标题与正文**（取最新一条时间线更新的正文，没有正文时回退到事件描述）；未填写该语言的内容时对称回退到另一语言，若该语言已被状态页停用，则自动改用状态页唯一启用的语言。双语状态页的通知详情链接和退订链接会自动附带 `?lang=` 参数。详见[订阅管理](/zh/on-call/statuspage/subscriptions)。
- **嵌入组件（Widget）**：`<flashduty-status-widget>` 根据 `locale` 属性自动携带 `?lang=zh` 或 `?lang=en` 请求摘要接口。直接调用 `GET {状态页地址}/api/widget/v1/summary.json?lang=zh|en` 时，接口返回对应语言的状态页名称、受影响组件名称和分组名称，**以及事件的标题与时间线更新正文**（未填写该语言时回退到另一语言），并受状态页已启用语言钳制；双语页面未传 `?lang=` 时默认返回英文。详见[嵌入组件（Widget）](/zh/on-call/statuspage/widgets)。
- **RSS/Atom Feed**：`/feed.rss`、`/feed.atom` 及别名 `/history.rss`、`/history.atom` 支持附加 `?lang=zh` 或 `?lang=en`，返回对应语言的状态页标题、受影响组件名称，**以及事件的标题与更新正文**（未填写该语言时回退到另一语言；最新更新没有正文时回退展示事件描述），条目标签如 Status、Affected components 也随语言翻译。单语页面始终输出已启用语言；双语页面未传 `?lang=` 时默认输出英文。详见[订阅管理](/zh/on-call/statuspage/subscriptions)。
