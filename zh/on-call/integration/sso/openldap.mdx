通过 OpenLDAP 目录中的用户登录 Flashduty。

<Warning>
LDAP 集成登录仅 **私有化版本** 支持。
</Warning>

## 前提条件

- 已有可从 Flashduty 访问的 OpenLDAP 服务（默认端口：389；LDAPS：636），搭建方法见 [OpenLDAP 文档](https://www.openldap.org/doc/)。
- 目录中的用户条目带有 `mail` 属性。Flashduty 按邮箱关联成员，邮箱为必填映射字段。

## 在 Flashduty 中配置

进入 **平台管理 → 单点登录**，开启后点击 **设置**，协议类型选择 **LDAP**。以 `dc=flashduty,dc=com` 为例：

| 字段 | 示例值 |
| --- | --- |
| LDAP 链接 | `ldap://10.0.0.1:389` |
| BIND DN | `cn=admin,dc=flashduty,dc=com` |
| BIND DN 密码 | 该账号的密码 |
| 用户 DN | `ou=people,dc=flashduty,dc=com` |
| 认证过滤 | `(mail=%s)` |
| 字段映射：邮箱 | `mail` |
| 字段映射：用户名 | `cn` |
| 字段映射：手机 | `mobile` |

字段映射须与目录中的属性名一致。其余字段（加密机制、稳定用户 ID、登录即创建账号等）的含义见 [配置单点登录](/zh/platform/configure-sso#配置-ldap-协议)。

填写完成后，点击 **连接检测**，确认 Flashduty 能连接到 OpenLDAP 服务；连接成功后再点击 **保存**。
