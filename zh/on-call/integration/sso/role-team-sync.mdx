SAML2.0、OIDC 和 CAS 每次登录都会按身份提供商返回的角色名称、团队名称同步成员的角色与团队。同步开关、角色字段、团队字段和默认值的配置方法、覆盖规则以及默认值何时生效，见 [角色和团队映射](/zh/platform/configure-sso#角色和团队映射)。LDAP 按 Group DN 映射，见 [LDAP 角色和团队同步](/zh/platform/configure-sso#ldap-角色和团队同步)。

<Warning>
默认角色和默认团队通常应保持为空。不要为了登录测试配置管理员等高权限角色或敏感团队。
</Warning>

## 各协议取值来源

**角色字段** 和 **团队字段** 填写的名称，对应下表中的位置：

| 协议 | 角色/团队名称的取值来源 |
| --- | --- |
| SAML2.0 | SAML 断言（Assertion）中的属性，属性名即字段中填写的名称，如 `roles` |
| OIDC | ID Token 中的 claim，claim 名即字段中填写的名称。同步已开启而 ID Token 未携带该 claim 时，Flashduty 会再请求 **UserInfo** 端点，并将返回的属性与 ID Token 的 claim 合并后匹配 |
| CAS | CAS `/serviceValidate` 响应中的属性（attributes），属性名即字段中填写的名称 |

## 名称匹配细节

- 属性值可以是单个字符串或字符串数组；数组中的非字符串元素会被忽略。
- 名称去除首尾空格后精确匹配，区分大小写：`Ops` 与 `ops` 是两个名称。
- 预设角色 `Admin`、`Responder`、`Viewer` 始终可匹配。自定义角色须处于启用状态，已禁用的角色即使同名也不会命中。
- 团队只匹配未删除的团队。
- 同名的角色或团队有多个时，取 ID 最小的一个。
- 未匹配到的名称会被跳过，不影响其他名称。
- 被选为默认角色或默认团队的角色和团队无法删除，须先在 SSO 配置中取消选择，详见 [默认值何时生效](/zh/platform/configure-sso#默认值何时生效)。
