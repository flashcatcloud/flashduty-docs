[Authing](https://www.authing.cn/) 是一家提供身份识别和访问控制管理的供应商，通过 Authing 平台，可实现以 OIDC、SAML2.0 或 CAS 协议的方式登录 Flashduty 管理控制台。

## 准备工作

<Steps>
<Step title="登录或注册 Authing">
如果是新注册用户，需先创建用户池，根据提示创建即可。
</Step>

<Step title="创建应用">
- 选择标准 web 应用
- 填写应用名称
- 填写认证地址（SSO 登录时跳转的地址）

![创建应用](https://docs-cdn.flashcat.cloud/images/png/436934.png)
</Step>

<Step title="记录相关信息">
![应用信息](https://docs-cdn.flashcat.cloud/images/png/436952.png)

| 字段 | 描述 |
|---|---|
| App ID | 对应 Flashduty 的 Client ID |
| APP Secret | 对应 Flashduty 的 Client Secret |
| Issuer | 对应 Flashduty 的 Issuer |
| 认证地址 | 通过 SSO 登录时跳转的地址 |
</Step>
</Steps>

## 协议配置

<Tabs>
<Tab title="OIDC 协议">

### 1. 选择协议并填写连接参数

打开 [Flashduty](https://console.flashcat.cloud) 控制台，进入 **平台管理 → 组织 → 单点登录**，打开 **启用单点登录**，在 **协议与连接** 中选择 **OIDC**。

填写 Authing 应用的信息：

| Flashduty 字段 | 填写内容 |
| --- | --- |
| Issuer | Authing 应用的 Issuer |
| Client ID | Authing 应用的 App ID |
| Client Secret | Authing 应用的 App Secret |
| Scopes | 保持默认的 `openid`、`profile`、`email`、`phone` |

### 2. 填写成员匹配并保存

在 **成员匹配** 中填 **邮箱** `email`、**用户名** `username`、**手机** `phone_number`。**邮箱** 必须填写；没填邮箱时，**用户名** 与 **手机** 要同时填写，否则保存被拒绝（接口返回 `configure either an email mapping, or both phone and name mappings`）。成员关联规则见 [单点登录配置](/zh/platform/configure-sso#成员关联方式)。

点击 **保存**。保存成功后，页面底部出现 **Flashcat 服务提供商信息**，复制其中 OIDC 的 **Redirect URL**，填到 Authing 应用的 **认证配置 → 登录回调 URL** 并保存：

![回调 URL](https://docs-cdn.flashcat.cloud/images/png/436957.png)

### 3. 更改 Authing 配置

将 id_token 签名算法更改为 **RS256**：

![签名算法](https://docs-cdn.flashcat.cloud/images/png/436961.png)

**登录控制** 页签中，勾选 **用于登录** 列的账号字段（示例中全部勾选）：

![登录控制](https://docs-cdn.flashcat.cloud/images/png/436964.png)

**访问授权** 页签的 **应用访问控制** 中，将 **所有人** 的授权作用从 **拒绝** 改为 **允许**，并在确认框中点击 **更改**：

![权限配置](https://docs-cdn.flashcat.cloud/images/png/436967.png)

### 4. 创建用户并测试登录

<Note>
Flashduty 默认通过邮箱关联成员，建议用邮箱创建用户。新建 SSO 配置也可以配置稳定用户 ID 字段进行关联，详见 [单点登录配置](/zh/platform/configure-sso)。
</Note>

在 Authing 中创建用户：

![创建用户](https://docs-cdn.flashcat.cloud/images/png/436973.png)

配置保存后，Flashduty 单点登录页面顶部会出现可复制的 **成员登录地址**。复制它并在新窗口打开，会跳转到 Authing 的登录页；用刚创建的用户登录后回到 Flashduty 控制台。

<Tip>
您也可以访问 `console.flashcat.cloud`，选择 SSO 登录方式进入。
</Tip>

</Tab>

<Tab title="SAML2.0 协议">

<Tip>
可以新创建应用或者在已有的应用中修改，这里通过修改应用进行演示。
</Tip>

### 1. 启用 Authing 的 SAML2.0

在 Authing 应用的 **协议配置** 页签，把授权配置切换到 **SAML2.0**，打开 **启用 SAML2 Provider**：

![选择 SAML](https://docs-cdn.flashcat.cloud/images/png/436984.png)

页面上有两个地址要用：**SAML2 元数据文档** 下载后交给 Flashduty 上传；**默认 ACS 地址** 等 Flashduty 保存配置后，用 **Assertion Consumer Service URL** 填写。

### 2. 在 Flashduty 选择协议并上传元数据

进入 **平台管理 → 组织 → 单点登录**，打开 **启用单点登录**，在 **协议与连接** 中选择 **SAML 2.0**，在 **元数据文档** 里上传上一步下载的 SAML2 元数据文档：

![下载 metadata](https://docs-cdn.flashcat.cloud/images/png/436990.png)

SAML 2.0 首次保存必须有这份元数据文档，没上传时点 **保存** 会提示「请先上传元数据文档」。

### 3. 填写成员匹配并保存

在 **成员匹配** 中填 **邮箱** `email`、**用户名** `username`、**手机** `phone`。**邮箱** 必须填写；没填邮箱时，**用户名** 与 **手机** 要同时填写，否则保存被拒绝。成员关联规则见 [单点登录配置](/zh/platform/configure-sso#成员关联方式)。

点击 **保存**。保存成功后，页面底部出现 **Flashcat 服务提供商信息**，复制 **Assertion Consumer Service URL**。

### 4. 把 ACS 地址填回 Authing

将上一步复制的 **Assertion Consumer Service URL** 粘贴到 Authing 应用的 **默认 ACS 地址**，点击 **保存**：

![保存配置](https://docs-cdn.flashcat.cloud/images/png/436989.png)

### 5. 测试登录

参考 OIDC 协议的登录流程，用 **成员登录地址** 发起一次登录测试。

</Tab>

<Tab title="CAS 协议">

### 1. 选择协议并填写连接参数

打开 [Flashduty](https://console.flashcat.cloud) 控制台，进入 **平台管理 → 组织 → 单点登录**，打开 **启用单点登录**，在 **协议与连接** 中选择 **CAS**。

| Flashduty 字段 | 填写内容 |
| --- | --- |
| CAS 地址 | Authing 应用 **协议配置** 页里的 CAS IdP 地址，形如 `https://<用户池域名>/cas-idp/<应用 ID>` |
| CAS 登录路径 | `/login` |
| 跳过 TLS 检查 | 保持关闭；Authing 使用受信任的证书时不需要开启 |

### 2. 填写成员匹配并保存

在 **成员匹配** 中填 **邮箱** `email`、**用户名** `username`、**手机** `phone_number`。**邮箱** 必须填写；没填邮箱时，**用户名** 与 **手机** 要同时填写，否则保存被拒绝。成员关联规则见 [单点登录配置](/zh/platform/configure-sso#成员关联方式)。

点击 **保存**。保存成功后，页面底部出现 **Flashcat 服务提供商信息**，复制其中 CAS 的 **Redirect URL**，填到 Authing 应用的 **认证配置 → 登录回调 URL** 并保存。

### 3. 更改 Authing 配置

在 **协议配置** 页签中，将授权配置切换到 **CAS**，开启 **启用 CAS IdP**，**CAS 用户标识** 填写 `${user.email}`，其余保持默认。

**登录控制** 页签中，勾选 **用于登录** 列的账号字段（示例中全部勾选）：

![登录控制](https://docs-cdn.flashcat.cloud/images/png/436964.png)

**访问授权** 页签的 **应用访问控制** 中，将 **所有人** 的授权作用从 **拒绝** 改为 **允许**，并在确认框中点击 **更改**：

![权限配置](https://docs-cdn.flashcat.cloud/images/png/436967.png)

### 4. 创建用户并测试登录

<Note>
Flashduty 默认通过邮箱关联成员，建议用邮箱创建用户。新建 SSO 配置也可以配置稳定用户 ID 字段进行关联，详见 [单点登录配置](/zh/platform/configure-sso)。
</Note>

在 Authing 中创建用户：

![创建用户](https://docs-cdn.flashcat.cloud/images/png/436973.png)

配置保存后，复制 Flashduty 单点登录页面顶部的 **成员登录地址**，在新窗口打开，用刚创建的用户登录 Flashduty 控制台。

</Tab>
</Tabs>
