通过 webhook 的方式同步阿里云 Prometheus 监控告警事件到 Flashduty On-call。

<div className="hide">

## 在 Flashduty On-call
您可通过以下两种方式获取集成推送地址，任选其一即可。

### 使用专属集成

如果您只需将告警发往一个协作空间，选择此方式，配置更简单。

<AccordionGroup>
  <Accordion title="查看专属集成的配置步骤">
  
  1. 进入 Flashduty 控制台，选择 **协作空间**，打开一个协作空间
  2. 选择 **配置** → **集成数据** → **专属集成**，点击 **新增一个集成**
  3. 选择 **阿里云监控 Prometheus** 集成，点击 **保存**，生成卡片。
  4. 打开生成的集成卡片，复制 **推送地址**
  
    
</Accordion>
</AccordionGroup>

### 使用共享集成

如果您需要根据告警事件的 Payload 将告警路由到不同协作空间，选择此方式。

<AccordionGroup>
  <Accordion title="查看共享集成的配置步骤">
  
  1. 进入 Flashduty 控制台，选择 **集成中心 → 告警事件**
  2. 选择 **阿里云监控 Prometheus** 集成：
        - **集成名称**：为当前集成定义一个名称。
  3. 配置默认路由并选择协作空间；创建后可在 **路由** 中增加更多规则
  4. 点击 **保存**，复制生成的 **推送地址**
    
</Accordion>
</AccordionGroup>
</div>

## 在阿里云

<Steps>
<Step title="创建自定义 Webhook">

**操作路径**：云监控控制台 › Prometheus 监控 › 通知对象 › 自定义 Webhook

创建或编辑 **自定义 Webhook**：

| 字段 | 值 | 必填 |
| --- | --- | --- |
| 名称、标识符 | `Flashduty` | 必填 |
| URL | `{integration_url}` | 必填 |
| Header Key / Header Value | `Content-Type` / `application/json` | 必填 |
| Method | `POST` | 必填 |
| 数据格式 | `JSON` | 必填 |

点击 **确定** 完成配置。

</Step>

<Step title="配置报警规则">

**操作路径**：云监控控制台 › Prometheus 监控 › 报警规则 › 创建或编辑报警规则 › 通知模式

| 字段 | 值 | 必填 |
| --- | --- | --- |
| 通知模式 | 极简模式 | 必填 |
| 通知对象 | 上一步创建的自定义 Webhook | 必填 |

点击 **确定** 完成配置。

</Step>

<Step title="触发报警并确认">

**操作路径**：云监控控制台 › Prometheus 监控 › 报警规则 › 目标规则

等待规则触发报警。回到 Flashduty 控制台的集成列表，集成展示了 **最新事件时间**，说明配置成功。
{/* console:
接入清单中的「收到第一个事件」同时变为已完成。
*/}

</Step>
</Steps>

## 状态和告警等级
<div className="md-block">

阿里云 Prometheus 监控到 Flashduty 告警等级映射关系：

| 阿里云监控 | Flashduty |
| :--- | :--- |
| 紧急 | Critical |
| 错误 | Critical |
| 警告 | Warning |
| 普通 | Info |
