通过 webhook 的方式同步 UCloud CloudWatch 的告警事件到 Flashduty。

<div className="hide">

## 在 Flashduty On-call

您可通过以下两种方式获取一个 UCloud CloudWatch 告警集成地址，任选其一即可。

### 使用专属集成

如果您只需将告警发往一个协作空间，选择此方式，配置更简单。

<AccordionGroup>
  <Accordion title="查看专属集成的配置步骤">
  
  1. 进入 Flashduty 控制台，选择 **协作空间**，打开一个协作空间
  2. 选择 **配置** → **集成数据** → **专属集成**，点击 **新增一个集成**
  3. 选择 **UCloud CloudWatch** 集成，点击 **保存**，生成卡片。
  4. 点击生成的卡片，可以查看到 **UCloud CloudWatch 告警集成地址**，复制备用，完成。
    
</Accordion>
</AccordionGroup>

### 使用共享集成

如果您需要根据告警事件的 Payload 将告警路由到不同协作空间，选择此方式。

<AccordionGroup>
  <Accordion title="查看共享集成的配置步骤">
  
  1. 进入 Flashduty 控制台，选择 **集成中心 → 告警事件**
  2. 选择 **UCloud CloudWatch** 集成：
        - **集成名称**：为当前集成定义一个名称。
        - **推送模式**：选择 UCloud CloudWatch 告警在何种情况下触发或恢复 Flashduty 告警。
  3. 复制当前页面的 **UCloud CloudWatch 告警集成地址** 备用。
  4. 配置默认路由并选择协作空间；创建后可在 **路由** 中增加更多规则
    
</Accordion>
</AccordionGroup>

</div>

## 在 UCloud 中配置

<Steps>
<Step title="在 UCloud CloudWatch 中配置通知模版">

**操作路径**：UCloud 控制台 › CloudWatch › 通知管理 › 通知模版 › 创建（或编辑已有模版）

| 字段 | 填写 |
| --- | --- |
| 接口回调（必填） | 勾选 |
| 回调语言（必填） | `英文` |
| 回调地址（必填） | `{integration_url}` |
| 模版名称（必填） | `Flashduty` 或其他名称 |

其他选项按需配置，点击 **提交**。

![UCloud CloudWatch 告警集成：配置通知模版 界面截图](https://docs-cdn.flashcat.cloud/images/png/7243d6686265fd95da85f88efc1feab5.png)

</Step>

<Step title="在告警策略中使用该通知模版">

**操作路径**：UCloud 控制台 › CloudWatch › 告警管理 › 告警策略 › 新建（或编辑已有策略）› 通知设置

| 字段 | 填写 |
| --- | --- |
| 通知设置（必填） | 上一步创建的通知模版 |

其他选项按需配置，点击 **提交**。

</Step>

<Step title="触发告警并确认">

**操作路径**：UCloud 控制台 › CloudWatch › 告警管理 › 告警策略 › 目标策略

UCloud CloudWatch 未提供独立的回调测试入口。让策略中的一条规则触发，或等待真实告警。

回到 Flashduty，集成显示 **最新事件时间**，说明配置成功。
{/* console:
接入清单中的「收到第一个事件」同时变为已完成。
*/}

</Step>
</Steps>

## 状态和告警等级
当前 UCloud CloudWatch 告警集成推送到 Flashduty 的严重程度均为 Warning，但您可以通过[告警处理 Pipeline](/zh/on-call/integration/alert-integration/alert-pipelines) 来自定义严重程度。
