通过 webhook 的方式同步火山引擎日志服务 TLS 告警事件到 Flashduty On-call，实现告警事件自动化降噪处理。

<div className="hide">

## 在 Flashduty On-call
您可通过以下两种方式获取集成推送地址，任选其一即可。

### 使用专属集成

如果您只需将告警发往一个协作空间，选择此方式，配置更简单。

<AccordionGroup>
  <Accordion title="查看专属集成的配置步骤">
  
  1. 进入 Flashduty 控制台，选择 **协作空间**，打开一个协作空间
  2. 选择 **配置** → **集成数据** → **专属集成**，点击 **新增一个集成**
  3. 选择 **火山引擎 TLS** 集成，点击 **保存**，生成卡片。
  4. 打开生成的集成卡片，复制 **推送地址**
  
    
</Accordion>
</AccordionGroup>

### 使用共享集成

如果您需要根据告警事件的 Payload 将告警路由到不同协作空间，选择此方式。

<AccordionGroup>
  <Accordion title="查看共享集成的配置步骤">
  
  1. 进入 Flashduty 控制台，选择 **集成中心 → 告警事件**
  2. 选择 **火山引擎 TLS** 集成：
        - **集成名称**：为当前集成定义一个名称。
  3. 配置默认路由并选择协作空间；创建后可在 **路由** 中增加更多规则
  4. 点击 **保存**，复制生成的 **推送地址**
    
</Accordion>
</AccordionGroup>

</div>

## 在火山引擎日志服务 TLS 中配置

<Steps>
<Step title="在 TLS 中创建 Webhook 集成">

**操作路径**：日志服务控制台 › 常用功能 › 日志告警 › 通知管理 › Webhook 集成 › 创建 Webhook 集成

| 字段 | 填写 |
| --- | --- |
| 名称（必填） | `Flashduty` |
| 通知渠道类型（必填） | 自定义 Webhook |
| 请求方法（必填） | `POST` |
| 请求地址（必填） | `{integration_url}` |
| 请求头（可选） | 保持默认 `content-type: application/json` |

填写后点击 **创建**。

<img alt="创建 Webhook 集成" width="600" src="https://download.flashcat.cloud/flashduty/doc/ve-tls-1.png" />

<img alt="填写 Webhook 集成" width="600" src="https://download.flashcat.cloud/flashduty/doc/ve-tls-2.png" />

</Step>
<Step title="在 TLS 中创建内容模板">

**操作路径**：日志服务控制台 › 常用功能 › 日志告警 › 通知管理 › 内容模板 › 创建内容模板

| 字段 | 填写 |
| --- | --- |
| 模板名称（必填） | `Flashduty` |
| 自定义 Webhook 的通知内容（必填） | 下方 JSON 模板 |
| 其他渠道的通知内容（可选） | 可为空 |

```
{
	"AccountID":"{{AccountID}}",
	"ProjectName":"{{ProjectName}}",
	"AlarmTopicName":"{{AlarmTopicName}}",
	"Region":"{{Region}}",
	"Alarm":"{{Alarm}}",
	"AlarmID":"{{AlarmID}}",
	"Duration":"{{Duration}}",
	"Condition":"{{Condition}}",
	"HappenThreshold":"{{HappenThreshold}}",
	"Topics":"{{Topics|join:','}}", 
	"NotifyTimeUnix":"{{NotifyTimeUnix}}",
	"NotifyType":"{{NotifyType}}",
	"Severity":"{{Severity}}",
	"ConsecutiveAlertNums":"{{ConsecutiveAlertNums}}",
	"TriggerParams":{{toJson(TriggerParams)|safe}}, 
	"ExecuteQuery":{{toJson(ExecuteQuery)|safe}},
	"DetailUrl":"{{DetailUrl}}",
	"FireResultsCount":"{{FireResultsCount}}"
}
```

模板中必须保留 `NotifyType` 字段：`NotifyType` 为 `2` 时对应告警恢复。

填写后点击 **确认**。

<img alt="创建内容模板" width="600" src="https://download.flashcat.cloud/flashduty/doc/ve-tls-3.png" />

</Step>
<Step title="在 TLS 中创建通知组">

**操作路径**：日志服务控制台 › 常用功能 › 日志告警 › 通知管理 › 通知组 › 创建通知组

| 字段 | 填写 |
| --- | --- |
| 通知组名称（必填） | `Flashduty` |
| 通知策略 › 通知规则（可选） | 按需配置 |
| 通知策略 › 通知渠道 › 渠道类型（必填） | **默认渠道**，保持勾选 **自定义 Webhook** |
| Webhook（必填） | 选择第 1 步创建的 `Flashduty` |
| 内容模板（必填） | 选择第 2 步创建的 `Flashduty` |

填写后点击 **创建通知组**。

<img alt="创建通知组" width="600" src="https://download.flashcat.cloud/flashduty/doc/ve-tls-4.png" />

</Step>
<Step title="在告警策略中关联通知组">

**操作路径**：日志服务控制台 › 常用功能 › 日志告警 › 告警策略 › 创建告警策略（或编辑已有策略）

| 字段 | 填写 |
| --- | --- |
| 告警规则（必填） | 按需配置 |
| 通知组（必填） | 点击 **关联通知组**，在弹出的选择框中选择第 3 步创建的 `Flashduty`，点击 **关联** |

配置其他内容后点击 **创建 / 保存**。

<img alt="在告警策略中关联通知组" width="600" src="https://download.flashcat.cloud/flashduty/doc/ve-tls-5.png" />

</Step>
<Step title="触发一次告警并确认">

**操作路径**：日志服务控制台 › 常用功能 › 日志告警 › 告警策略

请让监控的日志命中告警规则（可临时调低触发条件），或等待真实告警。

回到 Flashduty，集成显示 **最新事件时间**，说明配置成功。
{/* console:
接入清单中的「收到第一个事件」同时变为已完成。
*/}

</Step>
</Steps>
