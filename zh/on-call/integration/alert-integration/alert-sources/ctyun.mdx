## 在 Flashduty On-call
您可通过以下两种方式获取集成推送地址，任选其一即可。

### 使用专属集成

如果您只需将告警发往一个协作空间，选择此方式，配置更简单。

<AccordionGroup>
  <Accordion title="查看专属集成的配置步骤">
  
  1. 进入 Flashduty 控制台，选择 **协作空间**，打开一个协作空间
  2. 选择 **配置** → **集成数据** → **专属集成**，点击 **新增集成**
  3. 选择 **天翼云** 集成，点击 **保存**，生成卡片。
  4. 打开生成的集成卡片，复制 **推送地址**

    
</Accordion>
</AccordionGroup>

### 使用共享集成

如果您需要根据告警事件的 Payload 将告警路由到不同协作空间，选择此方式。

<AccordionGroup>
  <Accordion title="查看共享集成的配置步骤">
  
  1. 进入 Flashduty 控制台，选择 **集成中心 → 告警事件**
  2. 选择 **天翼云** 集成：
        - **集成名称**：为当前集成定义一个名称。
  3. 配置默认路由并选择协作空间；创建后可在 **路由** 中增加更多规则
  4. 点击 **保存**，复制生成的 **推送地址**
    
</Accordion>
</AccordionGroup>
</div>

## 在天翼云中配置

<Steps>
<Step title="在天翼云中创建告警联系人/组">

**操作路径**：天翼云控制台 › 管理与部署 › 云监控 › 告警服务 › 告警联系人/组

创建相应的告警联系人/组，告警规则的通知对象需要它。

</Step>

<Step title="在告警规则中填写告警回调">

**操作路径**：天翼云控制台 › 管理与部署 › 云监控 › 告警服务 › 告警规则 › 创建告警规则（或修改已有规则）› 告警回调

| 字段 | 填写 |
| --- | --- |
| 告警回调（必填） | `{integration_url}` |

填写后点击 **测试**，测试成功后点击 **保存**。**测试** 只验证到推送地址的接口连通性，是否真正收到告警以真实告警为准。

天翼云从 182.43.5.0/24 和 182.43.7.0/24 发起回调，如有出站限制请加入白名单；回调失败重试 3 次，超时时间 5 秒，端点须返回 HTTP 200。

<img alt="天翼云告警规则中填写告警回调" width="600" src="https://download.flashcat.cloud/flashduty/doc/zh/statecloud/state-1.png" />

</Step>

<Step title="确认 Flashduty 收到事件">

**操作路径**：天翼云控制台 › 管理与部署 › 云监控 › 告警服务 › 告警规则 › 修改 › 告警回调 › 测试

**测试** 只验证连通性；请让规则触发一条真实告警，以确认 Flashduty 收到事件。

回到 Flashduty，集成显示 **最新事件时间**，说明配置成功。

{/* console:
接入清单中的「收到第一个事件」同时变为已完成。
*/}

</Step>
</Steps>
