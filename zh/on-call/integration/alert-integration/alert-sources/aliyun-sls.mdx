通过 webhook 的方式同步阿里云日志服务 SLS 监控告警事件到 Flashduty On-call。

<div className="hide">

## 在 Flashduty On-call
您可通过以下两种方式获取集成推送地址，任选其一即可。

### 使用专属集成

如果您只需将告警发往一个协作空间，选择此方式，配置更简单。

<AccordionGroup>
  <Accordion title="查看专属集成的配置步骤">
  
  1. 进入 Flashduty 控制台，选择 **协作空间**，打开一个协作空间
  2. 选择 **配置** → **集成数据** → **专属集成**，点击 **新增一个集成**
  3. 选择 **阿里云 SLS** 集成，点击 **保存**，生成卡片。
  4. 打开生成的集成卡片，复制 **推送地址**
  
    
</Accordion>
</AccordionGroup>

### 使用共享集成

如果您需要根据告警事件的 Payload 将告警路由到不同协作空间，选择此方式。

<AccordionGroup>
  <Accordion title="查看共享集成的配置步骤">
  
  1. 进入 Flashduty 控制台，选择 **集成中心 → 告警事件**
  2. 选择 **阿里云 SLS** 集成：
        - **集成名称**：为当前集成定义一个名称。
  3. 配置默认路由并选择协作空间；创建后可在 **路由** 中增加更多规则
  4. 点击 **保存**，复制生成的 **推送地址**
    
</Accordion>
</AccordionGroup>
</div>

## 在阿里云 SLS

<Steps>
<Step title="在 SLS 中创建 Webhook 集成">

**操作路径**：日志服务 SLS 控制台 › 目标 Project › 告警 › 告警管理 › Webhook集成 › 新建

<img alt="SLS 告警管理入口" width="600" src="https://download.flashcat.cloud/flashduty/integration/aliyun-sls/aliyun-sls-alert-management.jpg" />

| 字段 | 值 | 必填 |
| --- | --- | --- |
| 类型 | 通用 Webhook | 必填 |
| 请求方法 | `POST` | 必填 |
| 请求地址 | `{integration_url}` | 必填 |

点击 **确认** 保存。

<img alt="SLS 新建 Webhook 集成" width="600" src="https://download.flashcat.cloud/flashduty/integration/aliyun-sls/aliyun-sls-create-webhook.jpg" />

</Step>
<Step title="在 SLS 中创建内容模板">

**操作路径**：告警管理 › 内容模板 › 添加 › Webhook-自定义

| 字段 | 值 | 必填 |
| --- | --- | --- |
| 发送方式 | 逐条发送 | 必填 |
| 发送内容 | 见下方代码块 | 必填 |

```
{{ alert | to_json}}
```

点击 **确认** 保存。

<img alt="SLS 新建内容模板" width="600" src="https://download.flashcat.cloud/flashduty/integration/aliyun-sls/aliyun-sls-create-template.jpg" />

</Step>
<Step title="在 SLS 中创建行动策略">

**操作路径**：告警管理 › 行动策略 › 添加 › 第一行动列表

在 `第一行动列表` 中添加一个 `行动组` 节点：

| 字段 | 值 | 必填 |
| --- | --- | --- |
| 渠道 | 通用 Webhook | 必填 |
| 选择Webhook | 第 1 步创建的 Webhook | 必填 |
| 内容模板 | 第 2 步创建的内容模板 | 必填 |
| 发送时段 | 任意 | 必填 |

点击 **结束** 完成第一行动列表，再点击 **确认** 保存。

<img alt="SLS 新建行动策略" width="600" src="https://download.flashcat.cloud/flashduty/integration/aliyun-sls/aliyun-sls-create-action-policy.jpg" />

</Step>
<Step title="在告警规则中选择行动策略">

**操作路径**：日志服务 SLS 控制台 › 告警 › 规则/事务 › 新建告警（或编辑已有告警） › 告警规则 › 告警策略

| 字段 | 值 | 必填 |
| --- | --- | --- |
| 告警策略 | 普通模式 | 必填 |
| 行动策略 | 第 3 步创建的行动策略 | 必填 |

点击 **确定** 保存。对其他规则重复上述步骤，即可将全部告警推送到 Flashduty。

<img alt="SLS 告警规则选择行动策略" width="600" src="https://download.flashcat.cloud/flashduty/integration/aliyun-sls/aliyun-sls-update-alert-rule.jpg" />

</Step>
<Step title="触发告警并确认">

**操作路径**：日志服务 SLS 控制台 › 告警 › 规则/事务 › 目标告警

等待规则触发告警（或临时调低阈值触发一次）。回到 Flashduty，集成显示 **最新事件时间**，说明配置成功。
{/* console:
接入清单中的「收到第一个事件」同时变为已完成。
*/}

</Step>
</Steps>

## 阿里云操作审计 ActionTrail
<div className="md-block">

操作审计 ActionTrail 的“事件告警”功能由日志服务 SLS 提供，不是独立的推送通道。您需要先创建一条跟踪（Trail），把事件投递到一个 Logstore，再在该 Logstore 上配置 SLS 告警。通知渠道沿用上文的 Webhook 集成步骤，无需为 ActionTrail 单独接入。

1. 登录阿里云控制台，进入 **操作审计** 产品，创建一条跟踪，将事件投递到日志服务 SLS 的一个 Logstore
2. 进入 **操作审计控制台 → 事件告警 → 告警中心**（或直接进入该 Logstore 所在的日志服务 SLS 控制台），选择对应的跟踪或 Logstore
3. 按照上文“在阿里云 SLS”中的第 1–4 步，配置 Webhook、内容模板、行动策略与监控规则，推送地址使用同一个 Flashduty 集成推送地址

</div>
