通过 webhook 的方式同步观测云告警事件到 Flashduty On-call。

<div className="hide">

## 在 Flashduty On-call
您可通过以下两种方式获取集成推送地址，任选其一即可。

### 使用专属集成

如果您只需将告警发往一个协作空间，选择此方式，配置更简单。

<AccordionGroup>
  <Accordion title="查看专属集成的配置步骤">
  
  1. 进入 Flashduty 控制台，选择 **协作空间**，打开一个协作空间
  2. 选择 **配置** → **集成数据** → **专属集成**，点击 **新增一个集成**
  3. 选择 **观测云** 集成，点击 **保存**，生成卡片。
  4. 打开生成的集成卡片，复制 **推送地址**

    
</Accordion>
</AccordionGroup>

### 使用共享集成

如果您需要根据告警事件的 Payload 将告警路由到不同协作空间，选择此方式。

<AccordionGroup>
  <Accordion title="查看共享集成的配置步骤">
  
  1. 进入 Flashduty 控制台，选择 **集成中心 → 告警事件**
  2. 选择 **观测云** 集成：
        - **集成名称**：为当前集成定义一个名称。
  3. 配置默认路由并选择协作空间；创建后可在 **路由** 中增加更多规则
  4. 点击 **保存**，复制生成的 **推送地址**
    
</Accordion>
</AccordionGroup>
</div>

## 在观测云中配置

<Steps>
<Step title="在观测云中创建 Webhook 通知对象">

**操作路径**：观测云控制台 › 监控 › 通知对象管理 › 新建通知对象 › Webhook

| 字段 | 填写 |
| --- | --- |
| 名称（必填） | `Flashduty` |
| Webhook 地址（必填） | `{integration_url}` |

其他选项按需配置，点击 **确定** 完成创建。

<img alt="观测云新建 Webhook 通知对象" width="600" src="https://download.flashcat.cloud/flashduty/doc/zh/fd/guance-1.png" />

</Step>

<Step title="在告警策略中使用该通知对象">

**操作路径**：观测云控制台 › 监控 › 告警策略管理 › 新建告警策略（或修改已有策略）› 通知配置

| 字段 | 填写 |
| --- | --- |
| 等级（必填） | 选择需要通知的告警等级 |
| 通知对象（必填） | 上一步创建的 `Flashduty` |

其他选项按需配置，点击 **保存** 完成创建。

<img alt="观测云告警策略中选择通知对象" width="600" src="https://download.flashcat.cloud/flashduty/doc/zh/fd/guance-2.png" />

</Step>

<Step title="触发告警并确认">

**操作路径**：观测云控制台 › 监控 › 监控器 › 目标监控器

让一条已关联该告警策略的监控器触发告警，或等待真实告警。

回到 Flashduty，集成显示 **最新事件时间**，说明配置成功。
{/* console:
接入清单中的「收到第一个事件」同时变为已完成。
*/}

</Step>
</Steps>

## 状态和告警等级

<div className="md-block">

| 观测云 `df_status` | Flashduty | 状态 |
| --- | --- | --- |
| `critical`、`fatal` | Critical | 严重 |
| `error`、`warning` | Warning | 警告 |
| `info`、`nodata` | Info | 提醒 |
| 其他值 | Info | 提醒 |
| `ok` | Info | 已恢复（OK） |

</div>
