通过 webhook 的方式同步火山引擎云监控事件中心告警事件到 Flashduty On-call，实现告警事件自动化降噪处理。

<div className="hide">

## 在 Flashduty On-call
您可通过以下两种方式获取集成推送地址，任选其一即可。

### 使用专属集成

如果您只需将告警发往一个协作空间，选择此方式，配置更简单。

<AccordionGroup>
  <Accordion title="查看专属集成的配置步骤">
  
  1. 进入 Flashduty 控制台，选择 **协作空间**，打开一个协作空间
  2. 选择 **配置** → **集成数据** → **专属集成**，点击 **新增一个集成**
  3. 选择 **火山引擎CM 事件** 集成，点击 **保存**，生成卡片。
  4. 打开生成的集成卡片，复制 **推送地址**
  
    
</Accordion>
</AccordionGroup>

### 使用共享集成

如果您需要根据告警事件的 Payload 将告警路由到不同协作空间，选择此方式。

<AccordionGroup>
  <Accordion title="查看共享集成的配置步骤">
  
  1. 进入 Flashduty 控制台，选择 **集成中心 → 告警事件**
  2. 选择 **火山引擎CM 事件** 集成：
        - **集成名称**：为当前集成定义一个名称。
  3. 配置默认路由并选择协作空间；创建后可在 **路由** 中增加更多规则
  4. 点击 **保存**，复制生成的 **推送地址**
    
</Accordion>
</AccordionGroup>

</div>

## 在火山引擎云监控中配置

<Steps>
<Step title="在云监控中创建 Flashduty 回调地址">

<Tabs>
<Tab title="新版控制台（通知策略）">

**操作路径**：云监控控制台 › 通知 › 通知策略 › 通知对象 › 回调地址 › 创建回调地址

| 字段 | 填写 |
| --- | --- |
| 回调地址名称（必填） | `Flashduty_Event`（回调地址的唯一标识，不允许重名） |
| 通道（必填） | 通用回调地址通道 |
| 回调地址（必填） | `{integration_url}` |
| 自定义 Token / 自定义 Header（可选） | 无需鉴权时留空 |

填写后可点击左下角 **连通性测试**，再点击右下角 **确定**。

</Tab>
<Tab title="旧版控制台（通知组）">

**操作路径**：云监控控制台 › 通知组 › 回调 › 创建回调地址

| 字段 | 填写 |
| --- | --- |
| 回调地址名称（必填） | `Flashduty_Event` |
| 回调地址类型（必填） | 通用回调地址 |
| 回调地址（必填） | `{integration_url}` |

点击 **确认** 完成创建。旧版不支持连通性测试，即使点击测试出现连通性失败，也不会影响告警的接收。

<img alt="创建回调地址" width="600" src="https://download.flashcat.cloud/flashduty/doc/ve-m-1.png" />

<img alt="填写回调地址" width="600" src="https://download.flashcat.cloud/flashduty/doc/ve-m-2.png" />

</Tab>
</Tabs>

</Step>
<Step title="在事件规则中选择该回调地址">

**操作路径**：云监控控制台 › 事件中心 › 事件规则 › 创建事件规则（或编辑已有规则）

| 字段 | 填写 |
| --- | --- |
| 事件规则（必填） | 按需配置事件类型与条件 |
| 投递渠道（必填） | 勾选 **告警回调** |
| 告警回调（必填） | 在下拉框中选择上一步创建的 `Flashduty_Event` |

配置完成后点击 **确认**。

<img alt="在事件规则中选择告警回调" width="600" src="https://download.flashcat.cloud/flashduty/doc/ve-m-3.png" />

</Step>
<Step title="触发一次告警并确认">

**操作路径**：云监控控制台 › 事件中心 › 事件规则 › 目标规则

触发一个与事件规则匹配的云产品事件，或等待真实事件发生；云监控事件规则没有“发送测试”入口。

回到 Flashduty，集成显示 **最新事件时间**，说明配置成功。
{/* console:
接入清单中的「收到第一个事件」同时变为已完成。
*/}

</Step>
</Steps>
