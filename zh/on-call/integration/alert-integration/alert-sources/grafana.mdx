## 在 Flashduty On-call
您可通过以下两种方式获取集成推送地址，任选其一即可。

### 使用专属集成

如果您只需将告警发往一个协作空间，选择此方式，配置更简单。

<AccordionGroup>
  <Accordion title="查看专属集成的配置步骤">
  
  1. 进入 Flashduty 控制台，选择 **协作空间**，打开一个协作空间
  2. 选择 **配置** → **集成数据** → **专属集成**，点击 **新增一个集成**
  3. 选择 **Grafana** 集成，点击 **保存**，生成卡片。
  4. 打开生成的集成卡片，复制 **推送地址**
  
    
</Accordion>
</AccordionGroup>

### 使用共享集成

如果您需要根据告警事件的 Payload 将告警路由到不同协作空间，选择此方式。

<AccordionGroup>
  <Accordion title="查看共享集成的配置步骤">
  
  1. 进入 Flashduty 控制台，选择 **集成中心 → 告警事件**
  2. 选择 **Grafana** 集成：
        - **集成名称**：为当前集成定义一个名称。
  3. 配置默认路由并选择协作空间；创建后可在 **路由** 中增加更多规则
  4. 点击 **保存**，复制生成的 **推送地址**
    
</Accordion>
</AccordionGroup>
</div>

## 在 Grafana
Grafana V4~V8 默认启用 Legacy Alerting，V9 及以后默认启用 Grafana Alerting。两者的区别和启用方式见 [Grafana 官方文档](https://grafana.com/docs/grafana/v8.4/alerting/unified-alerting/opt-in/#opt-in-to-grafana-alerting)。请按您部署的版本选择下面的步骤。

### Legacy Alerting

<div className="md-block">

1. 打开您的 Grafana 控制台，选择 Alerting → Notification channels 页面
2. 点击 Add Channel，打开 Channel 配置弹窗
3. 填写名称，Type 选择 webhook，Url 填写集成推送地址，Method 选择 POST，如下图所示：

   <img src="https://download.flashcat.cloud/grafana-legacy-alerting.png" alt="drawing" width="600"/>

4. 保存后回到集成列表。产生告警后，如果集成展示了最新事件时间，说明配置成功

</div>

### Grafana Alerting

<div className="md-block">

1. 打开您的 Grafana 控制台，选择 Alerting → Contact points 页面
2. 点击 New contact point，打开配置弹窗页面
3. 填写名称，Type 选择 webhook，Url 填写集成推送地址，Method 选择 POST，如下图所示：

   <img src="https://download.flashcat.cloud/grafana-contact-point.png" alt="drawing" width="600"/>

4. 打开 Notification policies 页面，编辑或新增 policy，将上一步创建的 contact point 设为发送渠道，如下图所示：

   <img src="https://download.flashcat.cloud/grafana-notification-policy.png" alt="drawing" width="600"/>

5. 保存后回到集成列表。产生告警后，如果集成展示了最新事件时间，说明配置成功
6. 默认告警等级为 warning。如需自定义，请在告警详情页面配置 severity 标签（取值见下文状态对照），如下图所示：

   <img src="https://download.flashcat.cloud/grafana-alert-rule.png" alt="drawing" width="600"/>


</div>

## 状态对照
<div className="md-block">
  
Legacy Alerting 到 Flashduty 告警等级映射关系：

| Legacy Alerting |  Flashduty  | 状态 |
| --------------- | -------- | ---- |
| alerting        | Warning  | 警告 |
| no_data         | Critical | 严重 |
| ok              | Ok       | 恢复 |

Grafana Alerting 到 Flashduty 告警等级映射关系：

系统依次提取告警事件标签中的 `severity`、`priority` 和 `level`，取到的值作为 Grafana 自身的告警等级。如果都没有取到，告警等级设为 `warning`。

| Grafana Alerting |  Flashduty  | 状态 |
| ---------------- | -------- | ---- |
| critical         | Critical | 严重 |
| warning          | Warning  | 警告 |
| warn             | Warning  | 警告 |
| info             | Info     | 提醒 |
| acknowledged     | Info     | 提醒 |
| unknown          | Info     | 提醒 |
| unk              | Info     | 提醒 |
| ok               | Ok       | 恢复 |

</div>
