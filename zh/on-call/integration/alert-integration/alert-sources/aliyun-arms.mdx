通过 webhook 的方式同步阿里云 ARMS 监控告警事件到 Flashduty On-call。

<div className="hide">

## 在 Flashduty On-call
您可通过以下两种方式获取集成推送地址，任选其一即可。

### 使用专属集成

如果您只需将告警发往一个协作空间，选择此方式，配置更简单。

<AccordionGroup>
  <Accordion title="查看专属集成的配置步骤">
  
  1. 进入 Flashduty 控制台，选择 **协作空间**，打开一个协作空间
  2. 选择 **配置** → **集成数据** → **专属集成**，点击 **新增一个集成**
  3. 选择 **阿里云 ARMS** 集成，点击 **保存**，生成卡片。
  4. 打开生成的集成卡片，复制 **推送地址**
  
    
</Accordion>
</AccordionGroup>

### 使用共享集成

如果您需要根据告警事件的 Payload 将告警路由到不同协作空间，选择此方式。

<AccordionGroup>
  <Accordion title="查看共享集成的配置步骤">
  
  1. 进入 Flashduty 控制台，选择 **集成中心 → 告警事件**
  2. 选择 **阿里云 ARMS** 集成：
        - **集成名称**：为当前集成定义一个名称。
  3. 配置默认路由并选择协作空间；创建后可在 **路由** 中增加更多规则
  4. 点击 **保存**，复制生成的 **推送地址**
    
</Accordion>
</AccordionGroup>

</div>

## 在阿里云 ARMS

<Steps>
<Step title="在 ARMS 中新建 Webhook 通知对象">

**操作路径**：ARMS 控制台 › 告警管理 › 通知对象 › Webhook集成 › 新建 Webhook

| 字段 | 值 | 必填 |
| --- | --- | --- |
| 对象名称 | 自定义，例如 `Flashduty` | 必填 |
| 请求方法 | `Post` | 必填 |
| 推送地址 | `{integration_url}` | 必填 |
| Header | Key 填 `Content-Type`，Value 填 `application/json` | 必填 |
| 通知模板 | `$alertmanager_content` | 必填 |
| 恢复模板 | `$alertmanager_content` | 必填 |

点击 **确定** 保存。

<img alt="在 ARMS 新建 Webhook 通知对象" width="600" src="https://download.flashcat.cloud/flashduty/integration/aliyun-arms/notify_target.png" />

</Step>
<Step title="在 ARMS 中配置通知策略">

**操作路径**：ARMS 控制台 › 告警管理 › 通知策略 › 新建通知策略

单击 **新建通知策略**，或编辑已有策略；在 **通知对象** 中选择上一步创建的 `通用Webhook` 对象，提交保存。

<img alt="在 ARMS 通知策略中选择 Webhook 通知对象" width="600" src="https://download.flashcat.cloud/flashduty/integration/aliyun-arms/notify_rule.png" />

</Step>
<Step title="发送测试并确认">

**操作路径**：ARMS 控制台 › 告警管理 › 通知对象 › Webhook集成 › 新建 Webhook › 发送测试

ARMS 的 **发送测试** 无法替换 `$alertmanager_content`，只能检查连通性，不能用来验证事件内容。请等待真实告警触发。回到 Flashduty，集成显示 **最新事件时间**，说明配置成功。
{/* console:
接入清单中的「收到第一个事件」同时变为已完成。
*/}

</Step>
</Steps>

## 状态和告警等级
<div className="md-block">
  
阿里云 ARMS 监控到 Flashduty 告警等级映射关系：

| 阿里云 ARMS 监控 | Flashduty |
| ------------ | -------- |
| P1 | Critical |
| P2 | Warning |
| P3 | Warning |
| P4 | Info |
| P5 | Info |
| P6 | Info |
| critical | Critical |
| error | Warning |
| warning | Warning |
| page | Info |
| 其他值 | Info |

</div>
