## 在 Flashduty On-call
您可通过以下两种方式获取集成推送地址，任选其一即可。

### 使用专属集成

如果您只需将告警发往一个协作空间，选择此方式，配置更简单。

<AccordionGroup>
  <Accordion title="查看专属集成的配置步骤">
  
  1. 进入 Flashduty 控制台，选择 **协作空间**，打开一个协作空间
  2. 选择 **配置** → **集成数据** → **专属集成**，点击 **新增一个集成**
  3. 选择 **阿里云 ARMS** 集成，点击 **保存**，生成卡片。
  4. 打开生成的集成卡片，复制 **推送地址**
  
    
</Accordion>
</AccordionGroup>

### 使用共享集成

如果您需要根据告警事件的 Payload 将告警路由到不同协作空间，选择此方式。

<AccordionGroup>
  <Accordion title="查看共享集成的配置步骤">
  
  1. 进入 Flashduty 控制台，选择 **集成中心 → 告警事件**
  2. 选择 **阿里云 ARMS** 集成：
        - **集成名称**：为当前集成定义一个名称。
  3. 配置默认路由并选择协作空间；创建后可在 **路由** 中增加更多规则
  4. 点击 **保存**，复制生成的 **推送地址**
    
</Accordion>
</AccordionGroup>

## 在阿里云 ARMS
**步骤 1：配置通知对象**

<div className="md-block">

1. 登录阿里云控制台，打开 ARMS
2. 进入 `告警管理 -> 通知对象` 页面，选择 `Webhook集成`，单击 **新建 Webhook**
3. 如图所示，填写对象名称，选择 `Post`，粘贴集成推送地址
4. 添加 `Header`，输入 `Content-Type` 和 `application/json`
5. 通知模板内输入：`$alertmanager_content`
6. 点击 **确定** 保存。

<img alt="drawing" width="600" src="https://download.flashcat.cloud/flashduty/integration/aliyun-arms/notify_target.png" />


**步骤 2：配置通知策略**

1. 进入 `告警管理 -> 通知策略` 页面，单击 **新建通知策略**，或编辑已有策略
2. 如下图所示，在 `通知对象` 中选择已创建的 `通用Webhook` 对象
3. 提交保存，等待告警触发。

<img alt="drawing" width="600" src="https://download.flashcat.cloud/flashduty/integration/aliyun-arms/notify_rule.png" />

</div>
