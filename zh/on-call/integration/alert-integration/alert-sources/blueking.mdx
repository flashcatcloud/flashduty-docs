通过 webhook 的方式同步蓝鲸智云监控事件到 Flashduty On-call。

<div className="hide">

## 在 Flashduty On-call
您可通过以下两种方式获取集成推送地址，任选其一即可。

### 使用专属集成

如果您只需将告警发往一个协作空间，选择此方式，配置更简单。

<AccordionGroup>
  <Accordion title="查看专属集成的配置步骤">
  
  1. 进入 Flashduty 控制台，选择 **协作空间**，打开一个协作空间
  2. 选择 **配置** → **集成数据** → **专属集成**，点击 **新增集成**
  3. 选择 **蓝鲸智云** 集成，点击 **保存**，生成卡片。
  4. 打开生成的集成卡片，复制 **推送地址**
  
    
</Accordion>
</AccordionGroup>

### 使用共享集成

如果您需要根据告警事件的 Payload 将告警路由到不同协作空间，选择此方式。

<AccordionGroup>
  <Accordion title="查看共享集成的配置步骤">
  
  1. 进入 Flashduty 控制台，选择 **集成中心 → 告警事件**
  2. 选择 **蓝鲸智云** 集成：
        - **集成名称**：为当前集成定义一个名称。
  3. 配置默认路由并选择协作空间；创建后可在 **路由** 中增加更多规则
  4. 点击 **保存**，复制生成的 **推送地址**
    
</Accordion>
</AccordionGroup>
</div>

## 在蓝鲸智云中配置

以下内容已经在`蓝鲸V6/7版本`完成验证，V5 及以下版本官方已不再支持，建议您升级。

蓝鲸告警策略可以触发`处理套餐`，处理套餐可与周边系统打通，来完成复杂功能。我们首先创建一个处理套餐，配置 Flashduty 的回调地址，然后编辑告警策略，关联动作到该处理套餐，实现告警变更自动推送到 Flashduty。

<Steps>
<Step title="在蓝鲸监控平台中创建处理套餐">

**操作路径**：蓝鲸桌面 › 监控平台 › 配置 › 处理套餐 › 添加套餐

| 字段 | 填写 |
| --- | --- |
| 套餐名称（必填） | `Send To Flashduty` |
| 套餐类型（必填） | `HTTP回调` |
| 推送方式（必填） | `POST` |
| 回调地址（必填） | `{integration_url}` |
| 主体 › 类型（必填） | `JSON` |
| 主体 › 消息体（必填） | `{{alarm.callback_message}}`（实际产生告警时，蓝鲸会渲染变量内容作为 Payload 推送到目标回调地址） |

填写后保存套餐。

<img alt="蓝鲸监控平台创建处理套餐" width="600" src="https://download.flashcat.cloud/flashduty/integration/tencent-bk/create_package.jpg" />

</Step>
<Step title="在告警策略中关联处理套餐">

**操作路径**：蓝鲸桌面 › 监控平台 › 配置 › 告警策略 › 目标策略 › 编辑 › 告警处理

选择一个已有的策略编辑，或新建告警策略。

| 字段 | 填写 |
| --- | --- |
| 告警处理（必填） | 三种场景均选择 `Send To Flashduty` 处理套餐 |
| 防御规则 | 关闭 |

提交保存。对于其他想要推送到 Flashduty 的告警策略，重复以上步骤。

<img alt="蓝鲸监控平台告警策略关联处理套餐" width="600" src="https://download.flashcat.cloud/flashduty/integration/tencent-bk/update_alert_rule.jpg" />

</Step>
<Step title="确认 Flashduty 收到事件">

蓝鲸策略没有“发送测试”入口，需要等待已关联策略的真实告警触发。

回到 Flashduty，集成显示 **最新事件时间**，说明配置成功。
{/* console:
接入清单中的「收到第一个事件」同时变为已完成。
*/}

</Step>
</Steps>
