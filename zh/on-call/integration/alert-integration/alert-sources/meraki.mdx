通过 webhook 的方式同步 Meraki 告警事件到 Flashduty On-call。

<div className="hide">

## 在 Flashduty On-call
您可通过以下两种方式获取集成推送地址，任选其一即可。

### 使用专属集成

如果您只需将告警发往一个协作空间，选择此方式，配置更简单。

<AccordionGroup>
  <Accordion title="查看专属集成的配置步骤">
  
  1. 进入 Flashduty 控制台，选择 **协作空间**，打开一个协作空间
  2. 选择 **配置** → **集成数据** → **专属集成**，点击 **新增一个集成**
  3. 选择 **Meraki** 集成，点击 **保存**，生成卡片。
  4. 打开生成的集成卡片，复制 **推送地址**
  
    
</Accordion>
</AccordionGroup>

### 使用共享集成

如果您需要根据告警事件的 Payload 将告警路由到不同协作空间，选择此方式。

<AccordionGroup>
  <Accordion title="查看共享集成的配置步骤">
  
  1. 进入 Flashduty 控制台，选择 **集成中心 → 告警事件**
  2. 选择 **Meraki** 集成：
        - **集成名称**：为当前集成定义一个名称。
  3. 配置默认路由并选择协作空间；创建后可在 **路由** 中增加更多规则
  4. 点击 **保存**，复制生成的 **推送地址**
    
</Accordion>
</AccordionGroup>
</div>

## 在 Meraki 中配置

<Steps>
<Step title="在 Meraki 中添加 HTTPS receiver">

**操作路径**：Meraki Dashboard › Network-wide › Configure › Alerts › Webhooks › Add an HTTPS receiver

| 字段 | 填写 |
| --- | --- |
| Name（必填） | `Flashduty` |
| URL（必填） | `{integration_url}` |
| Shared secret（可选） | 留空 |
| Payload template（可选） | 保持默认的 `Meraki (included)` |

填写后点击 **Save**。URL 必须是公网可访问的 HTTPS 地址且使用受信任 CA 签发的证书，Flashduty 的推送地址满足该要求。

<img alt="Meraki 中 HTTPS receiver 的配置" width="600" src="https://download.flashcat.cloud/flashduty/doc/meraki-5.png" />

</Step>
<Step title="在 Meraki 中让告警发送到该 receiver">

**操作路径**：Meraki Dashboard › Network-wide › Configure › Alerts

在 **Alerts** 页面中，按需配置 `Cellular gateway` 和其他告警类型，并在各告警类型的接收方中选择上一步创建的 `Flashduty` receiver。只有被选中的告警类型才会推送到 Flashduty。

</Step>
<Step title="发送测试并确认">

**操作路径**：Meraki Dashboard › Organization › Configure › API & Webhooks › Webhooks

在 receiver 所在行点击 **Send test**，Meraki 显示 `Webhook test was successful!` 仅说明 Meraki 能连通推送地址，不代表告警内容已按真实告警解析。请以真实告警为准：触发一次已选中的告警类型，几秒后回到 Flashduty，集成显示 **最新事件时间**，说明配置成功。
{/* console:
接入清单中的「收到第一个事件」同时变为已完成。
*/}

</Step>
</Steps>

## 状态和告警等级

<div className="md-block">

| Meraki | Flashduty |
| ---------- | -------- |
| critical | Critical |
| warning | Warning |
| informational | Info |

其他取值按 Info 处理。Meraki 的告警事件不携带恢复状态，告警不会自动恢复；请在接收该集成的协作空间开启 [超时自动关闭](/zh/on-call/channel/create-edit)。

</div>
