通过 webhook 的方式同步腾讯云日志服务 CLS 监控告警事件到 Flashduty On-call。

<div className="hide">

## 在 Flashduty On-call
您可通过以下两种方式获取集成推送地址，任选其一即可。

### 使用专属集成

如果您只需将告警发往一个协作空间，选择此方式，配置更简单。

<AccordionGroup>
  <Accordion title="查看专属集成的配置步骤">
  
  1. 进入 Flashduty 控制台，选择 **协作空间**，打开一个协作空间
  2. 选择 **配置** → **集成数据** → **专属集成**，点击 **新增一个集成**
  3. 选择 **腾讯云 CLS** 集成，点击 **保存**，生成卡片。
  4. 打开生成的集成卡片，复制 **推送地址**
  
    
</Accordion>
</AccordionGroup>

### 使用共享集成

如果您需要根据告警事件的 Payload 将告警路由到不同协作空间，选择此方式。

<AccordionGroup>
  <Accordion title="查看共享集成的配置步骤">
  
  1. 进入 Flashduty 控制台，选择 **集成中心 → 告警事件**
  2. 选择 **腾讯云 CLS** 集成：
        - **集成名称**：为当前集成定义一个名称。
  3. 配置默认路由并选择协作空间；创建后可在 **路由** 中增加更多规则
  4. 点击 **保存**，复制生成的 **推送地址**
    
</Accordion>
</AccordionGroup>
</div>

## 在腾讯云 CLS 中配置

<Steps>
<Step title="在 CLS 中新建通知渠道组">

**操作路径**：腾讯云控制台 › 日志服务 CLS › 监控告警 › 通知渠道组 › 新建

| 字段 | 填写 |
| --- | --- |
| 名称（必填） | 自定义名称，例如 `Flashduty` |
| 渠道类型（必填） | `自定义接口回调` |
| 回调地址（必填） | `{integration_url}` |
| 请求方法（必填） | `POST` |

点击 **确定** 保存。点击 **添加** 可添加多个渠道。

<img alt="腾讯云 CLS 新建通知渠道组" width="600" src="https://fcpub-1301667576.cos.ap-nanjing.myqcloud.com/flashduty/integration/tencent-cls/tencent-cls-notify.png" />

</Step>
<Step title="在 CLS 中新建告警策略并关联渠道组">

**操作路径**：腾讯云控制台 › 日志服务 CLS › 监控告警 › 告警策略 › 新建

| 字段 | 填写 |
| --- | --- |
| 告警名称（必填） | 自定义名称 |
| 日志主题（必填） | 选择要监控的日志主题 |
| 执行语句（必填） | 填写查询语句并选择查询时间范围，点击预览可查看执行结果；然后填写触发条件 |
| 告警级别（必填） | 紧急、告警、提醒三选一，按告警的严重程度选择；按需设置执行周期 |
| 多维分析（可选） | 触发告警时对原始日志做额外检索，并将结果附加到告警通知中，用于辅助定位原因。多维分析不影响触发条件 |
| 告警通知 › 通知渠道组（必填） | 选择上一步创建的渠道组 |

<img alt="腾讯云 CLS 新建告警策略" width="600" src="https://fcpub-1301667576.cos.ap-nanjing.myqcloud.com/flashduty/integration/tencent-cls/tencent-cls-alert.png" />

</Step>
<Step title="配置自定义回调内容并确认">

**操作路径**：腾讯云控制台 › 日志服务 CLS › 监控告警 › 告警策略 › 新建 › 告警通知 › 自定义回调

关联渠道组后，页面显示回调内容配置：

| 字段 | 填写 |
| --- | --- |
| 请求头（可选） | 按需添加请求 headers |
| 请求内容（必填） | 使用下方 JSON |
