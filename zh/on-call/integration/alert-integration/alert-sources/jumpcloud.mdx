通过 JumpCloud 的 Webhook 通知渠道，将 Insights 规则产生的告警同步到 Flashduty On-call。每条 JumpCloud 告警对应一条 Flashduty 告警：告警产生时触发，在 JumpCloud 中被处理（Resolved）或自动恢复（Auto-Resolved）时恢复。

<div className="hide">

## 在 Flashduty On-call

您可通过以下两种方式获取集成推送地址，任选其一即可。

### 使用专属集成

1. 进入 Flashduty 控制台，选择 **协作空间**，打开一个协作空间
2. 选择 **配置** → **集成数据** → **专属集成**，点击 **新增一个集成**
3. 选择 **JumpCloud**，点击 **保存**
4. 打开生成的集成卡片，复制 **推送地址**

### 使用共享集成

1. 进入 Flashduty 控制台，选择 **集成中心 → 告警事件**
2. 选择 **JumpCloud**，填写集成名称
3. 配置默认路由并选择协作空间；创建后可在 **路由** 中增加更多规则
4. 点击 **保存**，复制生成的 **推送地址**

## 在 JumpCloud 中配置

<Steps>
<Step title="创建 Webhook 通知渠道">

1. 使用管理员账号登录 JumpCloud 管理控制台，进入 **Settings → Notification Channels → Webhooks**
2. 点击 **+Add**，填写渠道名称（最多 100 个字符）
3. 将 Flashduty 集成的完整推送地址粘贴到 **URL**，地址中需包含 `integration_key`
4. **Authentication** 选择 **None**，Flashduty 通过地址中的 `integration_key` 认证
5. 点击 **Save**；如果渠道默认是停用状态，在渠道右侧的更多菜单中启用它

</Step>

<Step title="在 Insights 规则中选择该渠道">

1. 进入需要接入的 Insights 规则，或新建一条规则
2. 在通知部分选择刚创建的 Webhook 渠道
3. 勾选 **Alert Resolution**（告警被处理时通知）和 **Alert Acknowledgement**（告警被确认时通知）。不勾选 Alert Resolution，Flashduty 收不到恢复通知，告警不会自动关闭
4. 保存规则

</Step>

<Step title="验证">

规则条件满足后，JumpCloud 生成告警并向渠道推送。在 Flashduty 中确认出现一条活动告警，再在 JumpCloud 中把该告警标记为 Resolved，确认 Flashduty 告警恢复。

渠道页面的 **Test Webhook** 按钮只在弹窗中显示模拟的请求和响应，JumpCloud 文档未说明它的请求内容。Flashduty 按真实告警的格式解析请求，缺少 `alert_id` 的请求会返回 400，如果测试请求因此失败，不影响真实告警。

</Step>
</Steps>

## Alert Key

Flashduty 用 `alert_id`（JumpCloud 告警的 ID）生成 Alert Key。同一条 JumpCloud 告警在每次状态变化（Open、Acknowledged、Resolved、Auto-Resolved）时推送的都是同一个 `alert_id`，所以触发和恢复落在同一条 Flashduty 告警上。标题、优先级、描述、更新时间等字段变化不会改变 Alert Key。缺少 `alert_id` 的请求会被拒绝。

JumpCloud 文档规定同一条告警在阈值达到后的新事件会更新已有告警，这些更新都归入同一条 Flashduty 告警。

## 状态和告警等级

| JumpCloud `status` | Flashduty 状态 |
| :--- | :--- |
| `Open`、`Acknowledged` | 触发或更新告警 |
| `Resolved`、`Auto-Resolved` | 恢复 |

| JumpCloud `priority` | Flashduty 等级 |
| :--- | :--- |
| `Critical`、`High` | Critical |
| `Medium` | Warning |
| `Low` | Info |
| 空值或其他值 | Warning |

恢复事件保留该告警最后一次推送的等级。

## 标签

| 标签 | 来源 |
| :--- | :--- |
| `alert_id` | `alert_id` |
| `category` | `category`，告警分类 |
| `priority` / `status` | `priority` 和 `status` |
| `rule_id` | `rule_id`，触发告警的规则 ID |
| `organization` | `organization_name` |
| `source_id` / `source_name` / `source_type` | 告警来源的 ID、名称和类型 |
| `event` | `di_event`，触发告警的事件 |
| `event_description` | `event_description` |
| `url` | `source_url` |

告警标题取自 `alert_title`，描述取自 `description`。

## 排查问题

- **Flashduty 返回参数错误**：确认 URL 完整且包含 `integration_key`，并确认请求体是 JSON
- **告警没有恢复**：确认规则中勾选了 Alert Resolution，并且渠道处于启用状态
- **收不到通知**：确认 Insights 规则选择了该 Webhook 渠道，并且触发事件发生在规则的监控窗口内

更多字段含义请参阅 [JumpCloud Webhook 通知渠道](https://jumpcloud.com/support/create-webhook-channels) 和 [创建 Insights 规则](https://jumpcloud.com/support/create-an-insights-rule)。
