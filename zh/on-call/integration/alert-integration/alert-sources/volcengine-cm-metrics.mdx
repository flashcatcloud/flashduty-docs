通过 webhook 的方式同步火山引擎云监控告警事件到 Flashduty On-call，实现告警事件自动化降噪处理。

<div className="hide">

## 在 Flashduty On-call
您可通过以下两种方式获取集成推送地址，任选其一即可。

### 使用专属集成

如果您只需将告警发往一个协作空间，选择此方式，配置更简单。

<AccordionGroup>
  <Accordion title="查看专属集成的配置步骤">
  
  1. 进入 Flashduty 控制台，选择 **协作空间**，打开一个协作空间
  2. 选择 **配置** → **集成数据** → **专属集成**，点击 **新增一个集成**
  3. 选择 **火山引擎CM 指标** 集成，点击 **保存**，生成卡片。
  4. 打开生成的集成卡片，复制 **推送地址**
  
    
</Accordion>
</AccordionGroup>

### 使用共享集成

如果您需要根据告警事件的 Payload 将告警路由到不同协作空间，选择此方式。

<AccordionGroup>
  <Accordion title="查看共享集成的配置步骤">
  
  1. 进入 Flashduty 控制台，选择 **集成中心 → 告警事件**
  2. 选择 **火山引擎CM 指标** 集成：
        - **集成名称**：为当前集成定义一个名称。
  3. 配置默认路由并选择协作空间；创建后可在 **路由** 中增加更多规则
  4. 点击 **保存**，复制生成的 **推送地址**
    
</Accordion>
</AccordionGroup>

</div>

## 在火山引擎云监控中配置

<Steps>
<Step title="在云监控中创建 Flashduty 回调地址">

<Tabs>
<Tab title="新版控制台（通知策略）">

**操作路径**：全栈可观测平台控制台 › 告警中心 › 通知配置

在通知对象中创建回调地址（厂商的回调地址文档写在 云监控控制台 › 通知 › 通知策略 › 通知对象 › 回调地址，新版控制台中的具体位置未确认）。

| 字段 | 填写 |
| --- | --- |
| 回调地址名称（必填） | `Flashduty_Metric`（回调地址的唯一标识，不允许重名） |
| 通道（必填） | 通用回调地址通道 |
| 回调地址（必填） | `{integration_url}` |
| 自定义 Token / 自定义 Header（可选） | 无需鉴权时留空 |

填写后可点击左下角 **连通性测试**，再点击右下角 **确定**。连通性测试只检查地址能否访问，不会在 Flashduty 产生有效事件，请用最后一步的真实告警验证。

</Tab>
<Tab title="旧版控制台（通知组）">

**操作路径**：云监控控制台 › 通知组 › 回调 › 创建回调地址

| 字段 | 填写 |
| --- | --- |
| 回调地址名称（必填） | `Flashduty_Metric` |
| 回调地址类型（必填） | 通用回调地址 |
| 回调地址（必填） | `{integration_url}` |

点击 **确认** 完成创建。旧版不支持连通性测试，即使点击测试出现连通性失败，也不会影响告警的接收。

<img alt="创建回调地址" width="600" src="https://download.flashcat.cloud/flashduty/doc/ve-m-1.png" />

<img alt="填写回调地址" width="600" src="https://download.flashcat.cloud/flashduty/doc/ve-m-5.png" />

</Tab>
</Tabs>

</Step>
<Step title="在告警策略中使用该回调地址">

<Tabs>
<Tab title="新版控制台（通知策略）">

**操作路径**：全栈可观测平台控制台 › 告警中心 › 通知配置 › 通知策略 › 创建通知策略

| 字段 | 填写 |
| --- | --- |
| 策略名称（必填） | 自定义，例如 `Flashduty` |
| 通知方式（必填） | 通用回调地址 |
| Webhook（必填） | 选择上一步创建的 `Flashduty_Metric` |
| 通知模板（必填） | 选择通用回调地址对应的通知模板 |

再把通知策略用到告警规则里。

**操作路径**：全栈可观测平台控制台 › 告警中心 › 告警配置 › 云监控 › 创建告警规则（或编辑已有规则）

| 字段 | 填写 |
| --- | --- |
| 发送聚合策略 | **规则和资源** |
| 告警恢复通知 | 保持开启 |
| 告警方式 › 通知策略（必填） | 选择刚创建的通知策略 |

配置完成后保存。

</Tab>
<Tab title="旧版控制台（告警渠道）">

**操作路径**：云监控控制台 › 告警中心 › 告警策略 › 创建告警策略（或编辑已有策略）

| 字段 | 填写 |
| --- | --- |
| 发送聚合策略 | **规则和资源** |
| 告警恢复通知 | 保持开启 |
| 告警渠道（必填） | 勾选 **告警回调**，并在下拉框中选择上一步创建的 `Flashduty_Metric` |

配置完成后点击 **确认**。

<img alt="在告警策略中选择告警回调" width="600" src="https://download.flashcat.cloud/flashduty/doc/ve-m-6.png" />

</Tab>
</Tabs>

</Step>
<Step title="触发一次告警并确认">

让监控指标临时越过策略阈值（或等待真实告警）。

回到 Flashduty，集成显示 **最新事件时间**，说明配置成功。

接入清单中的「收到第一个事件」同时变为已完成。
*/}

</Step>
</Steps>
