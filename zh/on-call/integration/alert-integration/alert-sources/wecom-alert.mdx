Flashduty 生成企业微信群机器人格式的 Webhook 地址。已在向企业微信群机器人推送告警的工具，把地址改为它即可将告警的发生与恢复接入 Flashduty。

## 操作步骤

### 创建企微机器人兼容集成

您可通过以下 2 种方式，获取一个企微机器人兼容集成地址，任选其一即可。

#### 使用专属集成

如果您只需将告警发往一个协作空间，选择此方式，配置更简单。

<AccordionGroup>
  <Accordion title="查看专属集成的配置步骤">
  
  1. 进入 Flashduty 控制台，选择 **协作空间**，打开一个协作空间
  2. 选择 **配置** → **集成数据** → **专属集成**，点击 **新增一个集成**
  3. 选择 **企微机器人兼容** 集成，点击 **保存**，生成卡片。
  4. 点击生成的卡片，可以查看到 **企微机器人兼容集成地址**，复制备用，完成。
    
</Accordion>
</AccordionGroup>

#### 使用共享集成

如果您需要根据告警事件的 Payload 将告警路由到不同协作空间，选择此方式。

<AccordionGroup>
  <Accordion title="查看共享集成的配置步骤">
  
  1. 进入 Flashduty 控制台，选择 **集成中心 → 告警事件**
  2. 选择 **企微机器人兼容** 集成：
        - **集成名称**：为当前集成定义一个名称。
        - **消息类型**：选择企微告警消息类型，目前仅支持文本（Text）、富文本（Post）。
        - **推送模式**：选择企微告警在何种情况下触发或恢复告警。
  3. 复制当前页面的 **企微机器人兼容集成地址** 备用。
  4. 配置默认路由并选择协作空间；创建后可在 **路由** 中增加更多规则
    
</Accordion>
</AccordionGroup>
</div>

## 推送模式与规则

| 推送模式 | 行为 |
| --- | --- |
| 总是触发新告警（默认） | 每条消息都触发一条新告警 |
| 根据规则触发或关闭告警 | 按自定义规则触发新告警或关闭已有告警 |

选择 **根据规则触发或关闭告警** 时：

- 至少需要一条 **触发** 规则。
- 关闭规则先于触发规则匹配；同类规则按配置的顺序匹配，命中第一条为止。
- 每条规则都要设置 Alert Key 的正则提取规则，系统用 Alert Key 查找未关闭的告警进行更新或关闭。正则须为合法的 RE2 正则，保存时校验，非法的表达式会被拦截并提示「请输入合法的正则表达式」。
- Alert Key 由正则捕获组的内容生成，多个捕获组用 `,` 连接。**正则没有提取到内容时，系统随机生成 Alert Key**：消息仍会生成告警，但不会与其他消息合并，也不会被恢复消息关闭。
- **默认规则**：如果以上规则均不满足，则 **新建一条告警**（每条消息生成一条新告警）或 **丢弃该消息**。

配置示例：

- 规则 1：**关闭**，条件为「消息内容 匹配 `/RESOLVED/`」
- 规则 2：**触发**，条件为「消息内容 匹配 `/PROBLEM/`」
- 两条规则都从 **消息内容** 提取 Alert Key，正则为：

  ```
  (?:PROBLEM|RESOLVED): (\S+ \S+) usage
  ```

消息 `PROBLEM: web-01 disk usage 93%` 和 `RESOLVED: web-01 disk usage 71%` 都捕获到 `web-01 disk`，Alert Key 相同，恢复消息会关闭对应告警。正则不加 `^`，因为消息内容前面可能还有其他文字。

### 为什么不能用 /(.*)/ 提取 Alert Key

`/(.*)/` 捕获整段内容。触发消息和恢复消息的内容不同，得到的 Alert Key 也不同，恢复消息找不到对应的告警，告警不会被关闭。正则只应捕获代表故障本身的部分，例如上面示例中的主机名加检查项。

## 无事件检测

**操作路径**：Flashduty › 集成中心 › 告警事件

在右侧集成列表中点开你的集成（类型为 企微机器人兼容），进入 **接收** › **无事件检测**。

在指定时长内未收到有效事件时，系统生成一条 Warning 告警。

| 配置项 | 说明 |
| :--- | :--- |
| **启用检测** | 开关，默认关闭。开启后，仅成功通过集成校验的上游事件会刷新检测时间 |
| **检测时间** | 在指定时长内未收到有效事件，即生成一条 Warning 告警。最短 10 分钟，最长 48 小时（默认 10 分钟） |
| **启用恢复** | 开关，默认开启。收到下一条有效事件时，恢复无事件检测产生的告警 |

## 注意事项

- 企微机器人兼容集成仅支持接收 text、markdown 和 markdown_v2 类型的消息，其他类型的消息无法接收。
- 告警标题固定为「企业微信机器人告警」。如需修改标题，可以通过[告警处理 Pipeline](/zh/on-call/integration/alert-integration/alert-pipelines) 自定义。

## 状态和告警等级

企微机器人兼容集成推送到 Flashduty 的告警等级固定为 Warning。如需按消息内容设置严重程度，在集成的 **告警处理** 页签中添加规则，参见[告警处理 Pipeline](/zh/on-call/integration/alert-integration/alert-pipelines)。
