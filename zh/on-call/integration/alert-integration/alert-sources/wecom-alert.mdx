Flashduty 生成企业微信群机器人格式的 Webhook 地址。已在向企业微信群机器人推送告警的工具，把地址改为它即可将告警的发生与恢复接入 Flashduty。

<div className="hide">

## 操作步骤

### 创建企微机器人兼容集成

您可通过以下 2 种方式，获取一个企微机器人兼容集成地址，任选其一即可。

#### 使用专属集成

如果您只需将告警发往一个协作空间，选择此方式，配置更简单。

<AccordionGroup>
  <Accordion title="查看专属集成的配置步骤">
  
  1. 进入 Flashduty 控制台，选择 **协作空间**，打开一个协作空间
  2. 选择 **配置** → **集成数据** → **专属集成**，点击 **新增一个集成**
  3. 选择 **企微机器人兼容** 集成，点击 **保存**，生成卡片。
  4. 点击生成的卡片，可以查看到 **企微机器人兼容集成地址**，复制备用，完成。
    
</Accordion>
</AccordionGroup>

#### 使用共享集成

如果您需要根据告警事件的 Payload 将告警路由到不同协作空间，选择此方式。

<AccordionGroup>
  <Accordion title="查看共享集成的配置步骤">
  
  1. 进入 Flashduty 控制台，选择 **集成中心 → 告警事件**
  2. 选择 **企微机器人兼容** 集成：
        - **集成名称**：为当前集成定义一个名称。
        - **消息类型**：选择企微告警消息类型，目前仅支持文本（Text）、富文本（Post）。
        - **推送模式**：选择企微告警在何种情况下触发或恢复告警。
  3. 复制当前页面的 **企微机器人兼容集成地址** 备用。
  4. 配置默认路由并选择协作空间；创建后可在 **路由** 中增加更多规则
    
</Accordion>
</AccordionGroup>
</div>

## 在发送告警的工具中配置

<Steps>
<Step title="在 Flashduty 中选择企微机器人兼容集成的推送模式">

**操作路径**：Flashduty 控制台 › 集成中心 › 告警事件 › 企微机器人兼容（专属集成：协作空间 › 配置 › 集成数据 › 专属集成 › 新增一个集成）

| 字段 | 填写 |
| --- | --- |
| 集成名称（必填） | 自定义名称 |
| 消息类型（必填） | Text、Markdown 或 Markdown V2，其他类型的消息无法接收 |
| 推送模式（必填） | 见下 |

推送模式：

- **每条消息创建新告警**（默认）
- **根据规则触发或关闭告警**：每收到新消息，按下一步的规则匹配，命中的消息触发新告警或关闭已有告警

系统会为集成生成唯一的企微机器人兼容集成地址 `{integration_url}`，它兼容企微机器人消息协议。保存后复制该地址，供第 3 步使用。

</Step>
<Step title="在 Flashduty 中配置触发和关闭规则">

**操作路径**：Flashduty 控制台 › 集成中心 › 告警事件 › 企微机器人兼容 › 推送模式 › 根据规则触发或关闭告警

只有选择「根据规则触发或关闭告警」时需要这一步。

| 配置项 | 填写 |
| --- | --- |
| 触发规则（必填） | 至少一条，命中的消息触发新告警 |
| 关闭规则（可选） | 命中的消息关闭已有告警 |
| Alert Key 提取（必填） | 选择提取来源（消息内容）并填写正则。系统用它查找历史告警，以便更新或关闭 |
| 所有规则都不匹配时（可选） | 丢弃消息，或作为新告警触发 |

规则匹配顺序：先判断全部关闭规则，再判断触发规则；同类规则按配置顺序判断，命中第一条即停止。

Alert Key 由正则捕获组的内容生成（多个捕获组以逗号连接）。正则没有匹配、没有捕获组或第一个捕获组为空，都算提取失败，此时系统随机生成 Alert Key，之后的关闭规则无法关闭这条告警，以确保告警不会因配置错误而丢失。所有规则都不匹配且选择不丢弃时，系统随机生成 Alert Key，每条消息都是一条新告警，不会合并。

配置示例：

- 接收所有消息，当消息内容中包含 **RESOLVED** 字样时，关闭告警，否则触发新告警；
- Alert Key 从消息内容中提取，规则为 **/(.\*)/**。

<Note>
正则提取规则必须是**合法的正则表达式（RE2 语法）**：提交时前端会校验其可编译性，非法正则（如不支持的语法）无法保存，并提示「请输入合法的正则表达式」。只有正则合法但未匹配到内容时，系统才会随机生成 Alert Key。
</Note>

</Step>
<Step title="在发送告警的工具中把企微机器人的 Webhook 地址改为 Flashduty">

**操作路径**：发送告警的工具中配置企业微信群机器人 Webhook 地址的位置

| 字段 | 填写 |
| --- | --- |
| Webhook 地址（必填） | `{integration_url}` |

保存后，该工具发给企微机器人的消息会进入 Flashduty。

</Step>
<Step title="发送一条测试消息并确认">

**操作路径**：能访问 Flashduty 推送地址的终端

用真实消息格式向推送地址 POST 一条消息：

```bash
curl -X POST '{integration_url}' \
  -H 'Content-Type: application/json' \
  -d '{"msgtype":"markdown","markdown":{"content":"Flashduty integration test"}}'
```

文本消息改用 `{"msgtype":"text","text":{"content":"..."}}`。其他消息类型会被拒绝。

几秒后回到 Flashduty，集成显示 **最新事件时间**，说明配置成功。使用规则模式时，再发送一条命中关闭规则、且提取出相同 Alert Key 的消息，确认告警被关闭。
{/* console:
接入清单中的「收到第一个事件」同时变为已完成。
*/}

</Step>
</Steps>

## 无事件检测

告警集成详情页（编辑与预览）的基础设置卡片下方提供 **无事件检测**配置卡片：在指定时间内未收到有效事件时，系统会生成一条 Warning 告警。

| 配置项 | 说明 |
| :--- | :--- |
| **启用无事件检测** | 开关，默认关闭。开启后，仅成功通过集成校验的上游事件会刷新检测时间 |
| **检测时间（分钟）** | 指定时间内未收到有效事件，即生成一条 Warning 告警。取值须为整数，范围为 10 分钟 ~ 48 小时（默认 10 分钟） |
| **收到新事件后自动恢复** | 开关，默认开启。收到下一条有效事件时，自动恢复无事件检测产生的告警 |

### 注意事项
- 企微机器人兼容集成地址仅支持接收 Text、Markdown、Markdown V2 消息类型，其他消息无法接收。
- Flashduty On-call 会生成默认告警标题： “企业微信机器人告警”，如果您需要更改标题，可以通过[告警处理 Pipeline](/zh/on-call/integration/alert-integration/alert-pipelines) 来自定义标题。

## 状态和告警等级

当前企微机器人兼容集成推送到 Flashduty 的严重程度均为 Warning，但您可以通过[告警处理 Pipeline](/zh/on-call/integration/alert-integration/alert-pipelines) 来自定义严重程度。
