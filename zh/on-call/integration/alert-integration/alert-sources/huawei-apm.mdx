通过 webhook 的方式同步华为云 APM 告警事件到 Flashduty On-call。

<div className="hide">

## 在 Flashduty On-call
您可通过以下两种方式获取集成推送地址，任选其一即可。

### 使用专属集成

如果您只需将告警发往一个协作空间，选择此方式，配置更简单。

<AccordionGroup>
  <Accordion title="查看专属集成的配置步骤">
  
  1. 进入 Flashduty 控制台，选择 **协作空间**，打开一个协作空间
  2. 选择 **配置** → **集成数据** → **专属集成**，点击 **新增一个集成**
  3. 选择 **华为云 APM** 集成，点击 **保存**，生成卡片。
  4. 打开生成的集成卡片，复制 **推送地址**

    
</Accordion>
</AccordionGroup>

### 使用共享集成

如果您需要根据告警事件的 Payload 将告警路由到不同协作空间，选择此方式。

<AccordionGroup>
  <Accordion title="查看共享集成的配置步骤">
  
  1. 进入 Flashduty 控制台，选择 **集成中心 → 告警事件**
  2. 选择 **华为云 APM** 集成： 
        - **集成名称**：为当前集成定义一个名称。
  3. 配置默认路由并选择协作空间；创建后可在 **路由** 中增加更多规则
  4. 点击 **保存**，复制生成的 **推送地址**
    
</Accordion>
</AccordionGroup>
</div>

## 在华为云 APM 中配置

<Steps>
<Step title="在华为云 SMN 中创建主题并添加 HTTPS 订阅">

**操作路径**：华为云控制台 › 消息通知服务 SMN › 主题管理 › 主题 › 创建主题

| 字段 | 填写 |
| --- | --- |
| 主题名称（必填） | `Flashduty` |

点击 **确认**。

<img src="https://download.flashcat.cloud/flashduty/doc/huawei-lts-1.png" alt="创建 Flashduty 主题" width="600"/>

回到主题列表，在刚创建的 `Flashduty` 主题所在行点击 **添加订阅**。主题策略的 **可发布消息的服务** 需要包含 APM，否则通知发送会失败。

<img src="https://download.flashcat.cloud/flashduty/doc/huawei-lts-2.png" alt="添加订阅入口" width="600"/>

| 字段 | 填写 |
| --- | --- |
| 协议（必填） | `HTTPS` |
| 订阅终端（必填） | `{integration_url}` |

点击 **确认**。

<img src="https://download.flashcat.cloud/flashduty/doc/huawei-lts-3.png" alt="订阅终端填写推送地址" width="600"/>

添加完成后，在订阅列表中确认该订阅的状态为 **已确认**。

<img src="https://download.flashcat.cloud/flashduty/doc/huawei-lts-4.png" alt="订阅状态已确认" width="600"/>

</Step>
<Step title="在华为云 APM 中添加通知配置">

**操作路径**：华为云控制台 › 应用性能管理 APM › 应用监控 › 指标 › 通知配置 › 新增

| 字段 | 填写 |
| --- | --- |
| 区域（必填） | 应用所在区域 |
| 主题（必填） | 上一步创建的 `Flashduty` |
| 默认（可选） | 开关；开启后，该区域的告警使用此主题发送 |

点击 **确认** 完成配置。

<img src="https://download.flashcat.cloud/flashduty/doc/zh/hw/hw-apm-1.png" alt="APM 通知配置" width="600"/>

</Step>
<Step title="在华为云 APM 中创建告警策略">

**操作路径**：华为云控制台 › 应用性能管理 APM › 告警中心 › 告警策略 › 创建告警策略

在 **通知对象** 下拉框选择 `Flashduty`。若通知对象是 HTTP/HTTPS 终端，**通知格式** 保持默认的 HTML 或选 JSON。

旧入口：**应用监控 › 指标 › 选择应用 › 设置 › 告警策略 › 新增自定义告警策略**。按华为云说明，从该入口创建的策略不会显示在 **告警中心 › 告警策略** 中（[来源](https://support.huaweicloud.com/usermanual-apm2/apm_07_0025.html)）。

| 字段 | 填写 |
| --- | --- |
| 告警指标、告警条件（必填） | 按业务需要配置 |
| 告警内容（可选） | 引用变量时建议使用 K:V 格式，便于后续告警事件解析，例如 `host:${hostInfo}` |
| 通知对象（必填） | 选择已创建的 `Flashduty` 通知渠道 |
| 恢复策略（可选） | 填写 N 分钟，表示 N 分钟内没有产生告警即视为已恢复 |
| 恢复时通知（必填） | 开启；否则 Flashduty 收不到恢复通知，告警不会自动恢复 |

点击 **确认** 完成配置。也可以编辑已有的告警策略。

<img src="https://download.flashcat.cloud/flashduty/doc/zh/hw/hw-apm-2.png" alt="APM 告警策略" width="600"/>

当前集成配置仅支持应用监控告警，还未完全兼容前端监控、链路追踪、App 监控告警。

</Step>
<Step title="触发告警并确认">

**操作路径**：华为云控制台 › 应用性能管理 APM › 告警中心 › 告警策略

让上一步的告警策略触发一次告警（例如临时调低阈值）。几秒后回到 Flashduty，集成显示 **最新事件时间**，说明配置成功。
{/* console:
接入清单中的「收到第一个事件」同时变为已完成。
*/}

</Step>
</Steps>

## 状态和告警等级

<div className="md-block">

Flashduty 按推送内容的格式分别映射告警等级。

JSON 内容（通过 SMN 推送）：

| 华为云 APM | Flashduty |
| ---------- | -------- |
| `CRITICAL` | Critical |
| `COMMON` | Warning |
| 其他 | Info |

文本内容：

| 华为云 APM 告警级别 | Flashduty |
| ---------- | -------- |
| 严重告警 | Critical |
| 轻微告警 | Info |

</div>
