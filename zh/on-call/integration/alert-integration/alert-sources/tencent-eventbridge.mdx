通过 webhook 的方式同步腾讯云事件总线 EB 事件到 Flashduty On-call。

<div className="hide">

## 在 Flashduty On-call
您可通过以下两种方式获取集成推送地址，任选其一即可。

### 使用专属集成

如果您只需将告警发往一个协作空间，选择此方式，配置更简单。

<AccordionGroup>
  <Accordion title="查看专属集成的配置步骤">
  
  1. 进入 Flashduty 控制台，选择 **协作空间**，打开一个协作空间
  2. 选择 **配置** → **集成数据** → **专属集成**，点击 **新增一个集成**
  3. 选择 **腾讯云 EventBridge** 集成，点击 **保存**，生成卡片。
  4. 打开生成的集成卡片，复制 **推送地址**
  
    
</Accordion>
</AccordionGroup>

### 使用共享集成

如果您需要根据告警事件的 Payload 将告警路由到不同协作空间，选择此方式。

<AccordionGroup>
  <Accordion title="查看共享集成的配置步骤">
  
  1. 进入 Flashduty 控制台，选择 **集成中心 → 告警事件**
  2. 选择 **腾讯云 EventBridge** 集成：
        - **集成名称**：为当前集成定义一个名称。
  3. 配置默认路由并选择协作空间；创建后可在 **路由** 中增加更多规则
  4. 点击 **保存**，复制生成的 **推送地址**
    
</Accordion>
</AccordionGroup>

</div>
## 在腾讯云 EventBridge 中配置

<Steps>
<Step title="在事件总线中新建事件规则">

**操作路径**：腾讯云控制台 › 事件总线 › 事件规则 › 新建

| 字段 | 填写 |
| --- | --- |
| 规则名称（必填） | `Flashduty` |
| 事件匹配（必填） | 表单模式选择特定事件；或使用 JSON 模式匹配全部事件，见下方代码块 |

<img alt="腾讯云 EventBridge 新建事件规则" width="600" src="https://download.flashcat.cloud/tencent-eb-new-rule.png" />

匹配全部事件的 JSON：

```
{
  "source": [
    {
      "suffix": ".cloud.tencent"
    }
  ]
}
```

<img alt="腾讯云 EventBridge 事件匹配规则" width="600" src="https://download.flashcat.cloud/tencent-eb-match-rule.png" />

</Step>
<Step title="配置事件目标为 Flashduty webhook">

**操作路径**：腾讯云控制台 › 事件总线 › 事件规则 › 新建 › 下一步（事件目标）

| 字段 | 填写 |
| --- | --- |
| 目标类型（必填） | `消息推送` |
| 通知模板（必填） | `通用通知模板` |
| 语言（必填） | `英文` |
| 推送方式（必填） | `接口回调` › `自定义 webhook` |
| webhook 地址（必填） | `{integration_url}` |

点击 **保存**。

<img alt="腾讯云 EventBridge 事件目标配置 webhook" width="600" src="https://download.flashcat.cloud/tencent-eb-target-webhook.png" />

</Step>
<Step title="发送测试事件并确认">

**操作路径**：腾讯云控制台 › 事件总线 › 事件集 › 目标事件集 › 发送事件

选择一个事件集，点击 **发送事件**。

<img alt="腾讯云 EventBridge 发送测试事件" width="600" src="https://download.flashcat.cloud/tencent-eb-test-send.png" />

回到 Flashduty，集成显示 **最新事件时间**，说明配置成功。
{/* console:
接入清单中的「收到第一个事件」同时变为已完成。
*/}

</Step>
</Steps>

## 状态和告警等级
<div className="md-block">
  
腾讯云事件总线所有事件均对应到 Flashduty On-call “警告（warning）”级别告警。

</div>
