当您开通 RUM 服务时，系统会自动为您创建此集成。此集成用于收集 RUM 服务产生的告警事件。

:::tips
您无法修改或删除此集成。但您可以管理集成下的标签增强、告警处理以及路由等规则。
:::

## 开启 RUM 告警

<Steps>
<Step title="在 RUM 中开启应用告警并选择协作空间">

**操作路径**：RUM › 应用管理

选择目标应用，再点击左侧的 **告警设置**。

| 字段 | 填写 |
| --- | --- |
| 告警开关（必填） | 开启 |
| 投递方式（必填） | `Flashduty 协作空间` |
| 协作空间（必填） | 可选择多个协作空间。告警的通知规则遵循协作空间下的分派策略，您可以为团队设定值班人员，在告警发生时分派给值班人 |

![RUM 告警集成：如何开启 RUM 告警 界面截图](https://docs-cdn.flashcat.cloud/images/png/2bbd455a2ac702246e8399b6628f9158.png)

</Step>
<Step title="确认收到告警">

让应用产生一个新的 Issue（或等待真实错误触发，触发条件见 [RUM Issue 告警](/zh/rum/error-tracking/issue-alerts)），几秒后回到 Flashduty，集成显示 **最新事件时间**，说明配置成功。Issue 关闭后会发送恢复事件，对应告警随之恢复。
{/* console:
接入清单中的「收到第一个事件」同时变为已完成。
*/}

</Step>
</Steps>

更多内容，请您参考 [RUM Issue 告警](/zh/rum/error-tracking/issue-alerts)。
