Veeam Service Provider Console（VSPC）的告警通知通过邮件发送，Flashduty 的 [邮件集成](/zh/on-call/integration/alert-integration/alert-sources/email) 可以接收这些邮件，并按规则从邮件标题生成告警，因此不需要单独的 VSPC 集成：在 Flashduty 创建邮件集成，把它的邮件地址填进 VSPC 的告警收件人，把 VSPC 的告警邮件主题设成下文的固定格式，再配置推送规则。

## 在 Flashduty On-call

您可通过以下两种方式获取集成邮件地址，任选其一即可。**集成类型都选择邮件 Email**，不是 Veeam Service Provider Console。

### 使用专属集成

1. 进入 Flashduty 控制台，选择 **协作空间**，打开一个协作空间
2. 选择 **配置** → **集成数据** → **专属集成**，点击 **新增一个集成**
3. 选择 **邮件 Email**，点击 **保存**
4. 打开生成的集成卡片，复制 **邮件地址**，再按下文配置推送规则

### 使用共享集成

1. 进入 Flashduty 控制台，选择 **集成中心 → 告警事件**
2. 选择 **邮件 Email**，填写集成名称，复制 **邮箱地址**
3. 按下文配置推送规则
4. 配置默认路由并选择协作空间，点击 **保存**

## 在 Flashduty 中配置推送规则

VSPC 的邮件里没有告警 ID。下面的主题格式把公司、站点和告警名放进标题，规则从标题提取这三项作为 Alert Key，同一公司、同一站点、同一告警名的邮件合并到同一条告警；告警状态不参与 Alert Key，因此同一告警从 Warning 变为 Error 时更新原有告警，不会新建。

1. **推送模式** 选择 **根据规则触发或关闭告警**
2. 添加下面 1 条规则：条件是 **邮件标题** **匹配** 给出的正则，类型选 **触发告警**，Alert Key **提取自** **邮件标题**
3. **默认规则** 选择：如果以上规则均不满足，则 **丢弃该邮件**

规则 1：触发告警

```
条件：邮件标题 匹配 /^VSPC (Error|Warning) \| /
正则表达式：/^VSPC (?:Error|Warning) \| (.+) \| (.+) \| (.+)$/
```

默认规则选丢弃，是为了让状态为 Information 的邮件不生成告警。

## 在 Veeam Service Provider Console 中配置

以下路径来自 VSPC 官方文档，需要管理员权限。

1. **邮件服务器**：进入 **Configuration** → **Server Settings** → **Email Server**，配置 SMTP 服务器（服务器地址、端口、加密方式）
2. **通知频率**：在 **Alarms** 区域把通知频率滑块设为 **Emails on every event**。**Summary emails only** 只发每日汇总，规则无法逐条处理
3. **主题**：在 **Alarms** 区域的 **Subject** 中填写：

```
VSPC %alarmStatus% | %company% | %location% | %alarmName%
```

`%alarmStatus%`、`%company%`、`%location%`、`%alarmName%` 是 VSPC 告警通知主题支持的变量。渲染后的主题形如：

```
VSPC Error | Contoso | London | Backup job failed
```

4. **收件人**：VSPC 默认把告警邮件发给站点管理员和公司管理员。要发给 Flashduty，进入 **Configuration** → **Templates** → **Predefined Alarms** 选项卡，选中告警后点击 **Edit**，在 **Actions** 步骤点击 **Add**，**Action** 选 **Send email notification**，**Value** 填 Flashduty 邮件集成的地址，条件选 **Errors and warnings**
5. **邮件格式**：规则只读取邮件标题，正文格式不影响匹配

## 限制

- **没有恢复邮件**：VSPC 默认只在新告警产生，或已有告警状态变为 Error 或 Warning 时发邮件，规则不会自动关闭告警。请在接收该集成的协作空间开启 [超时自动关闭](/zh/on-call/channel/create-edit)，建议 24 小时，或在 Flashduty 中手动关闭。
- **对象合并**：主题变量里没有对象名，同一公司、同一站点下同名告警作用在不同对象上时，会合并到同一条 Flashduty 告警。
- **类型与严重程度**：告警在 Flashduty 中显示的集成类型是邮件 Email；严重程度统一为 Warning，可以通过 [告警处理 Pipeline](/zh/on-call/integration/alert-integration/alert-pipelines) 按标题中的 `Error` 调整。
