通过 webhook 的方式同步 Harbor 的告警事件到 Flashduty。

<div className="hide">

## 在 Flashduty On-call

### 创建 Harbor 告警集成

您可通过以下 2 种方式，获取一个 Harbor 告警集成地址，任选其一即可。

#### 使用专属集成

如果您只需将告警发往一个协作空间，选择此方式，配置更简单。

<Accordion title="查看专属集成的配置步骤">
1. 进入 Flashduty 控制台，选择 **协作空间**，打开一个协作空间
2. 选择 **配置** → **集成数据** → **专属集成**，点击 **新增集成**
3. 选择 **Harbor** 集成，点击 **保存**，生成卡片。
4. 点击生成的卡片，可以查看到 **Harbor 告警集成地址**，复制备用，完成。
</Accordion>

#### 使用共享集成

如果您需要根据告警事件的 Payload 将告警路由到不同协作空间，选择此方式。

<Accordion title="查看共享集成的配置步骤">
1. 进入 Flashduty 控制台，选择 **集成中心 → 告警事件**
2. 选择 **Harbor** 集成：
      - **集成名称**：为当前集成定义一个名称。
      - **推送模式**：选择告警在何种情况下触发或恢复告警。
3. 复制当前页面的 **Harbor 告警集成地址** 备用。
4. 配置默认路由并选择协作空间；创建后可在 **路由** 中增加更多规则
</Accordion>

</div>

## 在 Harbor 中配置

<Steps>
<Step title="在 Harbor 项目中添加 Webhook">

**操作路径**：Harbor › Projects › 选择项目 › Webhooks › New Webhook

需使用至少具有项目管理员权限的账号登录 Harbor 界面。

| 字段 | 填写 |
| --- | --- |
| Notify Type（必填） | `HTTP` |
| Payload Format（必填，仅 HTTP 可选） | `Default` 或 `CloudEvents` |
| Event Type（必填） | 勾选要订阅的事件 |
| Endpoint URL（必填） | `{integration_url}` |
| Auth Header（可选） | Flashduty 通过推送地址中的 `integration_key` 认证，无需填写 |
| Verify Remote Certificate（可选） | 使用 HTTPS 推送地址时保持勾选 |

点击 **Add** 创建 Webhook。

</Step>

<Step title="验证">

**操作路径**：Harbor › Projects › 选择项目 › Webhooks

确认新建的 Webhook 处于启用状态，然后在该项目中触发一个已订阅的事件，例如向项目推送一个镜像（订阅了 Push artifact to registry 时）。回到 Flashduty，集成显示 **最新事件时间** 即说明配置成功。
{/* console:
接入清单中的「收到第一个事件」同时变为已完成。
*/}

</Step>
</Steps>

## 状态和告警等级

当前 Harbor 告警集成推送到 Flashduty 的严重程度均为 Warning，但您可以通过[告警处理 Pipeline](/zh/on-call/integration/alert-integration/alert-pipelines) 来自定义严重程度。

Harbor 的每条 Webhook 事件生成一条独立的告警（Alert Key 随机生成），不会合并，也没有恢复事件，请手动关闭，或在协作空间中开启[超时自动关闭](/zh/on-call/channel/create-edit)。
