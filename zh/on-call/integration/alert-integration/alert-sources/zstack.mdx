通过 webhook 的方式同步 zstack 告警事件到 Flashduty On-call。

<div className="hide">

## 在 Flashduty On-call
您可通过以下两种方式获取集成推送地址，任选其一即可。

### 使用专属集成

如果您只需将告警发往一个协作空间，选择此方式，配置更简单。

<AccordionGroup>
  <Accordion title="查看专属集成的配置步骤">
  
  1. 进入 Flashduty 控制台，选择 **协作空间**，打开一个协作空间
  2. 选择 **配置** → **集成数据** → **专属集成**，点击 **新增集成**
  3. 选择 **ZStack** 集成，点击 **保存**，生成卡片。
  4. 打开生成的集成卡片，复制 **推送地址**

    
</Accordion>
</AccordionGroup>

### 使用共享集成

如果您需要根据告警事件的 Payload 将告警路由到不同协作空间，选择此方式。

<AccordionGroup>
  <Accordion title="查看共享集成的配置步骤">
  
  1. 进入 Flashduty 控制台，选择 **集成中心 → 告警事件**
  2. 选择 **ZStack** 集成： 
        - **集成名称**：为当前集成定义一个名称。
  3. 配置默认路由并选择协作空间；创建后可在 **路由** 中增加更多规则
  4. 点击 **保存**，复制生成的 **推送地址**
    
</Accordion>
</AccordionGroup>
</div>

## 在 ZStack 中配置

<Steps>
<Step title="在 ZStack 中创建 Webhook 通知对象">

**操作路径**：ZStack 控制台 › 平台运维 › 云平台监控 › 通知对象 › 创建通知对象（或编辑已有对象）

| 字段 | 填写 |
| --- | --- |
| 名称（必填） | `Flashduty` |
| 类型（必填） | `Webhook` |
| 地址（必填） | `{integration_url}` |

点击 **确定** 完成配置。

<img alt="ZStack 创建 Webhook 通知对象" width="600" src="https://download.flashcat.cloud/flashduty/doc/zh/fd/zstack-1.png" />

</Step>

<Step title="在报警器中使用该通知对象">

**操作路径**：ZStack 控制台 › 平台运维 › 云平台监控 › 报警器 › 创建资源报警器 / 创建事件报警器（或编辑已有报警器）

| 字段 | 填写 |
| --- | --- |
| 通知对象（必填） | 上一步创建的 `Flashduty` |
| 恢复通知（可选） | 资源报警器建议打开 |

其他按需配置，点击 **确定** 完成配置。

<img alt="ZStack 报警器中选择通知对象" width="600" src="https://download.flashcat.cloud/flashduty/doc/zh/fd/zstack-2.png" />

</Step>

<Step title="发送测试消息并确认">

**操作路径**：ZStack 控制台 › 平台运维 › 云平台监控 › 通知对象

点击 **发送测试消息**，提示发送成功即说明地址可用。也可以等待报警器触发真实告警。

回到 Flashduty，集成显示 **最新事件时间**，说明配置成功。
{/* console:
接入清单中的「收到第一个事件」同时变为已完成。
*/}

</Step>
</Steps>
