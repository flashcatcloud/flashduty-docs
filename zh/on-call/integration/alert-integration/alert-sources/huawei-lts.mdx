通过 webhook 的方式同步华为云日志服务 LTS 告警事件到 Flashduty On-call。

<div className="hide">

## 在 Flashduty On-call
您可通过以下两种方式获取集成推送地址，任选其一即可。

### 使用专属集成

如果您只需将告警发往一个协作空间，选择此方式，配置更简单。

<AccordionGroup>
  <Accordion title="查看专属集成的配置步骤">
  
  1. 进入 Flashduty 控制台，选择 **协作空间**，打开一个协作空间
  2. 选择 **配置** → **集成数据** → **专属集成**，点击 **新增一个集成**
  3. 选择 **华为云日志服务 LTS** 集成，点击 **保存**，生成卡片。
  4. 打开生成的集成卡片，复制 **推送地址**
  
    
</Accordion>
</AccordionGroup>

### 使用共享集成

如果您需要根据告警事件的 Payload 将告警路由到不同协作空间，选择此方式。

<AccordionGroup>
  <Accordion title="查看共享集成的配置步骤">
  
  1. 进入 Flashduty 控制台，选择 **集成中心 → 告警事件**
  2. 选择 **华为云日志服务 LTS** 集成：
        - **集成名称**：为当前集成定义一个名称。
  3. 配置默认路由并选择协作空间；创建后可在 **路由** 中增加更多规则
  4. 点击 **保存**，复制生成的 **推送地址**
    
</Accordion>
</AccordionGroup>

</div>

## 在华为云中配置

<Steps>
<Step title="在华为云 SMN 中创建主题并添加 HTTPS 订阅">

**操作路径**：华为云控制台 › 消息通知服务 SMN › 主题管理 › 主题 › 创建主题

| 字段 | 填写 |
| --- | --- |
| 主题名称（必填） | `Flashduty` |

点击 **确认**。

<img src="https://download.flashcat.cloud/flashduty/doc/huawei-lts-1.png" alt="创建 Flashduty 主题" width="600"/>

回到主题列表，在刚创建的 `Flashduty` 主题所在行点击 **添加订阅**。

<img src="https://download.flashcat.cloud/flashduty/doc/huawei-lts-2.png" alt="添加订阅入口" width="600"/>

| 字段 | 填写 |
| --- | --- |
| 协议（必填） | `HTTPS` |
| 订阅终端（必填） | `{integration_url}` |

点击 **确认**。

<img src="https://download.flashcat.cloud/flashduty/doc/huawei-lts-3.png" alt="订阅终端填写推送地址" width="600"/>

添加完成后，在订阅列表中确认该订阅的状态为 **已确认**。

<img src="https://download.flashcat.cloud/flashduty/doc/huawei-lts-4.png" alt="订阅状态已确认" width="600"/>

</Step>
<Step title="在华为云 LTS 中创建消息模版和告警行动规则">

**操作路径**：华为云控制台 › 云日志服务 LTS › 日志告警 › 告警通知规则 › 消息模板 › 创建

旧版控制台中该入口为 **日志告警 › 告警行动规则 › 消息模版**，下文的「告警行动规则」在新版中对应告警通知规则。先创建消息模板：

| 字段 | 填写 |
| --- | --- |
| 名称（必填） | `Flashduty` |
| 消息头语言（必填） | `英文` |
| 通知类型（必填） | `HTTP/HTTPS` |
| 数据类型（必填） | `JSON` |

点击 **确认** 保存。

<img src="https://download.flashcat.cloud/flashduty/doc/huawei-lts-5.png" alt="消息模版入口" width="600"/>

<img src="https://download.flashcat.cloud/flashduty/doc/huawei-lts-6.png" alt="创建消息模版" width="600"/>

回到 `告警行动规则` 列表，点击 **创建**：

| 字段 | 填写 |
| --- | --- |
| 规则名称（必填） | `Flashduty` |
| 主题（必填） | 上一步创建的 `Flashduty` 主题 |
| 消息模版（必填） | 刚创建的 `Flashduty` 模版 |

<img src="https://download.flashcat.cloud/flashduty/doc/huawei-lts-7.png" alt="创建告警行动规则" width="600"/>

</Step>
<Step title="在华为云 LTS 的告警规则中使用行动规则">

**操作路径**：华为云控制台 › 云日志服务 LTS › 日志告警 › 告警规则 › 创建或编辑告警规则 › 高级设置

| 字段 | 填写 |
| --- | --- |
| 通知场景（必填） | 同时勾选 `告警触发` 和 `告警恢复` |
| 行动规则（必填） | 开启，选择上一步创建的 `Flashduty` 规则 |
| 语言（必填） | `英文` |

点击 **确认** 保存。

<img src="https://download.flashcat.cloud/flashduty/doc/huawei-lts-8.png" alt="告警规则中使用行动规则" width="600"/>

</Step>
<Step title="触发告警并确认">

**操作路径**：华为云控制台 › 云日志服务 LTS › 日志告警 › 告警规则

让上一步的告警规则触发一次告警，并等待恢复。几秒后回到 Flashduty，集成显示 **最新事件时间**，说明配置成功。
{/* console:
接入清单中的「收到第一个事件」同时变为已完成。
*/}

</Step>
</Steps>
