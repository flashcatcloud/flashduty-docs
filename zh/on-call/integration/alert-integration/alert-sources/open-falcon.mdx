通过 webhook 的方式同步 Open-Falcon 告警事件到 Flashduty On-call。

<div className="hide">

## 在 Flashduty On-call
您可通过以下两种方式获取集成推送地址，任选其一即可。

### 使用专属集成

如果您只需将告警发往一个协作空间，选择此方式，配置更简单。

<AccordionGroup>
  <Accordion title="查看专属集成的配置步骤">
  
  1. 进入 Flashduty 控制台，选择 **协作空间**，打开一个协作空间
  2. 选择 **配置** → **集成数据** → **专属集成**，点击 **新增一个集成**
  3. 选择 **Falcon** 集成，点击 **保存**，生成卡片。
  4. 打开生成的集成卡片，复制 **推送地址**
  
    
</Accordion>
</AccordionGroup>

### 使用共享集成

如果您需要根据告警事件的 Payload 将告警路由到不同协作空间，选择此方式。

<AccordionGroup>
  <Accordion title="查看共享集成的配置步骤">
  
  1. 进入 Flashduty 控制台，选择 **集成中心 → 告警事件**
  2. 选择 **Falcon** 集成：
        - **集成名称**：为当前集成定义一个名称。
  3. 配置默认路由并选择协作空间；创建后可在 **路由** 中增加更多规则
  4. 点击 **保存**，复制生成的 **推送地址**
    
</Accordion>
</AccordionGroup>
  
</div>

## 在 Falcon 中配置

在每个要推送事件的告警模板中填写回调地址，并把模板绑定到主机组。

<Steps>
<Step title="在 Falcon 告警模板中填写回调地址">

**操作路径**：Falcon Dashboard › Templates

| 字段 | 填写 |
| --- | --- |
| callback 回调地址（必填） | `{integration_url}` |

打开一个告警模板，在回调地址输入框填入推送地址，点击 **Save** 保存。针对所有要发送事件的告警模板重复此操作。

<img alt="drawing" width="600" src="https://download.flashcat.cloud/open-falcon-tmpls.png" />
<img alt="drawing" width="600" src="https://download.flashcat.cloud/saas-open-falcon-rule.png" />

同样的，针对 Expressions 告警规则，也可以配置相同的推送地址。

</Step>
<Step title="把告警模板绑定到主机组">

**操作路径**：Falcon Dashboard › HostGroups › templates

在主机组的 **templates** 页面输入模板名称，点击 **bind**。模板已绑定到主机组时跳过此步。

</Step>
<Step title="触发告警并确认">

Falcon 没有发送测试回调的入口，请等待真实告警触发，或让绑定模板的主机触发一次阈值。

回到 Flashduty，集成显示 **最新事件时间**，说明配置成功。告警恢复时 Falcon 通过同一回调地址推送状态为 OK 的事件，Flashduty 自动关闭对应告警，不需要另外配置恢复通知。
{/* console:
接入清单中的「收到第一个事件」同时变为已完成。
*/}

</Step>
</Steps>

Open-Falcon 到 Flashduty 告警等级映射关系：

| Open-Falcon | Flashduty |
| ----------- | -------- |
| 0 | Critical |
| 1 | Critical |
| 2 | Warning |
| 3 | Warning |
| 4 | Info |
| 5 | Info |
| 6 | Info |
