通过 webhook 的方式同步火山引擎云拨测的告警事件到 Flashduty On-call，实现告警事件自动化降噪处理。

<div className="hide">

## 在 Flashduty On-call
您可通过以下两种方式获取集成推送地址，任选其一即可。

### 使用专属集成

如果您只需将告警发往一个协作空间，选择此方式，配置更简单。

<AccordionGroup>
  <Accordion title="查看专属集成的配置步骤">
  
  1. 进入 Flashduty 控制台，选择 **协作空间**，打开一个协作空间
  2. 选择 **配置** → **集成数据** → **专属集成**，点击 **新增集成**
  3. 选择 **火山引擎云拨测** 集成，点击 **保存**，生成卡片。
  4. 打开生成的集成卡片，复制 **推送地址**
  
    
</Accordion>
</AccordionGroup>

### 使用共享集成

如果您需要根据告警事件的 Payload 将告警路由到不同协作空间，选择此方式。

<AccordionGroup>
  <Accordion title="查看共享集成的配置步骤">
  
  1. 进入 Flashduty 控制台，选择 **集成中心 → 告警事件**
  2. 选择 **火山引擎云拨测** 集成：
        - **集成名称**：为当前集成定义一个名称。
  3. 配置默认路由并选择协作空间；创建后可在 **路由** 中增加更多规则
  4. 点击 **保存**，复制生成的 **推送地址**
    
</Accordion>
</AccordionGroup>

</div>

## 在火山引擎云拨测中配置

<Steps>
<Step title="在云拨测中创建系统集成">

**操作路径**：云拨测控制台 › 报警管理 › 通知对象管理 › 系统集成 › 创建系统集成

| 字段 | 填写 |
| --- | --- |
| 系统集成（必填） | 自定义名称，例如 `Flashduty`（1～256 个字符，可含中文、英文字母、数字、下划线，不可重名） |
| 回调 URL（必填） | `{integration_url}` |

填写后点击 **确定**。云拨测会向该地址发送 POST 请求，请求体为 JSON 格式的报警通知。

<img alt="在云拨测中创建系统集成" width="600" src="https://download.flashcat.cloud/flashduty/doc/zh/fd/volcengine-1.png" />

</Step>
<Step title="在告警策略中选择该系统集成">

**操作路径**：云拨测控制台 › 报警管理 › 告警策略 › 创建告警策略（或编辑已有策略） › 配置通知规则

| 字段 | 填写 |
| --- | --- |
| 通知方式（必填） | 勾选 **系统集成** |
| 选择对接系统（必填） | 选择上一步创建的 `Flashduty` |
| 其他选项（可选） | 按需配置 |

填写后点击 **确定**。

<img alt="在告警策略中选择系统集成" width="600" src="https://download.flashcat.cloud/flashduty/doc/zh/fd/volcengine-2.png" />

</Step>
<Step title="触发一次报警并确认">

**操作路径**：云拨测控制台 › 报警管理 › 告警策略

请等待拨测任务触发该策略的报警（可临时调低报警阈值触发一次）。

回到 Flashduty，集成显示 **最新事件时间**，说明配置成功。
{/* console:
接入清单中的「收到第一个事件」同时变为已完成。
*/}

</Step>
</Steps>

## 状态对照

<div className="md-block">

| 火山引擎 | Flashduty | 状态 |
| ---------- | -------- | ---- |
| 严重告警（`grade` 为 `P0`） | Critical | 严重 |
| 普通告警（`grade` 为 `P2`） | Warning | 警告 |
| `grade` 为 `P3` | Warning | 警告 |
| 其他 | Info | 提醒 |

</div>

当回调中的 `alert_type` 为 `recovery` 时，对应告警恢复。云拨测官方的告警策略配置项中没有恢复通知开关，是否发送恢复通知以云拨测实际行为为准。
