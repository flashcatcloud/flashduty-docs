通过 webhook 的方式同步火山引擎 RTC 的告警事件到 Flashduty，实现告警事件自动化降噪处理。

<div className="hide">

## 在 Flashduty On-call
您可通过以下两种方式获取集成推送地址，任选其一即可。

### 使用专属集成

如果您只需将告警发往一个协作空间，选择此方式，配置更简单。

<AccordionGroup>
  <Accordion title="查看专属集成的配置步骤">
  
  1. 进入 Flashduty 控制台，选择 **协作空间**，打开一个协作空间
  2. 选择 **配置** → **集成数据** → **专属集成**，点击 **新增集成**
  3. 选择 **火山引擎 RTC** 集成，点击 **保存**，生成卡片。
  4. 打开生成的集成卡片，复制 **推送地址**
  
    
</Accordion>
</AccordionGroup>

### 使用共享集成

如果您需要根据告警事件的 Payload 将告警路由到不同协作空间，选择此方式。

<AccordionGroup>
  <Accordion title="查看共享集成的配置步骤">
  
  1. 进入 Flashduty 控制台，选择 **集成中心 → 告警事件**
  2. 选择 **火山引擎 RTC** 集成：
        - **集成名称**：为当前集成定义一个名称。
  3. 配置默认路由并选择协作空间；创建后可在 **路由** 中增加更多规则
  4. 点击 **保存**，复制生成的 **推送地址**
    
</Accordion>
</AccordionGroup>

</div>

## 在火山引擎 RTC 中配置

<Steps>
<Step title="在火山引擎 RTC 控制台创建告警规则并填入回调地址">

**操作路径**：火山引擎控制台 › 实时音视频 › 监控台 › 告警通知 › 告警规则 › 创建规则

| 字段 | 填写 |
| --- | --- |
| 告警规则（必填） | 按需选择规则类型（指标 / 实时 / 事件），并设置指标与阈值 |
| 告警回调（必填） | 勾选，并在地址框填入 `{integration_url}` |
| 其他选项（可选） | 按需配置 |

填写后点击 **确定** 完成配置。

![火山引擎 RTC 告警规则中勾选告警回调并填入推送地址](https://docs-cdn.flashcat.cloud/images/png/21908f6a040f61ad2e8091226874fe97.png)

</Step>
<Step title="启用规则并确认">

**操作路径**：火山引擎控制台 › 实时音视频 › 监控台 › 告警通知 › 告警规则

在规则列表中找到刚创建的规则，点击 **启用**，规则才会生效。请等待规则命中触发条件（可临时调低阈值触发一次）。

回到 Flashduty，集成显示 **最新事件时间**，说明配置成功。

## 严重程度与事件处理

火山引擎 RTC 的告警回调不区分级别：无论规则级别是 严重、警告 还是 通知，Flashduty 一律映射为 Warning。

- 每次推送都会生成新的告警标识，因此每条回调都是一条独立告警。
- 回调里没有恢复通知，告警不会自动恢复，需要在 Flashduty 中手动关闭。（无事件检测只会在 RTC 完全停止推送时另行告警，不会关闭这些告警。）
- 告警标题为 `<check>::<alert_type>`（取回调中 check 与 alert_type 字段的值）。

您可以通过[告警处理 Pipeline](/zh/on-call/integration/alert-integration/alert-pipelines) 来自定义严重程度。
