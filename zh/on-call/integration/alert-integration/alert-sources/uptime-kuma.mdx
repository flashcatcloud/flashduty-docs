通过 webhook 的方式同步 Uptime Kuma 告警事件到 Flashduty On-call。

<div className="hide">

## 在 Flashduty On-call
您可通过以下两种方式获取集成推送地址，任选其一即可。

### 使用专属集成

如果您只需将告警发往一个协作空间，选择此方式，配置更简单。

<AccordionGroup>
  <Accordion title="查看专属集成的配置步骤">
  
  1. 进入 Flashduty 控制台，选择 **协作空间**，打开一个协作空间
  2. 选择 **配置** → **集成数据** → **专属集成**，点击 **新增集成**
  3. 选择 **Uptime Kuma** 集成，点击 **保存**，生成卡片。
  4. 打开生成的集成卡片，复制 **推送地址**
  
    
</Accordion>
</AccordionGroup>

### 使用共享集成

如果您需要根据告警事件的 Payload 将告警路由到不同协作空间，选择此方式。

<AccordionGroup>
  <Accordion title="查看共享集成的配置步骤">
  
  1. 进入 Flashduty 控制台，选择 **集成中心 → 告警事件**
  2. 选择 **Uptime Kuma** 集成：
        - **集成名称**：为当前集成定义一个名称。
  3. 配置默认路由并选择协作空间；创建后可在 **路由** 中增加更多规则
  4. 点击 **保存**，复制生成的 **推送地址**
    
</Accordion>
</AccordionGroup>

</div>

## 在 Uptime Kuma

<Steps>
<Step title="在 Uptime Kuma 中设置通知渠道">

**操作路径**：Uptime Kuma › Settings › Notifications

单击 Setup 进行编辑，按下表填写后提交保存：

| 字段 | 填写 | 必填 |
| --- | --- | --- |
| Notification Type | `Flashduty（ Flashduty ）` | 必填 |
| Integration Key | `{integration_key}`（即集成推送地址中的 integration_key 参数值，也可以填完整推送地址 `{integration_url}`） | 必填 |
| Severity | 严重程度，按需选择 | 可选 |

<img alt="drawing" width="400" src="https://download.flashcat.cloud/flashduty/integration/uptime-kuma/notify_channel.png" />

</Step>
<Step title="在监控项中启用该通知">

**操作路径**：Uptime Kuma › Add New Monitor › Notifications

<div className="md-block">

1. 点击 `Add New Monitor` 或编辑已有的监控项，按需完成监控配置
2. 如图，右侧 `Notifications` 部分启用上一步创建的通知方式
3. 如需设置标签，可以添加 `Tags`，注意仅同时存在 Key/Value 的标签才会推送到 Flashduty
4. 提交保存

<img alt="drawing" width="600" src="https://download.flashcat.cloud/flashduty/integration/uptime-kuma/monitor.png" />

</div>

</Step>
<Step title="触发一次真实告警并验证">

让一个已启用该通知的监控项真正失败（例如暂停被监控的服务），等待 Uptime Kuma 发送告警，再恢复服务，确认 Flashduty 中的告警自动恢复（监控变为 Up 时 Uptime Kuma 发送恢复事件）。回到 Flashduty，集成显示 **最新事件时间**，说明配置成功。
{/* console:
接入清单中的「收到第一个事件」同时变为已完成。
*/}
</Step>
</Steps>

## 状态和告警等级
<div className="md-block">
  
监控变为 Down 时，告警等级取自通知渠道中的 **Severity**（下表）；变为 Up 时发送恢复事件，关闭同一监控的告警。

Uptime Kuma 到 Flashduty 告警等级映射关系：

| Uptime Kuma | Flashduty |
| ------------ | -------- |
| Critical | Critical |
| Warning | Warning |
| Info | Info |

</div>
