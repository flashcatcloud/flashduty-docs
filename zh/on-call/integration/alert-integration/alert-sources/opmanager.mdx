通过 webhook 的方式同步 Opmanager 告警事件到 Flashduty On-call。

<div className="hide">

## 在 Flashduty On-call
您可通过以下两种方式获取集成推送地址，任选其一即可。

### 使用专属集成

如果您只需将告警发往一个协作空间，选择此方式，配置更简单。

<AccordionGroup>
  <Accordion title="查看专属集成的配置步骤">
  
  1. 进入 Flashduty 控制台，选择 **协作空间**，打开一个协作空间
  2. 选择 **配置** → **集成数据** → **专属集成**，点击 **新增集成**
  3. 选择 **OpManager** 集成，点击 **保存**，生成卡片。
  4. 打开生成的集成卡片，复制 **推送地址**
  
    
</Accordion>
</AccordionGroup>

### 使用共享集成

如果您需要根据告警事件的 Payload 将告警路由到不同协作空间，选择此方式。

<AccordionGroup>
  <Accordion title="查看共享集成的配置步骤">
  
  1. 进入 Flashduty 控制台，选择 **集成中心 → 告警事件**
  2. 选择 **OpManager** 集成：
        - **集成名称**：为当前集成定义一个名称。
  3. 配置默认路由并选择协作空间；创建后可在 **路由** 中增加更多规则
  4. 点击 **保存**，复制生成的 **推送地址**
    
</Accordion>
</AccordionGroup>
</div>

## 在 OpManager 中配置

<Steps>
<Step title="在 OpManager 中新建 Webhook 通知配置文件">

**操作路径**：OpManager › Settings › Notifications › Add Profile › Invoke a Webhook

<img alt="OpManager 中添加 Invoke a Webhook 配置文件" width="600" src="https://download.flashcat.cloud/flashduty/doc/opm-1.png" />

在 Webhook 编辑页面填写：

| 字段 | 填写 |
| --- | --- |
| Hook URL 的请求方法（必填） | `POST` |
| URL（必填） | `{integration_url}` |
| Data Type（必填） | `raw` |
| Payload Type（必填） | `JSON` |
| Body Content（必填） | 见下方 JSON |
| Request Headers | 保持默认 |
| Time Out（必填） | 单位为秒，界面默认值为 15 |

`Body Content` 填写：

```json
{
     "alarmid":"$alarmid",
     "message":"$message",
     "displayName":"$displayName",
     "category":"$category",
     "severity":"$stringseverity",
     "strModTime":"$strModTime",
     "eventType":"$eventType",
     "entity":"$entity",
     "lastPolledValue":"$lastPolledValue",
     "Intf_ifDescr":"$IntfField(ifDescr)",
     "Intf_displayName":"$IntfField(displayName)",
     "Intf_ifAlias":"$IntfField(ifAlias)",
     "Intf_ifName":"$IntfField(ifName)",
     "Intf_ipAddress":"$IntfField(ipAddress)",
     "Intf_physMedia":"$IntfField(physMedia)",
     "Intf_ifIndex":"$IntfField(ifIndex)",
     "Intf_ifCircuitID":"$IntfField(ifCircuitID)",
     "Intf_ifSpeedIn":"$IntfField(ifSpeedIn)",
     "Intf_ifSpeedOut":"$IntfField(ifSpeedOut)",
     "Intf_lineID":"$IntfCustomField(Circuit ID)",
     "Intf_note":"$IntfCustomField(Comments)",
     "Intf_contacts":"$IntfCustomField(Contact Name)",
     "Intf_SLA":"$IntfCustomField(SLA)",
     "Custom_building":"$CustomField(Building)",
     "Custom_cabinet":"$CustomField(Cabinet)",
     "Custom_note":"$CustomField(Comments)",
     "Custom_contacts":"$CustomField(Contact Name)",
     "Custom_department":"$CustomField(Department)",
     "Custom_floor":"$CustomField(Floor)",
     "Custom_serial":"$CustomField(SerialNumbe)",
     "Monitor_monitorName":"$MonitorField(monitorName)",
     "Monitor_instance":"$MonitorField(instance)",
     "Monitor_protocol":"$MonitorField(protocol)",
     "Device_type":"$DeviceField(type)",
     "Device_ipAddress":"$DeviceField(ipAddress)",
     "Device_isSNMP":"$DeviceField(isSNMP)",
     "Device_hardDiskSize":"$DeviceField(hardDiskSize)",
     "Device_ramSize":"$DeviceField(ramSize)"
}
```

JSON 的键名必须与上面一致，Flashduty 只读取这些键。暂不支持添加额外的自定义字段，即使在 Body Content 中引用了其他字段，也不会生效。

填写完成后点击下一步。

<img alt="OpManager 中 Webhook 的 Time Out 配置" width="600" src="https://download.flashcat.cloud/flashduty/doc/opm-2.png" />

</Step>
<Step title="配置触发条件和恢复通知">

**操作路径**：OpManager › Settings › Notifications › Add Profile › Invoke a Webhook › Choose the criteria

勾选 `Notify when the alarm is cleared`，这样 OpManager 在告警清除时会再发送一次通知，Flashduty 据此恢复告警。其他条件按需配置。

<img alt="OpManager 中勾选 Notify when the alarm is cleared" width="600" src="https://download.flashcat.cloud/flashduty/doc/opm-3.png" />

点击下一步，选择希望应用此配置文件的设备，使用右箭头将它们移动到选定设备窗口，再点击下一步。`Time Window`、`Delayed Trigger`、`Recurring Trigger` 可按需配置，然后点击下一步。

</Step>
<Step title="保存配置文件并确认">

**操作路径**：OpManager › Settings › Notifications

为该配置文件添加名称 `Flashduty`，点击 `Save`。然后让所选设备触发一次真实告警，几秒后回到 Flashduty，集成显示 **最新事件时间**，说明配置成功。
{/* console:
接入清单中的「收到第一个事件」同时变为已完成。
*/}

</Step>
</Steps>

## 状态和告警等级

<div className="md-block">

| OpManager | Flashduty |
| ---------- | -------- |
| Critical | Critical |
| Service Down | Critical |
| Trouble | Warning |
| Attention | Info |
| Clear | Ok（告警恢复） |

其他取值按 Info 处理。

</div>
