通过 webhook 的方式同步京东云监控告警事件到 Flashduty On-call。

<div className="hide">

## 在 Flashduty On-call
您可通过以下两种方式获取集成推送地址，任选其一即可。

### 使用专属集成

如果您只需将告警发往一个协作空间，选择此方式，配置更简单。

<AccordionGroup>
  <Accordion title="查看专属集成的配置步骤">
  
  1. 进入 Flashduty 控制台，选择 **协作空间**，打开一个协作空间
  2. 选择 **配置** → **集成数据** → **专属集成**，点击 **新增一个集成**
  3. 选择 **京东云监控** 集成，点击 **保存**，生成卡片。
  4. 打开生成的集成卡片，复制 **推送地址**
  
    
</Accordion>
</AccordionGroup>

### 使用共享集成

如果您需要根据告警事件的 Payload 将告警路由到不同协作空间，选择此方式。

<AccordionGroup>
  <Accordion title="查看共享集成的配置步骤">
  
  1. 进入 Flashduty 控制台，选择 **集成中心 → 告警事件**
  2. 选择 **京东云监控** 集成：
        - **集成名称**：为当前集成定义一个名称。
  3. 配置默认路由并选择协作空间；创建后可在 **路由** 中增加更多规则
  4. 点击 **保存**，复制生成的 **推送地址**
    
</Accordion>
</AccordionGroup>
</div>

## 在京东云

<Steps>
<Step title="创建通知模版">

**操作路径**：京东云控制台 › 云监控 › 告警管理 › 通知模版 › 创建（或编辑已有模版）

| 字段 | 填写 |
| --- | --- |
| 告警回调（必填） | 勾选 |
| URL（必填） | `{integration_url}` |
| POST（必填） | 下面的 JSON 模版 |

`POST` 编辑框中的模版内容：

   ```json
   {
     "resource_id": "${resourceId}",
     "request_id": "${requestId}",
     "metric": "${metric}",
     "current_value": "${currentValue}",
     "times": "${times}",
     "tags": "${tags}",
     "alert_time": "${alertTime}",
     "region": "${region}",
     "threshold": "${threshold}",
     "service_code": "${serviceCode}",
     "as_group_id": "${asGroupId}",
     "unhealthy_instance": "${unhealthyInstance}",
     "rule_policy_id": "${rulePolicyId}",
     "service_code_en": "${serviceCodeEN}",
     "service_code_cn": "${serviceCodeCN}",
     "level": "${level}",
     "resource_name": "${resourceName}",
     "ip_address": "${ipAddress}",
     "status": "${status}"
   }
   ```

其他选项按需配置，点击 **保存** 完成。

</Step>

<Step title="配置告警规则">

**操作路径**：京东云控制台 › 云监控 › 告警管理 › 全部告警规则 › 创建（或编辑已有规则）› 通知策略

| 字段 | 填写 |
| --- | --- |
| 通知策略（必填） | 选择 **使用模版**，并选择上一步创建的模版 |

其他选项按需配置，点击 **保存** 完成。

</Step>

<Step title="触发告警并确认">

**操作路径**：京东云控制台 › 云监控 › 告警管理 › 全部告警规则 › 目标规则

京东云监控未提供独立的回调测试入口。让该规则触发，或等待真实告警。

回到 Flashduty，集成显示 **最新事件时间**，说明配置成功。
{/* console:
接入清单中的「收到第一个事件」同时变为已完成。
*/}

</Step>
</Steps>
