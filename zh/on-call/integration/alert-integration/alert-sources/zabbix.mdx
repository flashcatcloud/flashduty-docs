通过 webhook 的方式同步 Zabbix 告警事件到 Flashduty（支持 Zabbix 3.x–7.x 版本，不同版本配置有差异）。

<div className="hide">

## 在 Flashduty On-call
您可通过以下两种方式获取集成推送地址，任选其一即可。

### 使用专属集成

如果您只需将告警发往一个协作空间，选择此方式，配置更简单。

<AccordionGroup>
  <Accordion title="查看专属集成的配置步骤">
  
  1. 进入 Flashduty 控制台，选择 **协作空间**，打开一个协作空间
  2. 选择 **配置** → **集成数据** → **专属集成**，点击 **新增集成**
  3. 选择 **Zabbix** 集成，点击 **保存**，生成卡片。
  4. 打开生成的集成卡片，复制 **推送地址**
  
    
</Accordion>
</AccordionGroup>

### 使用共享集成

如果您需要根据告警事件的 Payload 将告警路由到不同协作空间，选择此方式。

<AccordionGroup>
  <Accordion title="查看共享集成的配置步骤">
  
  1. 进入 Flashduty 控制台，选择 **集成中心 → 告警事件**
  2. 选择 **Zabbix** 集成：
        - **集成名称**：为当前集成定义一个名称。
  3. 配置默认路由并选择协作空间；创建后可在 **路由** 中增加更多规则
  4. 点击 **保存**，复制生成的 **推送地址**
    
</Accordion>
</AccordionGroup>
</div>

### Zabbix 7.x

#### 步骤 1：在 Zabbix 中导入 Flashduty media type

media type 是 Zabbix 中发送通知的传输通道。下载地址要求请求携带 `Referer` 头，缺少时返回 403，请保留命令中的 `--header` 参数。

**操作路径**：Zabbix › Alerts › Media types › Import

1. 在终端下载配置文件：

   ```bash
   wget --header="Referer: https://console.flashcat.cloud" https://download.flashcat.cloud/flashduty/integration/zabbix/zbx_mediatype_flashcat_v7.yml
   ```

2. 在 **Import** 页面选择该文件，点击 **Import**
3. 在 **Media types** 列表中点击导入的 media type 名称，补全以下参数后点击 **Update**：

   | 参数 | 填写 |
   | --- | --- |
   | `URL`（必填） | `{integration_url}` |
   | `zabbix_url`（可选） | Zabbix 控制台地址，配置了 tomcat/nginx 转发路径时一并带上。系统在其后拼接 trigger_id 等参数，生成告警详情页链接 |
   | `HTTPProxy`（可选） | Zabbix Server 不能直接访问 Flashduty 时填写代理地址 |

   <img alt="7.x 版本：补全 media type 的 URL、zabbix_url 和 HTTPProxy" width="600" src="https://download.flashcat.cloud/flashduty/doc/zabbix-2.png" />

#### 步骤 2：在 Zabbix 中为用户添加 Flashduty media

**操作路径**：Zabbix › Users › Users › Admin › Media › Add

media type 必须关联到用户才能发送事件，该用户至少拥有对 host 的 read 权限。建议直接关联到 Admin 用户。

| 字段 | 填写 |
| --- | --- |
| Type（必填） | 上一步的 Flashduty media type |
| Send to（必填） | `Flashduty` |
| 其他字段 | 保持默认 |

点击 **Add** 关闭弹窗，再点击 **Update** 保存用户。

<img alt="Zabbix 7.x: 为用户添加 media" width="600" src="https://download.flashcat.cloud/flashduty/doc/zabbix-3.png" />

#### 步骤 3：在 Zabbix 中创建发送到 Flashduty 的 trigger action

**操作路径**：Zabbix › Alerts › Actions › Trigger actions › Create action

1. **Name** 填写 `Send To Flashduty`
2. 在 **Operations** 中分别配置 **Operations**、**Recovery operations** 和 **Update operations**。每项点击 **Add**，填写后再点击 **Add**：

   | 字段 | 填写 |
   | --- | --- |
   | Send to users | 上一步添加了 media 的用户 |
   | Send only to（7.0.7 起为 Send to media type） | Flashduty media type |
   | 其他字段 | 保持默认 |

3. 点击 **Add** 保存 action

<img alt="Zabbix 7.x: 配置 action 的通知发送" width="600" src="https://download.flashcat.cloud/flashduty/doc/zabbix-5.png" />

#### 步骤 4：在 Zabbix 中触发告警并确认

**操作路径**：Zabbix › Monitoring › Problems › Actions

**Media types** 列表中的 **Test** 以宏原文（如 `{EVENT.SEVERITY}`）作为参数值，Flashduty 会因等级无效拒绝该请求，请用真实告警验证：

1. 等待或制造一个触发 action 的告警，在 **Monitoring › Problems** 中点击该告警 **Actions** 列，查看通知结果
2. Flashduty media type 对应记录的 Status 为 `Sent` 表示发送成功，否则按提示排查
3. 回到 Flashduty，集成显示 **最新事件时间**，说明配置成功

接入清单中的「收到第一个事件」同时变为已完成。
*/}

<img alt="Zabbix 7.x: 查看通知结果" width="600" src="https://download.flashcat.cloud/flashduty/doc/zabbix-6.png" />

### Zabbix 3.x–4.x

#### 步骤 1：创建 Flashduty media type 并安装脚本

media type 是 Zabbix 中发送通知的传输通道。下载地址要求请求携带 `Referer` 头，缺少时返回 403，请保留命令中的 `--header` 参数。

**操作路径**：Zabbix › Administration › Media types › Create media type

1. **Type** 选择 `Script`，**Script name** 填写 `send-to-flashduty.sh`
2. **Script parameters** 依次填写以下 5 个参数。不要调整顺序，没有值的也要留空，脚本按顺序读取：

   | 顺序 | 填写 |
   | --- | --- |
   | 1 | `{ALERT.SUBJECT}`（告警标题） |
   | 2 | `{ALERT.MESSAGE}`（告警信息） |
   | 3（必填） | `{integration_url}` |
   | 4（可选） | Zabbix 控制台地址，配置了 tomcat/nginx 转发路径时一并带上，用于生成告警详情页链接；没有则留空 |
   | 5（可选） | HTTPProxy：Zabbix Server 不能直接访问 Flashduty 时填写代理地址；没有则留空 |

   <img alt="3.x–4.x 版本：创建 Script 类型的 media type" width="600" src="https://download.flashcat.cloud/flashduty/integration/zabbix/v4_create_fd_media_type.jpg" />

3. 点击 **Update** 保存
4. 登录 Zabbix Server 所在服务器，下载脚本到告警脚本目录。目录由 Zabbix Server 配置文件中的 `AlertScriptsPath` 指定，一般为 `/usr/lib/zabbix/alertscripts`：

   ```bash
   cd /usr/lib/zabbix/alertscripts
   wget --header="Referer: https://console.flashcat.cloud" https://download.flashcat.cloud/flashduty/integration/zabbix/send-to-flashduty.sh
   chmod +x send-to-flashduty.sh
   ```

   脚本使用 `curl` 和 `jq` 命令，请确保 Zabbix Server 进程可以找到并执行这两个命令，没有则先安装。

#### 步骤 2：在 Zabbix 中为用户添加 Flashduty media

**操作路径**：Zabbix › Administration › Users › Admin › Media › Add

media type 必须关联到用户才能发送事件，该用户至少拥有对 host 的 read 权限。建议直接关联到 Admin 用户。

| 字段 | 填写 |
| --- | --- |
| Type（必填） | 上一步的 Flashduty media type |
| Send to（必填） | `N/A` |
| 其他字段 | 保持默认 |

点击 **Add** 关闭弹窗，再点击 **Update** 保存用户。

<img alt="Zabbix 3.x–4.x: 为用户添加 media" width="600" src="https://download.flashcat.cloud/flashduty/integration/zabbix/v4_bind_media_type.jpg" />

#### 步骤 3：在 Zabbix 中创建发送到 Flashduty 的 trigger action

**操作路径**：Zabbix › Configuration › Actions › Create action

1. **Name** 填写 `Send To Flashduty`
2. 在 **Operations** 中分别配置 **Operations**、**Recovery operations** 和 **Update operations**（3.x 为 **Acknowledgement operations**）。每项点击 **Add**，填写后再点击 **Add**：

   | 字段 | 填写 |
   | --- | --- |
   | Send to users | 上一步添加了 media 的用户 |
   | Send only to | Flashduty media type |
   | 其他字段 | 保持默认 |

3. 在三项配置的 **Default message** 中，把以下内容**完整粘贴到默认内容之后**。Flashduty 收到事件后解析这段文字，读取告警属性：

   ```
   -----Flashduty Required Starts-----event_severity={TRIGGER.SEVERITY}||event_name={TRIGGER.NAME}||event_id={EVENT.ID}||event_tags={EVENT.TAGS}||event_ack={EVENT.ACK.STATUS}||event_value={EVENT.VALUE}||trigger_id={TRIGGER.ID}||trigger_desc={TRIGGER.DESCRIPTION}||trigger_expr={TRIGGER.EXPRESSION}||host_group={TRIGGER.HOSTGROUP.NAME}||host_ip={HOST.IP}||host_name={HOST.NAME}||item_name={ITEM.NAME}||item_value={ITEM.VALUE}-----Flashduty Required Ends-----
   ```

4. 点击 **Add** 保存 action

<img alt="Zabbix 3.x–4.x: 配置 action 的通知发送" width="600" src="https://download.flashcat.cloud/flashduty/integration/zabbix/v4_create_action_operation_add.jpg" />

## 状态和告警等级

<div className="md-block">

Zabbix 到 Flashduty 告警等级映射关系：

| Zabbix | Flashduty |
| -------------- | -------- |
| Disaster | Critical |
| High | Critical |
| Average | Warning |
| Warning | Warning |
| Information | Info |
| Not classified | Info |
