通过 webhook 的方式同步监控宝告警事件到 Flashduty On-call。

<div className="hide">

## 在 Flashduty On-call
您可通过以下两种方式获取集成推送地址，任选其一即可。

### 使用专属集成

如果您只需将告警发往一个协作空间，选择此方式，配置更简单。

<AccordionGroup>
  <Accordion title="查看专属集成的配置步骤">
  
  1. 进入 Flashduty 控制台，选择 **协作空间**，打开一个协作空间
  2. 选择 **配置** → **集成数据** → **专属集成**，点击 **新增一个集成**
  3. 选择 **监控宝** 集成，点击 **保存**，生成卡片。
  4. 打开生成的集成卡片，复制 **推送地址**
  
    
</Accordion>
</AccordionGroup>

### 使用共享集成

如果您需要根据告警事件的 Payload 将告警路由到不同协作空间，选择此方式。

<AccordionGroup>
  <Accordion title="查看共享集成的配置步骤">
  
  1. 进入 Flashduty 控制台，选择 **集成中心 → 告警事件**
  2. 选择 **监控宝** 集成：
        - **集成名称**：为当前集成定义一个名称。
  3. 配置默认路由并选择协作空间；创建后可在 **路由** 中增加更多规则
  4. 点击 **保存**，复制生成的 **推送地址**
    
</Accordion>
</AccordionGroup>

</div>

## 在监控宝中配置

本集成同样适用于云智慧监控宝（含监控宝 6）的 URL 回调通知。

<Steps>
<Step title="在监控宝中添加 URL 回调">

**操作路径**：监控宝控制台 › 右上角个人配置 › Webhooks 设置 › 添加 › URL 回调

<img alt="监控宝个人配置入口" width="600" src="https://fcpub-1301667576.cos.ap-nanjing.myqcloud.com/flashduty/doc/jkb-1.png" />

<img alt="监控宝 Webhooks 设置中添加 URL 回调" width="600" src="https://fcpub-1301667576.cos.ap-nanjing.myqcloud.com/flashduty/doc/jkb-2.png" />

| 字段 | 填写 |
| --- | --- |
| 自定义名称（必填） | `Flashduty` |
| 回调 URL（必填） | `{integration_url}` |
| 回调方式（必填） | **POST** |
| 数据格式（必填） | **JSON** |
| 开启 URL 回调（必填） | 勾选 |

其他按需选择，点击保存。

<img alt="监控宝 URL 回调配置" width="600" src="https://fcpub-1301667576.cos.ap-nanjing.myqcloud.com/flashduty/doc/jkb-3.png" />

</Step>

<Step title="在监控任务中使用该 Webhook 通道">

**操作路径**：监控宝控制台 › 监控任务 › 创建（或编辑已有任务）› Webhook 通知

| 字段 | 填写 |
| --- | --- |
| Webhook 通知（必填） | 选择 `Flashduty` 通道 |

其他告警配置按需填写，保存监控任务。

<img alt="监控宝监控任务中选择 Flashduty 通道" width="600" src="https://fcpub-1301667576.cos.ap-nanjing.myqcloud.com/flashduty/doc/jkb-4.png" />

</Step>

<Step title="触发告警并确认">

**操作路径**：监控宝控制台 › 监控任务 › 目标任务

监控宝未提供独立的回调测试入口。让该任务产生一次告警，或等待真实告警。

回到 Flashduty，集成显示 **最新事件时间**，说明配置成功。
{/* console:
接入清单中的「收到第一个事件」同时变为已完成。
*/}

</Step>
</Steps>
