通过 webhook 的方式同步腾讯云监控 CM 告警事件到 Flashduty On-call。

<div className="hide">

## 在 Flashduty On-call
您可通过以下两种方式获取集成推送地址，任选其一即可。

### 使用专属集成

如果您只需将告警发往一个协作空间，选择此方式，配置更简单。

<AccordionGroup>
  <Accordion title="查看专属集成的配置步骤">
  
  1. 进入 Flashduty 控制台，选择 **协作空间**，打开一个协作空间
  2. 选择 **配置** → **集成数据** → **专属集成**，点击 **新增一个集成**
  3. 选择 **腾讯云监控 CM** 集成，点击 **保存**，生成卡片。
  4. 打开生成的集成卡片，复制 **推送地址**
  
    
</Accordion>
</AccordionGroup>

### 使用共享集成

如果您需要根据告警事件的 Payload 将告警路由到不同协作空间，选择此方式。

<AccordionGroup>
  <Accordion title="查看共享集成的配置步骤">
  
  1. 进入 Flashduty 控制台，选择 **集成中心 → 告警事件**
  2. 选择 **腾讯云监控 CM** 集成：
        - **集成名称**：为当前集成定义一个名称。
  3. 配置默认路由并选择协作空间；创建后可在 **路由** 中增加更多规则
  4. 点击 **保存**，复制生成的 **推送地址**
    
</Accordion>
</AccordionGroup>
</div>

## 在腾讯云监控 CM 中配置

<Steps>
<Step title="在腾讯云监控中新建通知模板">

**操作路径**：腾讯云控制台 › 云监控 › 告警管理 › 基础配置 › 通知模板 › 新建通知模板

| 字段 | 填写 |
| --- | --- |
| 模板名称（必填） | 自定义名称，例如 `Flashduty` |
| 接口回调 › 接口 URL / 回调地址（必填） | `{integration_url}` |
| 通知语言（必填） | `英文` |

填写后点击 **保存**。

<img alt="腾讯云监控中通知模板的配置" width="600" src="https://download.flashcat.cloud/saas-tecent-cm-template.png" />

</Step>
<Step title="在告警策略中关联通知模板">

**操作路径**：腾讯云控制台 › 云监控 › 告警管理 › 策略管理 › 目标告警策略 › 编辑 › 通知模板

在每个需要把事件发送到 Flashduty 的告警策略中，添加上一步新建的通知模板，保存策略。

<img alt="腾讯云监控告警策略中添加通知模板" width="600" src="https://download.flashcat.cloud/tecent-cm-rule.png" />

</Step>
<Step title="确认 Flashduty 收到事件">

腾讯云监控的通知模板没有“发送测试”入口，需要等待已关联策略的真实告警触发。

告警产生后回到 Flashduty，集成显示 **最新事件时间**，说明配置成功。
{/* console:
接入清单中的「收到第一个事件」同时变为已完成。
*/}

</Step>
</Steps>

## 状态和告警等级
<div className="md-block">
  
`alarmLevel` 存在时，按以下规则映射到 Flashduty 告警级别：

| 腾讯云监控 `alarmLevel` | Flashduty |
| --- | --- |
| `Remind` | Info |
| `Warn` | Warning |
| `Serious` | Critical |

未提供或未识别 `alarmLevel` 时，使用告警类型的默认级别：

| 腾讯云监控 `alarmType` | Flashduty |
| --- | --- |
| `metric` | Warning |
| `event`、`prometheus` 及其他类型 | Critical |

恢复状态单独判断：`event` 类型的 `recoverTime` 不为 `0` 时映射为已恢复（OK）；其他类型的 `alarmStatus` 为 `0` 时映射为已恢复（OK）。

</div>
