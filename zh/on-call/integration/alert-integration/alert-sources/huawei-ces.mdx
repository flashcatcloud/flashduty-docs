通过 webhook 的方式同步华为云监控 CES 告警事件到 Flashduty On-call。

<div className="hide">

## 在 Flashduty On-call
您可通过以下两种方式获取集成推送地址，任选其一即可。

### 使用专属集成

如果您只需将告警发往一个协作空间，选择此方式，配置更简单。

<AccordionGroup>
  <Accordion title="查看专属集成的配置步骤">
  
  1. 进入 Flashduty 控制台，选择 **协作空间**，打开一个协作空间
  2. 选择 **配置** → **集成数据** → **专属集成**，点击 **新增集成**
  3. 选择 **华为云监控 CES** 集成，点击 **保存**，生成卡片。
  4. 打开生成的集成卡片，复制 **推送地址**
  
    
</Accordion>
</AccordionGroup>

### 使用共享集成

如果您需要根据告警事件的 Payload 将告警路由到不同协作空间，选择此方式。

<AccordionGroup>
  <Accordion title="查看共享集成的配置步骤">
  
  1. 进入 Flashduty 控制台，选择 **集成中心 → 告警事件**
  2. 选择 **华为云监控 CES** 集成：
        - **集成名称**：为当前集成定义一个名称。
  3. 配置默认路由并选择协作空间；创建后可在 **路由** 中增加更多规则
  4. 点击 **保存**，复制生成的 **推送地址**
    
</Accordion>
</AccordionGroup>
</div>

## 在华为云监控 CES 中配置

<Steps>
<Step title="在华为云中准备 HTTPS 通知渠道">

<Tabs>
<Tab title="新版控制台（推荐）：SMN 主题订阅">

**操作路径**：华为云控制台 › 消息通知服务 SMN › 主题管理 › 主题 › 创建主题

| 字段 | 填写 |
| --- | --- |
| 主题名称（必填） | `Flashduty` |

保存后，在 `Flashduty` 主题所在行点击 **添加订阅**：

| 字段 | 填写 |
| --- | --- |
| 协议（必填） | `HTTPS` |
| 订阅终端（必填） | `{integration_url}` |

添加完成后，在订阅列表中确认该订阅的状态为 **已确认**，否则不会推送告警。

</Tab>
<Tab title="旧版控制台：通知对象与通知组">

通知对象与通知组页面在新版控制台中的入口未确认，以下为旧版控制台路径。部分区域显示为 **联系人/联系组**（[来源](https://support.huaweicloud.com/usermanual-ces/ces_01_0219.html)）。

**操作路径**：华为云控制台 › 云监控 CES › 告警 › 告警通知 › 通知对象 › 创建通知对象

| 字段 | 填写 |
| --- | --- |
| 协议（必填） | `HTTPS` |
| 名称（必填） | `flashduty` |
| 终端（必填） | `{integration_url}` |

点击 **确定**，完成通知对象创建。

<img src="https://download.flashcat.cloud/huawei-ces-create-notify-obj.png" alt="创建 HTTPS 通知对象" width="600"/>

然后进入 **告警 › 告警通知 › 通知组 › 创建通知组**：

| 字段 | 填写 |
| --- | --- |
| 组名称（必填） | `Flashduty` |
| 通知对象（必填） | 勾选上面创建的 `flashduty` |

点击 **确定**，完成通知组创建。

<img src="https://download.flashcat.cloud/huawei-ces-create-notify-group.png" alt="创建通知组" width="600"/>

创建通知组时，华为云会向 Flashduty On-call 发起请求以验证推送地址。请在通知组的通知对象列表中确认状态为 `已确认`，否则不会推送告警。

</Tab>
</Tabs>

</Step>
<Step title="在华为云监控 CES 的告警规则中使用该渠道">

**操作路径**：华为云控制台 › 云监控 CES › 告警 › 规则配置 › 创建告警规则

低版本控制台为 **告警 › 告警规则**。

| 字段 | 填写 |
| --- | --- |
| 发送通知（必填） | 开启 |
| 通知方式（必填） | 新版控制台可选 `通知策略` / `联系组` / `主题订阅`，推荐 `主题订阅` 并选择 `Flashduty` 主题；旧版控制台选择 `通知组` 为 `Flashduty` |
| 触发条件（必填） | 指标告警同时勾选 `出现告警` 和 `恢复正常`；事件告警只支持 `出现告警` |
| 生效时间（可选） | 选择联系组或主题订阅时可设置，例如 08:00-20:00 |

点击 **确定** 保存。

<img src="https://download.flashcat.cloud/huawei-ces-create-alarm.png" alt="告警规则中选择 Flashduty 通知渠道" width="600"/>

</Step>
<Step title="触发告警并确认">

**操作路径**：华为云控制台 › 云监控 CES › 告警 › 规则配置

当告警规则触发（或恢复）时，华为云会推送事件到 Flashduty。
{/* console:
接入清单中的「收到第一个事件」同时变为已完成。
*/}
几秒后回到 Flashduty，集成显示 **最新事件时间**，说明配置成功。

</Step>
</Steps>

<div className="md-block">

华为云监控到 Flashduty 告警等级映射关系：

| CES | Flashduty |
| ---- | -------- |
| 紧急 | Critical |
| 重要 | Critical |
| 次要 | Warning |
| 提示 | Info |
