通过 webhook 的方式同步华为云监控 CES 告警事件到 Flashduty On-call。

<div className="hide">

## 在 Flashduty On-call
您可通过以下两种方式获取集成推送地址，任选其一即可。

### 使用专属集成

如果您只需将告警发往一个协作空间，选择此方式，配置更简单。

<AccordionGroup>
  <Accordion title="查看专属集成的配置步骤">
  
  1. 进入 Flashduty 控制台，选择 **协作空间**，打开一个协作空间
  2. 选择 **配置** → **集成数据** → **专属集成**，点击 **新增一个集成**
  3. 选择 **华为云监控 CES** 集成，点击 **保存**，生成卡片。
  4. 打开生成的集成卡片，复制 **推送地址**
  
    
</Accordion>
</AccordionGroup>

### 使用共享集成

如果您需要根据告警事件的 Payload 将告警路由到不同协作空间，选择此方式。

<AccordionGroup>
  <Accordion title="查看共享集成的配置步骤">
  
  1. 进入 Flashduty 控制台，选择 **集成中心 → 告警事件**
  2. 选择 **华为云监控 CES** 集成：
        - **集成名称**：为当前集成定义一个名称。
  3. 配置默认路由并选择协作空间；创建后可在 **路由** 中增加更多规则
  4. 点击 **保存**，复制生成的 **推送地址**
    
</Accordion>
</AccordionGroup>
</div>

## 在华为云监控 CES 中配置

<Steps>
<Step title="在华为云监控 CES 中创建通知对象">

**操作路径**：华为云控制台 › 云监控 CES › 告警 › 告警通知 › 通知对象 › 创建通知对象

| 字段 | 填写 |
| --- | --- |
| 协议（必填） | `HTTPS` |
| 名称（必填） | `flashduty` |
| 终端（必填） | `{integration_url}` |

点击 **确定**，完成通知对象创建。

<img src="https://download.flashcat.cloud/huawei-ces-create-notify-obj.png" alt="创建 HTTPS 通知对象" width="600"/>

</Step>
<Step title="在华为云监控 CES 中创建通知组">

**操作路径**：华为云控制台 › 云监控 CES › 告警 › 告警通知 › 通知组 › 创建通知组

| 字段 | 填写 |
| --- | --- |
| 组名称（必填） | `Flashduty` |
| 通知对象（必填） | 勾选上一步创建的 `flashduty` |

点击 **确定**，完成通知组创建。

<img src="https://download.flashcat.cloud/huawei-ces-create-notify-group.png" alt="创建通知组" width="600"/>

创建通知组时，华为云会向 Flashduty On-call 发起请求以验证推送地址。请在通知组的通知对象列表中确认状态为 `已确认`，否则不会推送告警。

</Step>
<Step title="在告警规则中使用通知组并确认">

**操作路径**：华为云控制台 › 云监控 CES › 告警 › 告警规则 › 编辑或创建告警规则 › 告警规则详情

| 字段 | 填写 |
| --- | --- |
| 通知组（必填） | `Flashduty` |
| 触发条件（必填） | 同时勾选 `出现告警` 和 `恢复正常` |

点击 **确定** 保存。

<img src="https://download.flashcat.cloud/huawei-ces-create-alarm.png" alt="告警规则中选择 Flashduty 通知组" width="600"/>

当告警规则触发（或恢复）时，华为云会推送事件到 Flashduty。几秒后回到 Flashduty，集成显示 **最新事件时间**，说明配置成功。
{/* console:
接入清单中的「收到第一个事件」同时变为已完成。
*/}

</Step>
</Steps>

## 状态和告警等级
<div className="md-block">

华为云监控到 Flashduty 告警等级映射关系：

| CES | Flashduty |
| ---- | -------- |
| 紧急 | Critical |
| 重要 | Critical |
| 次要 | Warning |
| 提示 | Info |
