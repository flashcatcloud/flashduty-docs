通过 webhook 的方式同步 Skywalking 告警事件到 Flashduty On-call。

<div className="hide">

## 在 Flashduty On-call
您可通过以下两种方式获取集成推送地址，任选其一即可。

### 使用专属集成

如果您只需将告警发往一个协作空间，选择此方式，配置更简单。

<AccordionGroup>
  <Accordion title="查看专属集成的配置步骤">
  
  1. 进入 Flashduty 控制台，选择 **协作空间**，打开一个协作空间
  2. 选择 **配置** → **集成数据** → **专属集成**，点击 **新增一个集成**
  3. 选择 **Skywalking** 集成，点击 **保存**，生成卡片。
  4. 打开生成的集成卡片，复制 **推送地址**
  
    
</Accordion>
</AccordionGroup>

### 使用共享集成

如果您需要根据告警事件的 Payload 将告警路由到不同协作空间，选择此方式。

<AccordionGroup>
  <Accordion title="查看共享集成的配置步骤">
  
  1. 进入 Flashduty 控制台，选择 **集成中心 → 告警事件**
  2. 选择 **Skywalking** 集成：
        - **集成名称**：为当前集成定义一个名称。
  3. 配置默认路由并选择协作空间；创建后可在 **路由** 中增加更多规则
  4. 点击 **保存**，复制生成的 **推送地址**
    
</Accordion>
</AccordionGroup>
</div>

## 在 Skywalking 中配置

<Steps>
<Step title="在告警规则中添加 level 标签">

**操作路径**：Skywalking OAP 服务器 › `./config/alarm-settings.yml` › `rules`

登录 Skywalking 服务器，打开配置文件 `./config/alarm-settings.yml`，在每条告警规则中添加 `tags.level`，Flashduty 据此确定告警等级。

| 键 | 填写 |
| --- | --- |
| `tags.level`（可选，v8.6.0 及以上版本才支持 `tags`，其他版本可以不添加） | `Critical`、`Warning` 或 `Info`，注意大小写；不填或其他取值按 Info 处理 |

```yaml
rules:
    endpoint_relation_resp_time_rule:
        expression: sum(endpoint_relation_resp_time > 1000) >= 2
        period: 10
        message: Response time of endpoint relation {name} is more than 1000ms in 2 minutes of last 10 minutes
        tags:
            level: Warning
```

</Step>
<Step title="添加 Flashduty 的 webhook 地址并重启">

**操作路径**：Skywalking OAP 服务器 › `./config/alarm-settings.yml` › 文件底部

按 Skywalking 版本选择写法，地址为 `{integration_url}`：

<Tabs>
<Tab title="v8.8.0 ~ v9.5.0">

```yaml
webhooks:
    - url: {integration_url}
```

</Tab>
<Tab title="v10.0.0">

```yaml
hooks:
  webhook:
    default:
      is-default: true
      urls:
        - {integration_url}
```

</Tab>
</Tabs>

保存配置文件，并重启 Skywalking 服务使其生效。

</Step>
<Step title="触发告警并确认">

**操作路径**：Skywalking OAP 服务器 › `./config/alarm-settings.yml`

Skywalking 没有 webhook 测试入口，等待某条已配置规则的 `expression` 命中，即可产生真实告警。

几秒后回到 Flashduty，集成显示 **最新事件时间**，说明配置成功。
{/* console:
接入清单中的「收到第一个事件」同时变为已完成。
*/}

</Step>
</Steps>

## 状态和告警等级

<div className="md-block">
  
| Skywalking | Flashduty |
| --- | --- |
| Critical | Critical |
| Warning | Warning |
| Info | Info |
| 其他或为空 | Info |

Skywalking 不发送恢复通知，Flashduty 不会因此自动恢复告警。


</div>
