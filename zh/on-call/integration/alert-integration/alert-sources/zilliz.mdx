通过 webhook 的方式同步 zilliz 告警事件到 Flashduty On-call。

<div className="hide">

## 在 Flashduty On-call
您可通过以下两种方式获取集成推送地址，任选其一即可。

### 使用专属集成

如果您只需将告警发往一个协作空间，选择此方式，配置更简单。

<AccordionGroup>
  <Accordion title="查看专属集成的配置步骤">
  
  1. 进入 Flashduty 控制台，选择 **协作空间**，打开一个协作空间
  2. 选择 **配置** → **集成数据** → **专属集成**，点击 **新增集成**
  3. 选择 **zilliz** 集成，点击 **保存**，生成卡片。
  4. 打开生成的集成卡片，复制 **推送地址**

    
</Accordion>
</AccordionGroup>

### 使用共享集成

如果您需要根据告警事件的 Payload 将告警路由到不同协作空间，选择此方式。

<AccordionGroup>
  <Accordion title="查看共享集成的配置步骤">
  
  1. 进入 Flashduty 控制台，选择 **集成中心 → 告警事件**
  2. 选择 **zilliz** 集成： 
        - **集成名称**：为当前集成定义一个名称。
  3. 配置默认路由并选择协作空间；创建后可在 **路由** 中增加更多规则
  4. 点击 **保存**，复制生成的 **推送地址**
    
</Accordion>
</AccordionGroup>
</div>

## 在 zilliz 中配置

<Steps>
<Step title="在 Zilliz Cloud 中创建 Alert 并添加 Webhook 渠道">

**操作路径**：Zilliz Cloud 控制台 › Project Alerts › Alert Settings › + Alert（修改已有 Alert 则点击 Actions 列的 Edit）

需要组织所有者（owner）或项目管理员（project admin）权限。

| 字段 | 填写 |
| --- | --- |
| Send to（必填） | 点击 `+ Channel`，选择 `Webhook`，URL 填 `{integration_url}` |
| Alert Resolution Notification（建议选中） | 选中，Zilliz 才会发送恢复通知 |
| Enable Alert（可选） | 其他选项按需选择 |

点击 `Save` 或 `Create` 完成配置。

<img alt="drawing" width="600" src="https://download.flashcat.cloud/flashduty/doc/zh/fd/zilliz-1.png" />

</Step>
<Step title="测试并用真实告警确认">

**操作路径**：Zilliz Cloud 控制台 › Project Alerts › Alert Settings › Alert 编辑页 › Send to

Webhook 渠道旁有 **Send Test Message** 图标，可用于确认推送地址可达；测试消息不一定包含真实告警的全部字段，是否在 Flashduty 产生事件请以实际结果为准，并再用一条真实告警验证触发与恢复。

几秒后回到 Flashduty，集成显示 **最新事件时间**，说明配置成功。
{/* console:
接入清单中的「收到第一个事件」同时变为已完成。
*/}

</Step>
</Steps>

## 状态和告警等级

<div className="md-block">

| zilliz | Flashduty |
| ---------- | -------- |
| CRITICAL | Critical |
| WARNING | Warning |
| 其他或为空 | Info |

当 `status` 为 `NOT_TRIGGERED` 时，Flashduty 将该事件作为恢复（Ok）处理，并关闭对应告警。


</div>
