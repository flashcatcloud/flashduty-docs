在集成中心选择 **Link** 集成，可在故障详情中添加跳转按钮，用故障属性、标签或自定义字段的值拼出外部系统（如 CMDB）的链接，免去手动复制参数。每个协作空间至多绑定三个 Link 集成。

## 打开方式

- **弹窗**：在故障详情页内弹出窗口，查看后可直接返回。
- **新标签页**：在浏览器新标签中打开，保留当前页面。

## 配置 URL

在 URL 中用 <code>{"${}"}</code> 引用变量，引用前缀如下：

| 引用内容 | 写法 | 示例 |
| --- | --- | --- |
| 故障标签 | `labels.` 开头 | <code>{"${labels.sn}"}</code> |
| 自定义字段 | `fields.` 开头 | <code>{"${fields.sn}"}</code> |
| 故障属性 | 直接写属性名 | <code>{"${title}"}</code>、<code>{"${severity}"}</code> |

例如 URL 配置为：

```text
https://cmdb.com/vm?sn=${labels.sn}
```

若故障带有标签 `sn=VM123456`，生成的链接为：

```text
https://cmdb.com/vm?sn=VM123456
```

## 注意事项

- 引用的内容不存在时，仍会生成链接，但该变量没有值。
- 变量须按 <code>{"${...}"}</code> 的语法书写，否则取不到值。
