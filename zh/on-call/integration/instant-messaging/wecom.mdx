## 集成企业自建应用

1. 访问 [企业微信管理后台](https://work.weixin.qq.com/wework_admin/frame#apps)，进入 应用管理 → **应用** 页面，点击 **创建应用**。

   ![企业微信：集成企业自建应用 界面截图](https://docs-cdn.flashcat.cloud/images/png/ed274f6a897b808678a5a29b23adcb66.png)

2. 配置 **应用 Logo**、**应用名称** 和 **应用可见范围**。

   ![企业微信：集成企业自建应用 界面截图](https://docs-cdn.flashcat.cloud/images/png/26ec124891e580a6d1e1035ba52636ba.png)

3. 在 Flashduty 新建企业微信集成，**应用版本** 选择 **企业自建应用（推荐）**，然后在 **应用凭证** 中填写以下信息。

   - **企业 ID（我的企业）**：在企业微信管理后台的 **我的企业** 页面底部获取。
   - **AgentId（应用详情）** 和 **Secret（应用详情）**：在 **应用管理** 中点击刚创建的应用，在应用详情页获取。

   ![企业微信：在我的企业页面获取企业 ID 界面截图](https://docs-cdn.flashcat.cloud/images/png/c032dc755a72550d57658dd5962dafe4.png)

4. 填写 **访问域名**：使用本企业已备案域名下的一个子域名，如 `flashduty.example.com`。只填域名，不带 `https://` 和路径。企业微信要求可信域名和回调地址使用本企业备案主体的域名。

   如果企业微信为私有化部署版本，开启 **是否为私有化版本** 并填写 **Endpoint**。Flashduty 必须能访问该地址，您可以为它配置白名单授权。

5. 点击 **保存**。接收消息和智能机器人使用的 Token、EncodingAESKey 由 Flashduty 生成，无需在此填写。保存后按下一节「在企业微信完成配置」操作。

## 在企业微信完成配置

本节仅适用于企业自建应用。第 1 步在您的 DNS 服务商操作，其余在企业微信管理后台的应用详情页完成，集成详情页的步骤编号与本节一致。第 1–4 步和第 6 步由 Flashduty 检测，完成后自动打勾；第 5 步完成后需手动确认。第 6 步可选。

<Note>
私有化部署的 Flashduty 没有第 1 步，详情页的步骤编号比本文少 1。校验文件需自行放到访问域名根目录（http 和 https 都能直接访问，不能跳转），完成校验后点击 **我已完成校验**；可信 IP 填写贵司 Flashduty 服务器的出口 IP。
</Note>

<span id="step-dns"></span>

### 1. 添加 DNS 记录

在访问域名所在的 DNS 服务商，添加集成详情页第 1 步列出的两条 CNAME 记录。第一条证明域名归您所有，Flashduty 据此签发 HTTPS 证书；第二条把访问转到 Flashduty 的接入地址。您无需自建 Nginx 或反向代理，也无需申请证书。

接入地址按域名的备案情况选择：

| 接入地址 | 位置 | 适用的域名 |
| :--- | :--- | :--- |
| `wecom.flashduty.com`（默认） | 香港 | 任何已备案的域名 |
| `cn.wecom.flashduty.com` | 中国大陆 | 已在阿里云完成接入备案的域名，国内访问更快 |

DNS 服务商支持按地区解析时，两个都配。没有在阿里云完成接入备案的域名指向大陆地址会被阿里云拦截。

两条记录生效、证书签发后，这一步自动打勾。点击 **重新检测** 可立即刷新状态。

<span id="step-trusted-domain"></span>

### 2. 设置可信域名

1. 打开应用详情 › 开发者接口 › **网页授权及JS-SDK**，点击 **设置可信域名**，填写访问域名。
2. 点击 **申请校验域名**，下载 `WW_verify_xxx.txt`，在集成详情页第 2 步点击 **上传校验文件**。Flashduty 会在访问域名的根路径返回该文件。
3. 回到企业微信点击 **确定** 完成校验。同一页的 OAuth2.0 网页授权回调域名也填这个域名。

企业微信读取校验文件后，这一步自动打勾。

<Note>
企业微信要求域名的备案主体与本企业相同或有关联关系（母子公司、总分公司等）。不符时企业微信不允许保存，只能更换域名，或联系企业微信客服提交关联证明。详见企业微信官方文档 [《企业内部开发配置域名指引》](https://open.work.weixin.qq.com/wwopen/common/readDocument/40754)。
</Note>

![企业微信：设置可信域名 界面截图](https://docs-cdn.flashcat.cloud/images/png/09a91d682198d1c8f830b5ed523965ef.png)

### 3. 设置 API 接收消息

1. 打开应用详情 › 接收消息 › **设置 API 接收**。
2. 在集成详情页第 3 步点击 **生成并显示**，把 URL、Token 和 EncodingAESKey 粘贴到企业微信，点击 **保存**。企业微信保存时会立刻访问 URL 做校验。

企业微信校验通过后，这一步自动打勾。

<Warning>
Token 和 EncodingAESKey 只在生成时显示一次，离开页面后无法再查看，请立即复制到企业微信。不要在企业微信里点击 **随机获取**，两边必须使用 Flashduty 生成的同一套值。重新生成后，已保存的那一套立即失效，需要把新值填入企业微信并保存。
</Warning>

企业微信提示「回调地址请求不通过」时，先确认第 1 步已完成，再确认 Token 和 EncodingAESKey 是从集成详情页复制的。

![企业微信：设置 API 接收 界面截图](https://docs-cdn.flashcat.cloud/images/png/c990c27f7ad90af172e159fc4acfead7.png)

### 4. 配置企业可信 IP

在应用详情页底部的 **企业可信IP** 点击 **配置**，填写集成详情页第 4 步显示的 IP。企业微信要求先完成第 2 步或第 3 步，才允许配置可信 IP。

所有使用 Flashduty 的企业都填写这同一个 IP。如果企业微信提示「以下IP属于第三方服务商」，请把报错截图发给 Flashduty 技术支持。Flashduty 能用应用凭证正常调用企业微信接口后，这一步自动打勾。

![企业微信：配置企业可信 IP 界面截图](https://docs-cdn.flashcat.cloud/images/png/fe3b2b788dda5d331148ba0946631b91.png)

### 5. 设置工作台应用主页

在应用详情页的 **工作台应用主页** 点击 **设置**，选择 **网页**，填写集成详情页第 5 步显示的地址。成员在企业微信工作台点开 Flashduty 时会使用这个地址。

企业微信不回传这项配置，完成后在集成详情页点击 **我已设置**。

![企业微信：设置工作台应用主页 界面截图](https://docs-cdn.flashcat.cloud/images/png/595a71dd5624a37312676e83c45d79c4.png)

<span id="step-bot"></span>

### 6. 创建智能机器人

可选。配置后，可在企业微信单聊和群聊中 @ 智能机器人发起 AI SRE 会话。账户需已开通 AI SRE，且集成中的 **允许在 IM 中使用 AI SRE** 已开启（无需开启作战室），否则机器人收到消息后不会响应。

1. 在企业微信客户端进入 **工作台** › **智能机器人**，新建机器人，选择 **手动创建** › **使用 API 模式创建**。建议由企业内部成员创建：其他成员要等创建者分享后才能看到机器人。
2. 在机器人的 API 配置中，连接方式选择 **使用 URL 回调**。在集成详情页第 6 步点击 **生成并显示**，把 URL、Token 和 EncodingAESKey 填入企业微信后保存。企业微信会向该 URL 发起一次校验，Flashduty 自动应答。

企业微信校验通过后，这一步自动打勾。用法和排查方法见下文 [AI SRE 智能机器人](#aisre-bot)。

<Warning>
智能机器人使用**独立的一套** Token 和 EncodingAESKey，与第 3 步接收消息的那一套不同。两套混用会导致签名校验失败。
</Warning>

## 集成第三方应用

<Info>
Flashduty 作为企业微信服务商，为您提供 Flashduty 应用的长期免费版本。该应用需要获得企业微信接口调用许可才能使用（免密登录 + 消息发送）。该许可目前支持 **最多 60 天** 免费，超出该使用时长后，Flashduty 需要为您购买企业微信许可，您方可继续使用。
</Info>

1. 访问 [企业微信管理后台](https://work.weixin.qq.com/wework_admin/frame#apps)，进入 应用管理 → **应用** 页面，点击 **添加第三方应用**。

   ![企业微信：集成第三方应用 界面截图](https://docs-cdn.flashcat.cloud/images/png/ae4d35a354aaf22dd41b7493200517bc.png)

2. 在搜索栏输入 `Flashduty`，检索到应用后，点击 **添加** 按钮。

   ![企业微信：集成第三方应用 界面截图](https://docs-cdn.flashcat.cloud/images/png/77347db478c45f4c9d238d587d323a78.png)

3. 修改应用 **可见范围**，推荐选择全员或具体部门节点，以避免新增企业成员时仍需修改。然后，点击 **同意以上授权并添加** 完成安装。

   ![企业微信：集成第三方应用 界面截图](https://docs-cdn.flashcat.cloud/images/png/0821d1afdeb5db34c4c9b5548d5c8ca1.png)

4. 在 Flashduty 新建企业微信集成，**应用版本** 选择 **第三方应用（扫码）**，**企业绑定方式** 选择 **企业已安装 Flashduty 应用**，点击 **保存**。

5. 请该企业的任一成员用企业微信 App 扫描弹出的二维码，并在打开的页面上确认绑定。确认后集成自动保存。

如果企业还没有安装 Flashduty 应用，也可以跳过第 1–3 步：**企业绑定方式** 选择 **还没有安装 Flashduty 应用**，保存时打开企业微信授权页，由企业管理员扫码安装应用，完成后自动绑定该企业。

## 关联用户

在集成详情页的 **关联用户** 页签中，您可以查看团队成员与企业微信账号的关联状态，并快速完成批量关联。

### 查看关联状态

列表展示所有团队成员及其关联状态，可按 **全部 / 已关联 / 未关联** 筛选，也可按名称或邮箱搜索。

### 一键关联

当存在未关联的成员时，可以点击 **一键关联** 按钮。系统将尝试通过手机号或邮箱换取企业微信开放平台的账号 ID 并自动关联，效果等同于成员使用相同信息在企业微信平台登录 Flashduty。

<Tip>
成员完成关联后，系统才能向其推送企业微信消息通知。如果关联失败，请确认成员的手机号或邮箱是否与企业微信账号一致。
</Tip>

## 配置作战室

<Warning>
作战室功能仅支持在 **企业自建应用** 模式下开启。
</Warning>

完成先前步骤后，在 Flashduty On-call 集成配置页面的 **增强功能** 模块，勾选 **开启作战室** 即可启用该功能，无需额外配置。

<Warning>
同一时间仅支持在一个 IM 集成中开启作战室功能。如果您已在其他 IM 集成（如钉钉、飞书、Slack）中启用了作战室，需要先在该集成中关闭后，才能在当前企业微信集成中开启。
</Warning>

## AI SRE 控制项

以下 AI SRE 控制项在集成配置页面的 **增强功能** 模块中配置，默认开启：

- **允许在 IM 中使用 AI SRE**：无需开启作战室即可配置，同时控制该集成的群聊 @ AI SRE 与机器人私聊两个入口；关闭后对应入口不会触发 AI SRE 回复。

企业微信的两种应用模式对 AI SRE 入口的支持不同。**允许在 IM 中使用 AI SRE** 在两种模式下都会显示，集成详情预览页也会展示其状态：

| 应用模式 | 群聊 @ AI SRE | 机器人私聊 |
| :--- | :--- | :--- |
| **企业自建应用** | 支持 | 支持 |
| **第三方应用** | 不支持，需切换为 **企业自建应用** 模式 | 支持 |

如果账户尚未启用 AI SRE，以上配置暂不生效。

作战室创建后的自动 AI 故障分析不在本页配置：如需在作战室创建时自动发起一次，请在 [自动化](/zh/ai-sre/automations) 中新建一条规则，触发方式选择 **作战室创建触发**，并选好要监听的协作空间与严重程度。

## AI SRE 智能机器人

在企业微信单聊或群聊中 @ 智能机器人，即可发起 AI SRE 排障会话，无需离开企业微信。智能机器人只能在 **企业自建应用** 模式下配置，配置步骤见 [6. 创建智能机器人](#step-bot)。

<Warning>
企业微信暂不支持在创建作战室后自动将智能机器人拉入群聊。要在作战室中使用 AI SRE，需要手动将智能机器人添加到对应群聊。
</Warning>

### 使用方式

配置完成后，在企微单聊或群聊中 **@ 智能机器人**，输入问题或故障描述，即可触发 AI SRE 会话。支持以下消息类型：

| 类型 | 说明 |
| :--- | :--- |
| **文本** | 直接提问或描述问题 |
| **图片** | 发送截图，AI 将解析图片内容进行分析 |
| **文件** | 发送日志或配置文件，AI 将读取内容辅助排查 |
| **引用回复** | 引用上一条消息追问，AI 会结合上下文作答 |

<Note>
企业微信智能机器人采用**拉取式流式响应**（stream polling）：AI 生成回复时，企业微信客户端会定期向回调地址发送 `msgtype=stream` 请求拉取最新内容，直到回复完成。这是企业微信的平台机制，无需额外配置。
</Note>

### 排查问题

<AccordionGroup>

<Accordion title="机器人收到消息后没有任何响应">
请按以下顺序排查：
1. 确认账户已开通 AI SRE，且集成中的 **允许在 IM 中使用 AI SRE** 已开启
2. 确认企业微信中填写的 URL 是从集成详情页第 6 步复制的，其中的 `integration_key` 与集成一致
3. 确认企业微信中填写的 Token 和 EncodingAESKey 是第 6 步生成的那一套，而不是第 3 步接收消息的那一套
4. 在企业微信中查看该机器人的回调记录（如有），确认请求是否到达以及是否有错误码
</Accordion>

<Accordion title="配置回调 URL 时提示「URL 验证失败」">
- 确认 [1. 添加 DNS 记录](#step-dns) 已完成，证书已签发
- 确认企业微信中填写的 Token 和 EncodingAESKey 与第 6 步最近一次生成的值完全一致
- 确认回调 URL 中的 `integration_key` 参数正确，且对应的集成处于启用状态
</Accordion>

<Accordion title="签名验证失败（invalid signature）">
通常是 Token 或 EncodingAESKey 填写有误。智能机器人的凭据与第 3 步接收消息的凭据是**两套独立凭据**。请在集成详情页第 6 步重新生成，并把新值更新到企业微信中该机器人的 API 配置。
</Accordion>

</AccordionGroup>

## 常见问题

<AccordionGroup>
<Accordion title="点击集成保存按钮后，系统报错「authorize app first」？">
- 请检查您是否已完成应用的安装步骤。例如，您是否可以在企业微信工作台中看到 Flashduty On-call 应用
- 请检查 **企业绑定方式** 是否选择正确：企业尚未安装应用时，应选择 **还没有安装 Flashduty 应用**
</Accordion>

<Accordion title="如何完成账户关联或消息发送提示「未关联应用」？">
1. 登录企业微信客户端（桌面端和移动端均可），进入 **工作台**，找到并打开 Flashduty 应用
2. 首次进入应用需要登录。选择您的成员账号，通过密码或单点登录方式登入成功后，即可完成 Flashduty 账号与企业微信账号的关联
3. 后续进入应用将自动免密登录
</Accordion>

<Accordion title="如何发送故障通知？">
1. 发送通知前，必须参照上一问题完成账户关联
2. 进入指定协作空间，导航至 `分派策略` → **个人渠道**，选择 `企业微信` 作为通知方式即可
3. Flashduty On-call 支持对企业微信通知内容进行自定义。您可以前往 **模板管理** 页面，设定自定义模板

<Note>
自定义区域最多可展示 8 行，超出部分将被企业微信截断。
</Note>

![企业微信：如何发送故障通知？ 界面截图](https://docs-cdn.flashcat.cloud/images/png/9cb6a325b4b16875fec3e0c5054be25b.png)
</Accordion>

<Accordion title="如何在企业微信内处理告警？">
- 点击卡片消息，可直接进入告警详情页面
- 点击 **开始处理**，可直接将告警置为 `处理中` 状态
- 点击 **直接关闭**，可直接将告警置为 `已关闭` 状态
- 点击 **屏蔽 2 小时**，可直接将告警屏蔽 2 小时。如果想屏蔽更长时间，可点击卡片右上角的 `...` 查看更多屏蔽选项
</Accordion>

<Accordion title="为什么卡片消息提供了「状态刷新」按钮？">
根据企业微信的限制，一次卡片交互后，72 小时内只可更新一次。每一次按钮操作，都视为一次交互。

当告警状态发生变化时，Flashduty On-call 会请求更新卡片内容。当告警状态频繁变化时，可能因超出更新次数限制导致卡片无法实时更新。此时，您可以点击 **刷新** 按钮，手动获取一次更新卡片状态的机会。
</Accordion>

<Accordion title="Mac 桌面端如何设置使用系统默认浏览器打开？">
