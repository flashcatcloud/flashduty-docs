## 所需权限

飞书应用的权限分三组，与集成详情页第 1 步的分组一致：

- **基础（必需）**：告警通知、卡片按钮、关联成员、作战室，共 6 项。
- **作战室复盘导入群聊记录时需要**：共 1 项。
- **在飞书里使用 AI SRE 时需要**：共 8 项，其中 `im:message.group_msg` 与上一组共用。

三组合计 14 项。扫码接入的应用由 Flashduty 自动申请；手动接入的应用按下文 [1. 开通权限](#step-permissions) 批量导入。

| 分组 | 官方权限名称 | 用途 |
| :--- | :--- | :--- |
| 基础 | `im:message` | 读取和发送单聊、群组消息 |
| 基础 | `im:message:send_as_bot` | 以机器人身份发送告警通知、作战室消息和 AI SRE 回复 |
| 基础 | `im:message:update` | 更新应用已发送的消息 |
| 基础 | `im:chat` | 创建和管理作战室群、获取群信息、添加群成员 |
| 基础 | `im:resource` | 上传和下载消息中的图片、文件等资源 |
| 基础 | `contact:user.id:readonly` | 通过手机号或邮箱获取用户 ID，用于关联成员和邀请成员进入作战室 |
| 作战室复盘、AI SRE | `im:message.group_msg` | 读取群聊历史消息，用于作战室复盘导入群聊记录和 AI SRE 读取群聊上下文 |
| AI SRE | `im:message.p2p_msg:readonly` | 接收用户发给机器人的单聊消息；缺少该权限时，AI SRE 收不到单聊提问 |
| AI SRE | `im:message.group_at_msg:readonly` | 接收群聊中 @ 机器人的消息；缺少该权限时，AI SRE 收不到群聊提问 |
| AI SRE | `im:message.reactions:read` | 查询消息表情反应，用于标记 AI SRE 处理状态 |
| AI SRE | `im:message.reactions:write_only` | 添加或删除消息表情反应，用于标记 AI SRE 处理状态 |
| AI SRE | `cardkit:card:write` | 创建和更新 CardKit 卡片，用于 AI SRE 流式回复 |
| AI SRE | `contact:contact.base:readonly` | 获取通讯录基本信息，用于显示发送者名称 |
| AI SRE | `contact:user.base:readonly` | 获取用户基础信息，用于显示发送者名称 |

## 创建飞书应用

在 Flashduty 新建飞书集成时，**飞书应用授权** 提供以下接入方式。扫码接入的应用由 Flashduty 自动管理，您无需打开飞书开发者后台。Lark 和飞书私有化部署只能手动填写凭证；私有化部署的 Flashduty 同样只支持手动填写凭证。

### 方式一：扫码创建新应用（推荐）

1. 在 Flashduty 新建飞书集成，**飞书应用授权** 默认选中 **创建新应用（推荐）**。
2. 点击 **保存**，用飞书扫描弹出的二维码，在飞书确认页点击 **创建**。确认之前 Flashduty 不保存任何记录。
3. 等待飞书管理员审批两次：先审核应用；通过后 Flashduty 自动完成配置，再审核配置版本。集成详情页显示当前是第几次审批，提供 **去飞书管理后台审核** 和 **复制消息给管理员** 两个按钮，并每 10 秒自动检查一次审核结果。

<Tip>
如果您是飞书企业管理员，请用管理员账号扫码，两次审核都可以马上自己完成。
</Tip>

两次审批都通过后，集成即可使用。Flashduty 已配置好事件推送、卡片回调和登录重定向，并把可用范围设为全部成员，无需再做下文「在飞书完成配置」的 5 步。

Flashduty 按已开启的增强功能申请[所需权限](#aisre-permissions)中对应的分组，另外申请 `application:application:self_manage` 和 `application:application:patch`，用于自行更新应用配置和发布新版本。之后开启作战室或 AI SRE 需要新权限时，集成详情页会提示 **已开启的功能需要追加 N 项飞书权限**。点击 **提交给飞书管理员审核** 后，Flashduty 自动加上权限并发布新版本，管理员审核通过后生效，无需重新扫码。

### 方式二：扫码授权已有应用

1. 在 Flashduty 新建飞书集成，**飞书应用授权** 选择 **使用已有应用**，填写该应用的 **App ID**。
2. 点击 **保存**，用应用所有者或协作者的飞书账号扫码，授权 Flashduty 管理这个应用。

授权后，该应用同样由 Flashduty 自动管理，状态和待审批事项显示在集成详情页。

### 方式三：手动填写凭证

1. 访问 [飞书开发者后台](https://open.feishu.cn/app)，创建企业自建应用。Lark 的开发者后台为 [open.larksuite.com](https://open.larksuite.com)。应用图标可使用 [Flashduty 官方 icon](https://flashduty-public.oss-cn-beijing.aliyuncs.com/icons/flashduty-20251216.png)，详见飞书开发文档 [创建企业自建应用](https://open.feishu.cn/document/uYjL24iN/uMTMuMTMuMTM/development-guide/step1#132c1aac)。

   ![飞书/Lark：创建自建应用 界面截图](https://docs-cdn.flashcat.cloud/images/png/d456a3be638252127dde907617d63fb7.png)

2. 前往 **凭证与基础信息** 页面，复制 `App ID` 和 `App Secret`。

   ![飞书/Lark：复制凭证信息 界面截图](https://docs-cdn.flashcat.cloud/images/png/69f98fad9e5a076aac5f9b0058ebd8dc.png)

3. 前往 开发配置 → 事件与回调 → **加密策略** 页面，复制 `Verification Token`。推荐同时设置并复制 `Encrypt Key`。

   ![飞书/Lark：复制事件回调的 Token 信息 界面截图](https://docs-cdn.flashcat.cloud/images/png/ac558d48464310fe27ef97912b298df1.png)

4. 在 Flashduty 新建飞书集成，在 **飞书应用授权** 中点击 **改为手动填写凭证**，填入 **App ID**、**App Secret**、**Verification Token** 和 **Encrypt Key**（飞书里没有设置就留空），点击 **保存**。保存时 Flashduty 会用 App ID 和 App Secret 向飞书换一次访问凭证，填错会直接提示。

   - 使用 Lark 时，开启 **是否为 Lark 版本**。
   - 使用飞书私有化部署时，开启 **是否为私有化版本** 并填写 **Endpoint**。Flashduty 必须能访问该地址。

保存后，按下一节「在飞书完成配置」的 5 步操作；集成详情页的步骤编号与本节一致。

### 升级为自动管理

手动接入的飞书集成可以改由 Flashduty 管理（Lark、飞书私有化部署和私有化部署的 Flashduty 除外）。在集成详情页点击 **升级为自动管理**，用应用所有者或协作者的飞书账号扫码授权。升级后不用再做下一节的 5 步，新功能需要的权限会自动提交给飞书管理员审核。App Secret 和推送地址不变，告警通知不中断。

## 在飞书完成配置

手动填写凭证接入后，在飞书开发者后台完成以下 5 步，每步对应一个页面。第 1 步和第 3 步由 Flashduty 检测，完成后自动打勾；其余 3 步完成后，在集成详情页点击对应按钮确认。

<span id="step-permissions"></span>

### 1. 开通权限

1. 在集成详情页第 1 步点击 **复制权限清单（14 项）**。
2. 打开 **权限管理**，点击 **批量处理 › 批量导入/导出权限**，粘贴权限清单，点击 **下一步，确认新增权限** 后确认开通。
3. 回到集成详情页，点击 **重新检测**。

基础 6 项都开通后，这一步自动打勾；另外两组按需开通，不影响打勾。权限要在第 5 步发布后才生效。

![飞书/Lark：申请应用权限 界面截图](https://docs-cdn.flashcat.cloud/images/png/d919be62107f6b9d0c662f440d620e61.png)

### 2. 添加网页应用和机器人

1. 打开 **添加应用能力**，按能力添加 **网页应用** 和 **机器人**。

   ![飞书/Lark：开通并配置应用能力 界面截图](https://docs-cdn.flashcat.cloud/images/png/5ab84aec1593c7118782765676a51c6a.png)

2. 进入 **网页应用**，**桌面端主页** 和 **移动端主页** 都填集成详情页第 2 步显示的地址。详见飞书开发文档 [配置应用主页地址](https://open.feishu.cn/document/uYjL24iN/uMTMuMTMuMTM/development-guide/step1#8366b844)。

   ![飞书/Lark：配置网页应用主页 界面截图](https://docs-cdn.flashcat.cloud/images/png/d91efc598bda17e1bfcb367aec47c779.png)

3. 应用图标可使用 [Flashduty 官方 icon](https://flashduty-public.oss-cn-beijing.aliyuncs.com/icons/flashduty-20251216.png)，在 **凭证与基础信息** 上传。

飞书不回传应用能力，完成后在集成详情页点击 **我已添加**。

### 3. 配置事件与回调

事件和回调使用同一个请求地址，即集成详情页第 3 步显示的地址。飞书保存时会立刻访问这个地址做校验。

1. 打开 **事件与回调**，在 **事件配置** 页将订阅方式设为 **将事件发送至开发者服务器**，粘贴请求地址并保存，再添加事件 `im.message.receive_v1`。
2. 切到 **回调配置** 页，同样粘贴请求地址并保存，再添加回调 `card.action.trigger`。

飞书校验通过请求地址后，这一步自动打勾。

<Note>
飞书提示「请求地址校验失败」时，多半是新建集成时填写的 Verification Token 或 Encrypt Key 与飞书 **加密策略** 页不一致。在集成编辑页改成一致，再回到飞书保存。
</Note>

### 4. 配置重定向 URL

打开 **安全设置**，在 **重定向URL** 添加集成详情页第 4 步显示的两条地址（网页端和移动端）。配置后，从飞书消息里打开 Flashduty 时免登录。详见飞书开发文档 [配置重定向 URL](https://open.feishu.cn/document/uYjL24iN/uYjN3QjL2YzN04iN2cDN?lang=zh-CN#c863e533)。

飞书不回传这项配置，完成后在集成详情页点击 **我已添加**。

![飞书/Lark：添加重定向 URL 到飞书应用 界面截图](https://docs-cdn.flashcat.cloud/images/png/00a7cdd10c09c90c2d7b2f0a99ee4d8d.png)

<span id="publish"></span>

### 5. 调整可见范围并发布

打开 **版本管理与发布**，创建版本，可用范围选择 **全部员工**，提交发布，企业管理员审核通过后生效。发布前只有您能使用该应用，第 1–4 步的改动也要发布后才生效；之后再改权限、事件或回调，需要再发一个版本。详见飞书开发文档 [应用发布与使用](https://open.feishu.cn/document/uYjL24iN/uMTMuMTMuMTM/development-guide/step-4)。

完成后在集成详情页点击 **我已发布**。

![飞书/Lark：应用发布与使用 界面截图](https://docs-cdn.flashcat.cloud/images/png/6bbc285986808af14c29d0eb633a2bf7.png)

应用发布后，即可通过 **手机端** 或 **PC 端** 访问应用，入口相同：飞书 → 工作台 → 搜索应用名称 → **打开应用**。首次访问需要登录并关联飞书与 Flashduty 账号，后续可以免登录使用。

![飞书/Lark：PC 端 界面截图](https://docs-cdn.flashcat.cloud/images/png/eed8557808874a0c488b958c4049ea72.png)

## 配置作战室

完成先前步骤后，在 Flashduty On-call 集成配置页面的 **增强功能** 模块，勾选 **开启作战室** 即可启用该功能，无需额外配置。

<Warning>
同一时间仅支持在一个 IM 集成中开启作战室功能。如果您已在其他 IM 集成（如钉钉、Slack、企业微信）中启用了作战室，需要先在该集成中关闭后，才能在当前飞书集成中开启。
</Warning>

## AI SRE 控制项

在 **增强功能** 中分别配置以下 AI SRE 控制项，默认均为开启：

- **允许在 IM 中使用 AI SRE**：无需开启作战室即可配置。开启后，可在该集成接入的群聊中 @ AI SRE，或在机器人私聊中直接发起对话；关闭后这两个入口都不会触发 AI SRE 回复。
- **普通群聊中 AI SRE 使用话题回复**：无需开启作战室即可配置。开启后，普通群聊中的每个话题对应一个独立 Session；作战室仍直接在群内回复。

如果账户尚未启用 AI SRE，以上配置暂不生效。

作战室创建后的自动 AI 故障分析不在本页配置：如需在作战室创建时自动发起一次，请在 [自动化](/zh/ai-sre/automations) 中新建一条规则，触发方式选择 **作战室创建触发**，并选好要监听的协作空间与严重程度。

## 关联用户

在集成详情页的 **关联用户** 页签中，您可以查看团队成员与飞书账号的关联状态，并快速完成批量关联。

### 查看关联状态

列表展示所有团队成员及其关联状态，可按 **全部 / 已关联 / 未关联** 筛选，也可按名称或邮箱搜索。

### 一键关联

当存在未关联的成员时，可以点击 **一键关联** 按钮。系统将尝试通过手机号或邮箱换取飞书开放平台的账号 ID 并自动关联，效果等同于成员使用相同信息在飞书平台登录 Flashduty。

<Tip>
成员完成关联后，系统才能向其推送飞书消息通知。如果关联失败，请确认成员的手机号或邮箱是否与飞书账号一致。
</Tip>

## 常见问题

<AccordionGroup>
<Accordion title="消息无法投递到个人，操作记录提示「未关联应用」？">
前往 飞书 → 工作台 → 搜索应用名称 → **打开应用**，完成一次登录以关联飞书与 Flashduty 账号，系统才能获取用户身份进行消息推送。
</Accordion>

<Accordion title="消息卡片按钮点击无效或报错？">
- 确保账户已经完成关联。您可以前往 飞书 → 工作台 → 搜索应用名称 → **打开应用**，完成一次登录。如果已经登录过，请尝试点击右上角菜单，切换账户后重新登录以绑定账号
- 确保已购买足够的 License。已使用 License 情况，可以在 控制台 → **费用中心** 查看
</Accordion>

<Accordion title="分派策略飞书群聊列表为空？">
- 前往飞书，在指定群聊会话中添加已创建的 Flashduty 机器人
- 回到分派策略配置页面，刷新后重新选择群聊列表

![飞书/Lark：分派策略飞书群聊列表为空？ 界面截图](https://docs-cdn.flashcat.cloud/images/png/0e21e9e689855d9a636fb94848f58c13.png)
</Accordion>

<Accordion title="飞书自建应用 API 限制？">
**调用量限制：**

| **飞书版本** | **调用总量/月** | **刷新时间** |
| :---: | :---: | :---: |
| 基础免费版 | 10,000 次 | 每月 1 日 |
| 其他版本 | 不限制 | - |

**频控限制：**

| **场景** | **限制** |
| :---: | :--- |
| 所有接口 | 每个应用最高频率 50 次/秒 |
| 发消息接口 | 每个应用最高频率 1000 次/分钟 |
| 群机器人 Webhook | 最高频率 100 次/分钟 |
| 给同一个用户或同一个群发消息 | 最高频率 5 次/秒 |
   
<Warning>
超出 API 调用量限制后，飞书应用将无法正常推送消息，建议合理使用通知渠道。详见 [飞书官方文档](https://open.feishu.cn/document/uAjLw4CM/ugTN1YjL4UTN24CO1UjN/platform-updates-/custom-app-api-call-limit)。
</Warning>
