## 概览与架构对比

Flashduty 提供两种相互独立的 Zoom 接入方式：**Zoom Team Chat 应用**（通道标识 `zoom_app`，本页介绍）与传统的 **Zoom Incoming Webhook 机器人**（通道标识 `zoom`，详见 [通知渠道](/zh/on-call/configuration/notifications)）。已有 Webhook 机器人配置不受影响，您可以按需并存或平滑迁移至 Zoom Team Chat 应用。

| 能力维度 | Zoom Team Chat 应用 (`zoom_app`) | Zoom Webhook 机器人 (`zoom`) |
| :--- | :--- | :--- |
| **接入与鉴权机制** | OAuth 2.0 组织级应用授权，自动轮换并持久化刷新令牌 | 单频道 Incoming Webhook 地址与 Verify Token，绑定创建者个人账号 |
| **故障消息形态** | 可交互 Zoom App Card，支持就地认领、解决、暂缓、自定义操作并实时刷新状态 | 单向纯文本推送，不支持卡片按钮交互 |
| **个人 1:1 私聊通知** | 支持，成员可在个人通知偏好中勾选接收私聊卡片 | 不支持 |
| **值班交接班提醒** | 支持群聊频道通知与个人私聊提醒 | 仅支持群聊通知 |
| **成员身份识别** | 按企业邮箱自动匹配 Flashduty 成员，无需维护映射表 | 需手动收集 `zoom_jid` 并在配置中心维护映射表 |
| **自动故障作战室** | 支持一键或自动创建私密 Zoom 频道（Private Channel）并拉入响应人 | 不支持 |
| **对话式 AI SRE** | 支持频道 `@Flashduty`、机器人 1:1 私聊、`/fd` 斜杠命令、话题隔离与主动接话 | 不支持 |

<Note>
如果您仅需要单向群聊文本推送，仍可在分派策略中配置旧版 [通知渠道](/zh/on-call/configuration/notifications) 中的 Zoom 机器人；若需要双向故障卡片交互、个人私聊通知、自动私密作战室或 AI SRE 协同排障，请使用本页的 **Zoom Team Chat 应用**。
</Note>

## 安装与一键授权（SaaS）

<Steps>
<Step title="添加集成">
访问 Flashduty 控制台 **集成中心 → 即时消息 → Zoom**，点击 **添加**。
</Step>

<Step title="完成 Zoom OAuth 授权">
点击页面上的 **获取 Zoom 授权**，浏览器将跳转至 Zoom 官方授权页。使用具备 Team Chat 应用安装权限的 Zoom 账号登录并点击 **Allow** 完成授权，页面会自动携授权码回跳至 Flashduty。
</Step>

<Step title="确认配置并保存">
填写 **集成名称** 与 **管理团队**，按需确认 **增强功能** 中的作战室与 AI SRE 开关，点击 **保存** 完成接入。
</Step>
</Steps>

### 成员关联说明

Zoom Team Chat 集成不提供手动 **关联用户** 页签，也无需维护 `zoom_jid` 映射表。Flashduty 通过企业**邮箱**（忽略大小写）自动关联成员：

- 发送个人 1:1 私聊告警或邀请成员加入作战室时，系统使用 Flashduty 成员邮箱查询同组织下的 Zoom 用户。
- 成员在 Zoom 中点击告警卡片按钮或向 AI SRE 提问时，系统读取操作者的 Zoom 邮箱并与当前账户成员比对。请确保成员的 Zoom 账号邮箱与 Flashduty 登录邮箱一致；若未匹配到成员，系统会在 Zoom 中提示邮箱未关联。

## 权限分级说明

Flashduty 遵循最小权限原则，将 Zoom OAuth 权限拆分为**默认必需权限**与**按需增量权限**两档。

### 默认必需权限（Required Scopes）

首次点击 **获取 Zoom 授权** 安装应用时，Flashduty 仅申请以下基础与协作权限：

| 官方 scope 名称 | 用途 |
| :--- | :--- |
| `imchat:bot` | 注册 Team Chat 机器人收发能力，接收 `@` 提及与 `/fd` 斜杠命令 |
| `team_chat:write:user_message` | 向频道与个人私聊发送故障卡片、值班提醒、作战室通知和 AI SRE 回复 |
| `team_chat:update:user_message` | 就地更新故障卡片处理状态，以及流式刷新 AI SRE 排查进展 |
| `team_chat:read:list_user_channels` | 读取应用可见的 Zoom 频道列表，供分派策略和值班表下拉选择 |
| `team_chat:write:user_channel` | 为故障自动创建专属私密作战室频道 |
| `team_chat:write:members` | 按成员邮箱批量邀请故障响应人员加入作战室频道 |
| `team_chat:read:files` | 下载会话中附带的报错截图与日志文件（单文件上限 25 MB，仅允许受信任 Zoom 域名）供 AI SRE 分析 |
| `user:read:user` | 读取组织内 Zoom 用户基础信息与邮箱，用于自动成员匹配 |

### 主动接话可选权限（Optional Scopes）

以下两项频道消息读取权限属于敏感权限，**不包含在默认安装请求中**，仅在您需要开启 **允许 AI 主动接话** 时按需增量授权：

| 官方 scope 名称 | 用途 |
| :--- | :--- |
| `team_chat:read:user_message` | 接收频道内未 `@` 机器人的普通消息事件，用于上下文缓冲与主动接话判断 |
| `team_chat:read:list_messages` | 读取频道与话题历史消息，用于补充 AI SRE 排障上下文及生成故障复盘摘要 |

<Warning>
当控制台通过权限校验检测到当前集成尚未授予 `team_chat:read:user_message` 或 `team_chat:read:list_messages` 时，**允许 AI 主动接话** 开关会自动锁定为关闭状态，并在下方展示缺失权限提示。点击 **增量授权开启旁听** 即可跳转至 Zoom 补全上述两项可选权限，原有集成配置与频道规则保持不变。
</Warning>

## 告警通知与自动私密作战室

### 频道可交互告警卡片

先在目标 Zoom 频道（尤其是私密频道）中将 Flashduty 应用添加至频道成员，随后前往 **协作空间 → 分派策略**，在群聊通知方式中选择 **Zoom 应用**，选定集成实例与目标频道并保存。

故障触发后，Flashduty 会向频道推送交互式 App Card：

- **快捷响应操作**：支持直接在卡片上执行 **认领**、**解决**、**暂缓**、**拉起作战室** 及预设的**自定义操作**，操作完成后卡片状态就地刷新。
- **自定义通知模板**：支持在 [通知模板](/zh/on-call/configuration/templates) 中定制 `Zoom` 应用渠道模板（Go `text/template` 语法，单条卡片上限 15,000 字节）。

### 个人私聊通知与值班提醒

- **个人 1:1 故障通知**：成员进入 **个人设置 → 通知偏好**，在故障通知渠道中勾选已启用的 Zoom 应用，即可通过 Zoom 1:1 私聊接收分派给自己的交互式故障卡片。
- **值班交接班提醒**：在 [值班管理](/zh/on-call/configuration/schedule) 的值班通知设置中，支持选择 **Zoom 应用** 向指定频道广播排班动态，同时支持向当班成员发送个人私聊提醒。

### 自动私密作战室与 AI 根因分析

在 Zoom 集成的 **增强功能** 区域，默认开启 **开启作战室** 与 **自动发起 AI 故障分析**：

- **私密频道隔离**：从故障详情页、告警卡片或分派策略拉起作战室时，Flashduty 默认创建 **私密 Zoom 频道（Private Channel）**，按邮箱自动分批拉入故障处理人，并发送置顶故障摘要卡片。
- **自动根因分析**：当 **自动发起 AI 故障分析** 开启且命中账户内的作战室创建触发规则时，AI SRE 会在作战室建群后立即结合故障详情、时间线与近期变更输出首轮根因诊断。更多规则说明见 [作战室](/zh/on-call/advanced/war-room)。

## 对话式 AI SRE

在集成中开启 **允许在 IM 中使用 AI SRE**（默认开启）后，团队成员可在 Zoom Team Chat 内直接协同排障。通用会话机制见 [IM 平台](/zh/ai-sre/im)。

### 交互入口与流式回执

- **频道 `@Flashduty` 提问**：在已接入的频道中提及 `@Flashduty` 并输入问题；若需带上频道内更早的报错文本或截图，可回复该消息后再 `@Flashduty`。
- **机器人 1:1 私聊**：在 Zoom Team Chat 中直接打开与 Flashduty 应用的私聊窗口提问，适合个人独立排查。
- **流式卡片更新与宽表产物**：由于 Zoom Team Chat 机器人接口不提供消息表情回执，AI SRE 收到请求后会立即发送一条「思考中」占位卡片，并按节流间隔就地更新分析进展与最终结论。当输出包含超过 4 列的宽表格或长篇分析报告时，卡片会附带可点击的产物查看链接。

### `/fd` 斜杠命令

在 Zoom 频道或机器人私聊中可使用 `/fd` 命令管理 AI SRE 会话：

| 命令 | 说明 |
| :--- | :--- |
| `/fd <问题>` | 向 AI SRE 发起新提问或在当前会话中继续追问 |
| `/fd new [消息]` | 重置当前会话上下文并开启全新对话；若附带消息则直接以该消息开始排查 |
| `/fd env [环境名]` | 查看可用运行环境、切换至指定 Runner 或沙箱环境，或传入 `/fd env clear` 恢复默认环境 |
| `/fd scope [团队名]` | 查看当前会话绑定的团队与协作空间范围、切换目标团队，或传入 `/fd scope clear` 恢复默认范围 |
| `/fd help` | 查看支持的 `/fd` 子命令与用法提示 |

此外，在开启主动接话的群聊中，您还可以发送 `/ambient on`、`/ambient off`、`/ambient inherit` 或 `/ambient status` 单独控制当前频道的主动接话行为。

### 话题回复隔离与主动接话

- **普通群聊中 AI-SRE 使用话题回复**（默认开启）：开启后，AI SRE 通过 Zoom 的 `reply_main_message_id` 在原消息所属话题（Thread）内回复，每个话题绑定独立的排查 Session（`group_thread`），互不串扰；关闭后则在频道主消息流中回复并共用频道级 Session（`group_chat`）。作战室频道始终直接在群内回复。
- **允许 AI 主动接话**（默认关闭）：完成[主动接话可选权限](#ambient-scopes)增量授权并开启开关后，系统在频道内维护最近 30 条消息（24 小时过期）的滑动上下文缓冲，仅当判定某条未 `@` 消息需要介入排障时才主动回复。

## 私有化部署（自建 Zoom 应用）

如果您使用私有化部署版 Flashduty，请在企业自己的 Zoom 组织下创建内部应用并配置服务端参数。以下示例使用占位域名 `console.example.com` 与 `api.example.com`，部署时请替换为您的实际访问域名。

### 1. 在 Zoom App Marketplace 创建应用

登录 [Zoom App Marketplace](https://marketplace.zoom.us/)，创建一个内部 **General App**（勾选 **Team Chat** 机器人与交互式卡片能力），记录应用的 `Client ID`、`Client Secret`、Webhook `Secret Token` 以及 Team Chat 机器人的 `Bot JID`。

### 2. 配置回调地址与白名单

在 Zoom 应用后台填写以下地址：

- **OAuth Redirect URL**：`https://console.example.com/settings/source/im/add/zoom_app`（同时将该域名加入 **OAuth Allow List**）
- **Bot Endpoint URL**：`https://api.example.com/event/push/zoom_app/data`
- **Event Notification Endpoint URL**：`https://api.example.com/event/push/zoom_app/data`

Flashduty 事件引擎会自动校验 `x-zm-signature` 请求签名与 5 分钟时间戳窗口，并自动响应 Zoom 的 `endpoint.url_validation` 地址校验请求。

### 3. 配置事件订阅与 OAuth Scopes

在 Zoom 应用的 **Event Subscriptions** 中订阅以下事件：

- **必选事件**：`bot_notification`、`team_chat.app_mention`、`interactive_message_actions`、`app_deauthorized`
- **可选事件**（仅开启「允许 AI 主动接话」时订阅）：`chat_message.sent`、`chat_message.replied`

随后在 **Scopes** 页面添加[权限分级说明](#aisre-permissions)中列出的默认必需权限（以及按需添加的两项可选权限）。

### 4. 配置 Flashduty 服务端与前端

在 `fc-datasource` 与 `fc-event` 的配置文件（`etc/*.yaml`）的 `deploy` 段中填入自建应用参数（切勿将真实密钥提交至代码仓库）：

```yaml
deploy:
  zoomClientID: "<YOUR_ZOOM_CLIENT_ID>"
  zoomClientSecret: "<YOUR_ZOOM_CLIENT_SECRET>"
  zoomSecretToken: "<YOUR_ZOOM_SECRET_TOKEN>"
  zoomBotJID: "<YOUR_ZOOM_BOT_JID>"
  zoomRedirectURI: "https://console.example.com/settings/source/im/add/zoom_app"
```

服务端同样支持通过环境变量 `ZOOM_CLIENT_ID`、`ZOOM_CLIENT_SECRET`、`ZOOM_SECRET_TOKEN`、`ZOOM_BOT_JID`、`ZOOM_REDIRECT_URI` 注入上述配置。在前端控制台侧，配置构建环境变量 `VITE_ZOOM_CLIENT_ID`（或运行时配置 `zoomClientId`；若使用自定义 Zoom OAuth 网关，可同时配置 `VITE_ZOOM_OAUTH_URL` 或 `VITE_ZOOM_INSTALL_URL`），重启服务后即可按 SaaS 相同流程完成一键授权。

## 常见问题

<AccordionGroup>
<Accordion title="分派策略或值班表的频道下拉列表中找不到目标 Zoom 频道？">
- 确认 Zoom 集成已完成 OAuth 授权且状态为启用
- 若目标频道为私密频道（Private Channel），请先在 Zoom 客户端打开该频道，将 Flashduty 应用添加为频道成员；公开频道也建议先将应用或授权人加入频道
- 返回 Flashduty 分派策略或值班表配置页，点击频道选择框右侧的刷新按钮重新拉取频道列表（服务端频道列表默认缓存 5 分钟，手动刷新会立即更新）
</Accordion>

<Accordion title="点击 Zoom 故障卡片按钮时提示未匹配到成员？">
Zoom Team Chat 集成通过成员邮箱识别操作人。请核对您在 Zoom 客户端登录账号的邮箱是否与 Flashduty **成员管理** 中的邮箱一致（大小写不敏感）；修改一致后即可直接操作卡片，无需手动绑定。
</Accordion>

<Accordion title="为什么「允许 AI 主动接话」开关处于禁用状态？">
为了最小化默认授权范围，初始安装时不会请求读取频道普通消息的权限（`team_chat:read:user_message` 与 `team_chat:read:list_messages`）。如需使用主动接话，请点击开关下方的 **增量授权开启旁听** 链接并在 Zoom 授权页同意补充权限，返回控制台后即可开启该开关。
</Accordion>

<Accordion title="开启作战室时有哪些注意事项？">
- 同一账户下同一时间只能有一个 IM 集成开启作战室；若其他 IM 集成已启用作战室，请先在对应集成中关闭，详见 [作战室](/zh/on-call/advanced/war-room)
- 如果系统检测到当前授权缺少创建频道或拉人等必需权限，集成配置页会展示缺失的 scope 清单并提供 **重新授权** 入口，点击完成重新授权即可恢复
</Accordion>
</AccordionGroup>
