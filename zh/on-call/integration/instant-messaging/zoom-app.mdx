## 概览与架构对比

Flashduty 提供两种相互独立的 Zoom 接入方式：**Zoom Team Chat 应用**（通道标识 `zoom_app`，本页介绍）与传统的 **Zoom Incoming Webhook 机器人**（通道标识 `zoom`，详见 [通知渠道](/zh/on-call/configuration/notifications)）。已有 Webhook 机器人配置不受影响，您可以按需并存或平滑迁移。

Zoom Team Chat 应用采用**企业自建 General App + Manifest 清单一键导入 + 自动代托管**模式，同时支持 **Zoom 国际版（`zoom.us`）** 与 **Zoom 中国大陆专区（`zoom.com.cn`）**，企业内部应用无需提交公共应用市场审核即可立即生效。

| 能力维度 | Zoom Team Chat 应用 (`zoom_app`) | Zoom Webhook 机器人 (`zoom`) |
| :--- | :--- | :--- |
| **接入与运维方式** | 导入 `flashduty-zoom-manifest.json` 一键创建企业自建应用，首次 OAuth 后由 Flashduty 自动代托管配置与权限升级 | 单频道 Incoming Webhook 地址与 Verify Token，绑定创建者个人账号 |
| **多区域支持** | 原生支持国际版 `zoom.us`、中国大陆专区 `zoom.com.cn` 及自定义网关 | 依赖单频道 Webhook 地址 |
| **故障消息形态** | 可交互 Zoom App Card，支持就地认领、解决、暂缓、自定义操作并实时刷新状态 | 单向纯文本推送，不支持卡片按钮交互 |
| **个人 1:1 私聊通知** | 支持，成员可在个人通知偏好中勾选接收私聊卡片 | 不支持 |
| **值班交接班提醒** | 支持群聊频道通知与个人私聊提醒 | 仅支持群聊通知 |
| **成员身份识别** | 按企业邮箱自动匹配 Flashduty 成员，无需维护映射表 | 需手动收集 `zoom_jid` 并在配置中心维护映射表 |
| **自动故障作战室** | 支持一键或自动创建私密 Zoom 频道（Private Channel）并拉入响应人 | 不支持 |
| **对话式 AI SRE** | 支持频道 `@Flashduty`、机器人 1:1 私聊、`/fd` 斜杠命令、话题隔离与主动接话 | 不支持 |

<Note>
如果您仅需要单向群聊文本推送，仍可在分派策略中配置 [通知渠道](/zh/on-call/configuration/notifications) 中的 Zoom 机器人；若需要双向故障卡片交互、个人私聊通知、自动私密作战室或 AI SRE 协同排障，请使用本页的 **Zoom Team Chat 应用**。
</Note>

## 三步接入：Manifest 一键导入与自动代托管

新建 Zoom 集成时，系统会自动预生成专属 `integration_key` 并为您生成可直接导入的 Zoom App Manifest 文件，无需在 Zoom 开发者后台逐项填写回调地址、斜杠命令或事件订阅。

<Steps>
<Step title="选择区域并一键导入 Manifest 创建应用">
访问 Flashduty 控制台 **集成中心 → 即时消息 → Zoom**，点击 **添加**：

1. 在 **步骤 1** 选择您的 Zoom 账号所属区域：**Zoom 国际版 (`zoom.us`)**、**Zoom 中国大陆专区 (`zoom.com.cn`)** 或 **自定义端点**。
2. 点击 **下载专属配置清单 (`flashduty-zoom-manifest.json`)**（或点击 **复制配置清单 JSON**）。
3. 点击页面上的 **打开 Zoom App Marketplace**（国际版进入 `marketplace.zoom.us`，中国大陆专区进入 `marketplace.zoom.com.cn`），依次选择 **Develop → Build App → Build from an app manifest**，上传刚才下载的 `flashduty-zoom-manifest.json` 确认创建企业内部 General App。

导入完成后，Zoom 会在 30 秒内自动配齐 OAuth 回调地址与白名单、带专属 `integration_key` 的事件回调地址、`/fd` 斜杠命令、Team Chat 事件订阅以及后续自动代托管所需的权限清单。
</Step>

<Step title="填写自建应用凭证（RSA 加密存储）">
从新建好的 Zoom 应用后台复制以下 5 项信息，填入 Flashduty 表单的 **步骤 2**：

- **App ID**：位于 Zoom 应用后台浏览器地址栏 `/develop/apps/{appId}`（或 **Basic Information** 页），用于 Flashduty 调用 Marketplace Manifest 接口执行配置核对与一键权限补齐。
- **Bot JID**：位于 **Features → Surface → Team Chat**，形如 `v1...@xmpp.zoom.us` 或 `v1...@xmpp.zoom.com.cn`。
- **Client ID** 与 **Client Secret**：位于应用凭证页（Development / Production Credentials）。
- **Secret Token**：位于 **Features → Access** 页面，用于校验 `x-zm-signature` 请求签名并自动通过 Zoom 的 `endpoint.url_validation` 地址验证。

`Client Secret` 与 `Secret Token` 在浏览器端经 RSA 公钥加密传输（`zoom.is_encrypted: true`），并在服务端信封加密存储；后续编辑集成时未修改的密钥以掩码原样保留，无需重复输入。
</Step>

<Step title="保存并前往 Zoom 完成首次授权">
填写集成名称与管理团队后，点击 **步骤 3** 中的 **保存并前往 Zoom 授权**：

1. Flashduty 先保存集成记录与 `Secret Token`，使专属回调地址立即可响应 Zoom 的 URL 校验请求。
2. 浏览器自动跳转至对应区域（`zoom.us` 或 `zoom.com.cn`）的 OAuth 授权页，登录管理员或应用所有者账号点击 **Allow**。
3. 授权完成后自动携授权码跳回 Flashduty 完成绑定，集成即刻生效并进入自动代托管状态。
</Step>
</Steps>

### 自动代托管与配置自愈

完成首次 OAuth 授权后，集成详情页的 **Zoom 应用与自动代托管** 卡片会通过 Zoom App Manifest 接口持续核对应用状态：

- **配置漂移检测与一键自愈**：若有人在 Zoom 后台误删了 `/fd` 斜杠命令、改动了事件回调地址或遗漏了必需权限，详情页会列出具体偏差项并提供 **一键同步修复配置** 按钮。点击后 Flashduty 会自动拉取远端 Manifest、保留您自定义的应用名称与图标，并将回调、命令和权限恢复至预期状态。
- **功能升级零手工改表**：后续开启需要额外权限或新事件订阅的功能（如主动接话）时，无需再次打开 Zoom 开发者后台改配置，直接在 Flashduty 详情页或编辑页一键写入即可。

### 成员关联说明

Zoom Team Chat 集成不设手动 **关联用户** 页签，也无需维护 `zoom_jid` 映射表。Flashduty 通过企业**邮箱**（忽略大小写）自动关联成员：

- 发送个人 1:1 私聊告警或邀请成员加入作战室时，系统按 Flashduty 成员邮箱查询同组织下的 Zoom 用户。
- 成员在 Zoom 中点击告警卡片按钮或向 AI SRE 提问时，系统读取操作者的 Zoom 邮箱并与当前账户成员比对。请确保成员的 Zoom 账号邮箱与 Flashduty 登录邮箱一致；若未匹配到成员，系统会在 Zoom 中提示邮箱未关联。

## 权限分级说明

Flashduty 遵循最小权限原则，将 Zoom OAuth 权限拆分为**默认必需权限**与**主动接话可选权限**两档。

### 默认必需权限（Required Scopes）

默认生成的 `flashduty-zoom-manifest.json` 包含以下 10 项权限，覆盖卡片通知、私密作战室、AI SRE 对话及应用生命周期自动代托管：

| 官方 scope 名称 | 用途 |
| :--- | :--- |
| `imchat:bot` | 注册 Team Chat 机器人收发能力，接收 `@` 提及与 `/fd` 斜杠命令 |
| `team_chat:write:user_message` | 向频道与个人私聊发送故障卡片、值班提醒、作战室通知和 AI SRE 回复 |
| `team_chat:update:user_message` | 就地更新故障卡片处理状态，以及流式刷新 AI SRE 排查进展 |
| `team_chat:read:list_user_channels` | 读取应用可见的 Zoom 频道列表，供分派策略和值班表下拉选择 |
| `team_chat:write:user_channel` | 为故障自动创建专属私密作战室频道 |
| `team_chat:write:members` | 按成员邮箱批量邀请故障响应人员加入作战室频道 |
| `team_chat:read:files` | 下载会话中附带的报错截图与日志文件（单文件上限 25 MB，仅允许受信任 Zoom 域名）供 AI SRE 分析 |
| `user:read:user` | 读取组织内 Zoom 用户基础信息与邮箱，用于自动成员匹配 |
| `marketplace:read:app` | 读取当前自建应用的 Manifest 配置，用于检测回调、命令或权限是否发生偏差 |
| `marketplace:write:app` | 自动同步修复应用配置偏差，并在开启新功能时一键向自建应用写入所需权限与事件订阅 |

### 主动接话可选权限（Optional Scopes）

以下两项频道消息读取权限属于敏感权限，**默认不包含在初始启用权限中**，仅在您需要开启 **允许 AI 主动接话** 时按需注入并授权：

| 官方 scope 名称 | 用途 |
| :--- | :--- |
| `team_chat:read:user_message` | 接收频道内未 `@` 机器人的普通消息事件（`chat_message.sent`、`chat_message.replied`），用于上下文缓冲与主动接话判断 |
| `team_chat:read:list_messages` | 读取频道与话题历史消息，用于补充 AI SRE 排障上下文及生成故障复盘摘要 |

<Note>
当检测到当前集成尚未授予上述两项权限时，**允许 AI 主动接话** 开关会自动锁定为关闭状态：

- **已开启自动代托管（推荐）**：点击开关下方的 **自动写入旁听权限并前往授权**，Flashduty 会通过 `marketplace:write:app` 接口自动将两项权限及 `chat_message.sent`、`chat_message.replied` 事件写入您的自建 Zoom 应用（企业内部 General App 即时生效、无需提交市场审核），并立即跳转至 Zoom 完成一次增量授权。
- **未开启自动代托管**：若您手动创建应用时未授予 `marketplace:write:app`，可点击 **下载含旁听权限清单** 在 Zoom 后台导入更新（或手动勾选上述权限与事件），再点击 **增量授权开启旁听**。
</Note>

## 告警通知与自动私密作战室

### 频道可交互告警卡片

先在目标 Zoom 频道（尤其是私密频道）中将自建的 Flashduty 应用添加至频道成员，随后前往 **协作空间 → 分派策略**，在群聊通知方式中选择 **Zoom 应用**，选定集成实例与目标频道并保存。

故障触发后，Flashduty 会向频道推送交互式 App Card：

- **快捷响应操作**：支持直接在卡片上执行 **认领**、**解决**、**暂缓**、**拉起作战室** 及预设的**自定义操作**，操作完成后卡片状态就地刷新。
- **自定义通知模板**：支持在 [通知模板](/zh/on-call/configuration/templates) 中定制 `Zoom` 应用渠道模板（Go `text/template` 语法，单条卡片上限 15,000 字节）。

### 个人私聊通知与值班提醒

- **个人 1:1 故障通知**：成员进入 **个人设置 → 通知偏好**，在故障通知渠道中勾选已启用的 Zoom 应用，即可通过 Zoom 1:1 私聊接收分派给自己的交互式故障卡片。
- **值班交接班提醒**：在 [值班管理](/zh/on-call/configuration/schedule) 的值班通知设置中，支持选择 **Zoom 应用** 向指定频道广播排班动态，同时支持向当班成员发送个人私聊提醒。

### 自动私密作战室与 AI 根因分析

在 Zoom 集成的 **增强功能** 区域，默认开启 **开启作战室** 与 **自动发起 AI 故障分析**：

- **私密频道隔离**：从故障详情页、告警卡片或分派策略拉起作战室时，Flashduty 默认创建 **私密 Zoom 频道（Private Channel）**，按邮箱自动分批拉入故障处理人，并发送置顶故障摘要卡片。
- **自动根因分析**：当 **自动发起 AI 故障分析** 开启且命中账户内的作战室创建触发规则时，AI SRE 会在作战室建群后立即结合故障详情、时间线与近期变更输出首轮根因诊断。更多规则说明见 [作战室](/zh/on-call/advanced/war-room)。

## 对话式 AI SRE

在集成中开启 **允许在 IM 中使用 AI SRE**（默认开启）后，团队成员可在 Zoom Team Chat 内直接协同排障。通用会话机制见 [IM 平台](/zh/ai-sre/im)。

### 交互入口与流式回执

- **频道 `@Flashduty` 提问**：在已接入的频道中提及 `@Flashduty` 并输入问题；若需带上频道内更早的报错文本或截图，可回复该消息后再 `@Flashduty`。
- **机器人 1:1 私聊**：在 Zoom Team Chat 中直接打开与自建 Flashduty 应用的私聊窗口提问，适合个人独立排查。
- **流式卡片更新与宽表产物**：由于 Zoom Team Chat 机器人接口不提供消息表情回执，AI SRE 收到请求后会立即发送一条「思考中」占位卡片，并按节流间隔就地更新分析进展与最终结论。当输出包含超过 4 列的宽表格或长篇分析报告时，卡片会附带可点击的产物查看链接。

### `/fd` 斜杠命令

在 Zoom 频道或机器人私聊中可使用 `/fd` 命令管理 AI SRE 会话：

| 命令 | 说明 |
| :--- | :--- |
| `/fd <问题>` | 向 AI SRE 发起新提问或在当前会话中继续追问 |
| `/fd new [消息]` | 重置当前会话上下文并开启全新对话；若附带消息则直接以该消息开始排查 |
| `/fd env [环境名]` | 查看可用运行环境、切换至指定 Runner 或沙箱环境，或执行 `/fd env clear` 恢复默认环境 |
| `/fd scope [团队名]` | 查看当前会话绑定的团队与协作空间范围、切换目标团队，或执行 `/fd scope clear` 恢复默认范围 |
| `/fd help` | 查看支持的 `/fd` 子命令与用法提示 |

此外，在开启主动接话的群聊中，您还可以发送 `/ambient on`、`/ambient off`、`/ambient inherit` 或 `/ambient status` 单独控制当前频道的主动接话行为。

### 话题回复隔离与主动接话

- **普通群聊中 AI-SRE 使用话题回复**（默认开启）：开启后，AI SRE 通过 Zoom 的 `reply_main_message_id` 在原消息所属话题（Thread）内回复，每个话题绑定独立的排查 Session（`group_thread`），互不串扰；关闭后则在频道主消息流中回复并共用频道级 Session（`group_chat`）。作战室频道始终直接在群内回复。
- **允许 AI 主动接话**（默认关闭）：完成[主动接话可选权限](#ambient-scopes)一键写入与增量授权并开启开关后，系统在频道内维护最近 30 条消息（24 小时过期）的滑动上下文缓冲，仅当判定某条未 `@` 消息需要介入排障时才主动回复。

## 私有化部署说明

私有化部署版 Flashduty 与 SaaS 版共享完全一致的 **Manifest 一键导入 + 自动代托管** 体验：

1. 确保您的 Flashduty 控制台域名（如 `https://console.example.com`）与事件网关域名（如 `https://api.example.com`）对 Zoom 服务器可达（满足回调签名校验与事件推送）。
2. 直接在控制台新建 Zoom 集成并下载 `flashduty-zoom-manifest.json`——系统会自动把您私有化环境的实际回调地址（`https://api.example.com/event/push/zoom_app/data?integration_key=<key>`）与 OAuth 重定向地址（`https://console.example.com/settings/source/im/add/zoom_app`）写入清单，无需修改服务端配置文件。

如果您希望在单租户私有化环境中配置全局兜底凭证（当数据源未单独填写凭证时自动回退使用），可在 `fc-datasource` 与 `fc-event` 的 `etc/*.yaml` 中按需配置以下可选字段（或注入同名环境变量 `ZOOM_CLIENT_ID`、`ZOOM_CLIENT_SECRET`、`ZOOM_SECRET_TOKEN`、`ZOOM_BOT_JID`、`ZOOM_REDIRECT_URI`）：

```yaml
deploy:
  zoomClientID: "<YOUR_ZOOM_CLIENT_ID>"
  zoomClientSecret: "<YOUR_ZOOM_CLIENT_SECRET>"
  zoomSecretToken: "<YOUR_ZOOM_SECRET_TOKEN>"
  zoomBotJID: "<YOUR_ZOOM_BOT_JID>"
  zoomRedirectURI: "https://console.example.com/settings/source/im/add/zoom_app"
```

## 常见问题

<AccordionGroup>
<Accordion title="Zoom 国际版（zoom.us）与中国大陆专区（zoom.com.cn）应该如何选择？">
请根据您团队登录 Zoom 客户端与开发者后台的实际域名选择。若您的企业账号托管在 `zoom.com.cn`，请在步骤 1 选择 **Zoom 中国大陆专区 (`zoom.com.cn`)**，Flashduty 会自动将 API 地址切换至 `https://api.zoom.com.cn`、OAuth 地址切换至 `https://zoom.com.cn`，并引导您在 `marketplace.zoom.com.cn` 导入配置清单。
</Accordion>

<Accordion title="分派策略或值班表的频道下拉列表中找不到目标 Zoom 频道？">
- 确认 Zoom 集成已完成 OAuth 授权且状态为启用
- 若目标频道为私密频道（Private Channel），请先在 Zoom 客户端打开该频道，将自建应用添加为频道成员；公开频道也建议先将应用或授权人加入频道
- 返回 Flashduty 分派策略或值班表配置页，点击频道选择框右侧的刷新按钮重新拉取频道列表（服务端频道列表默认缓存 5 分钟，手动刷新会立即更新）
</Accordion>

<Accordion title="点击 Zoom 故障卡片按钮时提示未匹配到成员？">
Zoom Team Chat 集成通过成员邮箱识别操作人。请核对您在 Zoom 客户端登录账号的邮箱是否与 Flashduty **成员管理** 中的邮箱一致（大小写不敏感）；修改一致后即可直接操作卡片，无需手动绑定。
</Accordion>

<Accordion title="为什么「允许 AI 主动接话」开关处于锁定状态？">
默认导入的 Manifest 不启用读取频道普通消息的敏感权限（`team_chat:read:user_message` 与 `team_chat:read:list_messages`）。点击开关下方的 **自动写入旁听权限并前往授权**，Flashduty 会自动将所需权限与消息事件写入您的自建 Zoom 应用并跳转完成增量授权，返回控制台后即可开启该开关。
</Accordion>
