自定义字段用于扩展故障的描述信息。Flashduty On-call 已支持接入大部分常见告警系统，将推送内容放到 Labels 展示。但您可能还需要记录额外信息，比如人工标记故障是否为误报。自定义字段正是为此设计。

## 配置字段

### 创建字段

<Note>
一个账户最多支持创建 **15 个**自定义字段。
</Note>

<Steps>
<Step title="进入配置页面">
前往控制台 **配置中心** → **自定义字段**
</Step>
<Step title="创建字段">
点击 **创建**，输入以下信息：

| 配置项 | 说明 | 约束 |
| :--- | :--- | :--- |
| **字段名称** | API 中标识字段，创建后不可修改 | 1-40 字符；仅支持字母、数字、下划线，且不能以数字开头 |
| **展示名称** | 故障详情页中的展示字段，创建后可修改 | 1-40 字符 |
| **字段描述** | 辅助故障处理人理解和使用该字段 | 最多 200 字符，可选 |
</Step>
<Step title="选择字段类型">
| 类型 | 说明 |
| :--- | :--- |
| **文本** | 纯文本输入框，最多 3000 字符。可通过故障列表的键入检索搜索内容 |
| **单选** | 单选下拉框，最多 20 个选项，每项不超过 200 字符 |
| **多选** | 多选下拉框，最多 20 个选项，每项不超过 200 字符 |
| **复选** | Checkbox 勾选框 |
</Step>
<Step title="完成创建">
按需设置可选项和默认值，点击 **提交** 完成。

<Note>
单选 / 多选字段的**默认值**必须是当前字段已定义的选项之一；若选项被删除或修改，请同步更新默认值，否则无法保存。
</Note>
</Step>
</Steps>

<Frame>
<img src="https://docs-cdn.flashcat.cloud/images/png/48b65984bb34159824643ebd77a6095a.png" alt="创建自定义字段" />
</Frame>

<Tip>
如果字段设置了默认值，系统将在故障生成时自动写入该字段。注意，字段配置仅对新故障生效，不影响已有故障。
</Tip>

### 更新字段

仅允许更新以下内容：

- 展示名称
- 字段描述
- 字段可选项（仅单选和多选类型）
- 默认值

<Note>
字段更新后仅对新故障生效，不影响已有故障。
</Note>

### 删除字段

您可以随时在控制台发起删除操作。

<Warning>
删除需要一些时间。在删除完成前，您无法创建同名字段。
</Warning>

### 故障信息关联

打开故障详情，在 **综合信息 → 自定义字段** 中直接填写或选择字段值。修改会自动保存，无需另行提交；编辑需要故障更新权限。

点击 **展示空字段**，可填写尚未设置的字段；点击 **收起空字段**，只保留已有值的字段。

### 按字段筛选视图

在故障列表点击 **添加筛选 → 自定义字段**，选择字段和值。单选、多选和复选字段支持精确筛选，不支持通配或正则；多选字段匹配包含所选值的故障，复选字段选择 `true` 或 `false`。

文本字段请在筛选条行尾的搜索框输入关键词。搜索会匹配故障标题、标签和自定义字段中的内容，不限定于某一个字段。详情见[检索与查看故障](/zh/on-call/incident/search-view-incident)。

## 常见问题

<AccordionGroup>
<Accordion title="为什么自定义字段筛选中找不到文本字段？">
自定义字段筛选仅列出单选、多选和复选字段。要查找文本字段中的内容，请使用故障列表行尾的搜索框输入关键词。字段内容更新后，搜索结果可能存在短暂延迟。
</Accordion>
</AccordionGroup>
