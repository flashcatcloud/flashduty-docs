## Overview

An artifact is a file AI SRE produces in a session and publishes to the artifact gallery. There are two ways to publish:

- **The agent publishes**: the agent publishes its output from the session as an artifact, in any of the types in the table below. The most common example is the operational insight report that `/insight` generates in a session.
- **You publish**: select the "Publish to artifact gallery" button next to a file in the session (see [Creating an artifact](#creating-an-artifact) below).

   <Accordion title="View publishable file types">

   | Category | Common extensions |
   |---|---|
   | Web pages & documents | `.html` `.htm` `.md` `.markdown` `.txt` `.log` |
   | Data & config | `.csv` `.tsv` `.json` `.yaml` `.yml` `.xml` `.toml` `.ini` |
   | Images | `.png` `.jpg` `.jpeg` `.gif` `.svg` `.webp` |
   | Video & audio | `.mp4` `.webm` `.mov` `.mp3` `.m4a` `.wav` |
   | PDF | `.pdf` |
   | Source code | `.py` `.go` `.js` `.mjs` `.ts` `.jsx` `.tsx` `.java` `.c` `.h` `.cpp` `.cs` `.rb` `.rs` `.php` `.sh` `.sql` `.kt` `.swift` `.scala` `.css` `.vue` `.svelte` `.proto` `.tf` `.hcl`, and more |
   | Archives | `.zip` `.tar` `.gz` `.tgz` |

   </Accordion>

Files outside the table above don't show a "Publish to artifact gallery" button in the session.

A published artifact initially inherits its source session's scope: artifacts from a personal session belong to their creator ("Personal"). Artifacts from a session bound to a team belong to that team and can be shared with other account members. Users with edit permission can change the scope later.

Entry point: **AI SRE → Artifacts** in the left navigation.

### Content forms and how they display

| Form | What you see |
|---|---|
| Multi-file page | One HTML page can bundle its styles, scripts, and images and is shown as-is on the artifact detail page. A single publish allows up to 255 files (including the entry page) and 64 MiB in total. A page, text, data, or code file can be up to 16 MiB each; images, video, audio, PDF, and archives up to 15 MiB each |
| Canvas | Several pages laid out on one canvas that you can pan and zoom (2%–400%); select a board to view it full window, where ←/→ or the **Previous** / **Next** buttons step through every board in the canvas and Esc or **Close** exits. Suited to reviewing several interface designs side by side |
| Slides | Each page is a fixed 1920×1080. Turn pages with the arrow keys, PageUp / PageDown, Home / End, or Space (Shift + Space goes back), and swipe left or right on a touch screen; select **Present** for full screen, where clicking the left or right half of the screen turns the page and the page number shows at the bottom |
| Table | `.csv` / `.tsv` files display as a table with a fixed header row. Up to 1000 rows and 200 columns are shown, within 20000 cells in total, so a wide table shows fewer rows |
| Video & audio | `.mp4` `.webm` `.mov` and `.mp3` `.m4a` `.wav` play in the browser's built-in player |

A publish that exceeds the file-count or size limits is rejected with the reason; trim the files and publish again.

<Note>
You can't upload files to the artifact gallery directly. The agent produces and publishes every artifact in a session, and **New artifact** also opens a session for this. The gallery is for browsing, searching, and managing published artifacts.
</Note>

## List page

- **Search and filter**: search by title; filter by scope (**All / Personal / Team**). Choosing "Team" lets you pick specific teams; picking none means all teams visible to you.
- **Views**: switch between card view (default) and list view at the top right; your choice is saved in the browser. List view shows the name, scope (team name, or the creator for personal artifacts), source conversation (click to jump. "Conversation deleted" if it no longer exists), created and updated times, a pin button, and actions.
- **Sorting**: sort by created or updated time; the default is **updated time, newest first**. Whatever the sort, the artifacts you pinned always come first (most recently pinned first).
- **Paging**: 12 / 24 / 48 per page, 24 by default.
- **Shareable URL**: the page URL keeps the scope, search term, sorting, and page. Copy it to share or bookmark the filtered list. When you return from a detail page, you land where you were.

Each card shows a content thumbnail, a type icon, the title, the edited time, and the scope. It also shows whether a public link is on and whether the artifact is pinned. The thumbnail is a static preview for HTML, Markdown, images, plain text, tables (the header and first few rows), video (the first frame), and canvases / slide decks (their first board or first slide); only PDFs and audio show an empty frame. Hover over the edited time to see the exact time.

### Pinning

Click the pin button on a row or card, or choose **Pin** / **Unpin** from the **More actions** menu.

Pinning is **your personal preference, not an edit**: you can pin any artifact you can see (including other people's personal artifacts and team artifacts) with **no edit permission**. It only floats the artifact to the top of your own gallery; it doesn't change the artifact or the order anyone else sees. Pinning an artifact on page 2 moves it to page 1.

### Creating an artifact

Click **New artifact** at the top right to open a chat with a prefilled draft prompt. The agent first asks about the target audience, content/data source, interactions, and visual style, then builds and publishes the artifact — there is no form to fill out.

<Tip>
If a session has already produced the file, click "Publish to artifact gallery" next to it instead — it's faster than starting a new conversation.
</Tip>

## Card actions

The "More actions" menu on each card offers:

| Action | Notes |
|---|---|
| Pin / Unpin | Changes only your own list order; no edit permission needed. See [Pinning](#pinning) |
| Copy link | Copies the link to the artifact's detail page to share with other account members |
| Download | Shown when the artifact has a linked file; downloads the original file |
| Rename | Requires edit permission |
| Change scope | Requires edit permission; choose Personal or an accessible team. Only the creator can change it back to Personal |
| Delete | Requires edit permission and confirmation. Removes the artifact from the gallery only; the source session and the file itself are kept |

## Detail page

The top of the detail page offers:

- **Title**: with edit permission, click the title to edit it — Enter saves, Esc cancels. The creator is shown below the title;
- **Share**: choose "Account only" or "Public link" — see [Share an artifact](#share-an-artifact) below;
- **Delete** and **Change scope** (edit permission required) and **Download** (when there is a linked file);
- **Source session**: the edited time and "Recently updated from session 〈session name〉", which opens the source session's full conversation. It is hidden if the session was deleted or you lack access; the artifact itself stays viewable.

The body renders according to the artifact's content type (for example, an HTML report renders inline as a page).

<Note>
On a phone, the detail page is a **read-only reader**: only the title and body are shown, with no editing, sharing, scope changes, or deletion. When the artifact has a linked file, **Download** is still available under "More actions".
</Note>

## Share an artifact

The **Share** button in the detail page toolbar opens the share panel. **Manage permission** at the top lists who can manage sharing for this artifact (the creator is labeled "Owner"; team artifacts also list team members). **Visibility** below offers two modes:

| Mode | Who can open it | Content |
|---|---|---|
| Account only | Members signed in to the same account | Viewable once signed in; content is **always the latest version** |
| Public link | Anyone with the link, **no sign-in required** | Shows a **content snapshot** taken the moment the link was generated; it doesn't automatically sync after the artifact is updated |

### Public link

<Tip>**Plan requirement**: Public links require an On-call Pro or higher subscription. [Learn more](https://flashcat.cloud/flashduty/price/)</Tip>

After you choose **Public link**, the panel first shows a content preview and a risk notice; the link only takes effect once you click **Generate public link**:

<Warning>
Once you generate a public link, anyone who gets the link can view this artifact, and the link can be forwarded further. Don't share secrets, personal information, or unauthorized third-party content.
</Warning>

The link is copied to your clipboard automatically. Public links take the form `https://<console domain>/share/artifact/<artifact ID>`; they contain no token, so anyone with the link can open it.

<Note>
On private deployments, public links require the instance to be configured with a reachable share static-asset base (CDN). When it is not configured, the share panel does not offer the **Public link** option and only "Account only" sharing is available; public links generated earlier remain manageable and revocable. SaaS is not affected by this restriction.
</Note>

Visitors see a read-only page marked "Content is user-generated and unverified." next to the title, with **Feedback** (to report inappropriate content) and **Sign in** entries.

| Action | Description |
|---|---|
| Generate public link | Copies the artifact's current content as a public snapshot and enables the link |
| Update snapshot | Appears only when the artifact's content has changed since the snapshot was taken (an "Artifact content has changed — update the snapshot to sync the latest content" notice). Clicking it overwrites the snapshot with the latest content; **the link itself stays the same** |
| Revoke public link | Turns off public access; the link stops working immediately |

## Update a published artifact

Publishing the same file again does **not** silently overwrite a published artifact. When the agent updates an artifact, it names the artifact and the version it is based on. If someone changed the artifact in the meantime, the agent reads the current content and merges before retrying, instead of overwriting it. The link and artifact ID stay the same after an update.

A few more details:

- If the content hasn't changed, the artifact is left alone.
- Showing the same file again in a session does **not** update the published artifact; ask the agent to publish again.
- The agent will not revive a deleted artifact by republishing it; only clicking "Publish to artifact gallery" next to the file in a session restores a deleted artifact.

## Permissions

Any one of the following lets you rename, change the scope of, or delete an artifact:

| Condition | Notes |
|---|---|
| Creator | The owner of the session the artifact was published from |
| Account Owner / admin | Any artifact in the account, including other members' personal artifacts (unlike automation rules) |
| Team member | Members of the team that owns a team artifact |

Without edit permission you can only pin, copy the link, and download. For the general scope and permission rules, see [Context](/en/ai-sre/context#scope-and-permissions).
