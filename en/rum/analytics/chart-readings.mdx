## Sampling and exact queries

With a large amount of data, not every chart on the analytics dashboards reads all of it. The **Sampled** mark next to the title means this chart was computed from a sample, so its values are estimates. Hover over the mark to see roughly what fraction of the data was sampled.

When you need the exact number for a chart, click the **Sampled** mark: that chart alone is computed once over all data, showing **Computing…** while it runs, and the mark disappears when it's done. Changing the time range or the filters puts the chart back on sampling.

An account can run a limited number of exact queries at once (2 by default), and the rest queue. A query that times out in the queue shows **Failed**; click the mark to retry.

A trend chart switched to **Cumulative** reads all data, so it shows no **Sampled** mark.

## Trend chart granularity and cumulative view

The **User Access Trend** chart on the overview page has two controls: the **Per interval / Cumulative** switch and the **Granularity** dropdown.

| Control | Values | Description |
|---------|--------|-------------|
| **Trend view** | **Per interval** (default), **Cumulative** | Per interval is the value within each interval; cumulative is the running total from the start of the selected range to that interval |
| **Granularity** | **5 min**, **1 hour** (default), **1 day** | The time each point covers; when the current range cannot be drawn at that width, an available one is used instead |

- Every point in the cumulative view covers everything from the start of the range, so you can't drill down from one. UV counts each user once, so the end of the cumulative line is not the sum of per-interval UV.
- When a granularity cannot draw the current range, the dropdown says why: **Range too long** (too many points) or **Range too short** (fewer than two points).
- With **1 day**, each bucket starts at midnight in your display time zone (the one in [personal settings](/en/on-call/configuration/personal-settings), or the [organization time zone](/en/platform/organization-info) when you have not set your own), not at midnight UTC.
