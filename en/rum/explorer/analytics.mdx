The RUM Explorer gives you two view modes: **List** and **Analytics**. The **Analytics** view aggregates events of the current type by the aggregation and group you pick. Use it to answer questions like "which page loads slowest" or "which browsers do the errors come from". Switch back to the list when you need individual events.

## List and analytics

The top of the Explorer has two tabs: **List** shows events one by one, and **Analytics** aggregates them into charts. Both share the same event type, query conditions and time range, so switching tabs never drops your filters. The analytics view is kept in the URL, so you can copy the link to share the same chart (see [URL parameters](#url-parameters)).

## Choosing the aggregation and fields

The **Measure** row at the top of the analytics view decides what is computed: pick an **Aggregation**, then a **Measured field** where one is needed, then a **Group-by field**.

### Aggregations

| Aggregation | Description |
|-------------|-------------|
| **Count** | Number of events; takes no field |
| **Unique count** | Number of distinct values of a field |
| **Average** | Mean of a numeric field |
| **Sum** | Total of a numeric field |
| **Min** | Smallest value of a numeric field |
| **Max** | Largest value of a numeric field |
| **P50 / P75 / P90 / P95 / P99** | Approximate percentiles of a numeric field, for watching the long tail |

Every aggregation except **Count** needs a **Measured field**:

- Average, Sum, Min, Max and percentiles accept numeric fields only (timestamps excluded).
- Unique count accepts any field you can group by.
- If you switch to an event type that lacks the field, pick another one.

In the legend, table and CSV, Count and Distribution measures read "Events"; other aggregations read "Aggregation (field name)", such as "Average (view_loading_time)".

### Group-by field

The **Group-by field** splits the measure so each value is shown separately. Use **top** to keep the top `5`, `10` (default), `20` or `50` groups; without a group-by, the result is a single number. Array fields cannot be grouped by, and a **Distribution** does not use a group-by.

## Chart types

The analytics view offers five chart types:

| Chart type | Description |
|------------|-------------|
| **Timeseries** | The measure over time (default) |
| **Top list** | Groups ranked by the measure, largest first |
| **Pie** | Share of each group. Requires a group-by and **Count** or **Sum** (the only aggregations that add up to a whole) |
| **Table** | Two columns: the group and the measure |
| **Distribution** | Histogram of events per value range of one numeric field; see [Distribution](#distribution) |

A **Timeseries** can be drawn as **Bars** (default) or **Line**. With a group-by and Count or Sum, bars are stacked by group so the bar height is the total; other aggregations do not add up, so they are not stacked.

## Drilling down

Click a point in time, row, slice or range on a chart to drill down from the aggregate to individual events:

| Menu item | What it does |
|-----------|--------------|
| **View in list** | Switches to the list tab, showing only the events behind the clicked element |
| **Split "value"** | Keeps only that value and lets you pick the next group-by field (**Filter to "range"** on a distribution) |
| **Exclude "value"** | Drops the clicked group value from the result |

A drill-down adds ordinary filters (a time-point drill-down narrows the time range), which you can see and undo in the search box. After **View in list**, click **Back to analytics** at the top of the list to return to the analysis you drilled from.

<Note>
The empty group (shown as "(empty)") cannot be split or excluded yet.
</Note>

## Zooming a timeseries

Drag across a **Timeseries** to zoom in. The zoom affects this chart only, not the Explorer's time range. Click the close button on the **Zoomed** badge to reset it; changing the event type, query or time range also resets it.

## Downloading an image and exporting CSV

From the top-right corner of the chart:

- **Download image**: exports a PNG at 2× resolution. Not available for tables or a single ungrouped number.
- **CSV**: exports the chart data. A timeseries has one row per time, group and measure; other charts have one row per group.

## Distribution

A **Distribution** buckets one numeric field by value range and shows the number of events in each range, without an aggregation or group-by.

- About 40 round-numbered buckets cover the range from the minimum to `P99`. Values above `P99` go into a final "≥ edge" bucket, so a long tail doesn't squeeze most data into the first bar.
- Ranges use the field's unit, such as `1s–1.5s`.

## Sampled estimates

With large data volumes, results are estimated from a sample and the chart shows a **Sampled** badge in its top-right corner.

## URL parameters

The analytics view keeps its state in the URL, so a copied link reproduces the same analysis, and you can build links from the table below. Invalid values fall back to the default.

| Parameter | Meaning | Values | Default |
|-----------|---------|--------|---------|
| `mode` | View mode | `analytics` | omitted, that is, the list |
| `agg` | Aggregation | `count`, `count_distinct`, `avg`, `sum`, `min`, `max`, `p50`, `p75`, `p90`, `p95`, `p99` | `count` |
| `aggField` | Measured field | a field name | none |
| `groupBy` | Group-by field | a field name | none (no grouping) |
| `top` | Number of groups kept | `5`, `10`, `20`, `50` | `10` |
| `viz` | Chart type | `timeseries`, `toplist`, `pie`, `table`, `distribution` | `timeseries` |
| `style` | Timeseries draw style | `line`, `bar` | `bar` |
