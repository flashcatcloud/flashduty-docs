The performance data analysis page helps identify the root causes of browser performance issues by analyzing real user traffic data. Use browser metrics such as Core Web Vitals and custom loading time metrics to troubleshoot slow page loading. These metrics evaluate complete page load time from the user's perspective.

## Accessing performance analysis

Open **Performance** in the RUM menu, then switch views with the **Table** and **Tree** buttons at the top right to analyze performance data by page or by metric.

### Table view

Select **Table** to list every page with each metric value, sorted by visit count from highest to lowest by default:

- The color marker before a value shows the metric's band, so you can spot the metrics that need work
- Hover over a metric to see its current level against the standard
- Select a row to open that page's metric details

### Tree view

Select **Tree** to group pages into **Good**, **Warning**, and **Poor** bands for the selected metric; each block's area is the page's visit count:

- The **Metric** dropdown lists only the metrics the current app's platform reports (WeChat Mini Program and browser / Electron have different metric sets); the options change with the app
- Select a band header to zoom into it, then **Back** to return to every band
- Select a block to open that page's metric details for further diagnosis

## Data analysis dimensions

Through global filters, you can analyze page performance from different dimensions to gain insights into performance data trends:

| Dimension | Description |
|-----------|-------------|
| Browser Name | Filter by browser type |
| Status | Filter by device connection status |
| Device Type | Filter by device type |
| Country | Filter by the user's country |

<Frame>
  <img src="https://docs-cdn.flashcat.cloud/imges/png/fee74402b3013913c8a9dfbae3acecfa.png" alt="Data Analysis Dimensions" />
</Frame>

<Tip>
The **Display mode** setting at the top right offers **Sidebar** and **Page**. The default **Sidebar** opens metric details in a panel on the right of the current list; with **Page**, details open on their own page with more room for data and diagnosis.
</Tip>
