RUM (Real User Monitoring) helps you find and fix issues in your websites and apps. It captures errors automatically and attaches context, so you can locate the root cause and fix it quickly.

## Features

- [Error reporting](/en/rum/error-tracking/error-reporting/web): the SDK captures unhandled errors automatically, and you can report handled errors manually with context
- [Error grouping](./error-aggregation): groups similar error events into one Issue to reduce duplicate alerts
- [Issue overview and details](./error-viewing): view an Issue's occurrences, stack traces, affected users, and session timeline
- [Source mapping](./source-mapping): upload symbol files to restore minified or obfuscated stacks to original code locations

## Error tracking workflow

<Steps>
  <Step title="Find the problem">
    - **Data analysis**: view error rate and error type trends in the **Errors** tab of the analytics dashboard
    - **Alert notifications**: turn on alerts in the application to notify a channel when errors occur
    - **Active inspection**: review the Issue list and trends in the **Error tracking** module
  </Step>
  <Step title="Locate the cause">
    In the Issue details, review the stack trace, user environment, and the session timeline that led to the error.
  </Step>
</Steps>

## Contextual information

- **User Environment**: Browser type, device model, operating system
- **Error Stack**: Detailed call stack information
- **Session Timeline**: Operation path that triggered the error
