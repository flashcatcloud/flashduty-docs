### Integration steps

<Steps>
<Step title="Open RUM">
On SaaS, an account that has not opened the RUM plan yet sees an empty **Applications** page whose primary button is **Start for free**. Selecting it opens the free plan and continues into the application setup.

Accounts that already have the plan, and self-hosted deployments, skip this step.
</Step>

<Step title="Create an application">
A RUM application is a container for performance monitoring data. We recommend creating applications based on business systems or applications, such as: official website, e-commerce store, admin dashboard, and so on.

1. On the **Applications** page, select **Create application** at the top right (with an empty list, the empty-state button is **Create the first app**)
2. In the drawer, fill in **Application type**, **Application name**, **Team**, and **Access level** in that order
3. Set **Geographic data collection** and **Alerting** in the lower half of the same drawer
4. Select **Save**

**Application type** decides which data the application can collect and cannot be changed after creation. **Access level** defaults to **Private**, visible only to team managers, the application creator, and account administrators. The primary button in the empty state starts the guided setup, which asks only for application type, application name, and team; the remaining settings live on the application's **Basic information**, **Privacy**, and **Alerting** tabs after creation.

<Tip>
Go to [Application management](/en/rum/quickstart/app-management) to learn more configuration options.
</Tip>
</Step>

<Step title="Integrate SDK">
After creating the RUM application, you need to integrate the SDK into your application.

1. Get SDK integration configuration information on the application details page
2. Choose the appropriate integration guide based on your application type

<Step title="Verify Data Reporting">
After SDK integration, the system automatically collects page or screen performance, resource and network requests, user actions, and errors. The exact scope differs by platform; see the data collection page of your SDK, for example [Web data collection](/en/rum/sdk/web/data-collection).

<Check>
Data usually appears in the console within 2-5 minutes.
</Check>
</Step>
</Steps>
