Sign in to Flashduty with users from an OpenLDAP directory.

<Warning>
LDAP sign-in is supported only in **self-hosted deployments**.
</Warning>

## Prerequisites

- An OpenLDAP service reachable from Flashduty (default port 389; LDAPS 636). To set one up, see the [OpenLDAP documentation](https://www.openldap.org/doc/).
- User entries in the directory have a `mail` attribute. Flashduty matches members by email, and email is a required mapping field.

## Configure in Flashduty

Go to **Platform Management → Single Sign-On**, turn it on, click **Settings**, and select **LDAP** as the protocol type. The example values use `dc=flashduty,dc=com`:

| Field | Example value |
| --- | --- |
| LDAP URL | `ldap://10.0.0.1:389` |
| BIND DN | `cn=admin,dc=flashduty,dc=com` |
| BIND DN Password | The password of that account |
| User DN | `ou=people,dc=flashduty,dc=com` |
| Auth Filter | `(mail=%s)` |
| Field Mapping: Email | `mail` |
| Field Mapping: Username | `cn` |
| Field Mapping: Phone | `mobile` |

Field mappings must match the attribute names in your directory. For the other fields (encryption, stable user ID, Create Account on Sign In, and so on), see [Configure single sign-on](/en/platform/configure-sso#configuring-ldap-protocol).

Click **Test connection** to confirm Flashduty can reach the OpenLDAP service, then click **Save**.
