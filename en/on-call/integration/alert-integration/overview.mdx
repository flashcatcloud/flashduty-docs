Flashduty On-call receives alerts that external systems push or that Flashduty pulls through alert integrations. The generic methods that do not depend on a specific tool come first, followed by every alert integration sorted by name. You can also search for a tool name with Ctrl K.

## Before you start

Every integration can be connected as a **dedicated integration** (alerts go straight into one channel) or a **shared integration** (alerts are routed to channels by routing rules). See [Integrate Data](/en/on-call/channel/integrate-data) and [Routing Rules](/en/on-call/integration/alert-integration/routing-rules).

## Generic ingestion methods

<CardGroup cols={2}>
  <Card title="Standard Alert Event" href="/en/on-call/integration/alert-integration/alert-sources/standard-alert">
    Push alerts in the Flashduty standard format, for in-house systems or tools without a dedicated integration
  </Card>
  <Card title="Email" href="/en/on-call/integration/alert-integration/alert-sources/email">
    Generate a dedicated email address and sync alert triggers and recoveries by email
  </Card>
  <Card title="HTTP Pull" href="/en/on-call/integration/alert-integration/alert-sources/http-pull">
    Let Flashduty periodically pull alerts from an HTTP endpoint
  </Card>
  <Card title="Database Pull (DB Pull)" href="/en/on-call/integration/alert-integration/alert-sources/db-pull">
    Let Flashduty periodically query alert records from a database
  </Card>
</CardGroup>
