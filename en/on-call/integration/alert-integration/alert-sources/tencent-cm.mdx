Sync Tencent Cloud Monitor CM alert events to Flashduty through webhook.

<div className="hide">

## In Flashduty On-call
You can get the integration push URL in either of the following ways.

### Use a dedicated integration

Choose this option if all alerts go to one channel. It's the simpler setup.

<AccordionGroup>
  <Accordion title="View dedicated integration setup steps">
  
  1. In the Flashduty console, select **Channel** and open a channel
  2. Select **Configuration** → **Integrations** → **Private integration**, then click **Add an integration**
  3. Select **Tencent Cloud Monitor CM** integration and click **Save** to generate a card
  4. Open the generated integration card and copy the **Push URL**
  
</Accordion>
</AccordionGroup>

### Use a shared integration

Choose this option if you need to route alerts to different channels based on the alert payload.

<AccordionGroup>
  <Accordion title="View shared integration setup steps">
  
  1. In the Flashduty console, go to **Integration Center → Alert Events**
  2. Select **Tencent Cloud Monitor CM** integration:
        - **Integration Name**: Define a name for this integration
  3. Configure the default route and select a channel. You can add more rules under **Routing** after creation
  4. Click **Save** and copy the generated **Push URL**
    
</Accordion>
</AccordionGroup>
</div>

## Configure Tencent Cloud Monitor CM

<Steps>
<Step title="Create a notification template in Tencent Cloud Monitor">

**Where**: Tencent Cloud console › Cloud Monitor › 告警管理 (Alarm Management) › 基础配置 (Basic Configuration) › 通知模板 (Notification Templates) › 新建通知模板 (New)

| Field | Value |
| --- | --- |
| Template name (required) | A name of your choice, for example `Flashduty` |
| 接口回调 (API callback) › URL / callback address (required) | `{integration_url}` |
| Notification language (required) | `English` |

Click **Save**.

<img alt="Notification template in Tencent Cloud Monitor" width="600" src="https://download.flashcat.cloud/saas-tecent-cm-template.png" />

</Step>
<Step title="Add the template to your alert policies">

**Where**: Tencent Cloud console › Cloud Monitor › 告警管理 (Alarm Management) › 策略管理 (Policy Management) › your alert policy › Edit › 通知模板 (Notification Template)

In every alert policy that should send events to Flashduty, add the notification template you created, then save the policy.

<img alt="Adding the notification template to an alert policy" width="600" src="https://download.flashcat.cloud/tecent-cm-rule.png" />

</Step>
<Step title="Confirm Flashduty receives events">

Tencent Cloud Monitor notification templates have no "send test" button. Wait for a real alert from a linked policy.

After an alert fires, return to Flashduty. If the integration shows a **latest event time**, the setup works.
{/* console:
The "first event received" item in the setup checklist turns green as well.
*/}

</Step>
</Steps>

## Status and severity
<div class="md-block">
  
When `alarmLevel` is present, Flashduty maps the alert severity as follows:

| Tencent Cloud Monitor `alarmLevel` | Flashduty |
| --- | --- |
| `Remind` | Info |
| `Warn` | Warning |
| `Serious` | Critical |

When `alarmLevel` is missing or unrecognized, Flashduty uses the default severity for the alert type:

| Tencent Cloud Monitor `alarmType` | Flashduty |
| --- | --- |
| `metric` | Warning |
| `event`, `prometheus`, and other types | Critical |

Recovery is evaluated independently: an `event` alert is resolved (OK) when `recoverTime` is not `0`; all other alert types are resolved (OK) when `alarmStatus` is `0`.

</div>
