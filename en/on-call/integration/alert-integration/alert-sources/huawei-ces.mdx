Sync Huawei Cloud CES alerts to Flashduty through webhook.

<div className="hide">

## In Flashduty On-call
You can get the integration push URL in either of the following ways.

### Use a dedicated integration

Choose this option if all alerts go to one channel. It's the simpler setup.

<AccordionGroup>
  <Accordion title="View dedicated integration setup steps">
  
  1. In the Flashduty console, select **Channel** and open a channel
  2. Select **Configuration** → **Integrations** → **Private integration**, then click **Add integration**
  3. Choose **Huawei Cloud CES** integration and click **Save** to generate a card
  4. Open the generated integration card and copy the **Push URL**
  
</Accordion>
</AccordionGroup>

### Use a shared integration

Choose this option if you need to route alerts to different channels based on the alert payload.

<AccordionGroup>
  <Accordion title="View shared integration setup steps">
  
  1. In the Flashduty console, go to **Integration Center → Alerts**
  2. Select **Huawei Cloud CES** integration:
        - **Integration Name**: Define a name for this integration
  3. Configure the default route and select a channel. You can add more rules under **Routing** after creation
  4. Click **Save** and copy the generated **Push URL**
    
</Accordion>
</AccordionGroup>
</div>

## Configure in Huawei Cloud CES

<Steps>
<Step title="Prepare an HTTPS notification channel in Huawei Cloud">

<Tabs>
<Tab title="New console (recommended): SMN topic subscription">

**Where**: Huawei Cloud console › Simple Message Notification (SMN) › Topic Management › Topics › Create Topic

| Field | Value |
| --- | --- |
| Topic name (required) | `Flashduty` |

After saving, click `Add Subscription` on the `Flashduty` topic:

| Field | Value |
| --- | --- |
| Protocol (required) | `HTTPS` |
| Subscription endpoint (required) | `{integration_url}` |

After adding, check that the subscription status in the subscription list shows **Confirmed**. Otherwise, alerts aren't pushed.

</Tab>
<Tab title="Legacy console: notification object and group">

The entry to the notification object and group pages in the new console is unconfirmed; the paths below are those of the legacy console. In some regions they are shown as **Contacts/Contact Groups** ([source](https://support.huaweicloud.com/usermanual-ces/ces_01_0219.html)).

**Where**: Huawei Cloud console › Cloud Eye Service › Alarm › Alarm Notifications › Notification Objects › Create Notification Object

| Field | Value |
| --- | --- |
| Protocol (required) | `HTTPS` |
| Name (required) | `flashduty` |
| Endpoint (required) | `{integration_url}` |

Click `OK` to create the notification object.

<img src="https://download.flashcat.cloud/flashduty/doc/en/hw/hw-1.png" alt="Create an HTTPS notification object" width="500"/>

Then go to **Alarm › Alarm Notifications › Notification Groups › Create Notification Group**:

| Field | Value |
| --- | --- |
| Group name (required) | `Flashduty` |
| Notification objects (required) | Select the `flashduty` object you created |

Click `OK` to create the notification group.

<img src="https://download.flashcat.cloud/flashduty/doc/en/hw/hw-2.png" alt="Create a notification group" width="500"/>

When you create the group, Huawei Cloud sends a request to Flashduty to verify the push URL. In the group's object list, confirm that the object status is `Confirmed`. Otherwise, alerts aren't pushed.

</Tab>
</Tabs>

</Step>
<Step title="Use the channel in a Huawei Cloud CES alarm rule">

**Where**: Huawei Cloud console › Cloud Eye Service › Alarm › Rule Configuration › Create Alarm Rule

In earlier console versions this menu is **Alarm › Alarm Rules**.

| Field | Value |
| --- | --- |
| Send notifications (required) | On |
| Notification method (required) | The new console offers `Notification Policy` / `Contact Group` / `Topic Subscription`; `Topic Subscription` with the `Flashduty` topic is recommended. In the legacy console, set the notification group to `Flashduty` |
| Trigger condition (required) | For metric alarms select both `Alarm Triggered` and `Cleared`; event alarms support only `Alarm Triggered` |
| Effective time (optional) | Available with contact group or topic subscription, for example 08:00-20:00 |

Click `OK` to save.

<img src="https://download.flashcat.cloud/flashduty/doc/en/hw/hw-3.png" alt="Select the Flashduty notification channel in an alarm rule" width="500"/>

</Step>
<Step title="Trigger an alarm and confirm">

**Where**: Huawei Cloud console › Cloud Eye Service › Alarm › Rule Configuration

When the alarm rule triggers (or recovers), Huawei Cloud pushes the event to Flashduty.
{/* console:
The checklist item "Receive the first event" is then complete as well.
*/}
After a few seconds, go back to Flashduty. If the integration shows a **Latest event time**, the setup works.

</Step>
</Steps>
