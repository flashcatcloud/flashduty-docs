Sync Huawei Cloud CES alerts to Flashduty through webhook to achieve automated alert noise reduction.

<div class="hide">

## In Flashduty
You can get the integration push URL in either of the following ways.

### Use a dedicated integration

Choose this option if all alerts go to one channel. It's the simpler setup.

<AccordionGroup>
  <Accordion title="View dedicated integration setup steps">
  
  1. In the Flashduty console, select **Channel** and open a channel
  2. Select **Configuration** → **Integrations** → **Private integration**, then click **Add an integration**
  3. Choose **Huawei Cloud CES** integration and click **Save** to generate a card
  4. Open the generated integration card and copy the **Push URL**
  
</Accordion>
</AccordionGroup>

### Use a shared integration

Choose this option if you need to route alerts to different channels based on the alert payload.

<AccordionGroup>
  <Accordion title="View shared integration setup steps">
  
  1. In the Flashduty console, go to **Integration Center → Alerts**
  2. Select **Huawei Cloud CES** integration:
        - **Integration Name**: Define a name for this integration
  3. Configure the default route and select a channel. You can add more rules under **Routing** after creation
  4. Click **Save** and copy the generated **Push URL**
    
</Accordion>
</AccordionGroup>
</div>

## In Huawei Cloud CES
<div class="md-block">

1. Log in to the Huawei Cloud console, then search for and open `Cloud Eye Service`
2. Go to `Alarm-Alarm Notifications-Notification Objects` and click `Create Notification Object`
3. Set the protocol to `HTTPS`, the name to `flashduty`, and the endpoint to the integration push URL (generated after you name and save the integration in Flashduty)
4. Click `OK`

   <img src="https://download.flashcat.cloud/flashduty/doc/en/hw/hw-1.png" alt="drawing" width="500"/>

5. Go to `Alarm-Alarm Notifications-Notification Groups` and click `Create Notification Group`
6. Set the group name to `Flashduty` and select the `flashduty` notification object you created
7. Click `OK`

   <img src="https://download.flashcat.cloud/flashduty/doc/en/hw/hw-2.png" alt="drawing" width="500"/>

   When you create the group, Huawei Cloud sends a request to Flashduty to verify the push URL. In the group's object list, confirm that the object status is `Confirmed`. Otherwise, alerts aren't pushed

8. Go to `Alarm-Alarm Rules`, and edit or create an alarm rule to open its `Alarm Rule Details` page
9. Set the notification group to `Flashduty`, select both `Alarm Triggered` and `Cleared`, and click `OK`

   <img src="https://download.flashcat.cloud/flashduty/doc/en/hw/hw-3.png" alt="drawing" width="500"/>

10. Return to the integration list in the Flashduty console. If the integration shows a latest event time, the setup works

</div>

## Status mapping
<div class="md-block">

Huawei Cloud CES to Flashduty alert severity mapping:

| CES      | Flashduty | Status   |
| -------- | --------- | -------- |
| Critical | Critical  | critical |
| Major    | Critical  | critical |
| Minor    | Warning   | warning  |
| Info     | Info      | info     |
