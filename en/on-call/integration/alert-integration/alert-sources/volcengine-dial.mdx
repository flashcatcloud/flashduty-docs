Sync Volcengine Cloud-Detect alert events to Flashduty through webhook.

<div className="hide">

## In Flashduty On-call
You can get the integration push URL in either of the following ways.

### Use a dedicated integration

Choose this option if all alerts go to one channel. It's the simpler setup.

<AccordionGroup>
  <Accordion title="View dedicated integration setup steps">
  
  1. In the Flashduty console, select **Channel** and open a channel
  2. Select **Configuration** → **Integrations** → **Private integration**, then click **Add an integration**
  3. Choose **Volcengine Detect** integration and click **Save** to generate a card
  4. Open the generated integration card and copy the **Push URL**
  
</Accordion>
</AccordionGroup>

### Use a shared integration

Choose this option if you need to route alerts to different channels based on the alert payload.

<AccordionGroup>
  <Accordion title="View shared integration setup steps">
  
  1. In the Flashduty console, go to **Integration Center → Alert Events**
  2. Select **Volcengine Detect** integration:
        - **Integration Name**: Define a name for this integration
  3. Configure the default route and select a channel. You can add more rules under **Routing** after creation
  4. Click **Save** and copy the generated **Push URL**
    
</Accordion>
</AccordionGroup>
</div>

An alert recovers when `alert_type` in the callback is `recovery`. Volcengine's alert policy settings list no recovery-notification switch, so whether a recovery is sent follows Cloud-Detect's actual behavior.

## Configure in Volcengine Cloud-Detect

<Steps>
<Step title="Create a system integration in Cloud-Detect">

**Where**: Cloud-Detect console › Alert Management › Notification Objects › System Integration › Create System Integration

| Field | Value |
| --- | --- |
| System Integration (required) | A name of your choice, for example `Flashduty` (1 to 256 characters: Chinese characters, letters, digits or underscores; must be unique) |
| Callback URL (required) | `{integration_url}` |

Click `OK`. Cloud-Detect sends a POST request with a JSON alert notification to this URL.

<img alt="Create a system integration in Cloud-Detect" width="600" src="https://download.flashcat.cloud/flashduty/doc/zh/fd/volcengine-1.png" />

</Step>
<Step title="Select the system integration in an alert policy">

**Where**: Cloud-Detect console › Alert Management › Alert Policies › Create Alert Policy (or edit an existing one) › Configure Notification Rules

| Field | Value |
| --- | --- |
| Notification method (required) | Check **System Integration** |
| Select integrated system (required) | Select the `Flashduty` integration created in the previous step |
| Other options (optional) | Configure as needed |

Click `OK`.

<img alt="Select the system integration in the alert policy" width="600" src="https://download.flashcat.cloud/flashduty/doc/zh/fd/volcengine-2.png" />

</Step>
<Step title="Trigger an alert and confirm">

**Where**: Cloud-Detect console › Alert Management › Alert Policies

Wait for a probe task to trigger the policy (you can lower the alert threshold temporarily to trigger it once).

Back in Flashduty, the integration shows a **Latest event time**, which means the setup works.
{/* console:
The checklist item "Receive the first event" also turns green.
*/}

</Step>
</Steps>
