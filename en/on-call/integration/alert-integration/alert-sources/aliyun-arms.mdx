Sync Alibaba Cloud ARMS monitoring alerts to Flashduty through webhook.

<div className="hide">

## In Flashduty On-call
You can get the integration push URL in either of the following ways.

### Use a dedicated integration

Choose this option if all alerts go to one channel. It's the simpler setup.

<AccordionGroup>
  <Accordion title="View dedicated integration setup steps">
  
  1. In the Flashduty console, select **Channel** and open a channel
  2. Select **Configuration** → **Integrations** → **Private integration**, then click **Add an integration**
  3. Choose **Alibaba Cloud ARMS** integration and click **Save** to generate a card
  4. Open the generated integration card and copy the **Push URL**
  
</Accordion>
</AccordionGroup>

### Use a shared integration

Choose this option if you need to route alerts to different channels based on the alert payload.

<AccordionGroup>
  <Accordion title="View shared integration setup steps">
  
  1. In the Flashduty console, go to **Integration Center → Alerts**
  2. Select **Alibaba Cloud ARMS** integration:
        - **Integration Name**: Define a name for this integration
  3. Configure the default route and select a channel. You can add more rules under **Routing** after creation
  4. Click **Save** and copy the generated **Push URL**
  
</Accordion>
</AccordionGroup>
</div>

## In Alibaba Cloud ARMS

<Steps>
<Step title="Create a Webhook notification target in ARMS">

**Where**: ARMS console › Alert Management › Notification Target › Webhook Integration › New Webhook

| Field | Value | Required |
| --- | --- | --- |
| Target name | Your choice, for example `Flashduty` | Required |
| Request method | `Post` | Required |
| Push URL | `{integration_url}` | Required |
| Header | Key `Content-Type`, Value `application/json` | Required |
| Notification template | `$alertmanager_content` | Required |
| Recovery template | `$alertmanager_content` | Required |

Click **Confirm** to save.

<img src="https://download.flashcat.cloud/flashduty/doc/en/aliyun/arms-1.png" alt="Creating a Webhook notification target in ARMS" width="500"/>

</Step>
<Step title="Configure a notification policy in ARMS">

**Where**: ARMS console › Alert Management › Notification Policy › New Notification Policy

Click **New Notification Policy**, or edit an existing policy. Under `Notification Target`, select the `Generic Webhook` target you created, then save.

<img src="https://download.flashcat.cloud/flashduty/doc/en/aliyun/arms-2.png" alt="Selecting the Webhook target in an ARMS notification policy" width="500"/>

</Step>
<Step title="Send a test and confirm">

**Where**: ARMS console › Alert Management › Notification Target › Webhook Integration › New Webhook › Send Test

**Send Test** in ARMS cannot substitute `$alertmanager_content`, so it only checks connectivity and does not verify event content. Wait for a real alert to trigger. Go back to Flashduty. If the integration shows a **Latest event time**, the setup works.
{/* console:
The checklist item "Receive the first event" is then complete as well.
*/}

</Step>
</Steps>
