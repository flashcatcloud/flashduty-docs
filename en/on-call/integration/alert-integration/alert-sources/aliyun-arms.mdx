Sync Alibaba Cloud ARMS monitoring alerts to Flashduty through webhook for automated alert noise reduction.

<div class="hide">

## In Flashduty
You can get the integration push URL in either of the following ways.

### Use a dedicated integration

Choose this option if all alerts go to one channel. It's the simpler setup.

<AccordionGroup>
  <Accordion title="View dedicated integration setup steps">
  
  1. In the Flashduty console, select **Channel** and open a channel
  2. Select **Configuration** → **Integrations** → **Private integration**, then click **Add an integration**
  3. Choose **Alibaba Cloud ARMS** integration and click **Save** to generate a card
  4. Open the generated integration card and copy the **Push URL**
  
</Accordion>
</AccordionGroup>

### Use a shared integration

Choose this option if you need to route alerts to different channels based on the alert payload.

<AccordionGroup>
  <Accordion title="View shared integration setup steps">
  
  1. In the Flashduty console, go to **Integration Center → Alerts**
  2. Select **Alibaba Cloud ARMS** integration:
        - **Integration Name**: Define a name for this integration
  3. Configure the default route and select a channel. You can add more rules under **Routing** after creation
  4. Click **Save** and copy the generated **Push URL**
  
</Accordion>
</AccordionGroup>
</div>

## In Alibaba Cloud ARMS
**Step 1: Configure notification target**

<div class="md-block">

1. Log in to the Alibaba Cloud console and open ARMS
2. Go to `Alert Management -> Notification Target` page, select `Webhook Integration`, and click **New Webhook**
3. Set the target name, select `Post`, and paste the integration push URL
4. Add `Header`, enter `Content-Type` and `application/json`
5. Enter `$alertmanager_content` in the notification template
6. Click **Confirm**

<img src="https://download.flashcat.cloud/flashduty/doc/en/aliyun/arms-1.png" alt="drawing" width="500"/>


**Step 2: Configure notification policy**

1. Go to `Alert Management -> Notification Policy`, and click **New Notification Policy** or edit an existing policy
2. Under `Notification Target`, select the `Generic Webhook` target you created
3. Save and wait for alerts to trigger

<img src="https://download.flashcat.cloud/flashduty/doc/en/aliyun/arms-2.png" alt="drawing" width="500"/>

</div>
