Sync Uptime Kuma alert events to Flashduty through webhook for automated alert noise reduction.

<div class="hide">

## In Flashduty
You can get the integration push URL in either of the following ways.

### Use a dedicated integration

Choose this option if all alerts go to one channel. It's the simpler setup.

<AccordionGroup>
  <Accordion title="View dedicated integration setup steps">
  
  1. In the Flashduty console, select **Channel** and open a channel
  2. Select **Configuration** → **Integrations** → **Private integration**, then click **Add an integration**
  3. Select **Uptime Kuma** integration and click **Save** to generate a card
  4. Open the generated integration card and copy the **Push URL**
  
</Accordion>
</AccordionGroup>

### Use a shared integration

Choose this option if you need to route alerts to different channels based on the alert payload.

<AccordionGroup>
  <Accordion title="View shared integration setup steps">
  
  1. In the Flashduty console, go to **Integration Center → Alert Events**
  2. Select **Uptime Kuma** integration:
        - **Integration Name**: Define a name for this integration
  3. Configure the default route and select a channel. You can add more rules under **Routing** after creation
  4. Click **Save** and copy the generated **Push URL**
    
</Accordion>
</AccordionGroup>

</div>

## In Uptime Kuma

**Step 1: Set up notification channel**

1. Go to `Settings -> Notifications` page, click Setup to edit, as shown below;
2. Select `Flashduty (Flashduty)` as the `Notification Type`;
3. Copy and paste the integration_key parameter value from the integration push URL into `Integration Key`;
4. Select `Severity` as needed;
5. Submit and save

<img src="https://download.flashcat.cloud/flashduty/doc/en/upk/upk-1.png" alt="drawing" width="500"/>

**Step 2: Configure monitoring items**

<div class="md-block">

1. Click `Add New Monitor` or edit existing monitors, configure monitoring settings as needed;
2. Enable the notification method created in the previous step in the `Notifications` section;
3. If needed, add `Tags`. Note that only tags with both Key/Value will be pushed to Flashduty;
4. Submit and save, then wait for alerts to trigger.

<img src="https://download.flashcat.cloud/flashduty/doc/en/upk/upk-2.png" alt="drawing" width="500"/>

</div>
