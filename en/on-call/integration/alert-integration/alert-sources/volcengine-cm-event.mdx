Sync Volcengine Cloud Monitor Event Center alert events to Flashduty through webhook.

<div className="hide">

## In Flashduty On-call
You can get the integration push URL in either of the following ways.

### Use a dedicated integration

Choose this option if all alerts go to one channel. It's the simpler setup.

<AccordionGroup>
  <Accordion title="View dedicated integration setup steps">
  
  1. In the Flashduty console, select **Channel** and open a channel
  2. Select **Configuration** → **Integrations** → **Private integration**, then click **Add an integration**
  3. Choose **Volcengine CM Event** integration and click **Save** to generate a card
  4. Open the generated integration card and copy the **Push URL**
  
</Accordion>
</AccordionGroup>

### Use a shared integration

Choose this option if you need to route alerts to different channels based on the alert payload.

<AccordionGroup>
  <Accordion title="View shared integration setup steps">
  
  1. In the Flashduty console, go to **Integration Center → Alert Events**
  2. Select **Volcengine CM Event** integration:
        - **Integration Name**: Define a name for this integration
  3. Configure the default route and select a channel. You can add more rules under **Routing** after creation
  4. Click **Save** and copy the generated **Push URL**
    
</Accordion>
</AccordionGroup>
</div>

## Configure in Volcengine Cloud Monitor

<Steps>
<Step title="Create a Flashduty callback URL in Cloud Monitor">

<Tabs>
<Tab title="New console (notification policies)">

**Where**: Cloud Monitor console › Notification › Notification Policies › Notification Objects › Callback URLs › Create Callback URL

| Field | Value |
| --- | --- |
| Callback URL name (required) | `Flashduty_Event` (unique identifier, no duplicates) |
| Channel (required) | General callback URL channel |
| Callback URL (required) | `{integration_url}` |
| Custom Token / Custom Header (optional) | Leave empty if no authentication is needed |

Click `Connectivity Test` at the bottom left if you like, then click `OK` at the bottom right.

</Tab>
<Tab title="Old console (notification groups)">

**Where**: Cloud Monitor console › Notification Groups › Callback › Create Callback URL

| Field | Value |
| --- | --- |
| Callback URL name (required) | `Flashduty_Event` |
| Callback URL type (required) | General Callback URL |
| Callback URL (required) | `{integration_url}` |

Click `Confirm` to finish. The old console does not support connectivity testing; even if the test shows a connectivity failure, it won't affect alert reception.

<img src="https://download.flashcat.cloud/flashduty/doc/en/volcengine/event-1.png" alt="Create callback URL" width="500"/>

<img src="https://download.flashcat.cloud/flashduty/doc/en/volcengine/event-2.png" alt="Fill in the callback URL" width="500"/>

</Tab>
</Tabs>

</Step>
<Step title="Select the callback URL in an event rule">

**Where**: Cloud Monitor console › Event Center › Event Rules › Create Event Rule (or edit an existing one)

| Field | Value |
| --- | --- |
| Event rule (required) | Configure event types and conditions as needed |
| Delivery channel (required) | Check **Alert Callback** |
| Alert callback (required) | Select `Flashduty_Event` created in the previous step from the dropdown |

Click `Confirm` after finishing.

<img src="https://download.flashcat.cloud/flashduty/doc/en/volcengine/metric-3.png" alt="Select the alert callback in the event rule" width="500"/>

</Step>
<Step title="Trigger an alert and confirm">

**Where**: Cloud Monitor console › Event Center › Event Rules › your rule

Trigger a cloud product event that matches the event rule, or wait for a real one; event rules have no "send test" button.

Back in Flashduty, the integration shows a **Latest event time**, which means the setup works.
{/* console:
The checklist item "Receive the first event" also turns green.
*/}

</Step>
</Steps>
