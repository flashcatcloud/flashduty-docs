Sync OceanBase alert events to Flashduty through webhook

<div className="hide">

## In Flashduty On-call
You can get the integration push URL in either of the following ways.

### Use a dedicated integration

Choose this option if all alerts go to one channel. It's the simpler setup.

<AccordionGroup>
  <Accordion title="View dedicated integration setup steps">
  
  1. In the Flashduty console, select **Channel** and open a channel
  2. Select **Configuration** → **Integrations** → **Private integration**, then click **Add an integration**
  3. Choose **OceanBase** integration and click **Save** to generate a card
  4. Open the generated integration card and copy the **Push URL**
  
</Accordion>
</AccordionGroup>

### Use a shared integration

Choose this option if you need to route alerts to different channels based on the alert payload.

<AccordionGroup>
  <Accordion title="View shared integration setup steps">
  
  1. In the Flashduty console, go to **Integration Center → Alert Events**
  2. Select **OceanBase** integration:
        - **Integration Name**: Define a name for this integration
  3. Configure the default route and select a channel. You can add more rules under **Routing** after creation
  4. Click **Save** and copy the generated **Push URL**
    
</Accordion>
</AccordionGroup>
</div>

## In OceanBase

<Steps>
<Step title="Create an alert channel in OceanBase">

**Where**: OceanBase OCP console › Alert Center › Alert Channels › New Channel

| Field | Value |
| --- | --- |
| Channel type (required) | `Custom Script` |
| Basic settings (required) | Channel name and so on, as shown below |
| Channel configuration (required) | Copy the script below |
| Response validation (required) | `{}` |
| Alert message format (required, under Message Configuration) | `Markdown` |
| Alert message template (required) | Select **Simplified Chinese**, fill in the template below, and submit |

<img alt="drawing" width="600" src="https://fcpub-1301667576.cos.ap-nanjing.myqcloud.com/flashduty/doc/oceanbase-1.png" />

Copy the following script content into the channel configuration. In the console, `address` and `INTEGRATION_KEY` in the script are filled in with the push domain and integration_key of the current integration; if you are reading this on the docs site, set `INTEGRATION_KEY` to the integration_key value from your Flashduty push URL. The script compares the Chinese level and status names that OCP sends (for example 停服 and 严重), so the message template and push language must be Simplified Chinese.

```
#!/usr/bin/env bash

function sendToFlashduty() {
    URL="${address}/event/push/alert/standard?integration_key=${INTEGRATION_KEY}"
    curl -s -X POST ${URL} -H 'Content-Type: application/json' -d '{
        "event_status": "'${alert_level}'",
        "alert_key": "'${alarm_id}'",
        "description": "'"${alarm_description//\"/\\\"}"'",
        "title_rule": "$app_types::$name::$alarm_targets",
        "event_time":'${timestamp}',
        "labels": {
            "app_types":"'${app_type}'",
            "id":"'${alarm_id}'",
            "name":"'${alarm_name}'",
            "alarm_level":"'${alarm_level}'",
            "alarm_status":"'${alarm_status}'",
            "alarm_active_at":"'${alarm_active_at}'",
            "alarm_threshold":"'${alarm_threshold}'",
            "alarm_type":"'${alarm_type}'",
            "alarm_targets":"'${alarm_target}'",
            "ob_cluster_group":"'${ob_cluster_group}'",
            "ob_cluster":"'${ob_cluster}'",
            "hostIP":"'${host_ip}'",
            "app_cluster":"'${app_cluster}'",
            "alarm_description":"'"${alarm_description//\"/\\\"}"'",
            "alarm_url":"'${alarm_url}'"
        }
    }'

    return $?
}

alarm_name=$(echo ${alarm_name} | sed  "s/ /_/g")
alarm_target=$(echo ${alarm_target} | sed  "s/ /_/g")

timestamp=$(TZ=UTC date -d "${alarm_updated_at}" +%s)

levelMd5=$(echo ${alarm_level} | md5sum | awk '{print$1}')
statusMd5=$(echo ${alarm_status} | md5sum | awk '{print$1}')

active="048d106318302b41372b4292b5696ad4"
Inactive="bf7da164d431439fe9668fbc964110c4"

down="2e1558b0a152fae2dd15884561b1508d"
critical="59b9b38574ca2ee4f5e264b56f49a83f"
alert="723931b03a5d1cec59eac40cf0703580"   
caution="abf4d55ba8926eff32cb44065e634ed3"
info="6aae3f4254789d72aa0cc8ed55b8f11f"

address="{api_host}"
INTEGRATION_KEY="{integration_key}"

if [[ ${statusMd5} == ${Inactive} ]];then
    alert_level="Ok"
    timestamp=$(TZ=UTC date -d "${alarm_resolved_at}" +%s)
elif [[ ${statusMd5} == "${active}" ]];then
    if [[ ${levelMd5} == ${down} || ${levelMd5} == ${critical} ]];then
        alert_level="Critical"
    elif [[ ${levelMd5} == ${alert} ]];then
        alert_level="Warning"
    elif [[ ${levelMd5} == ${caution}  ||  ${levelMd5} == ${info} ]];then
        alert_level="Info"
    fi
fi

if [[ ${statusMd5} == ${active} || ${statusMd5} == ${Inactive} ]];then
    sendToFlashduty
fi
```

Alert message template:

```
OCP Alert Notification - Single Alert
- Alert ID: ${alarm_id}
- Name: ${alarm_name}
- Severity: ${alarm_level}
- Alert Target: ${alarm_target}
- Service: ${service}
- Summary: ${alarm_summary}
- Triggered at: ${alarm_active_at}
- Updated at: ${alarm_updated_at}
- Resolved at: ${alarm_resolved_at}
- Details: ${alarm_description}
- Status: ${alarm_status}
- Alert Type: ${alarm_type}
- Alert Threshold: ${alarm_threshold}
- Cluster Group: ${ob_cluster_group}
- Cluster: ${ob_cluster}
- Host: ${host_ip}
- App Cluster: ${app_cluster}
- OCP Link: ${alarm_url}
```

<Step title="Trigger an alert and confirm Flashduty receives the event">

**Where**: OceanBase OCP console › Alert Center

The script relies on variables OCP injects into real alerts, so wait for a real alert within the subscription scope; alerts in a shielded or suppressed state are not pushed. After a few seconds, go back to Flashduty. If the integration shows a **Latest event time**, the setup works. With recovery notification enabled, an `Ok` event is pushed when the alert recovers and the corresponding alert in Flashduty recovers automatically.

## Status and severity

<div class="md-block">
  
| OceanBase | Flashduty |
| --- | --- |
| Down | Critical |
| Critical | Critical |
| Warning | Warning |
| Caution | Info |
| Notice | Info |

</div>

The script pushes only when the alert is active or recovered: active alerts use the mapping above, recovered alerts push `Ok`; shielded or suppressed alerts are not pushed.
