Sync Meraki alert events to Flashduty through webhook for automated alert noise reduction.

<div class="hide">

## In Flashduty
You can get the integration push URL in either of the following ways.

### Use a dedicated integration

Choose this simpler option when you don't need to route alert events to different channels.

<AccordionGroup>
  <Accordion title="View dedicated integration setup steps">
  
  1. Go to the Flashduty console, select **Channel**, and enter a channel's details page
  2. Select **Configuration** → **Integrations** → **Private integration**, then click **Add an integration**
  3. Choose **Meraki** integration, click **Save** to generate a card
  4. Click the generated card to view the **push URL**, copy it for later use, and you're done
  
</Accordion>
</AccordionGroup>

### Use a shared integration

Choose this option when you need to route alerts to different channels based on the alert event payload.

<AccordionGroup>
  <Accordion title="View shared integration setup steps">
  
  1. In the Flashduty console, go to **Integration Center → Alert Events**
  2. Select **Meraki** integration:
        - **Integration Name**: Define a name for this integration
  3. Configure the default route and select a channel. You can add more rules under **Routes** after creation
  4. Click **Save** and copy the generated **Push URL**
    
</Accordion>
</AccordionGroup>
</div>

## In Meraki

<div class="md-block">


1. Log in to your `Meraki` console and select the device you want to configure alerts for
2. On the `Alerts` page, configure `Cellular gateway` and other sections as needed
3. Under `Webhooks`, configure `HTTPS receivers`
4. Enter `Flashduty` for `Name`, and enter the **integration push URL** for `URL`
5. Leave `Shared secret` empty, and keep `Payload template` as the default `Meraki(included)`
6. Click `Save` to save the settings
