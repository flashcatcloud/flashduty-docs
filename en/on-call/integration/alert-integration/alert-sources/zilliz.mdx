Sync Zilliz alert events to Flashduty through webhook.

<div className="hide">

## In Flashduty On-call
You can get the integration push URL in either of the following ways.

### Use a dedicated integration

Choose this option if all alerts go to one channel. It's the simpler setup.

<AccordionGroup>
  <Accordion title="View dedicated integration setup steps">
  
  1. In the Flashduty console, select **Channel** and open a channel
  2. Select **Configuration** → **Integrations** → **Private integration**, then click **Add an integration**
  3. Choose **Zilliz** integration and click **Save** to generate a card
  4. Open the generated integration card and copy the **Push URL**

</Accordion>
</AccordionGroup>

### Use a shared integration

Choose this option if you need to route alerts to different channels based on the alert payload.

<AccordionGroup>
  <Accordion title="View shared integration setup steps">
  
  1. In the Flashduty console, go to **Integration Center → Alert Events**
  2. Select **Zilliz** integration:
        - **Integration Name**: Define a name for this integration
  3. Configure the default route and select a channel. You can add more rules under **Routing** after creation
  4. Click **Save** and copy the generated **Push URL**
    
</Accordion>
</AccordionGroup>
</div>

## In Zilliz

<Steps>
<Step title="Create an alert in Zilliz Cloud and add a webhook channel">

**Where**: Zilliz Cloud console › Project Alerts › Alert Settings › + Alert (to change an existing alert, click Edit in the Actions column)

You must be an organization owner or a project admin.

| Field | Value |
| --- | --- |
| Send to (Required) | Click `+ Channel`, choose `Webhook`, and enter `{integration_url}` as the URL |
| Alert Resolution Notification (Recommended) | Select it so Zilliz sends recovery notifications |
| Enable Alert (Optional) | Set other options as needed |

Click `Save` or `Create` to complete the configuration.

<img alt="drawing" width="600" src="https://download.flashcat.cloud/flashduty/doc/zh/fd/zilliz-1.png" />

</Step>
<Step title="Test and confirm with a real alert">

**Where**: Zilliz Cloud console › Project Alerts › Alert Settings › alert edit page › Send to

Next to the webhook channel there is a **Send Test Message** icon, which confirms the push URL is reachable. A test message may not carry every field of a real alert, so whether it creates an event in Flashduty depends on the actual result; verify trigger and recovery with a real alert as well.

After a few seconds, go back to Flashduty. If the integration shows a **Latest event time**, the setup works.
{/* console:
The checklist item "Receive the first event" is then complete as well.
*/}

</Step>
</Steps>

## Status and severity

<div class="md-block">

| Zilliz | Flashduty |
| --------- | --------- |
| CRITICAL | Critical |
| WARNING | Warning |
| Others or empty | Info |

When `status` is `NOT_TRIGGERED`, Flashduty treats the event as a recovery (Ok) and closes the matching alert.

</div>
