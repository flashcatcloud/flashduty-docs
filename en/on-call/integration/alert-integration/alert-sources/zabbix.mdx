Synchronize Zabbix alert events to Flashduty through webhook (supports Zabbix 3.x–7.x versions, with different configuration requirements).

<div className="hide">

## In Flashduty On-call

You can get the integration push URL in either of the following ways.

### Use a dedicated integration

Choose this option if all alerts go to one channel. It's the simpler setup.

<AccordionGroup>
  <Accordion title="View dedicated integration setup steps">
  
  1. In the Flashduty console, select **Channel** and open a channel
  2. Select **Configuration** → **Integrations** → **Private integration**, then click **Add integration**
  3. Choose **Zabbix** integration, click **Save** to generate a card
  4. Open the generated integration card and copy the **Push URL**
  
</Accordion>
</AccordionGroup>

### Use a shared integration

Choose this method when you need to route alerts to different channels based on alert event payload information.

<AccordionGroup>
  <Accordion title="View shared integration setup steps">
  
  1. In the Flashduty console, go to **Integration Center → Alert Events**
  2. Select **Zabbix** integration:
        - **Integration Name**: Define a name for this integration
  3. Configure the default route and select a channel. You can add more rules under **Routing** after creation
  4. Click **Save** and copy the generated **Push URL**
    
</Accordion>
</AccordionGroup>
</div>

### Zabbix 7.x

#### Step 1: Import the Flashduty media type in Zabbix

A media type is the channel Zabbix uses to send notifications. The download URL requires a `Referer` header and returns 403 without it, so keep the `--header` option in the command.

**Where**: Zabbix › Alerts › Media types › Import

1. Download the configuration file in a terminal:

   ```bash
   wget --header="Referer: https://console.flashcat.cloud" https://download.flashcat.cloud/flashduty/integration/zabbix/zbx_mediatype_flashcat_v7.yml
   ```

2. On the **Import** page, select the file and click **Import**
3. In the **Media types** list, click the imported media type's name, fill in the parameters below, and click **Update**:

   | Parameter | Value |
   | --- | --- |
   | `URL` (required) | `{integration_url}` |
   | `zabbix_url` (optional) | Your Zabbix console URL, including any tomcat/nginx forwarding path. The system appends parameters such as trigger_id to build the alert details link |
   | `HTTPProxy` (optional) | A proxy address, if Zabbix Server can't reach Flashduty directly |

   <img alt="7.x: fill in URL, zabbix_url, and HTTPProxy for the media type" width="600" src="https://download.flashcat.cloud/flashduty/doc/zabbix-2.png" />

#### Step 2: Add the Flashduty media to a user in Zabbix

**Where**: Zabbix › Users › Users › Admin › Media › Add

A media type must be linked to a user to send events, and the user needs at least read permission on the hosts. We recommend linking it to the Admin user.

| Field | Value |
| --- | --- |
| Type (required) | The Flashduty media type from the previous step |
| Send to (required) | `Flashduty` |
| Other fields | Keep the defaults |

Click **Add** to close the dialog, then click **Update** to save the user.

<img alt="Zabbix 7.x: add media to the user" width="600" src="https://download.flashcat.cloud/flashduty/doc/zabbix-3.png" />

#### Step 3: Create a trigger action that sends to Flashduty in Zabbix

**Where**: Zabbix › Alerts › Actions › Trigger actions › Create action

1. Set **Name** to `Send To Flashduty`
2. Under **Operations**, configure **Operations**, **Recovery operations**, and **Update operations**. For each, click **Add**, fill in the fields, and click **Add** again:

   | Field | Value |
   | --- | --- |
   | Send to users | The user you added the media to in the previous step |
   | Send only to (Send to media type from 7.0.7) | The Flashduty media type |
   | Other fields | Keep the defaults |

3. Click **Add** to save the action

<img alt="Zabbix 7.x: configure the action notifications" width="600" src="https://download.flashcat.cloud/flashduty/doc/zabbix-5.png" />

#### Step 4: Trigger an alert in Zabbix and confirm

**Where**: Zabbix › Monitoring › Problems › Actions

The **Test** link in the **Media types** list sends the raw macros (such as `{EVENT.SEVERITY}`) as parameter values, and Flashduty rejects the request because the severity is invalid. Verify with a real alert instead:

1. Wait for or cause an alert that fires the action. In **Monitoring › Problems**, click the alert's **Actions** column to see the notification results
2. If the Flashduty media type's entry shows Status `Sent`, the notification went out. Otherwise, follow the message to troubleshoot
3. Go back to Flashduty. If the integration shows a **Latest event time**, the setup works

{/* console:
The checklist item "Receive the first event" is then complete as well.
*/}

<img alt="Zabbix 7.x: view notification results" width="600" src="https://download.flashcat.cloud/flashduty/doc/zabbix-6.png" />

### Zabbix 3.x–4.x

#### Step 1: Create the Flashduty media type and install the script

A media type is the channel Zabbix uses to send notifications. The download URL requires a `Referer` header and returns 403 without it, so keep the `--header` option in the command.

**Where**: Zabbix › Administration › Media types › Create media type

1. Set **Type** to `Script` and **Script name** to `send-to-flashduty.sh`
2. Enter these five **Script parameters** in order. Don't reorder them, and leave empty ones blank; the script reads them by position:

   | Order | Value |
   | --- | --- |
   | 1 | `{ALERT.SUBJECT}` (alert title) |
   | 2 | `{ALERT.MESSAGE}` (alert message) |
   | 3 (required) | `{integration_url}` |
   | 4 (optional) | Your Zabbix console URL, including any tomcat/nginx forwarding path, used to build the alert details link; leave blank if none |
   | 5 (optional) | HTTPProxy: a proxy address, if Zabbix Server can't reach Flashduty directly; leave blank if none |

   <img alt="3.x–4.x: create a Script media type" width="600" src="https://download.flashcat.cloud/flashduty/integration/zabbix/v4_create_fd_media_type.jpg" />

3. Click **Update** to save
4. Log in to the Zabbix Server host and download the script to the alert scripts directory. The directory is set by `AlertScriptsPath` in the Zabbix Server configuration file, usually `/usr/lib/zabbix/alertscripts`:

   ```bash
   cd /usr/lib/zabbix/alertscripts
   wget --header="Referer: https://console.flashcat.cloud" https://download.flashcat.cloud/flashduty/integration/zabbix/send-to-flashduty.sh
   chmod +x send-to-flashduty.sh
   ```

   The script uses `curl` and `jq`. Make sure the Zabbix Server process can find and run both, and install them if needed.

#### Step 2: Add the Flashduty media to a user in Zabbix

**Where**: Zabbix › Administration › Users › Admin › Media › Add

A media type must be linked to a user to send events, and the user needs at least read permission on the hosts. We recommend linking it to the Admin user.

| Field | Value |

<img alt="Zabbix 3.x–4.x: add media to the user" width="600" src="https://download.flashcat.cloud/flashduty/integration/zabbix/v4_bind_media_type.jpg" />

#### Step 3: Create a trigger action that sends to Flashduty in Zabbix

**Where**: Zabbix › Configuration › Actions › Create action

1. Set **Name** to `Send To Flashduty`
2. Under **Operations**, configure **Operations**, **Recovery operations**, and **Update operations** (**Acknowledgement operations** on 3.x). For each, click **Add**, fill in the fields, and click **Add** again:

   | Field | Value |
   | --- | --- |
   | Send to users | The user you added the media to in the previous step |
   | Send only to | The Flashduty media type |
   | Other fields | Keep the defaults |

3. In the **Default message** of all three, **paste the following after the default content**. Flashduty parses this text to read the alert attributes:

   ```
   -----Flashduty Required Starts-----event_severity={TRIGGER.SEVERITY}||event_name={TRIGGER.NAME}||event_id={EVENT.ID}||event_tags={EVENT.TAGS}||event_ack={EVENT.ACK.STATUS}||event_value={EVENT.VALUE}||trigger_id={TRIGGER.ID}||trigger_desc={TRIGGER.DESCRIPTION}||trigger_expr={TRIGGER.EXPRESSION}||host_group={TRIGGER.HOSTGROUP.NAME}||host_ip={HOST.IP}||host_name={HOST.NAME}||item_name={ITEM.NAME}||item_value={ITEM.VALUE}-----Flashduty Required Ends-----
   ```

4. Click **Add** to save the action

<img alt="Zabbix 3.x–4.x: configure the action notifications" width="600" src="https://download.flashcat.cloud/flashduty/integration/zabbix/v4_create_action_operation_add.jpg" />

Zabbix to Flashduty severity mapping:

| Zabbix | Flashduty |
| -------------- | -------- |
| Disaster | Critical |
| High | Critical |
| Average | Warning |
| Warning | Warning |
| Information | Info |
| Not classified | Info |
