Sync Tencent Cloud Log Service (CLS) monitoring alerts to Flashduty through webhook for automated alert noise reduction.

<div class="hide">

## In Flashduty
You can get the integration push URL in either of the following ways.

### Use a dedicated integration

Choose this option if all alerts go to one channel. It's the simpler setup.

<AccordionGroup>
  <Accordion title="View dedicated integration setup steps">
  
  1. In the Flashduty console, select **Channel** and open a channel
  2. Select **Configuration** → **Integrations** → **Private integration**, then click **Add an integration**
  3. Choose **Tencent Cloud CLS** integration and click **Save** to generate a card
  4. Open the generated integration card and copy the **Push URL**
  
</Accordion>
</AccordionGroup>

### Use a shared integration

Choose this option if you need to route alerts to different channels based on the alert payload.

<AccordionGroup>
  <Accordion title="View shared integration setup steps">
  
  1. In the Flashduty console, go to **Integration Center → Alerts**
  2. Select **Tencent Cloud CLS** integration:
        - **Integration Name**: Define a name for this integration
  3. Configure the default route and select a channel. You can add more rules under **Routing** after creation
  4. Click **Save** and copy the generated **Push URL**
    
</Accordion>
</AccordionGroup>
</div>

## In Tencent Cloud CLS

**Step 1: Configure notification channel group**

<div class="md-block">

1. Log in to the Tencent Cloud console, open CLS, and go to **Monitoring Alerts - Notification Channel Groups**
2. Click `Create` to start

   <img alt="drawing" width="600" src="https://fcpub-1301667576.cos.ap-nanjing.myqcloud.com/flashduty/integration/tencent-cls/tencent-cls-notify.png" />

3. Enter a `Name`, set `Channel Type` to "Custom API Callback", enter the integration push URL in `Callback URL`, and set `Request Method` to POST

4. Click `OK` to save. Click `Add` to add more channels

</div>

**Step 2: Configure alert policy**

<div class="md-block">

1. Log in to the Tencent Cloud console, open CLS, and go to **Monitoring Alerts - Alert Policies**
2. Click `Create` to start

   <img alt="drawing" width="600" src="https://fcpub-1301667576.cos.ap-nanjing.myqcloud.com/flashduty/integration/tencent-cls/tencent-cls-alert.png" />

3. Enter an `Alert Name` and select a log topic

4. Enter a query in `Execution Statement` and select the query time range. Click **Preview** to check the results, and then enter the trigger condition

5. Set `Alert Level` to Critical, Warning, or Info based on severity, and set the execution cycle as needed

6. `Multi-dimensional Analysis` runs an extra search on the raw logs when an alert fires and attaches the results to the notification. It doesn't affect the trigger condition.

7. Under alert notifications, link the channel group you created in `Notification Channel Group`

</div>

**Step 3: Configure custom callback**

2. Add request headers as needed
