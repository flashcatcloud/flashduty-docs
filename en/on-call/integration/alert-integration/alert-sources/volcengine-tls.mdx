Sync Volcengine Log Service (TLS) alert events to Flashduty through webhook.

<div className="hide">

## In Flashduty On-call
You can get the integration push URL in either of the following ways.

### Use a dedicated integration

Choose this option if all alerts go to one channel. It's the simpler setup.

<AccordionGroup>
  <Accordion title="View dedicated integration setup steps">
  
  1. In the Flashduty console, select **Channel** and open a channel
  2. Select **Configuration** → **Integrations** → **Private integration**, then click **Add integration**
  3. Choose **Volcengine TLS** integration and click **Save** to generate a card
  4. Open the generated integration card and copy the **Push URL**
  
</Accordion>
</AccordionGroup>

### Use a shared integration

Choose this option if you need to route alerts to different channels based on the alert payload.

<AccordionGroup>
  <Accordion title="View shared integration setup steps">
  
  1. In the Flashduty console, go to **Integration Center → Alert Events**
  2. Select **Volcengine TLS** integration:
        - **Integration Name**: Define a name for this integration
  3. Configure the default route and select a channel. You can add more rules under **Routing** after creation
  4. Click **Save** and copy the generated **Push URL**
    
</Accordion>
</AccordionGroup>
</div>

## Configure in Volcengine Log Service (TLS)

<Steps>
<Step title="Create a webhook integration in TLS">

**Where**: TLS console › Common Functions › Log Alarm › Notification Management › Webhook Integration › Create Webhook Integration

| Field | Value |
| --- | --- |
| Name (required) | `Flashduty` |
| Notification channel type (required) | Custom Webhook |
| Request method (required) | `POST` |
| Request URL (required) | `{integration_url}` |
| Request headers (optional) | Keep the default `content-type: application/json` |

Click `Create`.

<img src="https://download.flashcat.cloud/flashduty/doc/en/volcengine/tls-1.png" alt="Create a webhook integration" width="500"/>

<img src="https://download.flashcat.cloud/flashduty/doc/en/volcengine/tls-2.png" alt="Fill in the webhook integration" width="500"/>

</Step>
<Step title="Create a content template in TLS">

**Where**: TLS console › Common Functions › Log Alarm › Notification Management › Content Templates › Create Content Template

| Field | Value |
| --- | --- |
| Template name (required) | `Flashduty` |
| Custom Webhook notification content (required) | The JSON template below |
| Content of other channels (optional) | Can be empty |

```
{
	"AccountID":"{{AccountID}}",
	"ProjectName":"{{ProjectName}}",
	"AlarmTopicName":"{{AlarmTopicName}}",
	"Region":"{{Region}}",
	"Alarm":"{{Alarm}}",
	"AlarmID":"{{AlarmID}}",
	"Duration":"{{Duration}}",
	"Condition":"{{Condition}}",
	"HappenThreshold":"{{HappenThreshold}}",
	"Topics":"{{Topics|join:','}}", 
	"NotifyTimeUnix":"{{NotifyTimeUnix}}",
	"NotifyType":"{{NotifyType}}",
	"Severity":"{{Severity}}",
	"ConsecutiveAlertNums":"{{ConsecutiveAlertNums}}",
	"TriggerParams":{{toJson(TriggerParams)|safe}}, 
	"ExecuteQuery":{{toJson(ExecuteQuery)|safe}},
	"DetailUrl":"{{DetailUrl}}",
	"FireResultsCount":"{{FireResultsCount}}"
}
```

The template must keep the `NotifyType` field: an alert recovers when `NotifyType` is `2`.

Click `Confirm`.

<img src="https://download.flashcat.cloud/flashduty/doc/en/volcengine/tls-3.png" alt="Create a content template" width="500"/>

</Step>
<Step title="Create a notification group in TLS">

**Where**: TLS console › Common Functions › Log Alarm › Notification Management › Notification Groups › Create Notification Group

| Field | Value |
| --- | --- |
| Notification group name (required) | `Flashduty` |
| Notification policy › Notification rules (optional) | Configure as needed |
| Notification policy › Notification channel › Channel type (required) | **Default channel**, keep **Custom Webhook** checked |
| Webhook (required) | Select `Flashduty` created in step 1 |
| Content template (required) | Select `Flashduty` created in step 2 |

Click `Create Notification Group`.

<img src="https://download.flashcat.cloud/flashduty/doc/en/volcengine/tls-4.png" alt="Create a notification group" width="500"/>

</Step>
<Step title="Associate the notification group in an alert policy">

**Where**: TLS console › Common Functions › Log Alarm › Alarm Policies › Create Alarm Policy (or edit an existing one)

| Field | Value |
| --- | --- |
| Alert rules (required) | Configure as needed |
| Notification group (required) | Click **Associate Notification Group**, choose `Flashduty` created in step 3 in the pop-up, then click `Associate` |

Click `Create` / `Save` after configuring other settings.

<img src="https://download.flashcat.cloud/flashduty/doc/en/volcengine/tls-5.png" alt="Associate the notification group in the alert policy" width="500"/>

</Step>
<Step title="Trigger an alert and confirm">

**Where**: TLS console › Common Functions › Log Alarm › Alarm Policies

Let the monitored logs match the alert rule (you can loosen the trigger condition temporarily), or wait for a real alert.

Back in Flashduty, the integration shows a **Latest event time**, which means the setup works.
{/* console:
The checklist item "Receive the first event" also turns green.
*/}

</Step>
</Steps>
