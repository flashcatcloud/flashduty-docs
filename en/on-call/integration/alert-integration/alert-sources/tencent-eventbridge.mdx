Sync Tencent Cloud EventBridge events to Flashduty through webhook.

<div className="hide">

## In Flashduty On-call
You can get the integration push URL in either of the following ways.

### Use a dedicated integration

Choose this option if all alerts go to one channel. It's the simpler setup.

<AccordionGroup>
  <Accordion title="View dedicated integration setup steps">
  
  1. In the Flashduty console, select **Channel** and open a channel
  2. Select **Configuration** → **Integrations** → **Private integration**, then click **Add integration**
  3. Choose **Tencent Cloud EventBridge** integration and click **Save** to generate a card
  4. Open the generated integration card and copy the **Push URL**
  
</Accordion>
</AccordionGroup>

### Use a shared integration

Choose this option if you need to route alerts to different channels based on the alert payload.

<AccordionGroup>
  <Accordion title="View shared integration setup steps">
  
  1. In the Flashduty console, go to **Integration Center → Alerts**
  2. Select **Tencent Cloud EventBridge** integration:
        - **Integration Name**: Define a name for this integration
  3. Configure the default route and select a channel. You can add more rules under **Routing** after creation
  4. Click **Save** and copy the generated **Push URL**
    
</Accordion>
</AccordionGroup>
</div>

## Configure Tencent Cloud EventBridge

<Steps>
<Step title="Create an event rule in EventBridge">

**Where**: Tencent Cloud console › EventBridge › 事件规则 (Event Rules) (select the region and event set at the top of the list) › 新建 (New)

| Field | Value |
| --- | --- |
| Rule name (required) | `Flashduty` |
| Event pattern (required) | Select specific events in form mode, or use JSON mode with the pattern below to match all events |

<img alt="New event rule in Tencent Cloud EventBridge" width="600" src="https://download.flashcat.cloud/tencent-eb-new-rule.png" />

JSON that matches all events:

```
{
  "source": [
    {
      "suffix": ".cloud.tencent"
    }
  ]
}
```

<img alt="Event pattern in Tencent Cloud EventBridge" width="600" src="https://download.flashcat.cloud/tencent-eb-match-rule.png" />

</Step>
<Step title="Set the event target to the Flashduty webhook">

**Where**: Tencent Cloud console › EventBridge › 事件规则 (Event Rules) › 新建 (New) › Next (event target)

| Field | Value |
| --- | --- |
| Target type (required) | `Message Push`. Only works for rules in a cloud-service event set, not custom event sets |
| Notification template (required) | `General Notification Template` |
| Language (required) | `English` |
| Delivery method (required) | `API Callback` › `Custom webhook` |
| Webhook address (required) | `{integration_url}` |

Click **Save**.

<img alt="Webhook event target in Tencent Cloud EventBridge" width="600" src="https://download.flashcat.cloud/tencent-eb-target-webhook.png" />

</Step>
<Step title="Send a test event and confirm">

**Where**: Tencent Cloud console › EventBridge › 事件集 (Event Sets) › your event set › 发送事件 (Send Event)

Select an event set and click **Send Event**.

<img alt="Sending a test event in Tencent Cloud EventBridge" width="600" src="https://download.flashcat.cloud/tencent-eb-test-send.png" />

Return to Flashduty. If the integration shows a **latest event time**, the setup works.
{/* console:
The "first event received" item in the setup checklist turns green as well.
*/}

</Step>
</Steps>

## Status and severity
<div class="md-block">
  
All Tencent Cloud EventBridge events correspond to "warning" severity level alerts in Flashduty.

</div>
