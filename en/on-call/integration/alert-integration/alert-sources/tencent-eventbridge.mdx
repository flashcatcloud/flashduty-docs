Sync Tencent Cloud EventBridge events to Flashduty through webhook for automated alert noise reduction.

<div class="hide">

## In Flashduty
You can get the integration push URL in either of the following ways.

### Use a dedicated integration

Choose this option if all alerts go to one channel. It's the simpler setup.

<AccordionGroup>
  <Accordion title="View dedicated integration setup steps">
  
  1. In the Flashduty console, select **Channel** and open a channel
  2. Select **Configuration** → **Integrations** → **Private integration**, then click **Add an integration**
  3. Choose **Tencent Cloud EventBridge** integration and click **Save** to generate a card
  4. Open the generated integration card and copy the **Push URL**
  
</Accordion>
</AccordionGroup>

### Use a shared integration

Choose this option if you need to route alerts to different channels based on the alert payload.

<AccordionGroup>
  <Accordion title="View shared integration setup steps">
  
  1. In the Flashduty console, go to **Integration Center → Alerts**
  2. Select **Tencent Cloud EventBridge** integration:
        - **Integration Name**: Define a name for this integration
  3. Configure the default route and select a channel. You can add more rules under **Routing** after creation
  4. Click **Save** and copy the generated **Push URL**
    
</Accordion>
</AccordionGroup>
</div>

## In Tencent Cloud EventBridge
<div class="md-block">

1. Log in to the Tencent Cloud console and open EventBridge
2. Go to the **Event Rules** page and click **New**
3. Set the name to Flashduty:

   <img alt="drawing" width="600" src="https://download.flashcat.cloud/tencent-eb-new-rule.png" />

4. For event matching, select specific events in form mode, or enter the following JSON to match all events:

   ```
   {
     "source": [
       {
         "suffix": ".cloud.tencent"
       }
     ]
   }
   ```

   As shown below:

   <img alt="drawing" width="600" src="https://download.flashcat.cloud/tencent-eb-match-rule.png" />

5. Next, configure the event target by selecting "Message Push", "General Notification Template", "English", "API Callback", and "Custom webhook". Enter the integration push URL in the webhook address field

   <img alt="drawing" width="600" src="https://download.flashcat.cloud/tencent-eb-target-webhook.png" />

6. Click **Save**, return to the **Event Set** page, select an event set, and click **Send Event** to test

   <img alt="drawing" width="600" src="https://download.flashcat.cloud/tencent-eb-test-send.png" />

7. Return to the integration list. If the integration shows a latest event time, the setup works

</div>

## Status mapping
<div class="md-block">
  
All Tencent Cloud EventBridge events correspond to "warning" severity level alerts in Flashduty.

</div>
