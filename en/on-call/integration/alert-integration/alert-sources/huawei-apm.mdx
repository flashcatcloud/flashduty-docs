Sync Huawei Cloud APM alerts to Flashduty through webhook.

<div className="hide">

## In Flashduty On-call
You can get an integration push URL through the following 2 methods, choose one of them.

### Use dedicated integration

When you don't need to route alerts to different channels, choose this method, it's simpler.

<AccordionGroup>
  <Accordion title="View dedicated integration setup steps">
  
  1. Go to Flashduty console, select **Channels**, enter the details page of a channel
  2. Select **Configuration** → **Integrations** → **Private integration**, then click **Add an integration**
  3. Select **Huawei Cloud APM** integration, click **Save** to generate a card
  4. Open the generated integration card and copy the **Push URL**
    
</Accordion>
</AccordionGroup>

### Use shared integration

When you need to route alerts to different channels based on alert payload information, this method is preferred.

<AccordionGroup>
  <Accordion title="View shared integration setup steps">
  
  1. In the Flashduty console, go to **Integration Center → Alerts**
  2. Select **Huawei Cloud APM** integration:
        - **Integration Name**: Define a name for the current integration
  3. Configure the default route and select a channel. You can add more rules under **Routing** after creation
  4. Click **Save** and copy the generated **Push URL**
    
</Accordion>
</AccordionGroup>
</div>

## Configure in Huawei Cloud APM

<Steps>
<Step title="Create a topic and an HTTPS subscription in Huawei Cloud SMN">

**Where**: Huawei Cloud console › Simple Message Notification (SMN) › Topic Management › Topics › Create Topic

| Field | Value |
| --- | --- |
| Topic name (required) | `Flashduty` |

Confirm.

<img src="https://download.flashcat.cloud/flashduty/doc/en/hw/lts-1.png" alt="Create the Flashduty topic" width="500"/>

Return to the topic list and click `Add Subscription` on the `Flashduty` topic. The topic policy's **Services That Can Publish Messages** must include APM; otherwise notifications fail to send.

<img src="https://download.flashcat.cloud/flashduty/doc/en/hw/lts-2.png" alt="Add subscription entry" width="500"/>

| Field | Value |
| --- | --- |
| Protocol (required) | `HTTPS` |
| Subscription endpoint (required) | `{integration_url}` |

Confirm.

<img src="https://download.flashcat.cloud/flashduty/doc/en/hw/lts-3.png" alt="Enter the push URL as the subscription endpoint" width="500"/>

After adding, check that the subscription status in the subscription list shows **Confirmed**.

<img src="https://download.flashcat.cloud/flashduty/doc/en/hw/lts-4.png" alt="Subscription status Confirmed" width="500"/>

</Step>
<Step title="Add a notification configuration in Huawei Cloud APM">

**Where**: Huawei Cloud console › Application Performance Management (APM) › Application Monitoring › Metrics › Notification › Add

| Field | Value |
| --- | --- |
| Region (required) | The region of your application |
| Topic (required) | The `Flashduty` topic created in the previous step |
| Default (optional) | Switch; when on, alerts of that region are sent to this topic |

Click `Confirm` to complete the configuration.

<img src="https://download.flashcat.cloud/flashduty/doc/en/hw/hw-apm-1.png" alt="APM notification configuration" width="600"/>

</Step>
<Step title="Create an alarm policy in Huawei Cloud APM">

**Where**: Huawei Cloud console › Application Performance Management (APM) › Alarm Center › Alarm Policies › Create Alarm Policy

Select `Flashduty` in the **Notification Object** drop-down. If the notification object is an HTTP/HTTPS endpoint, leave **Notification Format** at the default HTML or choose JSON.

Legacy entry: **Application Monitoring › Metrics › your application › Settings › Alarm Policy › Add Custom Alarm Policy**. Per Huawei Cloud, policies created there do not appear under **Alarm Center › Alarm Policies** ([source](https://support.huaweicloud.com/usermanual-apm2/apm_07_0025.html)).

| Field | Value |
| --- | --- |
| Alert metrics and conditions (required) | Configure according to your business needs |
| Notification Content (optional) | When referencing variables, use K:V format for easier alert parsing, such as `host:${hostInfo}` |
| Notification Object (required) | Select the created `Flashduty` notification channel |
| Recovery Policy (optional) | Enter N minutes; an alarm with no new occurrence for N minutes is treated as recovered |
| Notify on Recovery (required) | On; otherwise Flashduty receives no recovery notification and alerts do not close automatically |

Click `Confirm` to complete the configuration. You can also edit an existing alarm policy.

<img src="https://download.flashcat.cloud/flashduty/doc/en/hw/hw-apm-2.png" alt="APM alarm policy" width="600"/>

**Note:** The current integration configuration only supports application monitoring alerts, and does not fully support front-end monitoring, link tracking, and App monitoring alerts.

</Step>
<Step title="Trigger an alarm and confirm">

**Where**: Huawei Cloud console › Application Performance Management (APM) › Alarm Center › Alarm Policies

Let the alarm policy from the previous step fire once (for example, temporarily lower its threshold).
After a few seconds, go back to Flashduty. If the integration shows a **Latest event time**, the setup works.
{/* console:
The checklist item "Receive the first event" is then complete as well.
*/}


</Step>
</Steps>

## Status and severity

<div class="md-block">

Flashduty maps severity by the format of the pushed payload.

JSON payload (pushed through SMN):

| Huawei Cloud APM | Flashduty |
| ---------- | -------- |
| `CRITICAL` | Critical |
| `COMMON` | Warning |
| Anything else | Info |

Text payload:

| Huawei Cloud APM alarm level (告警级别) | Flashduty |
| ---------- | -------- |
| `严重告警` (Critical alarm) | Critical |
| `轻微告警` (Minor alarm) | Info |

</div>
