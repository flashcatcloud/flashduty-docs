Generate a unique Feishu robot address in Flashduty, and synchronize the occurrence and recovery of alerts through Feishu.

<div class="hide">

## Operation Steps

### Create Lark Bot Compatible Integration

You can obtain a Lark Bot Compatible integration address through either of these two methods:

#### Using Dedicated Integration

Choose this method when you don't need to route alert events to different channels. It's simpler and recommended.

<AccordionGroup>
  <Accordion title="View dedicated integration setup steps">
  
  1. Go to the Flashduty console, select **Channel**, and enter a specific channel's details page
  2. Select **Configuration** → **Integrations** → **Private integration**, then click **Add an integration** to enter the integration page
  3. Choose **Lark Bot Compatible** integration and click **Save** to generate a card
  4. Click the generated card to view the **Lark Bot Compatible Integration URL**, copy it for later use, and you're done
    
</Accordion>
</AccordionGroup>

#### Using Shared Integration

Choose this method when you need to route alerts to different channels based on the alert event's payload information.

<AccordionGroup>
  <Accordion title="View shared integration setup steps">
  
  1. Go to the Flashduty console, select **Integration Center → Alert Events** to enter the integration selection page
  2. Select **Lark Bot Compatible** integration:
        - **Integration Name**: Define a name for the current integration
        - **Message Type**: Select Feishu alert message type, currently only Text and Post (rich text) are supported
        - **Push Mode**: Choose when to trigger or recover alerts for Feishu notifications
  3. Copy the **Lark Bot Compatible Integration URL** for later use
  4. Configure the default route and select the corresponding channel (after integration creation, you can go to `Routes` to configure more routing rules)
  5. Done
    
</Accordion>
</AccordionGroup>
</div>

### Customize Lark Bot Compatible Integration

#### Lark Bot Compatible Integration URL

The system will generate a unique Lark Bot Compatible integration URL for you. This URL is compatible with Feishu robot message protocol. When platforms only support Feishu robot channels, you can use this URL to receive corresponding messages.

#### Push Mode

By default, the system always creates new alerts for each message, but you can switch to these modes:

1. **Trigger or Update Alert Based on Message Title**: In this mode, when receiving a new message, the system searches for open alerts based on the message title. If an alert is found, it will be updated; otherwise, a new alert will be triggered.
2. **Trigger or Close Alert Based on Rules**: In this mode, when receiving a new message, the system matches messages according to your rules and triggers new alerts or closes existing alerts based on the matching results.

   - You need to fill in at least one **trigger** rule
   - You must set up regex extraction rules for Alert Key. The system uses this field to find historical alerts for updates or closure. **If regex extraction fails, the system will use the message title to generate an Alert Key** to ensure alerts won't be lost due to configuration errors
   - You can choose whether to discard messages when none of the rules match

   Configuration example:

   - Receive all messages, close the alert when the message content contains **RESOLVED**, otherwise trigger a new alert
   - Extract Alert Key from message title using the rule **/(.*)/**.


### Notes
- Lark Bot Compatible integration URL only supports Text and post message types; other message types cannot be received
- When Feishu message type is Text, Flashduty will generate a default alert title "Feishu Alert"

## Severity Mapping

Currently, all alerts pushed to Flashduty through the Feishu(lark) integration are set to Warning severity. However, you can customize the severity using the [alert pipeline](/en/on-call/integration/alert-integration/alert-pipelines).

## Alibaba Cloud Message Center
<div class="md-block">

The "Robot Reception" feature in Alibaba Cloud's account Message Center can push account, product, and security notices to a custom webhook. Its data format can reuse the Feishu robot protocol, so it connects directly to the Lark Bot Compatible integration on this page.

1. Log in to Alibaba Cloud **Message Center**, go to **Robot Reception Management → Robot Management → Add Robot**
2. Select **Custom** for **Robot Platform**, enter the **Lark Bot Compatible Integration URL** from above for **Webhook Address**, and select **Format B (typically used by Feishu)** for **Data Format**
3. Complete the CAPTCHA verification and save

<Note>
Notices from Message Center are one-shot — there is no paired recovery message. Refer to "Push Mode" above and configure **Trigger or Update Alert Based on Message Title** or **Trigger or Close Alert Based on Rules** so alerts don't stay open forever.
</Note>

<Note>
If you're integrating Alibaba Cloud Monitor (CloudMonitor) alerts, use the [Alibaba Cloud Monitor CM Metrics Integration](/en/on-call/integration/alert-integration/alert-sources/aliyun-cm-metrics) directly for full dedup and recovery support.
</Note>
