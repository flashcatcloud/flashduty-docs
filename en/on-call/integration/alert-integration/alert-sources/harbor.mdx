## In Flashduty On-call

### Create Harbor alert integration

You can get the integration push URL in either of the following ways.

#### Use a dedicated integration

Choose this option if all alerts go to one channel. It's the simpler setup.

<Accordion title="View dedicated integration setup steps">
1. In the Flashduty console, select **Channel** and open a channel
2. Select **Configuration** → **Integrations** → **Private integration**, then click **Add an integration**
3. Choose **Harbor** integration and click **Save** to generate a card
4. Open the generated integration card and copy the **Push URL**
</Accordion>

#### Use a shared integration

Choose this option if you need to route alerts to different channels based on the alert payload.

<Accordion title="View shared integration setup steps">
1. In the Flashduty console, go to **Integration Center → Alert Events**
2. Select **Harbor** integration:
      - **Integration Name**: Define a name for this integration
3. Configure the default route and select a channel. You can add more rules under **Routing** after creation
4. Click **Save** and copy the generated **Push URL**
</Accordion>

## Configure Harbor

<Steps>
<Step title="Add a webhook to a Harbor project">

**Where**: Harbor › Projects › select a project › Webhooks › New Webhook

Sign in to Harbor with an account that has at least project administrator privileges.

| Field | Value |
| --- | --- |
| Notify Type (required) | `HTTP` |
| Payload Format (required, HTTP only) | `Default` or `CloudEvents` |
| Event Type (required) | Select the events you want to subscribe to |
| Endpoint URL (required) | `{integration_url}` |
| Auth Header (optional) | Not needed. Flashduty authenticates with the `integration_key` in the push URL |
| Verify Remote Certificate (optional) | Keep it selected when the push URL uses HTTPS |

Click **Add** to create the webhook.

</Step>

<Step title="Verify">

**Where**: Harbor › Projects › select a project › Webhooks

Confirm the new webhook is enabled, then trigger a subscribed event in the project, for example push an image to it (if you subscribed to Push artifact to registry). Go back to Flashduty: when the integration shows a **Latest event time**, the setup works.
{/* console:
The "First event received" item on the integration checklist also turns done.
*/}

</Step>
</Steps>

## Status and severity

Currently, all alerts pushed to Flashduty through the Harbor integration are set to Warning severity. However, you can customize the severity using the [alert pipeline](/en/on-call/integration/alert-integration/alert-pipelines).
