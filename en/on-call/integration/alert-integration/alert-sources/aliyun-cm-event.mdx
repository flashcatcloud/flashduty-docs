Sync Alibaba Cloud Monitor event center alerts to Flashduty through webhook.

<div className="hide">

## In Flashduty On-call
You can get the integration push URL in either of the following ways.

### Use a dedicated integration

Choose this option if all alerts go to one channel. It's the simpler setup.

<AccordionGroup>
  <Accordion title="View dedicated integration setup steps">
  
  1. In the Flashduty console, select **Channel** and open a channel
  2. Select **Configuration** → **Integrations** → **Private integration**, then click **Add an integration**
  3. Choose **Alibaba Cloud CM Event** integration and click **Save** to generate a card
  4. Open the generated integration card and copy the **Push URL**
  
</Accordion>
</AccordionGroup>

### Use a shared integration

Choose this option if you need to route alerts to different channels based on the alert payload.

<AccordionGroup>
  <Accordion title="View shared integration setup steps">
  
  1. In the Flashduty console, go to **Integration Center → Alerts**
  2. Select **Alibaba Cloud CM Event** integration:
        - **Integration Name**: Define a name for this integration
  3. Configure the default route and select a channel. You can add more rules under **Routing** after creation
  4. Click **Save** and copy the generated **Push URL**
    
</Accordion>
</AccordionGroup>
</div>

## In Alibaba Cloud Monitor CM event

<Steps>
<Step title="Create a push channel in CloudMonitor">

**Where**: CloudMonitor console › Event Center › Event Subscription › Push Channels › Create Push Channel

| Field | Value | Required |
| --- | --- | --- |
| Request Method | `POST` | Required |
| Address | `{integration_url}` | Required |

Click **Confirm**.

<img src="https://download.flashcat.cloud/flashduty/doc/en/aliyun/event-2.png" alt="Creating a push channel in CloudMonitor event subscription" width="500"/>

</Step>
<Step title="Create a subscription policy in CloudMonitor">

**Where**: CloudMonitor console › Event Center › Event Subscription › Subscription Policies › Create Subscription Policy

| Field | Value | Required |
| --- | --- | --- |
| Subscription name | Your choice | Required |
| Event type and scope | As needed | Required |
| Push channel (bottom of the page) | The Flashduty channel created in the previous step | Required |

Click **Confirm**. The image below shows subscription results for both threshold and system event types.

<img src="https://download.flashcat.cloud/flashduty/doc/en/aliyun/event-3.png" alt="CloudMonitor event subscription policies" width="500"/>

</Step>
<Step title="Debug the event subscription and confirm">

**Where**: CloudMonitor console › Event Center › Event Subscription › Subscription Policies › Debug Event Subscription

Click **Debug Event Subscription**, choose a product and event name to generate test content, and CloudMonitor sends a test notification to the push URL. You can also wait for a real event. Go back to Flashduty. If the integration shows a **Latest event time**, the setup works.
{/* console:
The checklist item "Receive the first event" is then complete as well.
*/}

</Step>
</Steps>
