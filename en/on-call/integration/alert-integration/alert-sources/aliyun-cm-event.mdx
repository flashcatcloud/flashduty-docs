Sync Alibaba Cloud Monitor event center alerts to Flashduty through webhook for automated alert noise reduction.

<div class="hide">

## In Flashduty
You can get the integration push URL in either of the following ways.

### Use a dedicated integration

Choose this option if all alerts go to one channel. It's the simpler setup.

<AccordionGroup>
  <Accordion title="View dedicated integration setup steps">
  
  1. In the Flashduty console, select **Channel** and open a channel
  2. Select **Configuration** → **Integrations** → **Private integration**, then click **Add an integration**
  3. Choose **Alibaba Cloud CM Event** integration and click **Save** to generate a card
  4. Open the generated integration card and copy the **Push URL**
  
</Accordion>
</AccordionGroup>

### Use a shared integration

Choose this option if you need to route alerts to different channels based on the alert payload.

<AccordionGroup>
  <Accordion title="View shared integration setup steps">
  
  1. In the Flashduty console, go to **Integration Center → Alerts**
  2. Select **Alibaba Cloud CM Event** integration:
        - **Integration Name**: Define a name for this integration
  3. Configure the default route and select a channel. You can add more rules under **Routing** after creation
  4. Click **Save** and copy the generated **Push URL**
    
</Accordion>
</AccordionGroup>
</div>

## In Alibaba Cloud Monitor CM event
**Step 1: Add push channel**

<div class="md-block">

1. Log in to the Alibaba Cloud console and open Cloud Monitor
2. Go to **Event Center → Event Subscription** page, switch to the **Push Channels** tab, and click **Create Push Channel**
3. Select **POST** as the **Request Method**, and fill in the integration push URL in the **Address** field
4. Click **Confirm**

<img src="https://download.flashcat.cloud/flashduty/doc/en/aliyun/event-2.png" alt="drawing" width="500"/>

</div>

**Step 2: Add subscription policy**

<div class="md-block">

1. Log in to the Alibaba Cloud console and open Cloud Monitor
2. Go to **Event Center → Event Subscription** page, switch to the **Subscription Policies** tab, and click **Create Subscription Policy**
3. Enter a subscription name and select the event type and scope. At the bottom, set the push channel to the Flashduty channel you created
4. Click **Confirm**
5. The image below shows subscription results for both threshold and system event types

<img src="https://download.flashcat.cloud/flashduty/doc/en/aliyun/event-3.png" alt="drawing" width="500"/>

</div>
