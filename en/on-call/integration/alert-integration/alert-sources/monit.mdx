When you enable the Monit service, the system will automatically create this integration for you. This integration is used to collect alert events generated by the Monit service.

:::tips
You cannot modify or delete this integration. However, you can manage the label enrichment, alert pipeline, and routing rules under the integration.
:::

## Enable Monit alerts

<Steps>
<Step title="Configure and enable an alert rule in Monit">

**Where**: Monit › Alert Rules › Rule Details

Configure the monitoring metrics and threshold conditions, and enable alerts.

![Monit Alert Integration: How to Enable Monit Alerts screenshot](https://docs-cdn.flashcat.cloud/images/png/59c9d2566db9a0482fb2eabb729ea739.png)

</Step>
<Step title="Choose where alerts are delivered">

**Where**: Monit › Alert Rules › Rule Details

- Deliver to channels: you can choose multiple channels. Alert notification rules follow the escalation rules under the channel, and you can set responders for the team to assign to responders when alerts occur.
- Deliver to the integration: to route alerts generated by the same alert rule to different channels based on conditions, deliver directly to the integration rather than to the channel list, and set [routing rules](/en/on-call/integration/alert-integration/routing-rules) under the current integration.

</Step>
<Step title="Confirm the alert arrives">

Let the alert rule fire once. A few seconds later the integration in Flashduty shows a **Latest event time**, which means the setup works.
{/* console:
The checklist item "Receive the first event" is then complete as well.
*/}

</Step>
</Steps>
