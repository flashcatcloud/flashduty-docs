Sync Guance monitoring alert events to Flashduty through webhook.

<div className="hide">

## In Flashduty On-call
You can get the integration push URL in either of the following ways.

### Use a dedicated integration

Choose this option if all alerts go to one channel. It's the simpler setup.

<AccordionGroup>
  <Accordion title="View dedicated integration setup steps">
  
  1. In the Flashduty console, select **Channel** and open a channel
  2. Select **Configuration** → **Integrations** → **Private integration**, then click **Add an integration**
  3. Select **Guance** integration and click **Save** to generate a card
  4. Open the generated integration card and copy the **Push URL**

</Accordion>
</AccordionGroup>

### Use a shared integration

Choose this option if you need to route alerts to different channels based on the alert payload.

<AccordionGroup>
  <Accordion title="View shared integration setup steps">
  
  1. In the Flashduty console, go to **Integration Center → Alert Events**
  2. Select **Guance** integration:
        - **Integration Name**: Define a name for this integration
  3. Configure the default route and select a channel. You can add more rules under **Routing** after creation
  4. Click **Save** and copy the generated **Push URL**
    
</Accordion>
</AccordionGroup>
</div>

## In Guance

<Steps>
<Step title="Create a Webhook notification target in Guance">

**Where**: Guance console › Monitoring › Notification Targets › Create › Webhook

| Field | Value |
| --- | --- |
| Name (required) | `Flashduty` |
| Webhook URL (required) | `{integration_url}` |

Configure other options as needed and click **Confirm**.

<img alt="Creating a Webhook notification target in Guance" width="600" src="https://download.flashcat.cloud/flashduty/doc/en/fd/guance-1.png" />

</Step>

<Step title="Use the notification target in an alert strategy">

**Where**: Guance console › Monitoring › Alert Strategies › create an alert strategy (or modify an existing one) › Notification Configuration

| Field | Value |
| --- | --- |
| Severity (required) | The alert severities to notify on |
| Notification Targets (required) | `Flashduty`, created in the previous step |

Configure other options as needed and click **Save**.

<img alt="Selecting the notification target in a Guance alert strategy" width="600" src="https://download.flashcat.cloud/flashduty/doc/en/fd/guance-2.png" />

</Step>

<Step title="Trigger an alert and confirm">

Let a monitor linked to this alert strategy fire, or wait for a real alert.

Go back to Flashduty. If the integration shows a **Latest event time**, the setup works.
{/* console:
The checklist item "Receive the first event" is then complete as well.
*/}

</Step>
</Steps>

## Status and severity

<div class="md-block">

| Guance `df_status` | Flashduty | Status |
| --- | --- | --- |
| `critical`, `fatal` | Critical | Critical |
| `error`, `warning` | Warning | Warning |
| `info`, `nodata` | Info | Info |
| Other values | Info | Info |
| `ok` | Info | Resolved (OK) |

</div>
