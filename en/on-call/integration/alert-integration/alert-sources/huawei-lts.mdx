Sync Huawei Cloud Log Tank Service (LTS) alert events to Flashduty through webhook.

<div className="hide">

## In Flashduty On-call
You can get the integration push URL in either of the following ways.

### Use a dedicated integration

Choose this option if all alerts go to one channel. It's the simpler setup.

<AccordionGroup>
  <Accordion title="View dedicated integration setup steps">
  
  1. In the Flashduty console, select **Channel** and open a channel
  2. Select **Configuration** → **Integrations** → **Private integration**, then click **Add an integration**
  3. Choose **Huawei Cloud LTS** integration and click **Save** to generate a card
  4. Open the generated integration card and copy the **Push URL**
  
</Accordion>
</AccordionGroup>

### Use a shared integration

Choose this option if you need to route alerts to different channels based on the alert payload.

<AccordionGroup>
  <Accordion title="View shared integration setup steps">
  
  1. In the Flashduty console, go to **Integration Center → Alert Events**
  2. Select **Huawei Cloud LTS** integration:
        - **Integration Name**: Define a name for this integration
  3. Configure the default route and select a channel. You can add more rules under **Routing** after creation
  4. Click **Save** and copy the generated **Push URL**
    
</Accordion>
</AccordionGroup>
</div>

## Configure in Huawei Cloud

<Steps>
<Step title="Create a topic and an HTTPS subscription in Huawei Cloud SMN">

**Where**: Huawei Cloud console › Simple Message Notification (SMN) › Topic Management › Topics › Create Topic

| Field | Value |
| --- | --- |
| Topic name (required) | `Flashduty` |

Confirm.

<img src="https://download.flashcat.cloud/flashduty/doc/en/hw/lts-1.png" alt="Create the Flashduty topic" width="500"/>

Return to the topic list and click `Add Subscription` on the `Flashduty` topic.

<img src="https://download.flashcat.cloud/flashduty/doc/en/hw/lts-2.png" alt="Add subscription entry" width="500"/>

| Field | Value |
| --- | --- |
| Protocol (required) | `HTTPS` |
| Subscription endpoint (required) | `{integration_url}` |

Confirm.

<img src="https://download.flashcat.cloud/flashduty/doc/en/hw/lts-3.png" alt="Enter the push URL as the subscription endpoint" width="500"/>

After adding, check that the subscription status in the subscription list shows **Confirmed**.

<img src="https://download.flashcat.cloud/flashduty/doc/en/hw/lts-4.png" alt="Subscription status Confirmed" width="500"/>

</Step>
<Step title="Create a message template and an alert action rule in Huawei Cloud LTS">

**Where**: Huawei Cloud console › Log Tank Service (LTS) › Log Alert › Alert Action Rules › Message Templates › Create

In some console versions this entry is **Log Alert › Alarm Notification Rules › Message Templates**. Create the message template first:

| Field | Value |
| --- | --- |
| Name (required) | `Flashduty` |
| Message header language (required) | `English` |
| Notification type (required) | `HTTP/HTTPS` |
| Data type (required) | `JSON` |

Click `Confirm` to save.

<img src="https://download.flashcat.cloud/flashduty/doc/en/hw/lts-5.png" alt="Message template entry" width="500"/>

<img src="https://download.flashcat.cloud/flashduty/doc/en/hw/lts-6.png" alt="Create the message template" width="500"/>

Return to the `Alert Action Rules` list and click `Create`:

| Field | Value |
| --- | --- |
| Rule name (required) | `Flashduty` |
| Topic (required) | The `Flashduty` topic created in the previous step |
| Message template (required) | The `Flashduty` template you just created |

<img src="https://download.flashcat.cloud/flashduty/doc/en/hw/lts-7.png" alt="Create the alert action rule" width="500"/>

</Step>
<Step title="Use the action rule in a Huawei Cloud LTS alert rule">

**Where**: Huawei Cloud console › Log Tank Service (LTS) › Log Alert › Alert Rules › create or edit an alert rule › Advanced Settings

| Field | Value |
| --- | --- |
| Notification scenarios (required) | Select both `Alert Trigger` and `Alert Recovery` |
| Action rules (required) | Turn on and select the `Flashduty` rule created in the previous step |
| Language (required) | `English` |

Click `Confirm` to save.

<img src="https://download.flashcat.cloud/flashduty/doc/en/hw/lts-8.png" alt="Use the action rule in an alert rule" width="500"/>

</Step>
<Step title="Trigger an alert and confirm">

**Where**: Huawei Cloud console › Log Tank Service (LTS) › Log Alert › Alert Rules

Let the alert rule from the previous step fire once, then let it recover.
After a few seconds, go back to Flashduty. If the integration shows a **Latest event time**, the setup works.
{/* console:
The checklist item "Receive the first event" is then complete as well.
*/}


</Step>
</Steps>
