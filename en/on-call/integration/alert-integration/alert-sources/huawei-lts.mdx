Sync Huawei Cloud Log Tank Service (LTS) alert events to Flashduty through webhook for automated alert noise reduction.

<div class="hide">

## In Flashduty
You can get the integration push URL in either of the following ways.

### Use a dedicated integration

Choose this option if all alerts go to one channel. It's the simpler setup.

<AccordionGroup>
  <Accordion title="View dedicated integration setup steps">
  
  1. In the Flashduty console, select **Channel** and open a channel
  2. Select **Configuration** → **Integrations** → **Private integration**, then click **Add an integration**
  3. Choose **Huawei Cloud LTS** integration and click **Save** to generate a card
  4. Open the generated integration card and copy the **Push URL**
  
</Accordion>
</AccordionGroup>

### Use a shared integration

Choose this option if you need to route alerts to different channels based on the alert payload.

<AccordionGroup>
  <Accordion title="View shared integration setup steps">
  
  1. In the Flashduty console, go to **Integration Center → Alert Events**
  2. Select **Huawei Cloud LTS** integration:
        - **Integration Name**: Define a name for this integration
  3. Configure the default route and select a channel. You can add more rules under **Routing** after creation
  4. Click **Save** and copy the generated **Push URL**
    
</Accordion>
</AccordionGroup>
</div>

## In Huawei Cloud

<div class="md-block">


### Step 1: Create Flashduty alert channel
1. Log in to the Huawei Cloud console, then search for and open `SMN` (Simple Message Notification)
2. Select `Topic Management=>Topics` from the left navigation bar
3. Click `Create Topic`, set the topic name to `Flashduty`, and confirm

   <img src="https://download.flashcat.cloud/flashduty/doc/en/hw/lts-1.png" alt="drawing" width="500"/>

4. In the topic list, click `Add Subscription` on the Flashduty topic

   <img src="https://download.flashcat.cloud/flashduty/doc/en/hw/lts-2.png" alt="drawing" width="500"/>

5. Set the protocol to `HTTPS`, enter the integration push URL as the subscription endpoint, and confirm

   <img src="https://download.flashcat.cloud/flashduty/doc/en/hw/lts-3.png" alt="drawing" width="500"/>

6. In the subscription list, confirm that the subscription status is **Confirmed**

<img src="https://download.flashcat.cloud/flashduty/doc/en/hw/lts-4.png" alt="drawing" width="500"/>

### Step 2: Configure log alert action rules

1. Log in to the Huawei Cloud console, then search for and open `LTS` (Log Tank Service)
2. Select `Log Alert=>Alert Action Rules=>Message Templates` from the left navigation bar and click `Create`

   <img src="https://download.flashcat.cloud/flashduty/doc/en/hw/lts-5.png" alt="drawing" width="500"/>

3. Set the name to **Flashduty** and the message header language to `English`
4. Select `HTTP/HTTPS` as notification type and `JSON` as data type
5. Click `Confirm` to save

   <img src="https://download.flashcat.cloud/flashduty/doc/en/hw/lts-6.png" alt="drawing" width="500"/>

6. Return to the `Alert Action Rules` list and click `Create`
7. Set the rule name to **Flashduty**, and select the **Flashduty** topic and template you created

<img src="https://download.flashcat.cloud/flashduty/doc/en/hw/lts-7.png" alt="drawing" width="500"/>

### Step 3: Use the action rule created in step 2 in alert rules

1. Return to the `Alert Rules` list
2. Create or edit existing alert rules
3. In `Advanced Settings`, select both `Alert Trigger` and `Alert Recovery` under notification scenarios
4. Turn on action rules and select the **Flashduty** rule from step 2
5. Set the language to `English` and click `Confirm`

<img src="https://download.flashcat.cloud/flashduty/doc/en/hw/lts-8.png" alt="drawing" width="500"/>

</div>
