Sync StateCloud monitoring alert events to Flashduty through webhook.

For resource monitoring events from StateCloud [secondary nodes](#secondary-nodes), please use Huawei Cloud integration. Refer to [Huawei Cloud Alert Integration Guide](/en/on-call/integration/alert-integration/alert-sources/huawei-ces).


<div className="hide">

## In Flashduty On-call
You can get the integration push URL in either of the following ways.

### Use a dedicated integration

Choose this option if all alerts go to one channel. It's the simpler setup.

<AccordionGroup>
  <Accordion title="View dedicated integration setup steps">
  
  1. In the Flashduty console, select **Channel** and open a channel
  2. Select **Configuration** → **Integrations** → **Private integration**, then click **Add an integration**
  3. Select **StateCloud** integration and click **Save** to generate a card
  4. Open the generated integration card and copy the **Push URL**

</Accordion>
</AccordionGroup>

### Use a shared integration

Choose this option if you need to route alerts to different channels based on the alert payload.

<AccordionGroup>
  <Accordion title="View shared integration setup steps">
  
  1. In the Flashduty console, go to **Integration Center → Alert Events**
  2. Select **StateCloud** integration:
        - **Integration Name**: Define a name for this integration
  3. Configure the default route and select a channel. You can add more rules under **Routing** after creation
  4. Click **Save** and copy the generated **Push URL**
    
</Accordion>
</AccordionGroup>
</div>

## In StateCloud

<Steps>
<Step title="Create an alarm contact/group in StateCloud">

**Where**: StateCloud console › Management & Deployment › Cloud Eye › Alarm Service › Alarm Contact/Group

Create the alarm contact/group that the alarm rule will notify.

</Step>

<Step title="Enter the alarm callback in an alarm rule">

**Where**: StateCloud console › Management & Deployment › Cloud Eye › Alarm Service › Alarm Rules › Create Alarm Rule (or modify an existing rule) › Alert Callback

| Field | Value |
| --- | --- |
| Alert Callback (required) | `{integration_url}` |

Click **Test**; after the test succeeds, click **Save**.

<img alt="Alert Callback field in a StateCloud alarm rule" width="600" src="https://download.flashcat.cloud/flashduty/doc/en/fd/state-1.png" />

</Step>

<Step title="Confirm Flashduty receives the event">

**Where**: StateCloud console › Management & Deployment › Cloud Eye › Alarm Service › Alarm Rules › your rule › Modify › Alert Callback › Test

Click **Test** again, or wait for the rule to fire a real alert.

Go back to Flashduty. If the integration shows a **Latest event time**, the setup works.
{/* console:
The checklist item "Receive the first event" is then complete as well.
*/}

</Step>
</Steps>
