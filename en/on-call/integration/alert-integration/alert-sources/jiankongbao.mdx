Sync Jiankongbao alert events to Flashduty through webhook.

<div className="hide">

## In Flashduty On-call
You can get the integration push URL in either of the following ways.

### Use a dedicated integration

Choose this option if all alerts go to one channel. It's the simpler setup.

<AccordionGroup>
  <Accordion title="View dedicated integration setup steps">
  
  1. In the Flashduty console, select **Channel** and open a channel
  2. Select **Configuration** → **Integrations** → **Private integration**, then click **Add an integration**
  3. Choose **Jiankongbao** integration and click **Save** to generate a card
  4. Open the generated integration card and copy the **Push URL**
  
</Accordion>
</AccordionGroup>

### Use a shared integration

Choose this option if you need to route alerts to different channels based on the alert payload.

<AccordionGroup>
  <Accordion title="View shared integration setup steps">
  
  1. In the Flashduty console, go to **Integration Center → Alert Events**
  2. Select **Jiankongbao** integration:
        - **Integration Name**: Define a name for this integration
  3. Configure the default route and select a channel. You can add more rules under **Routing** after creation
  4. Click **Save** and copy the generated **Push URL**
    
</Accordion>
</AccordionGroup>
</div>

## In Jiankongbao

This integration also covers Cloudwise Jiankongbao (including Jiankongbao 6) URL callback notifications.

<Steps>
<Step title="Add a URL callback in Jiankongbao">

**Where**: Jiankongbao console › Personal Configuration (upper right) › Webhooks Settings › Add › URL Callback

<img alt="Jiankongbao personal configuration entry" width="600" src="https://fcpub-1301667576.cos.ap-nanjing.myqcloud.com/flashduty/doc/jkb-1.png" />

<img alt="Adding a URL callback in Jiankongbao Webhooks Settings" width="600" src="https://fcpub-1301667576.cos.ap-nanjing.myqcloud.com/flashduty/doc/jkb-2.png" />

| Field | Value |
| --- | --- |
| Custom name (required) | `Flashduty` |
| Callback URL (required) | `{integration_url}` |
| Callback method (required) | **POST** |
| Data format (required) | **JSON** |
| Enable URL Callback (required) | Checked |

Configure other options as needed and click Save.

<img alt="Jiankongbao URL callback settings" width="600" src="https://fcpub-1301667576.cos.ap-nanjing.myqcloud.com/flashduty/doc/jkb-3.png" />

</Step>

<Step title="Use the webhook channel in a monitoring task">

**Where**: Jiankongbao console › Monitoring Tasks › Create (or edit an existing task) › Webhook notification

| Field | Value |
| --- | --- |
| Webhook notification (required) | Select the `Flashduty` channel |

Fill in other alert settings as needed and save the monitoring task.

<img alt="Selecting the Flashduty channel in a Jiankongbao monitoring task" width="600" src="https://fcpub-1301667576.cos.ap-nanjing.myqcloud.com/flashduty/doc/jkb-4.png" />

</Step>

<Step title="Trigger an alert and confirm">

Jiankongbao has no standalone callback test. Let the task raise an alert, or wait for a real one.

Go back to Flashduty. If the integration shows a **Latest event time**, the setup works.
{/* console:
The checklist item "Receive the first event" is then complete as well.
*/}

</Step>
</Steps>
