Send Grafana alert events to Flashduty through a webhook for automated alert noise reduction.

<div class="hide">

## In Flashduty
You can get the integration push URL in either of the following ways.

### Use a dedicated integration

Choose this option if all alerts go to one channel. It's the simpler setup.

<AccordionGroup>
  <Accordion title="View dedicated integration setup steps">
  
  1. In the Flashduty console, select **Channel** and open a channel
  2. Select **Configuration** → **Integrations** → **Private integration**, then click **Add an integration**
  3. Choose **Grafana** integration and click **Save** to generate a card
  4. Open the generated integration card and copy the **Push URL**
  
</Accordion>
</AccordionGroup>

### Use a shared integration

Choose this option if you need to route alerts to different channels based on the alert payload.

<AccordionGroup>
  <Accordion title="View shared integration setup steps">
  
  1. In the Flashduty console, go to **Integration Center → Alert Events**
  2. Select **Grafana** integration:
        - **Integration Name**: Define a name for this integration
  3. Configure the default route and select a channel. You can add more rules under **Routing** after creation
  4. Click **Save** and copy the generated **Push URL**
    
</Accordion>
</AccordionGroup>
</div>

## In Grafana
Grafana V4–V8 enable Legacy Alerting by default, and V9 and later enable Grafana Alerting by default. For the differences and how to switch, see the [Grafana alerting opt-in documentation](https://grafana.com/docs/grafana/v8.4/alerting/unified-alerting/opt-in/#opt-in-to-grafana-alerting). Follow the steps for your version.

### Legacy Alerting

<div class="md-block">

1. In the Grafana console, go to **Alerting → Notification channels**
2. Click **Add Channel**
3. Enter a name, set **Type** to webhook, paste the integration push URL into **Url**, and set **Method** to POST:

   <img src="https://download.flashcat.cloud/grafana-legacy-alerting.png" alt="drawing" width="600"/>

4. Save, and return to the integration list in Flashduty. After an alert fires, the integration shows a latest event time if the setup works

</div>

### Grafana Alerting

<div class="md-block">

1. In the Grafana console, go to **Alerting → Contact points**
2. Click **New contact point**
3. Enter a name, set **Type** to webhook, paste the integration push URL into **Url**, and set **Method** to POST:

   <img src="https://download.flashcat.cloud/grafana-contact-point.png" alt="drawing" width="600"/>

4. On the **Notification policies** page, edit or add a policy and select the contact point from the previous step:

   <img src="https://download.flashcat.cloud/grafana-notification-policy.png" alt="drawing" width="600"/>

5. Save, and return to the integration list in Flashduty. After an alert fires, the integration shows a latest event time if the setup works
6. The default severity is warning. To change it, set a severity label on the alert details page (see the status mapping below for values):

   <img src="https://download.flashcat.cloud/grafana-alert-rule.png" alt="drawing" width="600"/>


## Status mapping
  
Legacy Alerting to Flashduty severity mapping:

| Legacy Alerting |  Flashduty  | Status |
| --------------- | -------- | ---- |
| alerting        | Warning  | Warning |
| no_data         | Critical | Critical |
| ok              | Ok       | Resolved |

Grafana Alerting to Flashduty severity mapping:

Flashduty reads the `severity`, `priority`, and `level` labels in that order and uses the first value found as the Grafana severity. If none exists, the severity is `warning`.

| Grafana Alerting |  Flashduty  | Status |
| ---------------- | -------- | ---- |
| critical         | Critical | Critical |
| warning          | Warning  | Warning |
| warn             | Warning  | Warning |
| info             | Info     | Info |
| acknowledged     | Info     | Info |
| unknown          | Info     | Info |
| unk              | Info     | Info |
| ok               | Ok       | Resolved |

</div>
