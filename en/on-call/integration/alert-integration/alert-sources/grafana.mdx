Send Grafana alert events to Flashduty through a webhook.

<div className="hide">

## In Flashduty On-call
You can get the integration push URL in either of the following ways.

### Use a dedicated integration

Choose this option if all alerts go to one channel. It's the simpler setup.

<AccordionGroup>
  <Accordion title="View dedicated integration setup steps">
  
  1. In the Flashduty console, select **Channel** and open a channel
  2. Select **Configuration** → **Integrations** → **Private integration**, then click **Add integration**
  3. Choose **Grafana** integration and click **Save** to generate a card
  4. Open the generated integration card and copy the **Push URL**
  
</Accordion>
</AccordionGroup>

### Use a shared integration

Choose this option if you need to route alerts to different channels based on the alert payload.

<AccordionGroup>
  <Accordion title="View shared integration setup steps">
  
  1. In the Flashduty console, go to **Integration Center → Alert Events**
  2. Select **Grafana** integration:
        - **Integration Name**: Define a name for this integration
  3. Configure the default route and select a channel. You can add more rules under **Routing** after creation
  4. Click **Save** and copy the generated **Push URL**
    
</Accordion>
</AccordionGroup>
</div>

## Configure Grafana

Grafana 4–8 use Legacy Alerting by default, Grafana 9 and later use Grafana Alerting by default, and Grafana 11 removed Legacy Alerting. For the differences and how to switch, see the [Grafana alerting opt-in documentation](https://grafana.com/docs/grafana/v8.4/alerting/unified-alerting/opt-in/#opt-in-to-grafana-alerting).

<Steps>
<Step title="Add a webhook contact point in Grafana">

<Tabs>
<Tab title="Grafana 12">

**Where**: Grafana › Alerts & IRM › Alerting › Notification configuration › Contact points › + New contact point

| Field | Value |
| --- | --- |
| Name (required) | A name of your choice, for example `Flashduty` |
| Integration (required) | `Webhook` |
| URL (required) | `{integration_url}` |
| HTTP Method (optional, under Optional settings) | `POST` |

Then click **Save contact point**.

</Tab>
<Tab title="Grafana 9–11">

**Where**: Grafana › Alerts & IRM › Alerting › Contact points › + Add contact point

In Grafana 9–10, the entry point is **Alerting** (the bell icon) › **Contact points** in the left menu.

| Field | Value |
| --- | --- |
| Name (required) | A name of your choice, for example `Flashduty` |
| Integration (required) | `Webhook` |
| URL (required) | `{integration_url}` |
| HTTP Method (optional, under Optional Webhook settings) | `POST` |

Then click **Save contact point**.

<img src="https://download.flashcat.cloud/grafana-contact-point.png" alt="Webhook contact point settings in Grafana" width="600"/>

</Tab>
<Tab title="Legacy Alerting (4–8)">

**Where**: Grafana › Alerting (bell icon) › Notification channels › Add channel

| Field | Value |
| --- | --- |
| Name (required) | A name of your choice, for example `Flashduty` |
| Type (required) | `webhook` |
| Url (required) | `{integration_url}` |
| Http Method | `POST` |
| Default (send on all alerts) (optional) | When selected, every alert rule sends through this channel |

Then click **Save**.

<img src="https://download.flashcat.cloud/grafana-legacy-alerting.png" alt="Webhook channel settings in Grafana Legacy Alerting" width="600"/>

</Tab>
</Tabs>

</Step>
<Step title="Send alerts to the contact point in Grafana">

<Tabs>
<Tab title="Grafana 9 and later">

**Where**: Grafana › Alerts & IRM › Alerting › Notification policies › Default policy › … › Edit

In Grafana 12, **Notification policies** is under **Notification configuration**.

- To send all alerts to Flashduty: set **Default contact point** to the contact point from the previous step, then click **Save**.
- To send only some alerts: click **+New child policy**, add conditions under **Matching labels**, select the contact point from the previous step in **Contact point**, then click **Save policy**.

In Grafana 11 and later, you can skip the policy change: edit the alert rule and select the contact point under **Configure notifications**.

<img src="https://download.flashcat.cloud/grafana-notification-policy.png" alt="Selecting the Flashduty contact point in a Grafana notification policy" width="600"/>

</Tab>
<Tab title="Legacy Alerting (4–8)">

**Where**: Grafana › panel alert rule › Alert › Notifications › Send to

If you selected **Default (send on all alerts)** in the previous step, skip this step. Otherwise, select the channel from the previous step in **Send to** for each panel alert rule, and save the dashboard.

</Tab>
</Tabs>

</Step>
<Step title="Send a test notification from Grafana and confirm">

**Where**: Grafana › Alerts & IRM › Alerting › Contact points › your contact point › Edit › Test

Choose the predefined test notification and click **Send test notification**. In Grafana 12, **Contact points** is under **Notification configuration**. Legacy Alerting has no such test entry, so wait for a real alert to fire.

After a few seconds, go back to Flashduty. If the integration shows a **Latest event time**, the setup works.
{/* console:
The checklist item "Receive the first event" is then complete as well.
*/}

</Step>
</Steps>

## Status and severity

<div className="md-block">

Legacy Alerting to Flashduty severity mapping:

| Legacy Alerting | Flashduty |
| --------------- | -------- |
| alerting | Warning |
| no_data | Critical |
| ok | Ok |

Grafana Alerting to Flashduty severity mapping:

Flashduty reads the `severity`, `priority`, and `level` labels in that order and uses the first value found as the Grafana severity. If none exists, the severity is `warning`.

To set the severity, edit the alert rule and add a `severity` label under **Labels** (in Grafana 12, under **Set folder and labels**). Use a value from the table below:

<img src="https://download.flashcat.cloud/grafana-alert-rule.png" alt="Adding a severity label to a Grafana alert rule" width="600"/>

| Grafana Alerting | Flashduty |
| ---------------- | -------- |
| critical | Critical |
| warning | Warning |
| warn | Warning |
| info | Info |
| acknowledged | Info |
| unknown | Info |
| unk | Info |
| ok | Ok |

</div>
