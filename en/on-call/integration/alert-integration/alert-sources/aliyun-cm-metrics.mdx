Sync Alibaba Cloud Monitor alert events to Flashduty through webhook.

<div className="hide">

## In Flashduty On-call
You can get the integration push URL in either of the following ways.

### Use a dedicated integration

Choose this option if all alerts go to one channel. It's the simpler setup.

<AccordionGroup>
  <Accordion title="View dedicated integration setup steps">
  
  1. In the Flashduty console, select **Channel** and open a channel
  2. Select **Configuration** → **Integrations** → **Private integration**, then click **Add an integration**
  3. Choose **Alibaba Cloud CM Metrics** integration and click **Save** to generate a card
  4. Open the generated integration card and copy the **Push URL**
  
</Accordion>
</AccordionGroup>

### Use a shared integration

Choose this option if you need to route alerts to different channels based on the alert payload.

<AccordionGroup>
  <Accordion title="View shared integration setup steps">
  
  1. In the Flashduty console, go to **Integration Center → Alert Events**
  2. Select **Alibaba Cloud CM Metrics** integration:
        - **Integration Name**: Define a name for this integration
  3. Configure the default route and select a channel. You can add more rules under **Routing** after creation
  4. Click **Save** and copy the generated **Push URL**
    
</Accordion>
</AccordionGroup>
</div>

## Configure Alibaba Cloud CloudMonitor

This guide applies to threshold alerts in the CloudMonitor 1.0 console.

<Steps>
<Step title="Push alerts to Flashduty in CloudMonitor">

Use either of the following methods.

<Tabs>
<Tab title="By alert rule">

**Where**: CloudMonitor console › Alert Service › Alert Rules › your rule › Modify › Advanced Settings › Alert Callback

1. Enter `{integration_url}` in **Alert Callback**
2. Click **Confirm**
3. Repeat these steps for each alert rule that should sync events

<img alt="Entering the alert callback URL in the advanced settings of a CloudMonitor alert rule" width="500" src="https://download.flashcat.cloud/flashduty/doc/en/aliyun/metric-1.png" />

</Tab>
<Tab title="By alert contact">

**Where**: CloudMonitor console › Alert Service › Alert Contacts › your contact › Edit › Webhook

1. Enter `{integration_url}` in **Webhook**
2. Click **Confirm**
3. Repeat these steps for each contact that should sync events

<img alt="Entering the push URL in the Webhook field of a CloudMonitor alert contact" width="500" src="https://download.flashcat.cloud/flashduty/doc/en/aliyun/metric-2.png" />

</Tab>
</Tabs>

</Step>
<Step title="Send a test request from CloudMonitor and confirm">

**Where**: CloudMonitor console › Alert Service › Alert Rules › your rule › Modify › Advanced Settings › Alert Callback › Test

Click **Test** next to the callback URL to send a test request. If you configured an alert contact, click **Test** next to its Webhook URL. You can also wait for the rule to fire a real alert.

Go back to Flashduty. If the integration shows a **Latest event time**, the setup works.
{/* console:
The checklist item "Receive the first event" is then complete as well.
*/}

</Step>
</Steps>
