Sync Alibaba Cloud Monitor alert events to Flashduty through webhook for automated alert noise reduction.

<div class="hide">

## In Flashduty
You can get the integration push URL in either of the following ways.

### Use a dedicated integration

Choose this option if all alerts go to one channel. It's the simpler setup.

<AccordionGroup>
  <Accordion title="View dedicated integration setup steps">
  
  1. In the Flashduty console, select **Channel** and open a channel
  2. Select **Configuration** → **Integrations** → **Private integration**, then click **Add an integration**
  3. Choose **Alibaba Cloud CM Metrics** integration and click **Save** to generate a card
  4. Open the generated integration card and copy the **Push URL**
  
</Accordion>
</AccordionGroup>

### Use a shared integration

Choose this option if you need to route alerts to different channels based on the alert payload.

<AccordionGroup>
  <Accordion title="View shared integration setup steps">
  
  1. In the Flashduty console, go to **Integration Center → Alert Events**
  2. Select **Alibaba Cloud CM Metrics** integration:
        - **Integration Name**: Define a name for this integration
  3. Configure the default route and select a channel. You can add more rules under **Routing** after creation
  4. Click **Save** and copy the generated **Push URL**
    
</Accordion>
</AccordionGroup>
</div>

## In Alibaba Cloud Monitor
Choose one of the following two methods:

**Method 1: Rule-based configuration**

<div class="md-block">

1. Log in to the Alibaba Cloud console and open Cloud Monitor
2. Go to **Alert Service → Alert Rules**, select a rule, and click **Modify**
3. Under **Advanced Settings**, enter the integration push URL as the callback address
4. Click **Confirm**

   <img src="https://download.flashcat.cloud/flashduty/doc/en/aliyun/metric-1.png" alt="drawing" width="500"/>

5. Repeat these steps for each alert rule that should sync events
6. Return to the integration list. If the integration shows a latest event time, the setup works

</div>

**Method 2: Contact-based configuration**

<div class="md-block">

1. Log in to the Alibaba Cloud console and open Cloud Monitor
2. Go to **Alert Service → Alert Contacts** and edit a contact
3. Enter the integration push URL under Webhook
4. Click **Confirm**

   <img src="https://download.flashcat.cloud/flashduty/doc/en/aliyun/metric-2.png" alt="drawing" width="500"/>

5. Repeat these steps for each contact that should sync events
6. Return to the integration list. If the integration shows a latest event time, the setup works

</div>

| -------------------- | --------- | ------ |

| WARN                 | Warning   | Warning |
| INFO                 | Info      | Info |
| NODATA               | Info      | Info |
