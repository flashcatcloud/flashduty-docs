## In Flashduty
---
You can obtain an integration push URL in either of the following two ways.

### Dedicated Integration

Choose this simpler option when you do not need to route alert events to different channels.

<AccordionGroup>
  <Accordion title="Expand">

  1. Open the Flashduty console, select **Channels**, and enter a channel's detail page
  2. Select the **Integrations** tab and click **Add an integration**
  3. Select the **Huawei Cloud AOM** integration and click **Save** to generate a card
  4. Click the card to view the **push URL**; copy it for later use. Done.

</Accordion>
</AccordionGroup>

### Shared Integration

Choose this option when you need to route alerts to different channels based on the alert event payload.

<AccordionGroup>
  <Accordion title="Expand">

  1. Open the Flashduty console and go to **Integration Center => Alert Events**
  2. Select the **Huawei Cloud AOM** integration:
        - **Integration name**: define a name for this integration
  3. Configure the default route and select the target channel (after creation, go to `Routes` for more routing rules)
  4. Click **Save**, then copy the newly generated **push URL** on the page
  5. Done.

</Accordion>
</AccordionGroup>

## In Huawei Cloud AOM
---
<div className="md-block">

Huawei Cloud AOM pushes alarms through the SMN message notification service. You first create an SMN topic whose HTTPS subscription endpoint is the Flashduty push URL, then bind an alarm action rule to that topic in AOM.

### Create a Flashduty notification channel (SMN topic)

1. Log in to the Huawei Cloud console, search for the `SMN` (Simple Message Notification) service, and open its console.
2. In the left navigation, select `Topic Management => Topics`.
3. Click `Create Topic`, enter `Flashduty` as the topic name, and confirm.
4. On the newly created Flashduty topic, click `Add Subscription`.
5. In the edit page, select `HTTPS` as the protocol, paste the **integration push URL** as the subscription endpoint, and confirm.
6. In the subscription list, verify that the subscription status is **Confirmed**.

### Configure AOM alarm push

1. Open the `Huawei Cloud AOM` console and go to `Alarm Center => Alarm Action Rules`.
2. Click `Create Alarm Action Rule`, give it a name, select `SMN` as the notification method, and choose the `Flashduty` topic created above.
3. Confirm to create the alarm action rule.
4. Go to `Alarm Center => Alarm Rules`, create or edit an alarm rule, enable `Alarm Action Rule` and select the rule from the previous step; enable both `Alarm Triggered` and `Alarm Cleared` notifications so Flashduty alerts auto-recover.
5. After saving, return to the Flashduty console integration list — if a latest event time appears, the configuration succeeded and events are flowing.

</div>

## Status Mapping
---
<div className="md-block">

The severity field in AOM alarm events maps to Flashduty alert severities. You can adjust the mapping in the integration's **custom severity mapping (customSeverityMapping)** setting; the default mapping applies when it is not configured.

</div>
