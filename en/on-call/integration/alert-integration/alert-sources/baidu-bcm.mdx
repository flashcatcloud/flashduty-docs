Sync Baidu Cloud BCM alerts to Flashduty through webhook for automated alert noise reduction.

<div class="hide">

## In Flashduty
You can get the integration push URL in either of the following ways.

### Use a dedicated integration

Choose this option if all alerts go to one channel. It's the simpler setup.

<AccordionGroup>
  <Accordion title="View dedicated integration setup steps">
  
  1. In the Flashduty console, select **Channel** and open a channel
  2. Select **Configuration** → **Integrations** → **Private integration**, then click **Add an integration**
  3. Choose **Baidu Cloud BCM** integration and click **Save** to generate a card
  4. Open the generated integration card and copy the **Push URL**
  
</Accordion>
</AccordionGroup>

### Use a shared integration

Choose this option if you need to route alerts to different channels based on the alert payload.

<AccordionGroup>
  <Accordion title="View shared integration setup steps">
  
  1. In the Flashduty console, go to **Integration Center → Alerts**
  2. Select **Baidu Cloud BCM** integration:
        - **Integration Name**: Define a name for this integration
  3. Configure the default route and select a channel. You can add more rules under **Routing** after creation
  4. Click **Save** and copy the generated **Push URL**
    
</Accordion>
</AccordionGroup>
</div>

## In Baidu Cloud BCM
<div class="md-block">

1. Log in to your Baidu Cloud Console, search for the `Cloud Monitor` product, and enter its console
2. Baidu Cloud provides multiple ways to configure alert callbacks, refer to the [official documentation](https://cloud.baidu.com/doc/BCM/s/bkdzl6d69) for details. Below demonstrates the configuration through the `Alert Management-Alert Policy` entry
3. Go to the `Alert Management-Alert Policy` page, choose to edit an existing policy or create a new one
4. In the alert policy, fill in the integration push URL in the `Callback URL` field (enter the integration name on the current page, and the URL will be generated after saving)

   <img src="https://download.flashcat.cloud/flashduty/doc/en/baidu/bcm-1.png" alt="drawing" width="500"/>


</div>

## Status mapping
<div class="md-block">
  
Severity level mapping from Baidu Cloud Monitor to Flashduty:

| BCM      | Flashduty | Status   |
| -------- | --------- | -------- |
| Severe   | Critical  | Critical |
| Important| Critical  | Critical |
| Warning  | Warning   | Warning  |
| Notice   | Info      | Info     |
