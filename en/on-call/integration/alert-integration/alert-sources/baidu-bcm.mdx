Sync Baidu Cloud BCM alerts to Flashduty through webhook.

<div className="hide">

## In Flashduty On-call
You can get the integration push URL in either of the following ways.

### Use a dedicated integration

Choose this option if all alerts go to one channel. It's the simpler setup.

<AccordionGroup>
  <Accordion title="View dedicated integration setup steps">
  
  1. In the Flashduty console, select **Channel** and open a channel
  2. Select **Configuration** → **Integrations** → **Private integration**, then click **Add an integration**
  3. Choose **Baidu Cloud BCM** integration and click **Save** to generate a card
  4. Open the generated integration card and copy the **Push URL**
  
</Accordion>
</AccordionGroup>

### Use a shared integration

Choose this option if you need to route alerts to different channels based on the alert payload.

<AccordionGroup>
  <Accordion title="View shared integration setup steps">
  
  1. In the Flashduty console, go to **Integration Center → Alerts**
  2. Select **Baidu Cloud BCM** integration:
        - **Integration Name**: Define a name for this integration
  3. Configure the default route and select a channel. You can add more rules under **Routing** after creation
  4. Click **Save** and copy the generated **Push URL**
    
</Accordion>
</AccordionGroup>
</div>

## In Baidu Cloud BCM

<Steps>
<Step title="Enter the alarm callback URL in Baidu Cloud BCM">

<Tabs>
<Tab title="Per alarm policy">

**Where**: Baidu AI Cloud console › Cloud Monitor BCM › Alarm Management › Alarm Policies › Add Policy (or edit an existing policy)

| Field | Value |
| --- | --- |
| Alarm callback (required) | Enabled |
| Callback URL (required) | `{integration_url}` |

Save the policy. Each alarm policy can bind only one callback URL; repeat for every policy whose events you want to sync.

<img src="https://download.flashcat.cloud/flashduty/doc/en/baidu/bcm-1.png" alt="Callback URL field in a Baidu Cloud BCM alarm policy" width="500"/>

</Tab>
<Tab title="Per alarm template">

**Where**: Baidu AI Cloud console › Cloud Monitor BCM › Alarm Management › Alarm Templates › Add Template

| Field | Value |
| --- | --- |
| API Callback (required) | `{integration_url}`; one template accepts up to 5 URLs |

The menu name for templates can differ slightly between console versions. Save the template, then reference it in the alarm policy.

</Tab>
</Tabs>

Baidu Cloud offers several ways to configure alarm callbacks; see the [official documentation](https://cloud.baidu.com/doc/BCM/s/bkdzl6d69) for the other entries. The callback URL must be a publicly reachable HTTP/HTTPS address; Baidu Cloud pushes JSON with POST. The Flashduty push URL meets this requirement. The endpoint must return HTTP 200; otherwise BCM retries up to 3 times, with a 5-second timeout.

</Step>

<Step title="Trigger an alarm and confirm">

**Where**: Baidu AI Cloud console › Cloud Monitor BCM › Alarm Management › Alarm Policies

BCM has no standalone callback test. Temporarily lower the policy threshold so an alarm rule fires, or wait for a real alarm.

Go back to Flashduty. If the integration shows a **Latest event time**, the setup works.
{/* console:
The checklist item "Receive the first event" is then complete as well.
*/}

</Step>
</Steps>
