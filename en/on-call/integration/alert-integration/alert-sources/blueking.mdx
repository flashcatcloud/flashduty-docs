Sync Tencent BlueKing monitoring events to Flashduty through webhook.

<div className="hide">

## In Flashduty On-call
You can get the integration push URL in either of the following ways.

### Use a dedicated integration

Choose this option if all alerts go to one channel. It's the simpler setup.

<AccordionGroup>
  <Accordion title="View dedicated integration setup steps">
  
  1. In the Flashduty console, select **Channel** and open a channel
  2. Select **Configuration** → **Integrations** → **Private integration**, then click **Add integration**
  3. Choose **Tencent BlueKing** integration and click **Save** to generate a card
  4. Open the generated integration card and copy the **Push URL**
  
</Accordion>
</AccordionGroup>

### Use a shared integration

Choose this option if you need to route alerts to different channels based on the alert payload.

<AccordionGroup>
  <Accordion title="View shared integration setup steps">
  
  1. In the Flashduty console, go to **Integration Center → Alerts**
  2. Select **Tencent BlueKing** integration:
        - **Integration Name**: Define a name for this integration
  3. Configure the default route and select a channel. You can add more rules under **Routing** after creation
  4. Click **Save** and copy the generated **Push URL**
    
</Accordion>
</AccordionGroup>
</div>

## Configure Tencent BlueKing

The following content has been verified on `BlueKing V6/7 versions`. V5 and below versions are no longer officially supported, and upgrading is recommended.

BlueKing alert policies can trigger `Action Plans`, which can integrate with external systems for complex functionalities. First, create an Action Plan and configure the Flashduty callback URL, then edit the alert policy to associate actions with this plan, enabling automatic alert changes to be pushed to Flashduty.

<Steps>
<Step title="Create an action plan in the BlueKing Monitor Platform">

**Where**: BlueKing desktop › Monitor Platform › Configuration › Action Plans › Add Plan

| Field | Value |
| --- | --- |
| Plan name (required) | `Send To Flashduty` |
| Plan type (required) | `HTTP Callback` |
| Push method (required) | `POST` |
| Callback URL (required) | `{integration_url}` |
| Body › type (required) | `JSON` |
| Body › message (required) | `{{alarm.callback_message}}` (when an actual alert occurs, BlueKing renders the variable content as the payload and pushes it to the target callback URL) |

Save the plan.

<img alt="Creating an action plan in the BlueKing Monitor Platform" width="600" src="https://download.flashcat.cloud/flashduty/integration/tencent-bk/create_package.jpg" />

</Step>
<Step title="Associate the action plan with an alert policy">

**Where**: BlueKing desktop › Monitor Platform › Configuration › Alert Policies › your policy › Edit › Alert Processing

Select an existing policy to edit, or create a new one.

| Field | Value |
| --- | --- |
| Alert Processing (required) | Select the `Send To Flashduty` action plan for all three scenarios |
| Defense Rules | Disable |

Submit and save. Repeat these steps for other alert policies you want to push to Flashduty.

<img alt="Associating the action plan with an alert policy in BlueKing" width="600" src="https://download.flashcat.cloud/flashduty/integration/tencent-bk/update_alert_rule.jpg" />

</Step>
<Step title="Confirm Flashduty receives events">

BlueKing policies have no "send test" button. Wait for a real alert from a linked policy.

Return to Flashduty. If the integration shows a **latest event time**, the setup works.
{/* console:
The "first event received" item in the setup checklist turns green as well.
*/}

</Step>
</Steps>
