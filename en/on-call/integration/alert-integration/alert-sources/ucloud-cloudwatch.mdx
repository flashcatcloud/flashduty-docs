Sync UCloud CloudWatch alert events to Flashduty through webhook.

<div className="hide">

## In Flashduty On-call
You can get the integration push URL in either of the following ways.

### Use a dedicated integration

Choose this option if all alerts go to one channel. It's the simpler setup.

<AccordionGroup>
  <Accordion title="View dedicated integration setup steps">
  
  1. In the Flashduty console, select **Channel** and open a channel
  2. Select **Configuration** → **Integrations** → **Private integration**, then click **Add integration**
  3. Choose **UCloud CloudWatch** integration and click **Save** to generate a card
  4. Open the generated integration card and copy the **Push URL**
  
</Accordion>
</AccordionGroup>

### Use a shared integration

Choose this option if you need to route alerts to different channels based on the alert payload.

<AccordionGroup>
  <Accordion title="View shared integration setup steps">
  
  1. In the Flashduty console, go to **Integration Center → Alert Events**
  2. Select **UCloud CloudWatch** integration:
        - **Integration Name**: Define a name for this integration
  3. Configure the default route and select a channel. You can add more rules under **Routing** after creation
  4. Click **Save** and copy the generated **Push URL**
    
</Accordion>
</AccordionGroup>
</div>

## In UCloud

<Steps>
<Step title="Configure a notice template in UCloud CloudWatch">

**Where**: UCloud console › CloudWatch › Notice Management › Contact Template › Create (or edit an existing template)

| Field | Value |
| --- | --- |
| Webhook (required) | Checked |
| Callback Language (required) | `English` |
| Callback URL (required) | `{integration_url}` |
| Template name (required) | `Flashduty` or another name |

Configure other options as needed and click `Submit`.

![UCloud CloudWatch Alert Integration: Configure Notice Template screenshot](https://docs-cdn.flashcat.cloud/images/png/9e6ee0943b6f3ee6b942229bd456cf75.png)

</Step>

<Step title="Use the template in an alarm policy">

**Where**: UCloud console › CloudWatch › Alarm Management › Alarm Policy › Create (or edit an existing policy) › Notification Settings

| Field | Value |
| --- | --- |
| Notification Settings (required) | The notice template created in the previous step |

Configure other options as needed and click `Submit`.

</Step>

<Step title="Trigger an alert and confirm">

**Where**: UCloud console › CloudWatch › Alarm Management › Alarm Policy

UCloud CloudWatch has no standalone callback test. Let a rule in the policy fire, or wait for a real alert.

Go back to Flashduty. If the integration shows a **Latest event time**, the setup works.
{/* console:
The checklist item "Receive the first event" is then complete as well.
*/}

</Step>
</Steps>

## Status and severity
Currently, all UCloud CloudWatch alert events pushed to Flashduty have a severity of Warning. You can customize the severity through [Alert Processing Pipeline](/en/on-call/integration/alert-integration/alert-pipelines).
