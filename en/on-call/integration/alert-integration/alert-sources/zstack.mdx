Push ZStack alerts to Flashduty through webhook.

<div className="hide">

## In Flashduty On-call
You can get the integration push URL in either of the following ways.

### Use a dedicated integration

Choose this option if all alerts go to one channel. It's the simpler setup.

<AccordionGroup>
  <Accordion title="View dedicated integration setup steps">
  
  1. In the Flashduty console, select **Channel** and open a channel
  2. Select **Configuration** → **Integrations** → **Private integration**, then click **Add integration**
  3. Choose **ZStack** integration and click **Save** to generate a card
  4. Open the generated integration card and copy the **Push URL**

</Accordion>
</AccordionGroup>

### Use a shared integration

Choose this option if you need to route alerts to different channels based on the alert payload.

<AccordionGroup>
  <Accordion title="View shared integration setup steps">
  
  1. In the Flashduty console, go to **Integration Center → Alert Events**
  2. Select **ZStack** integration:
        - **Integration Name**: Define a name for this integration
  3. Configure the default route and select a channel. You can add more rules under **Routing** after creation
  4. Click **Save** and copy the generated **Push URL**
    
</Accordion>
</AccordionGroup>
</div>


## In ZStack

<Steps>
<Step title="Create a Webhook notification object in ZStack">

**Where**: ZStack console › Platform O&M › Cloud Platform Monitoring › Notification Objects › Create Notification Object (or edit an existing one)

| Field | Value |
| --- | --- |
| Name (required) | `Flashduty` |
| Type (required) | `Webhook` |
| Address (required) | `{integration_url}` |

Click **OK** to finish.

<img alt="Creating a Webhook notification object in ZStack" width="600" src="https://download.flashcat.cloud/flashduty/doc/en/fd/zstack-1.png" />

</Step>

<Step title="Use the notification object in an alarm">

**Where**: ZStack console › Platform O&M › Cloud Platform Monitoring › Alarms › Create Resource Alarm / Create Event Alarm (or edit an existing alarm)

| Field | Value |
| --- | --- |
| Notification Object (required) | `Flashduty`, created in the previous step |
| Recovery notification (optional) | Recommended for resource alarms |

Configure other options as needed and click **OK**.

<img alt="Selecting the notification object in a ZStack alarm" width="600" src="https://download.flashcat.cloud/flashduty/doc/en/fd/zstack-2.png" />

</Step>

<Step title="Send a test message and confirm">

**Where**: ZStack console › Platform O&M › Cloud Platform Monitoring › Notification Objects

Click **Send Test Message**; a success message means the address works. You can also wait for an alarm to fire a real alert.

Go back to Flashduty. If the integration shows a **Latest event time**, the setup works.
{/* console:
The checklist item "Receive the first event" is then complete as well.
*/}

</Step>
</Steps>
