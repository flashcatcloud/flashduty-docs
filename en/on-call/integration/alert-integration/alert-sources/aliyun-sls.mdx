Sync Alibaba Cloud Log Service (SLS) monitoring alert events to Flashduty through webhook for automated alert noise reduction.

<div class="hide">

## In Flashduty
You can get the integration push URL in either of the following ways.

### Use a dedicated integration

Choose this option if all alerts go to one channel. It's the simpler setup.

<AccordionGroup>
  <Accordion title="View dedicated integration setup steps">
  
  1. In the Flashduty console, select **Channel** and open a channel
  2. Select **Configuration** → **Integrations** → **Private integration**, then click **Add an integration**
  3. Choose **Alibaba Cloud SLS** integration and click **Save** to generate a card
  4. Open the generated integration card and copy the **Push URL**
  
</Accordion>
</AccordionGroup>

### Use a shared integration

Choose this option if you need to route alerts to different channels based on the alert payload.

<AccordionGroup>
  <Accordion title="View shared integration setup steps">
  
  1. In the Flashduty console, go to **Integration Center → Alerts**
  2. Select **Alibaba Cloud SLS** integration:
        - **Integration Name**: Define a name for this integration
  3. Configure the default route and select a channel. You can add more rules under **Routing** after creation
  4. Click **Save** and copy the generated **Push URL**
    
</Accordion>
</AccordionGroup>
</div>

## In Alibaba Cloud SLS
**Step 1: Configure webhook**

<div class="md-block">

1. Log in to the Alibaba Cloud console, open Log Service (SLS), and choose a project
2. Go to `Alert`->`Alert Management`->`Webhook Integration` and click `Create`

   <img src="https://download.flashcat.cloud/flashduty/doc/en/aliyun/sls-1.png" alt="drawing" width="500"/>

3. Set `Type` to "Generic Webhook" and `Request Method` to POST. In `Request URL`, enter the integration push URL (available after you save the integration)

   <img src="https://download.flashcat.cloud/flashduty/doc/en/aliyun/sls-2.png" alt="drawing" width="500"/>

4. Click `Confirm`

</div>

**Step 2: Configure content template**

<div class="md-block">

1. Switch to the `Content Template` page and click `Add`
2. Open the `Webhook-Custom` configuration, set `Send Method` to "Send Individually", and enter the following in `Send Content`:

   ```
   {{ alert | to_json}}
   ```

   <img src="https://download.flashcat.cloud/flashduty/doc/en/aliyun/sls-3.png" alt="drawing" width="500"/>

3. Click `Confirm`

</div>

**Step 3: Configure action policy**

<div class="md-block">

1. Switch to the `Action Policy` page and click `Add`
2. In the `First Action List` configuration, add an `Action Group` node
3. Set `Channel` to "Generic Webhook", pick the objects you created for `Select Webhook` and `Content Template`, and set `Send Period` to "Any"

   <img src="https://download.flashcat.cloud/flashduty/doc/en/aliyun/sls-4.png" alt="drawing" width="500"/>

4. Click `Finish` to complete the first action list
5. Click `Confirm`

</div>

**Step 4: Configure monitoring rules**

<div class="md-block">

1. Switch to the `Rules/Transactions` page and click `Create Alert`, or edit an existing alert
2. On the `Alert Rule` editing page, find `Alert Policy`
3. Set `Alert Policy` to "Normal Mode" and pick the object you created for `Action Policy`

   <img src="https://download.flashcat.cloud/flashduty/doc/en/aliyun/sls-5.png" alt="drawing" width="500"/>

4. Click `Confirm`
5. Repeat these steps for the other rules to push all alerts to Flashduty

</div>

## Alibaba Cloud ActionTrail
<div class="md-block">

Log Service (SLS) provides ActionTrail's "event alert" feature, so ActionTrail has no separate push channel. Create a trail that delivers events to a Logstore, and then configure an SLS alert on that Logstore. The notification channel reuses the webhook steps above, so you don't need a separate integration for ActionTrail.

1. Log in to the Alibaba Cloud Console, go to **ActionTrail**, and create a trail that delivers events to a Logstore in Log Service (SLS)
2. Go to **ActionTrail Console → Event Alert → Alert Center** (or go directly to the Log Service SLS console for that Logstore), and select the corresponding trail or Logstore
3. Follow steps 1–4 of "In Alibaba Cloud SLS" above to configure the webhook, content template, action policy, and monitoring rule, using the same Flashduty integration push URL

</div>
