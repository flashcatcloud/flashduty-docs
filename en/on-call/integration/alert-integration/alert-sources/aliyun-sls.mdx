Sync Alibaba Cloud Log Service (SLS) monitoring alert events to Flashduty through webhook.

<div className="hide">

## In Flashduty On-call
You can get the integration push URL in either of the following ways.

### Use a dedicated integration

Choose this option if all alerts go to one channel. It's the simpler setup.

<AccordionGroup>
  <Accordion title="View dedicated integration setup steps">
  
  1. In the Flashduty console, select **Channel** and open a channel
  2. Select **Configuration** → **Integrations** → **Private integration**, then click **Add integration**
  3. Choose **Alibaba Cloud SLS** integration and click **Save** to generate a card
  4. Open the generated integration card and copy the **Push URL**
  
</Accordion>
</AccordionGroup>

### Use a shared integration

Choose this option if you need to route alerts to different channels based on the alert payload.

<AccordionGroup>
  <Accordion title="View shared integration setup steps">
  
  1. In the Flashduty console, go to **Integration Center → Alerts**
  2. Select **Alibaba Cloud SLS** integration:
        - **Integration Name**: Define a name for this integration
  3. Configure the default route and select a channel. You can add more rules under **Routing** after creation
  4. Click **Save** and copy the generated **Push URL**
    
</Accordion>
</AccordionGroup>
</div>

## In Alibaba Cloud SLS

<Steps>
<Step title="Create a webhook integration in SLS">

**Where**: Log Service (SLS) console › your project › Alert › Alert Management › Webhook Integration › Create

<img src="https://download.flashcat.cloud/flashduty/doc/en/aliyun/sls-1.png" alt="SLS alert management entry" width="500"/>

| Field | Value | Required |
| --- | --- | --- |
| Type | Generic Webhook | Required |
| Request Method | `POST` | Required |
| Request URL | `{integration_url}` | Required |

Click **Confirm**.

<img src="https://download.flashcat.cloud/flashduty/doc/en/aliyun/sls-2.png" alt="Creating a webhook integration in SLS" width="500"/>

</Step>
<Step title="Create a content template in SLS">

**Where**: Alert Management › Content Template › Add › Webhook-Custom

| Field | Value | Required |
| --- | --- | --- |
| Send Method | Send Individually | Required |
| Send Content | See the code block below | Required |

```
{{ alert | to_json}}
```

Click **Confirm**.

<img src="https://download.flashcat.cloud/flashduty/doc/en/aliyun/sls-3.png" alt="Creating a content template in SLS" width="500"/>

</Step>
<Step title="Create an action policy in SLS">

**Where**: Alert Management › Action Policy › Add › First Action List

In `First Action List`, add an `Action Group` node:

| Field | Value | Required |
| --- | --- | --- |
| Channel | Generic Webhook | Required |
| Select Webhook | The webhook created in step 1 | Required |
| Content Template | The template created in step 2 | Required |
| Send Period | Any | Required |

Click `Finish` to complete the first action list, then click `Confirm`.

<img src="https://download.flashcat.cloud/flashduty/doc/en/aliyun/sls-4.png" alt="Creating an action policy in SLS" width="500"/>

</Step>
<Step title="Select the action policy in the alert rule">

**Where**: Log Service (SLS) console › Alert › Rules/Transactions › Create Alert (or edit an existing alert) › Alert Rule › Alert Policy

| Field | Value | Required |
| --- | --- | --- |
| Alert Policy | Normal Mode | Required |
| Action Policy | The action policy created in step 3 | Required |

Click `Confirm`. Repeat these steps for the other rules to push all alerts to Flashduty.

<img src="https://download.flashcat.cloud/flashduty/doc/en/aliyun/sls-5.png" alt="Selecting the action policy in an SLS alert rule" width="500"/>

</Step>
<Step title="Trigger an alert and confirm">

**Where**: Log Service (SLS) console › Alert › Rules/Transactions › your alert

Wait for the rule to fire (or temporarily lower its threshold to trigger once). Go back to Flashduty. If the integration shows a **Latest event time**, the setup works.
{/* console:
The checklist item "Receive the first event" is then complete as well.
*/}

</Step>
</Steps>

## Alibaba Cloud ActionTrail
<div class="md-block">

Log Service (SLS) provides ActionTrail's "event alert" feature, so ActionTrail has no separate push channel. Create a trail that delivers events to a Logstore, and then configure an SLS alert on that Logstore. The notification channel reuses the webhook steps above, so you don't need a separate integration for ActionTrail.

1. Log in to the Alibaba Cloud Console, go to **ActionTrail**, and create a trail that delivers events to a Logstore in Log Service (SLS)
2. Go to **ActionTrail Console → Event Alert → Alert Center** (or go directly to the Log Service SLS console for that Logstore), and select the corresponding trail or Logstore
3. Follow steps 1–4 of "In Alibaba Cloud SLS" above to configure the webhook, content template, action policy, and monitoring rule, using the same Flashduty integration push URL

</div>
