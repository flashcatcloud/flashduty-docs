Select the **Link** integration in the integration center to add a jump button to incident details. The button builds a link to an external system (such as a CMDB) from incident attributes, labels, or custom fields, so you don't copy parameters by hand. Each channel can bind at most three Link integrations.

## Opening method

- **Popup**: opens a window inside the incident details page, so you can return right after viewing.
- **New tab**: opens the link in a new browser tab and keeps the current page.

## Configure the URL

Reference variables in the URL with <code>{"${}"}</code>. The prefix depends on what you reference:

| Reference | Syntax | Example |
| --- | --- | --- |
| Incident label | Starts with `labels.` | <code>{"${labels.sn}"}</code> |
| Custom field | Starts with `fields.` | <code>{"${fields.sn}"}</code> |
| Incident attribute | The attribute name | <code>{"${title}"}</code>, <code>{"${severity}"}</code> |

For example, with this URL:

```text
https://cmdb.com/vm?sn=${labels.sn}
```

An incident with the label `sn=VM123456` produces:

```text
https://cmdb.com/vm?sn=VM123456
```

## Notes

- If the referenced content doesn't exist, the link is still generated, but that variable has no value.
- Write variables in the <code>{"${...}"}</code> syntax, or the value can't be retrieved.
