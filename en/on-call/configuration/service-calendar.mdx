## Use cases

| Scenario | Description |
| --- | --- |
| **Escalation Rules** | Assign to different on-call personnel based on workdays/rest days |
| **Silence Rules** | Only silence low-priority alerts on rest days |

## Creating a calendar

Go to **Configuration → Service Calendar** and click **Create**, then fill in the form in the **Create Service calendar** panel on the right.

| Configuration | Description |
| --- | --- |
| **Calendar Name** | Required, 1–40 characters. Recommend naming by business dimension, for example, "Settlement Business System" |
| **Management Team** | Required. The calendar belongs to this team, and team members gain edit permissions for it |
| **Calendar Description** | Overview of business characteristics for quick team understanding |

<Note>
Each account can create up to 5 service calendars by default. If you need more, contact Flashduty support.
</Note>

<Tip>
New calendars default to all workdays. After creation, open the calendar detail page to link national holidays — the system automatically marks statutory holidays as rest days, and you can adjust them manually.
</Tip>

## Editing a calendar

| Action | Description |
| --- | --- |
| **Modify Basic Info** | Calendar name, description, management team |
| **Link Holidays** | On the calendar detail page, link national holiday calendars. The system automatically marks statutory holidays as rest days and make-up workdays as workdays; you can adjust or unlink them at any time. The dropdown lists only the holiday calendars of the current interface language (an already-linked calendar of another language stays in the list so you can unlink it), and several can be linked at once; selecting or clearing an option saves and takes effect immediately, with no separate save step |
| **Bulk Mark Rest Days** | Quickly mark by day of week, for example, every Saturday and Sunday as rest days. A week must keep at least one workday: once only one workday is left, its toggle can no longer be switched to a rest day. With no rest day set, all seven days count as workdays |
| **Adjust Dates** | Click a date, or click two dates to select the days between them, then click **Set as workday**, **Set as day off**, or **Reset to default** in the action bar below. The note is optional |

![Edit Calendar](https://fcpub-1301667576.cos.ap-nanjing.myqcloud.com/flashduty/doc/rili-1.png)

<Warning>
Deleting a calendar is irreversible. Confirm no escalation rules or silence rules reference it before deletion.
</Warning>

## FAQ

<AccordionGroup>
  <Accordion title="What's the difference between a service calendar and a schedule?">
    They serve different purposes:
    
    - **Schedule**: Defines "who handles it", the recipient of incidents
    - **Service Calendar**: Defines "when to handle it", the time condition for escalation rules
    
    Service calendars are above schedules in hierarchy—first determining if it's a workday, then deciding whether to assign to on-call personnel.
  </Accordion>
  <Accordion title="Which setting wins when a day has more than one?">
    The first item in this order that has a setting for the day decides it:

    1. **Manual settings**: days you set as a workday or day off on the calendar
    2. **Linked holiday calendars**: a make-up workday wins over holiday rest days
    3. **Weekly rest days**: rest days marked by day of week

    Within one calendar, a day keeps only the last manual setting. Setting dates again (as a workday or a day off) that are already covered by an existing setting overwrites it: an existing setting entirely inside the selected range is deleted, one that only partly overlaps is shortened, and one spanning the whole range is split in two.

    A day with none of these settings is a workday. Clicking **Reset to default** on a day clears its manual setting, and the day goes back to the holiday calendars and weekly rest days.

    On the calendar, yellow marks a day off and green marks a workday set manually or by a holiday make-up day. Uncolored days follow the weekly settings and are workdays. Days set manually on this calendar additionally carry a ring around them, telling them apart from days decided by a holiday calendar or by the weekly rule. Hover over a day to see which layer decided it and which settings it overrides (listed with a strikethrough).
  </Accordion>
</AccordionGroup>
